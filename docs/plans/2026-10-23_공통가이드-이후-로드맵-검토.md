# 공통 가이드 이후 무엇을 할까 — 로드맵 검토 (2026-10-23)

## 결론

1. **먼저 1단계를 마무리한다 — 10장 「실습 과제 모음」.** 9장의 「다음 장」이 아직 "준비 중"이고, 이해도 확인 시험의 상급 실습 과제와 바로 이어진다. 새 사실 조사가 거의 필요 없어 가장 짧게 끝난다.
2. **그다음 2단계 「서비스별 가이드」를 한 서비스씩 연다.** 1단계가 "어디서나 통하는 원리"였다면 2단계는 "이 버튼은 어디 있고 무엇을 하나"다. 메뉴·요금·설정은 자주 바뀌므로 장마다 공식 문서 확인일을 남기고, 1단계 내용은 다시 쓰지 않고 링크한다.
3. **실습 화면(연습용 채팅 화면 + 말풍선 안내)은 2단계와 함께 만든다.** 서비스 화면을 다루는 2단계에서 가장 효과가 크고, 1단계에서는 프롬프트 편집기·퀴즈로 충분하다.
4. 3단계(Claude Code·Codex)와 4단계(AI-SDLC)는 2단계 두 서비스가 끝난 뒤로 둔다 — 독자층이 "코딩 도구를 설치하는 사람"으로 바뀌어 준비가 따로 필요하다.

## 3. 10장 실습 과제 모음 — 구성안

1~9장을 하나씩 다시 쓰게 만드는 과제 8~10개. 각 과제는 「상황 → 할 일 → 잘 됐는지 확인하는 점검표 → 막히면 다시 볼 장」 순서.

| 과제 | 쓰는 장 | 예 |
|---|---|---|
| 1. 한 줄 요청을 다섯 칸으로 바꾸기 | 4장 | 「회의록 요약해 줘」 → 누가·무엇을·어떤 모양으로 |
| 2. 예시 보여 주고 말투 맞추기 | 5장 | 가게 SNS 글 |
| 3. 답이 아쉬울 때 이어서 고치기 | 6장 | 세 번 안에 원하는 답 받기 |
| 4. 긴 자료를 붙여 넣고 요약받기 | 5·7장 | 공지문에서 나에게 해당하는 것 |
| 5. AI에게 프롬프트 만들게 하기 | 8장 | 생각나는 대로 쓴 여행 계획 |
| 6. 답 확인하기 | 1·9장 | 숫자·날짜 3개를 원래 자료와 대조 |
| 7. 개인정보 가리고 부탁하기 | 9장 | 경위서 |
| 8. 다시 쓸 틀 만들기 | 6·8장 | 주간 보고 틀 |
| 9. (종합) 내 일 하나를 처음부터 끝까지 | 전체 | 상급 레벨 실습 과제와 같은 점검표 |

- 점검표는 이해도 확인 시험의 `PRACTICE_CHECKS` 와 같은 문장을 써서 시험과 실습이 한 기준을 보게 한다
- 10장에도 「다 읽음」 버튼과 진행 현황이 붙으므로 `CHAPTERS` 에 10장을 추가한다

## 4. 2단계 서비스별 가이드 — 장 구성 틀 (ChatGPT·Claude 공통)

1단계와 겹치는 설명은 쓰지 않고 링크한다. 서비스마다 같은 틀을 써서 비교하기 쉽게 한다.

| 장 | 내용 | 1단계 연결 |
|---|---|---|
| 1. 시작하기 | 가입, 무료·유료 차이, 화면 둘러보기, 휴대폰 앱 | — |
| 2. 대화 관리 | 새 대화, 대화 기록 찾기·지우기, 공유 링크 | 6장 새 대화 |
| 3. 파일·사진 넣기 | 문서·사진 올리기, 표 읽히기 | 7장 |
| 4. 기억과 맞춤 설정 | 메모리, 맞춤 지시(내 소개) | 4장 맥락 |
| 5. 작업 공간 | 프로젝트, GPTs / Claude 프로젝트·아티팩트 | 8장 틀 |
| 6. 검색과 조사 | 웹 검색, 심층 조사 기능 | 9장 출처 확인 |
| 7. 개인정보 설정 | 학습에 쓰기 끄기, 기록 보관 기간, 회사 계정 | 9장 2절 |
| 8. 실습 | 실습 화면(코치 마크)으로 위 기능 따라 하기 | — |

- 2단계부터는 장마다 **"확인일"** 을 머리에 적고, 3개월마다 다시 확인한다(9장의 서비스 정책 수치는 이미 주의 대상)
- 어느 서비스를 먼저 할지는 독자층에 달렸다 — 탈잉 수강생이 주로 쓰는 서비스를 먼저 하는 것을 권한다(이 판단을 뒷받침할 이용률 수치는 이번에 확인하지 않았다)
