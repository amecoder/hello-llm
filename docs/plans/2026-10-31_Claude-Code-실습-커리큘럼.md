# 3단계 Claude Code — 실습 커리큘럼: 내 방식대로 정리해 주는 도구 만들기 (2026-10-31)

## 결론

1. **12장 목차는 그대로 두고, 실습 줄기 하나를 2~11장에 꿴다.** 줄기는 「내 방식대로 정리해 주는 도구 만들기」다. 회의 메모·공부 필기·하루 회고처럼 날것의 메모를 넣으면, **내가 정한 형식**의 회의록·공부 노트·주간 회고가 나오는 도구를 장마다 한 기능씩 더해 완성한다(2026-10-31 사용자 결정 — 종전 「독서모임 웹페이지」안 대체).
2. **왜 정리 도구인가**: 공부·회의·회고·문서 만들기는 누구나 매주 한다. NotebookLM 같은 요약 서비스는 정해진 방식으로 요약하지만, Claude Code는 **내 형식을 파일(CLAUDE.md·스킬)로 저장해 두고 매번 같은 방식으로** 돌릴 수 있다. 결과가 문서라서 코드를 몰라도 잘됐는지 판단할 수 있다.
3. **장마다 "결과물"과 "확인 질문"을 둔다.** 결과물은 실제 Claude 앱 Code 탭에서 만든 파일이고 화면 캡처와 함께 싣는다. 확인 질문은 내용이 아니라 기준을 묻는다("담당과 기한이 원본 메모와 맞나?").
4. **캡처는 사용자 유료 계정의 실제 앱에서 찍는다.** 옆 세션 목록은 숨기고, 실제 폴더·세션 이름이 보이는 부분은 거르거나 지운다.

## 3. 캡처 계획

- 2장: 새 세션 화면 ✓ · 폴더 메뉴 ✓ · 폴더 고른 뒤 입력창 줄 · 요청 보낸 뒤 허락 창(「수동」) · 결과 화면과 만든 파일.
- 결과물 파일은 `public/practice/notes/results/` 에 장별로 두어 독자가 내 결과와 비교할 수 있게 한다. 실제 모델 출력이라 날마다 다를 수 있음을 본문에 밝힌다.

## 5. 위험과 대응

- **결과물이 매번 다르다**: 같은 요청에도 출력이 달라진다. 본문은 "이런 식으로 나온다"로 쓰고, 확인 질문은 기준(담당·기한·숫자가 원본과 맞나)을 묻는다.
- **개인 정보 노출**: 폴더 메뉴에 최근 폴더가, 첫 화면에 CLI 세션 수가 보인다. 검색칸으로 거르거나 숫자를 지운 뒤 저장한다.
- **macOS 파일 선택 창**: 자동 조작이 닿지 않는다. 폴더 고르기는 사용자가 직접 한다.
- **NotebookLM과 비교 서술**: 다른 서비스의 기능은 확인한 범위에서만 쓴다. 비교는 "정해진 방식 vs 내가 정한 방식" 수준으로 두고 기능 단정은 하지 않는다.
