# 3단계 Codex — 실습 커리큘럼: Claude Code로 만든 정리 도구를 Codex로 옮겨 쓰기 (2026-11-01)

## 결론

1. **같은 정리 도구를 Codex로 옮긴다.** Claude Code 장에서 만든 `~/hello-ai-연습/정리도구`(메모 inbox·양식·CLAUDE.md·스킬 3개)를 Codex에서도 돌게 만든다. 개념(폴더·권한·규칙 파일·스킬·예약·터미널)은 Claude Code 장에서 이미 배웠으므로, 이 단계는 **차이만** 다룬다(CLAUDE.md 「공통 → 개별 순서」).
2. **Codex는 이제 ChatGPT 데스크톱 앱 안에 있다.** 공식 문서(learn.chatgpt.com, 2026-11-01 확인)는 앱 안에서 「ChatGPT」와 「Codex」를 고르게 안내한다. 독자는 앱 하나만 설치하면 된다.
3. **장은 8개다.** Claude Code 12장보다 짧다. 겹치는 설명은 Claude Code 장으로 링크한다.
4. **장마다 결과물과 확인 질문을 둔다.** 결과물은 실제 앱에서 만든 파일이고 캡처와 함께 싣는다.
5. **캡처는 사용자 계정의 실제 앱에서 찍는다.** 옆 대화 목록·프로젝트 이름·계정 이름은 잘라 내거나 가린다. 이 맥의 개인 설정(`~/.codex/AGENTS.md`)이 세션에 영향을 줄 수 있다 — Claude Code 때와 같이 "지금 환경 그대로" 찍고, 개인 규칙 흔적은 그림에서 지운다.

## 1. 연습 재료

- Claude Code 장의 재료를 그대로 쓴다: `public/practice/notes/inbox/` 메모 6개(모퉁이 카페 서연의 한 주, 모두 지어낸 내용).
- 출발점은 Claude Code 7장까지 마친 폴더다(CLAUDE.md + `.claude/skills/` 3개). Claude Code를 건너뛴 독자를 위해 그 상태의 파일을 `public/practice/notes/results/` 에서 받을 수 있게 안내한다.

## 2. 장별 커리큘럼 (장 번호 base 500)

| 장 | 배우는 것 | 실습 | 결과물 | 확인 질문 |
|---|---|---|---|---|
| 1 | Codex가 무엇인가 · Claude Code와 대응 | 없음(개념) | — | ChatGPT의 Chat·Work·Codex는 어떻게 다른가? |
| 2 | 설치·Codex 고르기·폴더 열기·첫 일 | 정리도구 폴더를 열고 회의 메모 하나 정리 | 회의록 1개 | 담당·기한이 메모와 맞나? |
| 3 | 규칙 파일 AGENTS.md · 가져오기(Import) | CLAUDE.md를 읽고 AGENTS.md로 옮겨 달라고 하기 → 규칙을 말하지 않고 다시 정리 | `AGENTS.md` | 규칙을 말하지 않아도 지켰나? |
| 4 | 권한 모드 · 바뀐 내용 보기 · 되돌리기 | 권한 메뉴 보기 → 고친 내용 확인 → Git으로 되돌리기 | (화면) | 무엇이 바뀌었는지 직접 봤나? |

| 7 | 터미널(Codex CLI) | `codex exec` 읽기 전용 한 줄 | 출력 텍스트 | 앱과 같은 규칙을 읽었나? |

## 3. 캡처 계획

- 2장: 앱 첫 화면(ChatGPT/Codex 고르기) · 폴더 열기 · 요청 · 결과
- 3장: AGENTS.md 만드는 요청 · 결과 · 설정의 가져오기 화면(목록만, 가져오기는 실행하지 않음 — 개인 설정이 계정으로 넘어감)
- 4장: 권한 메뉴 · 바뀐 내용(diff) 화면
- 5장: `$` 스킬 목록 · 실행 결과
- 6장: 예약 만들기 화면(저장하지 않음)
- 7장: 터미널 출력은 텍스트로 싣는다

## 4. 하지 않는 것

- 가져오기(Import)를 끝까지 실행하지 않는다 — 이 맥의 개인 Claude Code 설정이 사용자 계정으로 넘어간다. 화면과 공식 문서로만 설명한다.
- 예약 작업을 실제로 저장하지 않는다(Claude Code 8장과 같은 이유: 실제 작업이 드러나고 사용량을 쓴다).
- 클라우드 환경을 만들지 않는다(저장소 연결 필요).
