# 3단계 Claude Code 터미널 강좌 — 계획 (2026-11-06)

## 결론

1. **새 폴더 `guide/23-claude-code-cli/`에 독립 강좌로 만든다.** 장 번호는 `단계 base + N`, base 는 800이다. 기존 `guide/20-claude-code/10-terminal.md` 는 그대로 두고 새 강좌로 가는 링크만 단다(2026-11-06 사용자 결정).
2. **독자는 터미널을 처음 여는 비개발자다.** 앱 가이드를 읽지 않아도 혼자 따라올 수 있어야 한다(2026-11-06 사용자 결정).
3. **한국어를 먼저 공개하고 번역은 뒤로 미룬다**(2026-11-06 사용자 결정). `TRANSLATED_STAGES` 에 넣지 않는다.
4. **실습 줄기는 「명령 한 줄로 도는 주간 정리」다.** 앱 가이드와 같은 모퉁이 카페 메모로 시작해, 마지막에는 스크립트 하나로 주간 메모를 정리한다.

| 항목 | 내용 |

| 가설 | 터미널을 처음 여는 독자가 앱 가이드 없이 이 강좌만 읽고 설치부터 자동 실행 스크립트까지 따라올 수 있고, 본문의 사실과 명령은 2026-11-06 공식 문서·실제 실행과 어긋나지 않는다 |

### 주제 체크 목록(16개)

터미널 기초 명령, 설치, 로그인, 화면 읽기, 입력 요령(`@`·`!`·여러 줄), 슬래시 명령, 단축키, 세션 이어 가기, 맥락 관리, 권한 모드·규칙, 되돌리기, CLAUDE.md·설정 파일, 확장(스킬·서브에이전트·MCP·플러그인), 한 줄 실행과 자동화, 훅·상태 줄, 문제 해결.
