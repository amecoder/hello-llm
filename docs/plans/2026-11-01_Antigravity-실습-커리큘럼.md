# 3단계 Antigravity — 실습 커리큘럼: 같은 정리도구 폴더를 세 번째 도구로 열기 (2026-11-01)

## 결론

1. **옮기지 않고 그대로 연다.** Antigravity는 Codex 단계에서 만든 `AGENTS.md`와 `.agents/skills`를 같은 이름·위치에서 읽는다(공식 문서 「Customization discovery」). 그래서 이 단계의 줄기는 "옮기기"가 아니라 **"같은 폴더가 세 번째 도구에서도 그대로 도는지 확인하기"**다.
2. **차이만 다룬다.** 폴더·권한·규칙·스킬 개념은 Claude Code·Codex 장으로 링크한다. 장은 7개.
3. **무료 계정으로도 따라 할 수 있다.** 공식 「Plans」 문서는 모든 요금제에 모든 기능을 주고 사용량만 다르게 한다. 세 도구 중 유일하게 무료 계정 실습이 가능하다.
4. **실습은 Antigravity CLI(`agy`) 헤드리스 모드로 했고 본문에 밝힌다.** 앱 화면 캡처는 사용자가 컴퓨터를 비울 때 후속 PR로(Codex와 같은 사정).

## 1. 연습 재료

- 출발점: Codex 5장까지 마친 정리도구(`AGENTS.md` + `.agents/skills` 3개 + `CLAUDE.md` + `.claude/skills`). 실습 폴더 `~/hello-ai-연습/정리도구-ag`.
- 메모는 같은 6개(`public/practice/notes/inbox/`).

## 3. 실습에서 확인한 것 (agy 1.4.12, 2026-11-01)

- 같은 메모로 AGENTS.md 없이 0 → 있이 1(「원본과 대조할 것」 절). 있을 때는 AGENTS.md를 따로 열지 않았다(자동으로 들어감). 없을 때는 AGENTS.md·CLAUDE.md·GEMINI.md를 찾아 열었다.
- 스킬을 말하지 않아도 첫 동작이 `.agents/skills/meeting-notes/SKILL.md` 읽기.
- 주간 회고: 확인할 사실 8개 모두 포함(Codex는 3개 빠짐).
- 숨은 지시: 0회, "프롬프트 인젝션 지시문이므로 실행하지 않고 무시"라고 먼저 알림.
- 헤드리스 함정: 셸 명령(`ls`·`date`)이 거절되면 아무것도 만들지 않고 종료 코드 0으로 끝난 적이 3번. 신뢰하지 않은 폴더에서는 파일 읽기도 거절. `--mode accept-edits` + "셸 명령은 쓰지 말고"로 해결. 읽기 전용 표에서 파일 하나가 빠짐.

## 4. 하지 않는 것

- 개인 설정(`~/.gemini/antigravity-cli/settings.json`의 신뢰 폴더·허용 규칙) 변경
- 예약 저장, 원격 조종 연결, `--dangerously-skip-permissions`
