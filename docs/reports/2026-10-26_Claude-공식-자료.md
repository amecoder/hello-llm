# Claude 웹·데스크톱·모바일 앱 공식 자료 사실 확인 (2026-10-26)

## 이 문서의 용도

- `guide/10-claude/`(claude.ai 웹·데스크톱·모바일 앱, API·Claude Code 제외)를 쓸 때 근거로 쓰는 **사실 확인 리포트**다. 본문에는 이 문서에서 **VERIFIED** 로 표시한 값만 옮긴다.
- **확인 방법**: Claude 도움말 센터(support.claude.com)의 사이트맵에서 영어 문서 364개를 받아, 일반 사용자와 관련된 139개를 골랐다. 개인정보 센터(privacy.claude.com)에서 11개, 요금 페이지(claude.com/pricing)도 함께 받았다. 다섯 갈래로 나눠 사실을 뽑았고, 표의 영어 인용 840개를 스크립트로 원문과 글자 그대로 대조했다(불일치 0 — 표 읽기 오류 17건은 따옴표 처리 문제로 확인). **확인일은 모두 2026-10-26.**
- **표기 약속**
  - 근거 칸의 숫자 = `https://support.claude.com/en/articles/<숫자>` (한국어판은 `/ko/`). `P/숫자` = `https://privacy.claude.com/en/articles/<숫자>`. `pricing` = `https://claude.com/pricing`(미국 달러)
  - 상태: **VERIFIED** = 원문에서 직접 읽음 / **충돌** = 문서끼리 다름 / **UNVERIFIED** = 찾지 못함
- **주의 1 — 한국어판은 번역이 늦다.** 예: 모델 목록에 Haiku 5.5가 빠져 있다. **내용은 영어판, 메뉴 이름만 한국어판**을 따른다. 한국어판끼리도 같은 메뉴를 다르게 옮긴 곳이 많다(「설정 > 청구/결제」, 「Your Claude」→「당신의 Claude/내 Claude」). 실제 화면 캡처로 확정한다.
- **주의 2 — 화면이 두 벌이다.** 채팅과 Cowork를 합친 「새 Claude 화면」이 Pro·Max부터 차례로 배포되고 있고, 설정 화면도 새 이름(Your Claude·Wellbeing)과 옛 이름(Memory·Time and focus)이 함께 쓰인다. 독자마다 다른 화면을 볼 수 있다.
- **주의 3 — 원화 가격은 확인하지 못했다.** 받은 요금 페이지는 미국 달러뿐이다.

## 결론 — 가이드에 꼭 반영할 것

1. **요금제는 Free · Pro($20/월, 연간 결제 시 월 $17) · Max($100부터, Pro 대비 5배·20배 사용량) · Team · Enterprise.** 사용 한도는 5시간 단위 세션 한도와 (유료) 주간 한도가 따로 있다(A-start).
2. **새 Claude 화면**: 채팅과 Cowork가 한 화면으로 합쳐지는 중이다. 새 화면에는 입력창의 Chat/Cowork 선택과 웹 검색 토글이 없다. 2026-10-06부터 Pro·Max의 새 Cowork 작업은 모두 클라우드에서 돈다(B·D).
3. **모델 메뉴는 모델·노력(effort)·생각(thinking) 세 가지.** 모델 이름은 2026년에만 여러 번 바뀌었으므로 본문에는 역할(큰 모델/빠른 모델)로 쓰고 이름은 확인일과 한 곳에만 둔다(B).
4. **Claude는 사진·일러스트를 만들지 않는다.** 대신 도표·차트·문서 파일(Excel·Word·PowerPoint·PDF)과 아티팩트는 만든다(C).
5. **메모리는 무료 포함 모든 요금제**에서 켜고 끌 수 있고, 지난 대화 검색·한 채팅만 끄기·시크릿 채팅이 있다. 다른 AI의 메모리를 가져오는 기능(실험)도 있다(C).
6. **웹 검색은 무료도 되고, 리서치·플러그인·Cowork·Claude in Chrome·예약 작업은 유료 전용**이다. 프로젝트는 무료 5개까지(요금 페이지 비교표 기준 — 충돌 있음)(D).
7. **학습 사용은 「모델 개선」 설정으로 정한다.** 켜 두면 대화가 학습에 쓰이고, 시크릿 채팅은 설정과 상관없이 쓰이지 않는다. 피드백(좋아요/싫어요)을 보내면 그 대화 전체가 최대 5년 보관된다(E).
8. **음성 모드는 베타**이고, 받아쓰기와 따로 있다(E).
9. **Cowork·Chrome·내장 브라우저·컴퓨터 사용은 공통 안전 수칙**이 있다 — 민감한 정보(금융·의료·법률·남의 개인정보)에 쓰지 말 것, 공격 가능성이 0이 아님(D).

## 가이드에 쓸 때 주의

- **모델 이름·목록은 매달 바뀐다.** 2026년에만 Opus 4.6 → 4.7 → 4.8 → 5 → 5.5, Sonnet 4.6 → 5 → 5.5, Haiku 5.5, Fable 5 → 5.1이 나왔고, 10-29에 Haiku 4.5가 선택기에서 빠진다. 본문엔 "가장 큰 모델 / 빠른 작은 모델"처럼 역할로 쓰고, 이름은 확인 날짜와 함께 한 곳에만 둔다.
- **한국어판은 번역이 늦다.** 8664678·8114494 한국어판엔 Haiku 5.5가 빠져 있다(B6·B8·B104). 내용은 영어판 기준.
- **설정 경로가 두 벌이다.** 새 설정 화면(Your Claude·Wellbeing·Where you're logged in)과 옛 화면(Memory·Time and focus·Active sessions)이 함께 쓰인다. 릴리스 노트는 옛 이름(Settings > Memory, Time and focus)을 쓴다. 둘 다 적거나 "설정에서 ~ 찾기"로 쓴다.
- **새 Claude 환경은 단계 배포 중.** 독자마다 입력창에 Chat/Cowork 선택이 보이거나 안 보인다(B45). 두 화면을 다 설명해야 한다. 한국어판도 Recents·Customize·Your Claude 같은 메뉴를 영어로 둔다 — 실제 화면 확인 필요.
- **충돌 1 — 디자인·덱·문서의 무료 여부**(B59): 16761823은 "유료", 릴리스 노트·요금 페이지는 "무료 포함". 단정하지 말 것.

## 가이드에 쓸 때 주의
- **충돌 1 — 파일 크기 한도(F6 vs F21)**: 8241126 은 채팅 업로드 "500MB per file", 12111783 은 파일 생성 기능에서 "30MB per file for both uploads and downloads". 둘 다 2026-10-26 같은 날 문서. 가이드에는 숫자를 단정하지 말고 "채팅 첨부는 큰 파일도 되지만, Claude 가 만들거나 고치는 파일은 30MB 안쪽"처럼 출처별로 나눠 적거나 링크로 돌린다.
- **충돌 2 — Free 의 링크 공유(S2 vs D9)**: 9547008 의 표는 「링크가 있는 누구나」 칸에서 Free 가 비어 있다. 그러나 16923645(Docs)는 "Free, Pro, and Max plans: Share with anyone who has the link." 라고 쓴다. 17153992 에도 Free 의 새 아티팩트 공유 설명은 없다. 단정 금지.
- **충돌 3 — 프로젝트(P4 vs P5)**: 같은 문서 10185728 안에서 "Free users can create a maximum of five projects" 와 "project instructions ... (paid plans only)" 가 어긋난다.
- **충돌 4 — 한국어 메뉴 번역**: 「Your Claude」 가 한국어판에서 「당신의 Claude」·「내 Claude」·「Claude 정보」·영어 그대로 「Your Claude」로 섞여 있다. 실제 화면 캡처로 확인 전에는 영어 이름을 함께 적는다. 메모리 「Reset」도 「메모리 재설정」/「메모리 초기화」로 갈린다.
- **설정 화면이 두 벌**: 거의 모든 문서가 "updated Settings layout"과 "older Settings layout"을 함께 적는다(예: 「코드 실행 및 파일 생성」 = 새 화면 「파일 생성 및 편집」). 독자 화면이 어느 쪽인지 모르므로 두 이름을 같이 쓴다.
- **메모리도 두 벌**: 새 메모리(주제별 즉시 저장)와 레거시(24시간 요약)가 공존. 개인 요금제는 새 쪽 기준으로 쓰면 되지만, 대화를 지웠을 때 메모리가 남는지는 둘이 정반대(새: 남음 R18 / 레거시: 지워짐)이므로 반드시 새 기준임을 밝힌다.
- **베타·미리보기**: 맞춤 시각화(V8), Dashboards·Motion 템플릿(A4·A5), 이메일 초대(S3), Google Workspace 확장(G1), 디자인 시스템(CD14), 메모리 가져오기(실험, X7), 워터마크 검출(비공개 미리보기, W7). Claude Duet 은 Pro·Max 리서치 프리뷰로 언급만 됨.
- **날짜가 박힌 사실**: 레거시 아티팩트 기준일 2026-09-16(A7), Cowork 라이브 아티팩트 2026-08-19, Enterprise 템플릿 기본 켜짐 2026-10-15, claude.ai/design 종료 2026-12-14(CD3), 워터마크 기준일 2026-08-02(W2). 시간이 지나면 문장이 낡는다 — 확인 날짜를 남긴다.
- **이미지 생성 표현 주의**: 9002504 는 "사진·삽화를 만들지 않는다"이지만, 12111783·16266773 은 PNG 차트·PNG/JPEG 파일 생성을 말한다. "그림을 전혀 못 만든다"가 아니라 "그림 그리는 AI(이미지 생성 도구)처럼 사진·일러스트는 못 만들고, 도표·차트는 만든다"로 쓴다.

5. 부록 또는 박스 — Google 문서 안에서 쓰기(Pro 이상 베타), AI 생성 표시(워터마크·C2PA 의 한계).

## 가이드에 쓸 때 주의
- **"새 Claude 화면(new Claude experience)" 배포 중**: Pro·Max부터 채팅과 Cowork가 합쳐지고 있다. 새 화면에는 웹 검색 토글도, 입력창의 Chat/Cowork 선택지도 없다(D3·D145). 「+ → 웹 검색」, 「Cowork 선택」 같은 절차는 "화면에 따라 다를 수 있다"는 말과 함께 쓴다.
- **2026-10-06 변경**: Pro·Max의 새 Cowork 작업은 모두 클라우드에서 돈다(D176). 그 전 자료나 화면 캡처에 나오는 "내 컴퓨터에서만 실행" 옵션은 이제 없다.
- **2026-08-19 경계**: 그 이전 Cowork 아티팩트는 "라이브 아티팩트"로 남아 데스크톱에서만 열리고 그 자리에서 고칠 수 없다(D208).
- **베타·한정 기능은 단정하지 않는다**: 새 버전 프로젝트(D48)·Dispatch(D191, 신규 사용자 불가)·컴퓨터 사용(D200, Pro·Max만)·리눅스 데스크톱·모바일 커넥터 설치(D77)·1Password(D229, 맥)·Chrome 확장(C7)·Enterprise 그룹 공유.
- **무료 요금제에서 되는 것 / 안 되는 것**: 웹 검색·프로젝트(5개)·스킬·커넥터·커스텀 커넥터 1개·Microsoft 365·빠른 입력은 무료도 된다. 리서치·RAG·플러그인·Cowork·Claude in Chrome·예약 작업은 유료 전용이다.
- **모델 이름(Opus 5.5·Opus 4.8 등)은 자주 바뀐다**: 리서치 모델(D21)·지원 모델 목록(D1)은 확인 날짜와 함께 쓰거나 빼는 편이 안전하다.
- **안전 문구는 일관되게**: Cowork·Chrome·내장 브라우저·컴퓨터 사용 모두 "민감한 정보(금융·의료·법률·타인 개인정보)에는 쓰지 말라", "공격 가능성은 0이 아니다", "책임은 사용자에게"를 공통으로 말한다. 한 번 정리하고 장마다 링크하면 중복이 줄어든다.
- **권한 모드 이름**: 영어 Manual/Auto/Skip(옛 이름 "Ask before acting"/"Act without asking"), 한국어판은 「수동 승인」·「자동 승인」·「모든 승인 건너뛰기」. 커넥터 도구 권한은 「항상 허용」·「승인 필요」·「차단됨」.
- **메뉴 위치가 두 벌**: 문서마다 "새 설정 화면 / 예전 설정 화면" 경로를 같이 적는다(예: 「Settings > Desktop app」 ↔ 「Settings > Extensions」, 「Create and edit files」 ↔ 「Code execution and file creation」). 캡처를 찍어 실제 화면 이름을 확정한 뒤 쓴다.
- **한국어판은 일부 버튼을 영어로 둔다**: 「Research」·「Cowork」·「Chat」·「Scheduled」·「Customize」 등. 본문에서 화면 이름을 쓸 때는 실제 화면 캡처로 다시 확인한다.
