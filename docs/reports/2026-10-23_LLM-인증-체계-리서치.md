# AI·LLM 인증 체계 리서치와 hello-llm 인증 시험 검토 (2026-10-23)

## 이 문서의 용도

- 해외 공식 인증, 국내 자격, AI 리터러시 수준 체계(입문·중급·상급을 어떻게 나누는가)를 조사하고, 이 가이드의 「LLM 이해 인증 시험」과 비교한다.
- 조사 방법: 웹 검색 에이전트 2개(`agy` 검색 + 공식 페이지 WebFetch 직접 대조). 확인일은 모두 **2026-10-23**.
- 표기: 공식 페이지에서 직접 읽은 값만 확정으로 적고, 요약 엔진(`agy`)에서만 나온 값이나 공식 대조를 못 한 값은 **UNVERIFIED** 로 표시했다. 본문(가이드)에 옮길 때는 확정 값만 쓴다.

## 결론

1. **일반인이 개인으로 응시할 수 있는 감독 시험(proctored, 시험 감독관이 지켜보는 정식 시험)은 거의 없다.** 해외에서는 Microsoft AB-730(Copilot 업무 사용자)과 Google Cloud Generative AI Leader(비즈니스)가 가장 가깝다. Google AI Essentials, Anthropic Academy, OpenAI Academy, CompTIA AI Essentials 는 **수료증·배지형**이다.
2. **Anthropic 자격증(Claude Certified …)은 파트너사 직원만, OpenAI 자격증은 Enterprise/Edu 초대제로 보여 개인이 딸 수 없다.** 독자에게 "공식 Claude/ChatGPT 자격증"을 목표로 안내할 수 없다.
3. **국내는 등록민간자격이 대부분**이다. KAIT 「AI활용능력(프롬프트엔지니어·AI상식)」은 공식 페이지에 "국가공인 아님"이 명시돼 있다. AICE Associate 는 국가공인이라는 서술이 있으나 한 곳(나무위키)에서만 확인됐다.
4. **수준 체계는 3단계(UNESCO·OECD/EC AILit) 또는 4단계(EU DigComp 3.0)가 표준**이고, 수준을 가르는 축은 공통으로 **"안내를 받아 수행 → 혼자 해결 → 복잡한 일을 판단·남을 안내 → 새 방법을 만듦"** 이다.
5. **이 가이드의 시험은 "입문 수준의 지식 확인 배지"로는 업계 수료 배지와 비슷한 위치**다. 다만 문제 은행이 장별 확인 퀴즈와 같고(외워서 통과 가능), 브론즈 기준 50%가 업계 합격선(70~72%)보다 낮다. 중급·상급은 객관식만으로는 측정이 안 되고 시나리오형·실기형이 필요하다(아래 「제안」).

## 3. 수준 체계 — 입문·중급·상급을 무엇으로 나누나

| 체계 | 수준 이름 | 나누는 기준 | 평가 |
|---|---|---|---|
| EU DigComp 3.0 (2025-11-27) | Basic → Intermediate → Advanced → Highly advanced | 인지 요구도·과업 복잡성·자율성 | 평가 도구가 아니라 학습성과 523개를 평가 설계 기준으로 제공 |
| OECD·EC AILit (초안 2025-05) | Basic → Intermediate → Advanced | 4영역(Engage·Create·Manage·Shape) 19역량 | PISA 2029 「미디어·AI 리터러시」 평가에 기여 |
| UNESCO 학생용 (2024) | Understand → Apply → Create | 인간 중심 마인드셋·윤리·AI 기법·시스템 설계 | 평가 지침 없음 |
| Anthropic AI Fluency (4D) | 등급 없음 | 위임(Delegation)·설명(Description)·분별(Discernment)·성실(Diligence) | 과정 끝 평가 후 수료증 |
| EU AI Act 제4조 | 법정 등급 없음 | 역할·위험에 맞춘 교육 | 인증·측정 의무 없음(2025-02-02 적용) |

DigComp 3.0 의 수준 정의(보고서 표 3 요지):

- **Basic**: 안내를 받아 단순한 일을 기억하고 수행한다
- **Intermediate**: 잘 정의된 일과 문제를 혼자 해결한다
- **Advanced**: 여러 복잡한 일에서 방법을 평가·적용하고, 필요하면 남을 안내한다
- **Highly advanced**: 매우 복잡하거나 전문적인 문제에서 새 방법을 만들고 남을 이끈다

## 5. 제안 — 입문·중급·상급 배지 체계

가이드 로드맵(1단계 → 2단계 → 3·4단계)에 DigComp 의 수준 축을 그대로 겹친다. 실제 AI 를 호출하지 않는다는 비용 0 원칙을 지키는 방식만 골랐다.

| 수준 | 대상 단계 | 할 수 있어야 하는 것 (DigComp 축) | 평가 방식 | 자동 채점 |
|---|---|---|---|---|
| **입문** (지금 시험) | 1단계 공통 가이드 | 안내를 따라 좋은 요청을 쓰고, 답을 확인할 줄 안다 | 객관식 20문제. 시험 전용 문제 은행으로 분리 | 가능 |
| **중급** | 2단계 서비스별 가이드 이후 | 처음 보는 상황에서 혼자 요청을 설계하고 고친다 | **시나리오형**: 상황과 AI 답을 보여 주고 "무엇이 문제인가 / 가장 나은 다음 요청은?"을 고르게 한다. 프롬프트 편집기로 직접 만든 프롬프트를 체크리스트로 자동 점검(5요소·구분선 여부 등 규칙으로 판정) | 대부분 가능 |
| **상급** | 3·4단계(코딩 에이전트·AI-SDLC) 이후 | 큰 일을 AI 에게 나눠 맡기고 결과에 책임진다(AI Fluency 의 위임·성실) | **실기 과제 + 루브릭(채점 기준표) 자기 평가**: 결과물(예: 에이전트로 만든 작은 도구, 작업 기록)을 기준표로 스스로 점검하고 포트폴리오로 남긴다 | 불가 — 자기 평가 배지임을 밝힌다 |

입문 시험에 바로 할 수 있는 개선:

1. **시험 전용 문제 은행** — 확인 퀴즈와 다른 문제로 장마다 3~5문제 추가(이전부터 대기 중인 제안)
2. **상황 판단형 문제 비중** — "이 프롬프트에서 빠진 것은?" "이 답에서 먼저 확인할 것은?" 같은 문제를 절반 이상으로
3. **합격선 조정 검토** — 브론즈 50% → 60%(국내 KAIT AI상식과 같음). 골드 90%·실버 70%는 업계 수준과 비슷해 유지

## 6. 주의

1. **「인증 시험」·「자격」 명칭과 판매 연계 — 확인 필요.** 자격기본법은 민간자격을 운영하려면 등록하도록 하고 있다고 알고 있으나, **이번 조사에서 조문을 직접 확인하지 않았다(UNVERIFIED).** 탈잉 판매 강좌의 수강생 혜택으로 이 배지를 안내하고 있으므로, 배지가 "자격"으로 오인될 표현(자격증, 합격증, 공인)을 피하고 「학습 배지」「이해도 확인 시험」 같은 이름이 더 안전한지 법령(국가법령정보센터 자격기본법)이나 민간자격정보서비스 안내로 확인할 것
2. 해외 시험 정보(가격·출제 범위·응시 자격)는 자주 바뀐다 — AB-730 은 조사 사흘 전(2026-10-20), Anthropic 시험은 2026-12-07 에 개편된다. 본문에 쓰면 확인일을 함께 적는다
3. Anthropic·OpenAI 자격증은 개인 응시가 막혀 있다 — 2단계 서비스 가이드에서 "공식 자격증 따기"를 목표로 제시하지 않는다
