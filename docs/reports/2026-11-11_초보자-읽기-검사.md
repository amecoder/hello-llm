# 한국어판 97개 장 초보자 읽기 검사 (2026-11-11)

## 결론

- 문장은 짧다(평균 38자, 80자 넘는 문장 6%). 문제는 문장보다 **순서와 구성**이다.
- 장마다 되풀이되는 문제는 다섯 가지다: 그림 없음, 용어가 설명보다 먼저 나옴, 안 배운 것을 전제함, 본론 앞의 곁가지(요금·약관·확인 날짜·예외), 접힌 칸에만 있는 내용에 기대는 본문.
- **그림이 한 장도 없는 장이 45개**다. 대부분 3·4단계(Claude Code 8~12장, Codex, Antigravity, 터미널 강좌, AI-SDLC)다. 2단계 Claude·ChatGPT 15개 장에는 `스크린샷 필요` 자리표시가 21개 남아 있다. 이 두 숫자는 검사 모델과 상관없는 사실이다.
- 점수는 1·2단계가 높고 3·4단계가 낮다. 다만 3·4단계는 더 엄격한 모델(Claude)이 채점해서, 차이의 일부는 채점자 차이다(아래 「채점자 차이」).
- 공통 4장(프롬프트 기초)은 막힘·끊김 0건이다. 고칠 때 본보기로 쓴다.

## 방법

- **형식 지표(97개 장)**: 빈 줄을 뺀 줄, 문장 길이, 예시·그림·표·제목 없이 글만 이어지는 구간의 길이를 스크립트로 쟀다.
- **초보자 역할 읽기(97개 장)**: 모델에게 "프로그래밍을 모르고 ChatGPT를 검색창처럼만 써 본 회사원"이 되어 읽게 했다. 앞 장과 앞 단계는 읽었다고 가정했다(3단계는 공통 + ChatGPT, 터미널 강좌·4단계는 Claude Code 데스크톱까지). 결과는 장마다 이해·집중 점수(1~5)와 줄 번호가 붙은 문제 목록이다.
  - 문제 종류: 용어먼저 · 안배운것전제 · 곁가지 · 그림없음 · 글벽(예시 없는 긴 글) · 접힘누출 · 기타

## 한계

- 사람이 아니라 모델이 초보자를 흉내 냈다. 실제 독자가 같은 곳에서 막히는지는 확인하지 않았다.
- 두 모델이 같은 곳을 짚은 비율이 낮다(Gemini 11건 중 7건). 장별 목록 하나하나는 흔들릴 수 있고, 되풀이되는 유형이 더 믿을 만하다.
- 「그림없음」은 그림이 정말 필요한 곳인지 모델이 판단한 것이다. 0장이라는 사실과 필요하다는 판단은 별개다.

### 해석

- 용어먼저는 43% 줄었다. 처음 나올 때 풀이를 붙이는 일은 효과가 분명했다.
- 곁가지는 21% 줄었다. 옮긴 내용이 접는 칸이나 각주에 있어도 채점자는 "장마다 맨 앞의 확인 날짜" 같은 남은 곁가지를 계속 짚었다. 확인 날짜 줄은 CLAUDE.md 「사실 확인」 규칙 때문에 남겼다.
- 채점자 잡음이 크다. 바꾸지 않은 공통 4장에서 문제가 1건에서 4건으로 늘었다. 같은 글을 다시 읽혀도 새 지적이 나온다는 뜻이라, 장별 점수 차이는 대부분 잡음 안에 있다.
- 집중 점수는 거의 그대로다. 집중을 떨어뜨리는 가장 큰 원인으로 짚힌 「그림없음」(82건)을 이번에 고치지 않은 것도 이유일 수 있다.
