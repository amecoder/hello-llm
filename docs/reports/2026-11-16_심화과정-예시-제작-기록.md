## 트랙별로 정한 것과 이유

### 게임
- 라이브러리 없이 캔버스로 만들었다. 파일 4개(`index.html`·`style.css`·`logic.js`·`game.js`)라 초보자가 전체를 읽을 수 있다. Phaser는 쓰지 않았다
- 게임 규칙(`logic.js`)을 화면 코드와 나눴다. 같은 시드(seed)로 같은 게임을 다시 돌릴 수 있어 테스트가 된다
- 공유: 휴대폰은 공유 창(Web Share API), 컴퓨터는 문구 복사. 링크 미리보기 그림(`og-image.png`, 1200×630)은 `og.html` 을 브라우저로 찍어 만들었다
- `index.html` 을 더블클릭하면 동작하지 않는다(모듈 방식 `import` 를 브라우저가 파일 주소에서 막음). README에 로컬 서버 명령을 적었다. 강의 6장 전까지는 `python3 -m http.server` 로 본다

### 가게
- 더블클릭으로 열려야 해서 모듈을 쓰지 않고 일반 `<script>` 로 불렀다
- 저장은 브라우저 저장소(localStorage). 가정: 사장님 한 명이 한 컴퓨터에서 쓴다. 대신 「백업」 탭에 파일 내려받기·되돌리기와 마지막 백업 날짜를 두었다(9장 재료)
- 홍보 문구는 AI를 직접 부르지 않고 **AI에게 보낼 요청문**을 만든다(비용 0, 키 없음). 요청문에 「(광고)」 표시와 수신거부 자리, 지어내기 금지를 넣었다
- 손님 명단에 홍보 동의 여부와 동의한 날을 따로 두고, 동의를 거두면 날짜를 지운다. 밤 9시~아침 8시 안내를 화면에 띄운다(정보통신망법 제50조③ — 리포트 VERIFIED)
- 화면에 넣는 글은 전부 `textContent` 로 넣는다. 손님 이름 칸에 `<img src=x onerror=alert(1)>` 를 넣어도 그림 요소가 0개였다

### 재테크
- 차트는 Apache ECharts 6.1.0을 `vendor/` 에 넣었다(인터넷 없이도 열림). Apache 2.0 라이선스와 NOTICE 파일을 함께 넣었다
- 화려함: 어두운 배경, 네온 그라데이션, 숫자가 0부터 올라가는 움직임, 도넛·막대가 튀어나오는 애니메이션. 오르면 빨강, 내리면 파랑(한국 증권 화면 관례)
- 계산은 평균 단가 방식. 「달별 증감」은 새로 넣은 돈을 빼고 센다 — 넣은 돈이 늘어난 것을 수익으로 착각하지 않게
- 예시 자료는 지어낸 종목 4개(가상전자 등)와 시드 고정 난수 가격이다. 금융위 시세는 재배포 금지라 넣지 않았다
- 경제 지표: 한국은행 ECOS 응답에 CORS 허용 머리글이 없어(실측) 화면에서 바로 못 부른다. 그래서 `tools/fetch-ecos.mjs` 가 내 키(환경 변수 `ECOS_API_KEY`, 없으면 `sample`)로 CSV를 받고, 대시보드가 그 파일을 읽는다. 화면에 「출처: ECOS(한국은행)」를 적는다(약관 제7조②)

## 가설 대조 (계획의 판정 기준)

- ① 동작하는 예시: 게임은 공개 주소 HTTP 200, 가게·재테크는 로컬 동작 확인 → **충족(업무 트랙은 사용자 결정으로 대상에서 빠짐)**
- ② 「본문 순서대로 만들었고 본문에 없는 단계 0곳」: **아직 판정 못 함.** 이번 예시는 강의 본문보다 먼저, Claude가 직접 코드를 써서 만들었다. 독자처럼 AI에게 요청하는 순서를 밟지 않았다. 4단계(본문 작성) 뒤 본문의 프롬프트로 한 트랙 이상을 처음부터 다시 만들어 대조해야 한다

## 강의에 쓸 재료

- 2장 SPEC: 세 저장소의 `SPEC.md` 가 「넣는 것 / 넣지 않는 것 / 확인 기준」 모양의 견본이다
- 3장 화면: 게임 플레이, 가게 예약·메뉴판, 재테크 데스크톱·휴대폰 캡처(scratchpad `shots/`, 강의 쓸 때 장 `assets/` 로 옮김)
- 4장 데이터: 가게(브라우저 저장소 + 백업 파일), 재테크(CSV 파일 + 브라우저 저장소), 게임(최고 기록만 브라우저 저장소)
- 6장: 게임 저장소 만들기 → Pages 켜기(`gh api … /pages`) → 1분 안쪽에 HTTP 200. 가게·재테크는 「더블클릭으로 열기」와 바로 가기
- 7장 확인: 빈칸 저장, 이상한 글자 넣기, 새로 고침, 휴대폰 너비 — 이번에 실제로 잡은 문제 2개(재테크 휴대폰 가로 넘침, 범례 색 불일치)를 사례로 쓴다
- 9장: 가게 백업·되돌리기, 재테크 「저장한 내 자료 지우기」
- 10장: 게임 미리보기 그림과 자랑 문구, 가게 홍보 요청문
