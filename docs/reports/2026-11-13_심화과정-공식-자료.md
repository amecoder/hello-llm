# 심화 과정 공식 자료 — 호스팅·데이터·한국 법·재테크·게임 (2026-11-13)

심화 과정 「내 서비스 만들기」(계획: `docs/plans/2026-11-13_심화과정-내-서비스-만들기-계획.md`)의 본문에 쓸 사실을 공식 페이지에서 확인했다. **본문에는 이 리포트에서 확인(VERIFIED)으로 표시된 값만 쓴다.** 원문 인용 전체는 `2026-11-13_심화과정-공식-자료-대조표.md` 에 있다.

## 결론

- **가게 트랙(사업용)에 쓸 수 없는 곳**: GitHub Pages(온라인 사업·쇼핑몰 금지), Vercel 무료(「personal or non-commercial use」만).
- **무료 요금제의 사업용 사용을 금지하는 조항을 찾지 못한 곳**: Cloudflare, Netlify, Supabase, Firebase, Apps Script. 「허용한다」는 문구도 없다(침묵). Cloudflare 무료는 카드 정보를 받는 것만 막는다.
- **데이터 접근 규칙이 기본 안전장치다**: Supabase는 접근 규칙(RLS)이 꺼진 표를 경고하고 메일로 알린다. Firebase 문서는 「모두 허용」 규칙을 「절대 실제 서비스에 쓰지 말라」고 한다.
- **한국 법**: 예약으로 이름·전화번호를 받으면 처리방침 공개(위반 시 1천만 원 이하 과태료). 광고 문자는 사전 동의, 밤 9시~아침 8시는 별도 동의(위반 시 3천만 원 이하 과태료). 통신판매업 신고 면제는 직전 해 50회 미만 또는 간이과세자.
- **재테크 데이터**: 금융위원회 주식시세 API는 무료지만 「상업적 목적 여부와 상관없이 제3자 무단 제공 및 재배포 금지」다. 남에게 보여 주는 공개 대시보드에는 쓸 수 없다.
- **게임**: 영리 목적이 아니면 등급분류 면제(청소년이용불가·사행성 제외). GitHub Pages에 올릴 수 있다.

- 조사 에이전트 4개(호스팅, 데이터·로그인, 한국 법, 재테크·게임)가 원문을 읽고, 별도 대조 에이전트가 66개 항목을 원문 글자로 다시 찾았다.
- 대조 방법: `curl` 로 원문을 받아 글자 검색, 법령은 law.go.kr 원문 엔드포인트, PDF는 `pdftotext`. FRED만 요약 도구(WebFetch)로 읽었다.
- 결과: 확인 56 · 다름 7 · 못 찾음 2 · 못 엶 1. 다른 항목은 아래 「대조에서 고친 것」에 반영했다.
- 기준일 2026-11-13. 요금·한도·약관은 자주 바뀌므로 장마다 확인 날짜를 적는다.

## 2. 데이터 저장과 로그인

| 서비스 | 무료 한도 | 로그인 | 접근 규칙 | 백업 | 서울 |
|---|---|---|---|---|---|
| Supabase | DB 500MB, 월 사용자 5만, 프로젝트 2개 | 있음. 기본 메일 시간당 2통 | RLS. 꺼진 표에 경고 표시·메일 알림 | 무료는 백업 내려받기 불가(CLI `db dump` 권장) | 있음 |
| Firebase(Firestore) | 저장 1GiB, 하루 읽기 5만·쓰기 2만 | 있음. 이메일 링크 로그인 하루 5통 | Security Rules. 허용한 문서만 접근 | 정기 백업은 유료(Blaze)만 | 있음(`asia-northeast3`, 나중에 못 바꿈) |
| 구글 시트 + Apps Script | 시트 2천만 셀 또는 100MB, 실행 한 번 6분 | 구글 계정 | 웹 앱 접근: 나만 / 로그인한 사용자 / 누구나. 행 단위 규칙 없음 | 시트 버전 기록(이번에 확인 안 함) | — |
| Cloudflare D1 | 하루 읽기 500만 행·쓰기 10만 행, DB당 500MB | 없음(직접 만들어야 함) | 없음(서버 코드에서) | 무료도 7일 안 아무 때로 되돌리기(Time Travel) | 지정 불가(`apac` 힌트만) |

- Supabase 일시 정지: "Supabase pauses Free Plan projects that show low activity over a 7-day period". 정지된 프로젝트는 1년 안에 복원할 수 있다.
- Supabase 접근 규칙: RLS가 꺼진 표는 그 표에 권한(grant)이 있는 역할이면 API로 읽고 쓸 수 있다. 문서는 기본 권한이 남아 있는 프로젝트라면 권한을 거두라고 한다. (대조 전 메모의 「공개 키로 누구나」는 조건이 빠진 표현이라 고쳤다.)
- Firebase 원문: "NEVER use this rule set in production; it allows anyone to overwrite your entire database."
- Apps Script는 회사 관리자가 꺼 둘 수 있다(조사 메모, 대조 대상 아님 — 본문에 쓰기 전 다시 확인).
- Airtable 무료: 베이스당 1,000 레코드, 월 API 호출 1,000회.

## 5. 게임과 공유

- Phaser 4.2.1, MIT 라이선스.
- 링크 미리보기는 Open Graph 태그(`og:title`·`og:type`·`og:image`·`og:url`)를 읽는다. 그림을 넣으면 `og:image:alt` 도 넣는다.
- 카카오톡은 미리보기 정보를 따로 저장한다. 그림을 바꾸면 카카오 개발자 사이트 [도구] > [초기화 도구] > [OG 캐시]에서 지운다. 그림이 5MB를 넘으면 안 된다.

## 트랙별로 사실이 가리키는 것 (결정은 아님)

| 트랙 | 사실이 가리키는 방향 |
|---|---|
| 게임 | GitHub Pages(4단계에서 배움, 비영리 허용) + Phaser 또는 캔버스. 새 서비스 가입이 필요 없다 |
| 재테크 | 공개 대시보드에 시세 데이터를 다시 보여 주기 어렵다. 「나만 보는 대시보드」(내 컴퓨터에서 열거나 나만 접근) + 내 거래 기록처럼 내가 가진 데이터 + 출처를 밝힌 공공 자료. 공개 예시는 지어낸 데이터로 |
| 업무 | 회사 데이터는 공개 저장소·GitHub Pages에 맞지 않는다. 구글 시트 + Apps Script(로그인한 회사 사용자만)가 엑셀에서 옮겨 가기 가장 가깝다. 회사가 Apps Script를 막았을 수 있다 |
| 가게 | 사업용 금지가 없는 호스팅(Cloudflare·Netlify·Firebase) + 로그인과 접근 규칙이 있는 데이터 저장(Supabase·Firebase). 조합마다 약점이 다르다: Supabase는 7일 무활동 정지와 무료 백업 불가, Firebase는 이메일 링크 로그인 하루 5통과 무료 백업 불가, Netlify는 월 배포 약 20회, D1은 로그인 없음 |

## 대조에서 고친 것

- GitHub Pages: 「무료 계정에서 비공개 저장소로 만들어도 공개」가 아니라, 무료 계정은 저장소 자체가 공개여야 한다.
- Supabase: 「공개 키 + RLS 없음 = 누구나 읽고 쓰기」에 「그 표에 권한이 있으면」 조건을 붙였다.
- 정보통신망법 광고 위반 과태료: 5천만 원 → 3천만 원 이하(제76조②).
- 금융위원회 주식시세: 「출처만 밝히면 다시 보여 줄 수 있다」가 아니라 제3자 제공·재배포 금지.
- Open DART: 「무료 여부 없음」이 아니라 약관 제11조①에 「원칙적으로 무료」.
- 게임산업법 시행일: 2024-10-22(법률 제20485호).
- FRED: 「요청마다 키」 문구는 확인되지 않았다.

## 남은 공백

- 가입 시 카드 필요 여부(GitHub·Cloudflare·Netlify·Supabase).
- ECOS 호출 한도 수치(FAQ는 「추출 Row 건수 및 API 호출횟수 등으로 제한」이라고만 함).
- Firebase 테스트 모드 만료·열린 규칙 경고 문구.
- 결제 없는 예약 양식의 통신판매 해당 여부, PG 계약 서류, 카카오톡 광고성 판단 기준.
- Apps Script를 회사 관리자가 끌 수 있다는 문구, 처리방침 만들기 도구, 금융위 법령해석은 조사 메모에만 있고 대조하지 않았다.
