# GitHub 유사 프로젝트 경쟁 분석

- 조사일: 2026-10-20
- 방법: `gh search repos "<키워드>" --sort stars` 로 키워드 18개(영·한·중) 검색
- 한계: 저장소 이름·설명만 검색되므로 설명에 키워드가 없는 저장소는 빠졌을 수 있다. 별 수는 조사일 기준

## 결론

LLM 사용법 가이드는 별이 많은 저장소가 여럿 있지만, **비개발 일반인을 대상으로 챗봇 사용 → 코딩 에이전트 → AI-SDLC 까지 한 줄로 잇는 저장소는 찾지 못했다.** 각 단계를 따로 다루는 강자만 있다.

## 시사점

1. **한국어 일반인용 가이드가 비어 있다** — "프롬프트" 검색 최상위가 별 61개. 중국어 일반인용(PlexPt)이 6만 개를 넘은 것은 모국어 일반인 가이드 수요의 근거다.
2. **단계 사이 연결이 비어 있다** — 프롬프트·Claude Code·스펙 주도 개발이 각각 따로 있고 독자층도 다르다. 이것을 잇는 것이 차별점이다.
3. **실습 방식** — 실제 서비스와 같은 화면 + 코치 마크로 연습하는 형태는 찾지 못했다.
