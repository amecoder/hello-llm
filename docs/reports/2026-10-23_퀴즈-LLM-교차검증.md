# 퀴즈·시험 정답을 실제 LLM으로 교차 검증 (2026-10-23)

## 이 문서의 용도

- 사이트의 문제(확인 퀴즈·이해도 확인 시험·AI 지식 레벨 시험) 정답이 맞는지, **회사가 다른 LLM 3개에게 정답 없이 풀게 해서** 비교했다.
- 여러 모델이 같은 오답을 고르면 문제가 애매하거나 정답이 틀렸을 가능성이 크다는 가정으로, 그런 문제를 골라 근거와 다시 대조했다.
- 사이트는 이 검증과 무관하게 실제 AI를 호출하지 않는다(비용 0 원칙). 이 검증은 작업 때 한 번 돌린 것이다.

## 방법

| 항목 | 내용 |
|---|---|
| 대상 | 379문제 — 확인 퀴즈 103(1단계 51 + ChatGPT 52), 이해도 확인 시험 36, 레벨 시험 240(초급·중급·고급·전문가 각 60) |
| 풀이 모델 | OpenAI 계열(Codex CLI `codex exec`), Google 계열(agy), Anthropic 계열(Claude 하위 에이전트, 문제를 쓰지 않은 새 에이전트) |
| 조건 | 정답·해설·출처·가이드 본문 없이 문제와 보기만 제공. 도구·검색 사용 금지. 40문제씩 10묶음 |
| 판정 | 두 모델 이상이 정답과 다르면 「검토 대상」, 한 모델만 다르면 개별 확인 |
| 스크립트 | 세션 scratchpad `quiz-eval/`(export.mjs → run-solver.sh → compare.mjs) |

## 결과

| 묶음 | 문제 | Codex | Gemini | Claude |
|---|---|---|---|---|
| 확인 퀴즈 | 103 | 96% | 98% | 99% |
| 이해도 확인 시험 | 36 | 94% | 100% | 100% |
| 레벨 초급 | 60 | 97% | 100% | 100% |
| 레벨 중급 | 60 | 93% | 100% | 100% |
| 레벨 고급 | 60 | 97% | 100% | 100% |
| 레벨 전문가 | 60 | 93% | 100% | 100% |

- Codex 의 낮은 비율은 대부분 **답을 내지 않은 10문제**(한 묶음 일부 누락)를 오답으로 센 것이다. 답을 낸 문제에서 Codex 가 정답과 다르게 고른 것은 없었다.
- 정답과 다르게 고른 경우는 모두 2문제였고, 둘 다 **우리 정답이 맞았다**.

| 문제 | 모델의 답 | 우리 정답 | 판정 |
|---|---|---|---|
| `ch107-work` (ChatGPT 7장) 여러 단계로 발표 자료를 만드는 일에 알맞은 것 | Gemini: 「설정에서 에이전트 모드를 켠다」 | 「Work」로 바꿔 맡긴다 | 정답 유지 — 에이전트 모드는 종료되고 Work 로 대체됨(OpenAI 도움말 11752874 "ChatGPT agent is no longer available. Use ChatGPT Work", 확인일 2026-10-23) |
| `ch109-modes` (ChatGPT 9장) 카메라로 비추며 음성으로 묻기 | Gemini·Claude: 「라이브(Live) 방식」 | 「휴대폰 앱의 고급(Advanced) 방식」 | 정답 유지 — 도움말 20001274 는 영상·화면 공유가 고급 방식에만 있다고 안내(확인일 2026-10-23). 다만 실제 웹 설정 「음성 스타일」 화면에는 방식 선택이 보이지 않았다 — 본문에 "도움말 기준"임을 밝힌다 |

## 해석

1. **정답 오류는 발견되지 않았다.** 379문제 중 377문제는 세 모델 모두(또는 답을 낸 모델 모두) 우리 정답과 같았다.
2. **틀린 2문제는 모두 모델의 지식이 서비스 변경을 따라가지 못한 경우다.** 1단계 1장에서 설명한 「지식 컷오프」가 실제로 드러난 사례로, 서비스별 문제는 모델이 아니라 공식 문서와 실제 화면으로 검증해야 한다는 근거가 된다.
3. **이 결과는 사람에게 쉬운 문제라는 뜻이 아니다.** LLM 은 AI·LLM 지식을 이미 많이 학습했으므로 전문가 레벨까지 거의 다 맞힌다. 이 검증으로 알 수 있는 것은 「정답이 하나로 분명하고 널리 알려진 지식과 어긋나지 않는다」는 것이고, **초보자에게 얼마나 어려운지(난이도·변별력)는 따로 사람 대상 시험으로 재야 한다.**

## 다음에 할 일

- 문제를 새로 쓰거나 고치면 같은 방법으로 다시 돌린다(묶음당 수 분).
- 실제 수강생 몇 명의 점수 분포로 레벨 기준(60% + 과목 40%)이 적당한지 확인한다.
- 서비스(ChatGPT) 문제는 모델 교차 검증만으로 충분하지 않다 — 공식 도움말·실제 화면 대조를 우선한다.

## 재검증 (2026-10-24, 2단계 퀴즈 52문제)

2단계 퀴즈 보기의 길이 편향(정답이 가장 긴 보기 40% → 15%)을 고친 뒤 Codex·Gemini 로 다시 풀게 했다.

| 묶음 | 문제 | Codex | Gemini |
|---|---|---|---|
| 2단계 퀴즈 | 52 | 94%(무응답 2) | 98% |

- 두 모델이 함께 다르게 고른 문제는 이번에도 `ch109-modes` 하나 — 둘 다 「라이브(Live) 방식」을 골랐다. 도움말(20001274)은 영상·화면 공유가 휴대폰 앱의 고급 방식에만 있다고 하므로 정답 유지. 이름에서 짐작하기 쉬운 오해를 짚는 문제라 9장 본문과 함께 둔다. 단, 웹 「음성 스타일」 화면에서는 방식 선택을 볼 수 없었다(9장에 명시).
