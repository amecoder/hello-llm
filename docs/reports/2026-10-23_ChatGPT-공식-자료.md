# ChatGPT 웹·모바일 앱 공식 자료 사실 확인 (2026-10-23)

## 이 문서의 용도

- `guide/11-chatgpt/`(ChatGPT 웹 서비스·모바일 앱 심화, API 제외)를 쓸 때 근거로 쓰는 **사실 확인 리포트**다. 본문에는 이 문서에서 **VERIFIED** 로 표시한 값만 옮긴다.
- 앞선 검색 단계(검색 결과 요약만 본 단계)에서 나온 주장들을 하나씩 공식 원문과 대조했다.
- **확인 방법**: OpenAI 도움말 센터(help.openai.com)는 WebFetch 를 막아서, Playwright(브라우저 자동화 도구)로 실제 페이지를 열어 본문 텍스트를 저장한 뒤 읽었다. 영어판(`/en/`)을 기준으로 삼고, 한국어 화면 표기는 한국어판(`/ko-kr/`)에서 따왔다. **확인일은 모두 2026-10-23.**
- **표기 약속**
  - `HC/숫자` = `https://help.openai.com/en/articles/숫자` (예: `HC/8914046`). 한국어판은 `/en/` 을 `/ko-kr/` 로 바꾸면 된다.
  - `RN` = ChatGPT 릴리스 노트 `HC/6825453`, `MRN` = 모델 릴리스 노트 `HC/9624314`, `요금` = `https://openai.com/chatgpt/pricing`
  - 상태: **VERIFIED** = 공식 페이지에서 직접 읽음 / **CORRECTED** = 앞선 주장이 틀렸거나 빠진 게 있어 고침 / **UNVERIFIED** = 공식 페이지에서 찾지 못함
- **주의 1 — 한국어판은 번역이 늦다.** 예: 한국어 「ChatGPT 홈 페이지」는 "기본적으로 채팅은 모델 학습에 사용됩니다"라고 쓰지만, 같은 날 영어판은 "지역과 설정에 따라 다르다"로 바뀌어 있다. **내용은 영어판, 메뉴 이름만 한국어판**을 따른다.
- **주의 2 — 요금 페이지는 접속 국가에 맞춰 바뀐다.** 영어(en-US) 주소로 열어도 한국에서 열면 원화(₩)가 나온다. 그래서 미국 달러 가격 일부는 확인하지 못했다.
- **주의 3 — 도움말 문서끼리 어긋나는 곳이 있다.** 아래 표에 「충돌」로 따로 적었다. 이런 내용은 가이드에 단정해서 쓰지 않는다.

## 결론 — 가이드에 꼭 반영할 10가지

1. **요금제는 Free · Go · Plus · Pro(100/200/500 달러 3단계) · Business · Enterprise · Edu.** 한국 요금 페이지 기준으로 Go ₩13,000, Plus ₩29,000, Pro ₩159,000부터(월). Business 는 예전 Team 이 2025-08-29 에 이름을 바꾼 것이다.
2. **광고는 Free·Go 에서만 나올 수 있고**, Plus 이상과 임시 채팅에는 나오지 않는다. 다만 한국에서 광고 시험이 시작됐는지는 공식 페이지에서 확인하지 못했다.
3. **한국은 지원 국가**이고, 계정 없이(로그아웃 상태로) 대화 1개를 쓸 수 있다. 하지만 기록은 저장되지 않는다.
4. **2026-07-09 「ChatGPT Work」가 나오면서 화면이 Chat / Work 로 나뉘었다.** 예전 「에이전트 모드(agent)」는 **이제 쓸 수 없다**("ChatGPT agent is no longer available"). 같은 날 앱 디렉터리가 **플러그인 디렉터리**로 바뀌었고, 그룹 채팅은 새로 만들 수 없게 됐다.
5. **모델 선택은 "모델 이름"보다 "생각 수준"으로 바뀌었다.** 유료 사용자의 모델 메뉴에는 GPT-6 가 보이고 Instant · Medium · High · Extra High · Pro 수준을 고른다. Free·Go 사용자는 대신 「생각하기(Think)」를 쓴다. Free·Go 의 실제 모델 이름은 문서끼리 어긋난다(아래 「충돌」 참고).
6. **삭제한 채팅은 되돌릴 수 없고 30일 안에 영구 삭제되도록 예약된다.** 보관(Archive)은 사이드바에서만 숨기고 지우지 않는다.
7. **임시 채팅**은 기록에 남지 않고, 임시 상태인 동안 모델 학습에 쓰이지 않으며, 안전 목적으로 최대 30일 보관될 수 있다. 시작 전에 「개인 맞춤형 / 개인 맞춤 미적용」을 고를 수 있다.
8. **잠긴 대화(Locked chats, 2026-10-20)** 는 4자리 계정 PIN 으로 여는 숨김 기능이다. 암호화 금고가 아니고, **PIN 을 재설정하면 잠긴 대화가 전부 영구 삭제**된다.
9. **파일 한도**: 파일 하나 512MB, 문서는 파일당 200만 토큰, 이미지 20MB, 3시간에 80개. **Free 는 하루 3개까지만 업로드**할 수 있다(앞선 단계에서 빠진 값). 오디오 업로드는 유료 전용이다.
10. **맞춤형 GPT(custom GPTs)는 2026-12-11 에 종료**되고 플러그인으로 옮겨 간다. 캔버스(canvas)도 최신 모델에서는 빠졌다. 두 기능은 가이드에서 새로 가르치지 않는다.
