# 번역 도구 (2026-11-01, 영어·일본어판을 만들 때 쓴 것)

사이트(`/en/`, `/ja/`)를 만들 때 쓴 스크립트다. 원래 세션 작업 폴더(scratchpad)에서 돌렸기 때문에
**파일 안의 절대 경로 `S=/private/tmp/...` 와 `I=...` 를 실행 전에 이 폴더 경로로 바꿔야 한다.**

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `trl.sh <언어> <원문 경로>` | agy로 한국어 페이지 하나를 번역하고 `check.py` 로 구조를 대조, 실패하면 한 번 더 |
| 2 | `check.py <원문> <번역>` | 제목 수·각주·컴포넌트·링크·그림·영어 인용이 원문과 같은지 |
| 3 | `export-stage.ts`·`export-exams.ts` | 퀴즈·시험 문제를 `<묶음>-ko.json` 으로 내보내기 |
| 4 | `trq3.py <언어> <묶음>` | 문제 JSON을 25개씩 번역, 한국어가 남은 항목은 다시 번역 |
| 5 | `bal3.py <언어> <묶음>` (`bal-pick.ts` 사용) | 정답이 가장 긴/짧은 보기가 되지 않게 보기 길이 조정 |
| 6 | `bias-any.ts <파일...>` | 정답이 가장 긴/짧은 보기인 문제 수 측정 (기준: 각 40% 이하) |
| 7 | `en-fix.ts <저장소> <언어>` | 번역 페이지의 한국어 절 앵커를 번역 앵커로, 번역 없는 페이지 링크는 한국어 페이지로 |
| 8 | `en-post.py`·`en-img.py <저장소> <언어>` | 용어표의 한글 발음 열 정리, 그림 경로를 한국어 페이지의 assets 로 |
| 9 | `sidebar.py <저장소> <언어> <단계이름.json> <목차 이름> <폴더...>` | config 의 `// sidebar:<언어>` 자리에 사이드바 생성 |
| 10 | `gen-lang.py <저장소> <언어> [묶음,…]` | `theme/translations/<언어>/` 생성·등록 |
| 11 | `numdiff.py <저장소> <번역 폴더> <경로...>` | 원문과 번역의 숫자(날짜·금액·횟수) 목록 비교 — 「missing」이 있으면 사실이 바뀐 것 |
| 12 | `numdiff-es.py` | 스페인어용 숫자 대조 — 만·억 단위를 풀어 쓴 금액(300만 원 → 3.000.000)과 달 이름을 맞춰 비교 |
| 13 | `add-locale.py <저장소> <locale-<언어>.json>` | 새 언어의 설정 블록·검색 문구·화면 문구 등록(`after` 로 메뉴 순서 지정) |
| 14 | `sync-library.py <저장소> <언어>` · `libmatch.py` | 번역판 프롬프트 모음을 본문 프롬프트와 글자까지 일치 / 일치율 측정 |
| 15 | `make-hant.py` · `fix-anchors-by-position.ts` | 간체 → 번체(OpenCC s2twp) 변환과 앵커 재연결. 간체를 고친 뒤 다시 돌린다 |
| — | `agent-pages.md` | agy 대신 Claude 하위 에이전트에게 페이지 번역을 맡길 때 주는 지시서(LANG·CODE·EXAMPLE 을 바꿔 씀) |

- 번역 규칙(문체·보존할 것·고유명사)은 `rules-<언어>.txt`.
- agy 는 2026-11-01 사용 한도에 걸렸다(약 6.6일 뒤 초기화). 한도 중에는 Claude 하위 에이전트에게 같은 규칙 파일을 주고 번역시켰다.
- 번역 에이전트는 금액(원→엔)·지명(서울→도쿄)을 현지화하는 버릇이 있다(일본어 2단계에서 5곳). 지시서에 금지 조항을 넣고 `numdiff.py` 로 확인한다.
- 번역 뒤에는 반드시 `npm test`(언어별 번역 테스트)와 `npm run docs:build` 를 돌리고, 정답 보기 한국어↔번역 표본을 직접 읽어 뜻을 대조한다.
