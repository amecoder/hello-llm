# Stage 2 · ChatGPT User Guide

In Stage 1, you learned **how to ask good questions** that work with any AI. In Stage 2, you will learn **the screens and features of ChatGPT itself**.
You will see where the buttons are, how to organize your chats, and how your information is used.

> **The screens in this guide are based on the October 2026 web version (Korean UI, Plus plan).** ChatGPT changes its menu names and features often.
> If your screen looks different, follow the names you see on your screen, and check the official OpenAI Help links in each chapter's footnotes for the latest updates.
