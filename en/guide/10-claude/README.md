# Stage 2 · Claude User Guide

In Stage 1, you learned **how to ask good questions** that work with any AI. In Stage 2, you will learn **the screen and features of the Claude service**.
This includes where the buttons are, how to organize your chats, and how your information is used.

> **This guide is based on the official Anthropic Help Center checked on October 26, 2026.** Claude changes its menu names and features often.
> Right now, a new screen that combines chat and Cowork is rolling out gradually, so your screen might look slightly different from someone else's.
> If your screen looks different, follow the names shown on your screen. You can check the latest details through the official help links in the footnotes of each chapter.
