# 第4階段 · AI-SDLC 指南

SDLC（軟體開發生命週期）是一個想法變成真正能執行的軟體，所要經過的階段。第4階段裡，我們會和第3階段學過的 AI 工具一起，**把一個小網頁從規劃做到釋出、改進**。
不懂程式碼也沒關係。這個階段要學的不是怎麼寫程式碼，而是**交給 AI 什麼，又拿回什麼來確認**。

> **本指南依據 2026年11月1日確認的 GitHub、Claude Code 官方文件，以及 spec-kit、OpenSpec 倉庫裡的說明寫成。** 功能和畫面名稱經常變化。
> 有 GitHub 免費賬號就夠了。AI 工具直接用第3階段用過的（Claude Code、Codex、Antigravity）。
