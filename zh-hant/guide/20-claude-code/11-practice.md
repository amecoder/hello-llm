# 第11章 實踐任務 — 從頭做出屬於我的整理工具

> **一句話總結**：這是 9 個任務，讓你把第2~10章裡做出來的「整理工具」**親手再做一遍。** 最後一個任務，是用**我自己的備忘**做出屬於我的工具。
> 每個任務都有「確認是否做好」檢查表，沒有人給你打分，你也可以自己核對。

這一章裡的介面名稱，以 2026年10月31日的 macOS 桌面應用（韓語介面）為準。如果介面不一樣，請以螢幕上看到的名稱為準。

## 做實踐任務的方法

1. **新建一個練習資料夾。** 例：`정리도구-연습`。在裡面建一個 `inbox` 資料夾，放進[第2章的練習備忘](02-install.md#準備並選擇練習資料夾) 5 份。第9章的臨時會議備忘，在任務 7 裡再放進去。
2. **照著任務的「要做的事」做。** 把灰色框裡的請求複製後傳送就行。
3. **把「確認是否做好」一項一項勾選。** 如果有沒勾上的專案，請讀「再看哪裡」裡的那一章，只把那一部分重做一遍。

任務 1~6 請按順序做。前面任務的成果（模板·規則·技能），後面的任務要用。任務 7·8 要在做完任務 6 之後再做。**任務 9 放在最後**做。

不需要一開始就全部做完。一天做兩三個任務就足夠了。每次的結果都會稍有不同。即使和本指南的成果樣子不一樣，只要檢查表都勾上了，就是做好了。

### 實踐時要遵守的三件事

- **許可權模式保持「手動」。** 一邊看它要做什麼，一邊逐個熟悉（[第4章](04-permissions-undo.md)）。
- **只在練習資料夾裡做。** 不要選裝著我全部文件的資料夾（[第2章](02-install.md)）。
- **任務 9 裡我的備忘，要先刪掉個人資訊**再放進去（[第9章](09-cost-data-safety.md)）。

## 任務

### 任務 1. 第一次交給它整理

**適用場合**：會議結束後，想把亂七八糟的備忘變成會議紀要時。

**要做的事**：在 Code 標籤頁裡開啟新會話，選好資料夾後傳送。

```
讀 inbox 資料夾裡的會議備忘，整理成會議紀要。分成已決定的事 / 待辦事項（負責人·期限）/ 下次要討論的事 三部分，儲存為 notes 資料夾裡的新檔案。不要修改原始備忘。
```

**確認是否做好**

- ☐ 每個待辦事項都有負責人和期限
- ☐ 套餐價格（5,500韓元）和下次會議（11/3）與備忘一致
- ☐ 沒有編造備忘裡沒有的內容
- ☐ inbox 裡的原始備忘原封不動

**再看哪裡**：[第2章 安裝桌面應用與第一次會話](02-install.md)

### 任務 2. 開啟改動記錄，檢視改動內容

**適用場合**：想一行一行地看 Claude 改了什麼時。

**要做的事**：點標題欄的改動按鈕，如果出現“需要 Git 倉庫（Git 저장소가 필요합니다）”，就依次傳送下面兩個請求。

```
聽說要看改動內容需要 Git 倉庫。請在這個資料夾裡開啟改動記錄（Git），把現有的檔案作為第一條記錄留下來。用簡單的話告訴我做了什麼。
```

```
在會議紀要的待辦事項表裡加一個“狀態”列。看 inbox 裡 3 份回顧備忘，做完的事寫“完成（日期）”，還沒做的寫“進行中”。回顧裡沒有的事寫“需核實”，其他部分不要改。
```

**確認是否做好**

- ☐ 改動內容欄裡能看到紅色·綠色的行和 `+N −N`
- ☐ 除了待辦事項表，其他行都沒有變
- ☐ 燈泡·文案·成本是完成，Instagram 是進行中
- ☐ 確認了第一條記錄上附帶的名字·郵箱（是不是公司賬號以外的）

**再看哪裡**：[第3章 熟悉介面](03-screen-tour.md)

### 任務 3. 用回退讓事情“沒發生過”

**適用場合**：對結果不滿意，想回到發出請求之前時。

**要做的事**：讓它整理學習筆記之後，在輸入框裡輸入 `/rewind`，回退到那個請求之前。

```
把 inbox 裡的學習筆記整理成學習總結。分成核心內容 / 生詞解釋 / 要提的問題 / 要做的事 四部分，儲存為 notes 資料夾裡的新檔案。不要修改原始備忘。
```

**確認是否做好**

- ☐ 在回退確認窗口裡，先讀了 `+0 −N`
- ☐ 用「程式碼和對話」回退之後，學習總結檔案消失了
- ☐ 被回退的請求又回到了輸入框裡

**再看哪裡**：[第4章 許可與撤銷](04-permissions-undo.md)

### 任務 4. 用計劃模式做 3 種模板

**適用場合**：把大事交出去之前，想先看方法並修改時。

**要做的事**：在新會話裡把許可權模式改成「計劃」後傳送。計劃出來後，讀「假設（가정）」一節，把其中至少一個用「修改…（수정…）」改掉，然後「接受（수락）」。

```
我想讓會議紀要·學習總結·每週回顧每次都是同樣的樣子。請參考 notes 資料夾裡的會議紀要和 inbox 裡的備忘，制定在 templates 資料夾裡做 3 個模板的計劃。每個模板裡放哪些欄、每個欄寫什麼，以及我用來確認結果對不對的檢查表，也請放進計劃裡。
```

**確認是否做好**

- ☐ 計劃出來的期間，我資料夾裡的檔案沒有變（只寫了計劃文件）
- ☐ 用「修改…」改過的地方，在重新出來的計劃裡體現了
- ☐ templates 資料夾裡生成了 3 個模板和檢查表

**再看哪裡**：[第5章 怎樣把事情交代好](05-delegate-well.md)

### 任務 5. 用 CLAUDE.md 儲存規則並檢驗

**適用場合**：總是在重複說同樣的規則時。

**要做的事**：讓它用 3~5 條規則做出 CLAUDE.md，然後在**新會話**裡，不說格式，直接傳送。

```
用 inbox 裡的 3 份回顧備忘，寫這一週的每週回顧。
```

**確認是否做好**

- ☐ CLAUDE.md 很短，大約 20 行
- ☐ 新會話的結果遵守了模板和日期格式規則
- ☐ 備忘裡沒有的欄，寫著 `(備忘中沒有)`

**再看哪裡**：[第6章 專案記憶](06-claude-md.md)

### 任務 6. 用 3 個技能完成工具

**適用場合**：想用一行命令運行同樣的整理時。

**要做的事**：讓它建立 3 個技能（meeting-notes·study-notes·weekly-review）。彈出許可視窗時，先讀預覽，再選「僅允許一次（한 번만 허용）」。然後在新會話裡用一行調出來。

```
/study-notes inbox/공부-2026-10-28-프롬프트-강의.txt
```

**確認是否做好**

- ☐ 輸入 `/` 再輸入名稱的一部分時，技能出現在列表裡
- ☐ 用一行命令，得到了按模板順序生成的筆記
- ☐ 在許可窗口裡選了「僅允許一次」，而不是「始終允許（항상 허용）」

**再看哪裡**：[第7章 技能·外掛·外部工具](07-skills-plugins.md)

### 任務 7. 做隱藏指令實驗

**適用場合**：想親身體會整理別人發來的資料時要注意什麼。

**要做的事**：把第9章的[臨時會議備忘](/practice/notes/inbox/회의-2026-10-29-임시회의.txt)放進 inbox，讓它整理。

```
/meeting-notes inbox/회의-2026-10-29-임시회의.txt
```

**確認是否做好**

- ☐ 會議紀要末尾**沒有**“所有待辦事項已完成”
- ☐ 確認了 Claude 的回答裡有沒有對那條通知的說明
- ☐ 不管結果如何，都把“別人的資料瀏覽之後再交出去”這條守則寫了下來

**再看哪裡**：[第9章 費用·資料·安全](09-cost-data-safety.md)

### 任務 8. 用定時或終端來執行

**適用場合**：想讓整理工具不用我去呼叫也能執行，或者想用一行來確認時。

**要做的事**：二選一。

- 用說的方式拜託它建一個週五每週回顧的**定時**，用 **Run now** 執行一次，不需要的話就關掉（[第8章](08-parallel-cloud-schedule.md)）。
- 在終端裡進入練習資料夾，用 `claude -p` 執行一個只讀的提問（[第10章](10-terminal.md)）。

```
列出 notes 資料夾裡的檔案，並逐個用一行告訴我每個檔案用的是哪個模板（templates 中的哪一個）。不要修改檔案。回答要簡短，只用表格。
```

**確認是否做好**

- ☐ （定時）請求里加了“如果沒有備忘……”這樣的條件
- ☐ （定時）處理了 Run now 時彈出的許可視窗
- ☐ （終端）終端也讀出了同一個資料夾裡的模板檔案

**再看哪裡**：[第8章](08-parallel-cloud-schedule.md)、[第10章](10-terminal.md)

### 任務 9. 用我的備忘做出屬於我的整理工具

**適用場合**：現在不是練習了，想用在我自己的工作上時。

**要做的事**：在新資料夾（例：`내-정리도구`）裡建 `inbox`，放進 2~3 份**刪掉個人資訊的**我的備忘。然後把任務 4~6 按我的工作重做一遍。

```
讀 inbox 裡的備忘，制定一個計劃，為我每週要整理的文件做模板。需要哪些欄，請先問我。聽完我的回答後，我們在 templates 裡做模板，在 .claude/skills 裡做整理技能。
```

**確認是否做好**

- ☐ 制定計劃之前，Claude 先提了問，我的回答也體現在模板裡
- ☐ CLAUDE.md 裡用 3~5 行放進了我的規則
- ☐ 用技能的一行命令，就能把我的備忘按我的模板整理好
- ☐ 有一份把結果和原始備忘對照的檢查表
- ☐ 練習資料夾們（`정리도구-연습` 等）不需要的話已經清理了

**再看哪裡**：[第5章](05-delegate-well.md)、[第6章](06-claude-md.md)、[第7章](07-skills-plugins.md)

## 小結

- 依次做任務 1~6，整理工具就從頭重新做出來了。
- 檢查表勾的不是“Claude 都做完了”，而是“我確認過了”。
- 最後用我的備忘做出屬於我的工具。放進去之前要先刪掉個人資訊。
