# 第12章 像專家一樣使用——選功能、積累、檢查

> **一句話總結**：用得好，靠的不只是多認識幾個按鈕。靠的是這種能力：**按事情選合適的功能，把重複的東西積累下來，並按事情的分量檢查結果**。
> 本章講的是，如何把第1～11章學到的 Gemini 功能，按你的事情**組合起來使用**。

本章幾乎不講新功能。主題是：前面章節學到的 Gemini 功能，什麼時候用、怎麼用。

怎麼判斷該交給它什麼、交出去之前怎麼拿已知答案的事來測試這類**對任何 AI 都管用的方法**，在[第1階段第11章「像專家一樣使用」](../00-common/11-expert.md)裡。先讀過那一章，這一章會更容易。本章只是把那些方法對應到 Gemini 的功能和選單上。

## 按事情選合適的功能

別先挑選單。先看看眼前的事情是什麼樣子。這樣，該用的功能自然就定下來了（[第1階段第11章「先看事情的樣子」](../00-common/11-expert.md#先看事情的樣子)）。

| 如果是這樣的事 | 就用這個 | 詳見 |
|---|---|---|
| 提問、潤色、一起想 | 普通對話 | [第1階段](../00-common/) |
| 需要仔細推敲 | 調高模型按鈕裡的思考等級 | [第2章](02-screen-tour.md#模型按鈕-—-模型和思考級別) |
| 不想留下記錄的提問 | 臨時聊天 | [第2章](02-screen-tour.md#臨時聊天-—-不留記錄的對話) |
| 一起修改文件或小應用 | Canvas | [第4章](04-files-create.md#canvas-—-一起修改文件和應用) |
| 收集大量資料寫成報告 | Deep Research | [第6章](06-search.md#deep-research——拿到長篇調查報告) |
| 長期收集同一個主題的資料 | 筆記本 | [第6章](06-search.md#筆記本——按主題收集資料和對話) |
| 總是重複同樣的請求 | 技能 | [第7章](07-skills-apps.md#技能-—-把常做的請求儲存起來) |
| 在我的郵件、檔案裡查詢 | 已連線的應用 | [第7章](07-skills-apps.md#已連線的應用-—-在-gemini-裡用-gmail·drive·日曆) |
| 經過多個步驟，最後拿到成果 | 任務（付費） | [第8章](08-tasks.md#任務——不是聊天-而是把整件事交出去) |
| 每到固定時間就重複 | 日程 | [第8章](08-tasks.md#在定好的時間自動執行——日程) |

這張表是把前面各章的內容集中到一處。

大部分情況下，最上面一行，也就是普通對話，一個就夠了。越往下，用量花得越多（Deep Research、任務），或者交出去的個人資訊越多（已連線的應用、任務）。**只在真的需要時，才往下走一行。**

## 把重複的事積累下來

用著用著，你會發現自己總在重複同樣的話。把重複的東西寫下來一次，以後 Gemini 一開始就知道了。

能放的地方有四個。不必一開始就全用。按下面的順序，等需要了再加一個。什麼時候不該做成模板，在[第1階段第11章「把重複的事積累下來」](../00-common/11-expert.md#把重複的事積累下來)裡。

1. **所有對話都提同樣的請求** → 寫進「Gemini 請求事項（Gemini 요청 사항）」裡，作為指令（[第5章](05-memory.md#指令-—-不用每次都說)）。
2. **要不斷翻看同一個主題的資料** → 把這些資料收進筆記本（[第6章](06-search.md#筆記本——按主題收集資料和對話)）。
3. **每次都要解釋同樣的順序** → 把這個順序做成技能（[第7章](07-skills-apps.md#怎樣寫好技能)）。
4. **每到固定時間就做同樣的事** → 設定日程（[第8章](08-tasks.md#在定好的時間自動執行——日程)）。

指令和技能分不清的話，請這樣記。**指令是一直遵守的規則，技能是隻在合適的情境下才拿出來用的步驟。** Gemini 會看技能的名稱和說明，來判斷現在要不要用。[^write]

### 把做好的技能開關對比一下

對做好的技能，請把同一個請求發兩次來對比。一次開著技能，一次用「停用（비활성화）」關掉。[^skills] 對比和修改的要領，在[第1階段第11章「把做好的模板測試一下再修改」](../00-common/11-expert.md#把做好的模板測試一下再修改)裡。

對比的時候，請問問自己。

- 開著技能的回答，是不是更接近我想要的樣子？
- 在不需要技能的問題裡，技能有沒有插進來搗亂？

如果會插進來，就把技能說明裡**什麼時候用**寫得更窄一些（[第7章](07-skills-apps.md#寫名稱·說明·指令)）。

## 把表格和數字交給它

上傳表格檔案，Gemini 會幫你分析並畫圖表（[第4章](04-files-create.md#上傳檔案)）。

```
附件的表是附近小店過去三個月按品類記錄的銷售情況。請按品類算出合計，按從大到小的順序做成表格，並畫一張柱狀圖。
再用一行一行的文字寫出計算用的方法。
```

像最後一行那樣，**讓它同時寫出計算方法**，就更容易找出哪裡錯了。

做數字分析，最讓人擔心的是結果能不能信。請先用**已經算好的過去的資料**對一下。在你知道答案的資料上能對上，以後再交新資料時，就能多信幾分。方法和例子在[第1階段第11章「把表格和數字交給它」](../00-common/11-expert.md#把表格和數字交給它)裡。
重要的計算，請用電子表格或手算再確認一遍。把表格用「匯出到 Sheets（Sheets로 내보내기）」轉過去，就可以馬上重新計算（[第3章](03-chats.md#匯出到其他應用)）。

## 按事情的分量檢查

不用把所有回答檢查到同樣的程度。**錯了會損失得越大**，就看得越仔細（[第1階段第11章「按事情的分量檢查」](../00-common/11-expert.md#按事情的分量檢查)）。

| 事情的分量 | 例子 | 這樣檢查 |
|---|---|---|
| 輕 | 推薦晚飯選單 | 讀一遍，覺得怪就跳過 |
| 中 | 聚會通知 | 只把日期、場地、金額和原件對一下 |
| 重 | 合同、健康、錢 | 打開出處看，再請專家確認 |

把這份指南里學過的檢查工具再彙總一下，就是這樣。

- 打開回答下面的**「來源」**，和原文對一對（[第6章](06-search.md#核實回答的依據)）。
- 已連線應用給出的回答，要開啟**原來的郵件、檔案**看看（[第7章](07-skills-apps.md#好好提問的要領)）。
- 任務要仔細讀**徵求許可的介面**，並看著它執行（[第8章](08-tasks.md#交出去之前——安全守則)）。
- 醫療、法律、金融方面的判斷，不要交給 Gemini（[第9章](09-privacy.md#不能做的事-不能輕信的事)）。

## 親自動手試試

1. 想出這周做過的三件事，在上面的「按事情選合適的功能」表裡，分別找出它們屬於哪一行。
2. 找出過去一週裡你對 Gemini 提過兩次以上的請求，決定是放進指令，還是做成技能。
3. 把第7章做的技能開著發一次、關著發一次同樣的請求，對比結果。
4. 上傳一份你已經知道合計的家庭賬本表，讓它重新計算合計，看是否和你知道的數值相同。

**連續任務**（[籌備讀書會](../00-common/practice-kit.md)）：上傳作業裡的賬本檔案，讓它算出會費合計。確認是否和作業說明裡寫的合計一致；不一致的話，到 Gemini 寫出的計算方法裡找一找哪裡錯了。

## 小結

- 先看事情的樣子，再看選單。大部分情況下普通對話就夠了，只在需要時才下到 Deep Research、任務這樣的功能。
- 重複的東西，按指令 → 筆記本 → 技能 → 日程的順序，等需要了再一個一個積累。
- 指令是一直遵守的規則，技能是隻在合適的情境下才用的步驟。做好的技能要開關對比一下。
- 表格和數字，要讓它同時寫出計算方法，並先用已知答案的資料對一遍。
- 檢查按事情的分量來做。重要的事要打開出處，並請專家確認。
