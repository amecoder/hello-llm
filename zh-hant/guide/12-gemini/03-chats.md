# 第3章 對話管理 — 查詢·整理·分享·匯出

> **一句話總結**：過去的對話，可以在側邊選單裡**查詢、置頂、改名、刪除。**
> 要給別人看時，用**分享連結**；要搬到文件或郵件裡時，用**匯出**。只有一點一定要記住：分享連結是拿到連結的任何人都能讀。

介面以 2026年10月的網頁版為準，截圖是付費套餐（Google AI Pro）的韓語介面。手機應用裡選單的位置可能略有不同。

## 查詢過去的對話

過去的對話都集中在左側側邊選單的對話列表裡（[第2章](02-screen-tour.md)）。[^recent]
對話多了，往下翻列表就很難找。這時請點側邊選單上方的「搜尋聊天（채팅 검색）」（放大鏡），輸入要找的詞，再按 Enter。[^recent][^screen]

比如上週問過醃泡菜的材料，就用“醃泡菜”來搜。搜尋欄會單獨在螢幕上方開啟。[^screen]

**個人賬號必須開啟「儲存活動記錄（활동 기록 보관）」，才能使用對話的查詢·置頂·改名·刪除。**[^recent]
「儲存活動記錄」是把我的對話儲存在賬號裡的設定。年滿 18 週歲的話，一開始就是開著的。它在點「設定（설정）」→「活動（활동）」後開啟的「Gemini 應用活動（Gemini 앱 활동）」頁面裡。怎麼關、關了之後有什麼變化，在[第9章](09-privacy.md#開啟和關閉「保留活動記錄」)裡講。[^activity]

公司·學校賬號由管理員管理記錄。這時我不能刪除對話。[^recent]

## 置頂·改名·刪除

經常開啟的對話，請**置頂**。在對話列表裡把滑鼠移到那個對話上，右側會出現三個點（⋮）。點它就會開啟對話選單。[^recent][^screen]

![在側邊選單對話列表裡，點「[練習] 讀書會準備物品」對話右邊的三個點（①）後開啟的選單（②）— 「分享對話」「置頂」「重新命名」「新增到筆記本」「刪除」。其他對話標題是改成示例的介面](../../../guide/12-gemini/assets/shot-08-chat-menu-marked.png)

這是用練習用的對話截的圖，其他對話標題是改成示例的介面。點 ① 三個點，就會開啟 ② 選單。[^screen]

| 選單 | 作用 |
|---|---|
| 「置頂（고정）」 | 把對話固定在列表最上面（置頂之後變成「取消置頂（고정 해제）」） |
| 「重新命名（이름 변경）」 | 修改對話標題 |
| 「刪除（삭제）」 | 刪除對話 |
| 「分享對話（대화 공유）」 | 生成公開連結（見下面的“分享對話”） |
| 「新增到筆記本（노트북에 추가）」 | 把對話收進筆記本（筆記本在第6章） |

出處：Google 幫助文件和實際介面[^recent][^screen]

如果對話是開啟的，在右上角的三個點按鈕（讀屏名稱「開啟對話操作選單（대화 작업 메뉴 열기）」）裡，也可以做同樣的事。[^screen]

![點對話介面右上角三個點按鈕（①，「開啟對話操作選單」）後開啟的選單（②）— 「分享對話」「置頂」「重新命名」「下載 PDF」「匯出到 Docs」「新增到筆記本」「刪除」](../../../guide/12-gemini/assets/shot-09-top-menu-marked.png)

這個選單（②）裡還有側邊選單裡沒有的「下載 PDF（PDF 다운로드）」和「匯出到 Docs（Docs로 내보내기）」。[^screen]

把標題改成像“11月讀書會通知”這樣**帶有日期或事情名稱的標題**，在列表裡就更容易認出來。

**刪除之前有兩點要知道。**[^recent]

- **刪除對話，「Gemini 應用活動」裡也會一起被刪掉。** 它也會從我的對話記錄裡消失。
- **在那場對話裡做出的東西也會一起被刪掉。** 用 Canvas 做的文件或應用這類成果會一起消失（Canvas 在[第4章](04-files-create.md)）。

所以，如果那場對話裡做出的文件還要繼續用，請在刪除之前，先用[匯出](#匯出到其他應用)搬出來。

## 把對話分叉後繼續 — 分支

在一場很長的對話中間，有時你會**想往另一個方向試一試。** 比如在排旅行日程時，想單獨問一句“要是下雨怎麼辦？”。

這時請點那個位置的答案下方的「更多選項（옵션 더보기）」（三個點），選擇「在新聊天中建立分支（새 채팅에서 브랜치 생성）」。[^screen][^recent] 一場從那個位置分叉出來的**新對話**就會開啟。原來的對話原樣保留，以後可以回來接著聊。[^recent]

![點答案下方工具欄（①：「回答不錯」「回答不好」「重新執行」「複製」「更多選項」）裡的「更多選項」後開啟的選單。紅色編號標出：② 「在新聊天中建立分支」，③ 「匯出到 Docs」「在 Gmail 中起草」。此外還有「朗讀」「舉報法律問題」「顯示思考步驟」](../../../guide/12-gemini/assets/shot-10-answer-menu-marked.png)

點答案下方工具欄最右邊的三個點，選單就會開啟。② 是分支，③ 會在下面的“匯出到其他應用”裡用到。[^screen]

分支之後，原來的對話不會被旁枝末節的提問弄亂。這是在不丟失前面內容的情況下，實現[第1階段第6章](../00-common/06-conversation.md)裡學過的“話題變了就開新對話”的辦法。

**兩者是分開刪除的。** 刪除分叉出來的對話，原來的對話還在；刪除原來的對話，分叉出來的對話也還在。[^recent]

## 分享對話 — 公開連結

想把對話給別人看，就生成**公開連結**。請在對話選單（側邊選單的三個點，或右上角的三個點）裡選擇「分享對話」。上面的對話選單截圖裡有。[^screen] 連結（g.co/gemini/share/…）就生成了。[^share]

**拿到連結的任何人都可以讀這場對話。** 即使不是我親自發過去的人，只要有連結就能讀，還能再傳出去。[^share]
所以分享之前，請把整場對話瀏覽一遍。連結會顯示**整場對話。** 我上傳的照片，收到的人也可以下載。[^share]

需要知道的幾點如下。[^share]

- **不會帶上我的名字。** 連結地址和分享頁面上，不會顯示我的名字或賬號。
- **按生成連結那一刻的樣子顯示。** 之後修改或繼續這場對話，分享頁面也不會變。想讓別人看到修改後的內容，請重新生成連結。
- **做出的成果也會一起顯示。** Canvas 文件、圖片、影片也會進入分享頁面。
- **收到的人可以接著對話。** 開啟連結的人，可以用「繼續這個聊天（이 채팅 계속하기）」接著聊。不過，用 Gem 做的對話和未滿 18 週歲的人不行。另外，**如果是我用 Google AI 付費套餐做的對話，對方也必須是付費套餐**才能接著聊。

### 刪除分享過的連結

想收回分享，請到「設定（설정）」→「我的公開連結（내 공개 링크）」，把那個連結刪掉。也可以用「刪除所有連結（모든 링크 삭제）」一次全部刪掉。[^share][^screen]

即使刪了連結，也有些東西會留下。[^share]

- **發在其他地方的帖子照舊。** 把連結貼在論壇或聊天軟體裡的帖子，要到那裡另外刪。
- **我的對話不會被刪。** 只是連結消失，對話仍在我的列表裡。

反過來，**刪除對話，那場對話的連結也會一起消失。** 連結只有在對話還儲存在我的記錄裡的期間才能開啟。[^share]

分享之前這樣問一句，有助於找出漏掉的個人資訊。不過，不要相信 AI 能全部找出來，最後還是要自己讀一遍（[第1階段第9章](../00-common/09-safety.md)）。

```
我打算把這場對話分享給別人。請找一找到目前為止的對話裡，有沒有姓名、電話號碼、地址、公司名稱這類
別人看到會讓我為難的資訊，並列成清單告訴我。
```

## 匯出到其他應用

想把答案搬到文件或郵件裡時，請用**匯出**。不用自己複製貼上，新文件或郵件草稿就直接生成了。
點答案下方的「更多選項」（三個點），裡面有「匯出到 Docs」和「在 Gmail 中起草（Gmail 초안 작성）」（上圖的 ③）。[^screen][^export]

| 選單 | 所在位置 | 結果 |
|---|---|---|
| 「匯出到 Docs」 | 答案下方的三個點 | Google Drive 裡生成一份新文件 |
| 「在 Gmail 中起草」 | 答案下方的三個點 | Gmail 裡生成一封新郵件草稿 |
| 「匯出到 Sheets（Sheets로 내보내기）」 | 表格下方的三個點 | 答案裡的表格進入 Google 表格 |

出處：Google 幫助文件和實際介面[^export][^screen]

「匯出到 Sheets」要點表格正下方的小小三個點（…）才會出現。只有帶表格的答案裡才看得到，而且帶圖片的表格不能匯出。[^export][^screen]

![點表格正下方的小小三個點（①）後開啟的選單（②）— 「匯出到 Sheets」「複製」。下面的 ③ 是整個答案的工具欄](../../../guide/12-gemini/assets/shot-11-table-menu-marked.png)

① 表格下方的三個點和 ③ 答案下方的三個點是不同的選單。只想搬表格，就點 ①。[^screen]
「在 Gmail 中起草」需要有 Gmail 賬號。郵件不會直接發出去，而是儲存為**草稿**，所以請確認收件人和內容後，親自發送。[^export]

比如，像下面這樣得到的表格，用「匯出到 Sheets」搬過去，馬上就能排序和修改。

```
把下個月讀書會要準備的東西做成表格。列是準備物品、負責人、預計費用。
不要用其他應用，就在這個聊天裡用表格展示給我。
```

寫第二行是有原因的。本指南只發第一行時，Gemini 沒有在對話裡展示表格。它轉而想連線 Google Sheets，然後停住了。[^screen] 如果想先在對話裡確認表格，請像第二行那樣講清楚。

匯出的文件和郵件，遵循那個服務（Docs·Gmail）的條款和政策。[^export]

## 重新生成答案與核實

如果對答案不滿意，請**重新生成。** 點答案下方的「重新執行（다시 실행）」（圓形箭頭），就會對同一個問題生成新答案。[^screen][^regen] 只能對最近的一個答案這樣做。[^regen]
重新生成之後，可以用答案下方的箭頭來回切換前後的答案並比較。[^regen]

**如果知道哪裡不滿意，就說出來請它修改。** 在對話中繼續，可以請它改變長度、措辭的通俗程度和語氣。[^regen] 如果問題沒問題，只是答案碰巧不好，那「重新執行」是對的（[第1階段第6章](../00-common/06-conversation.md)）。

| 不夠好的請求 | 更好的請求 |
|---|---|
| （一直點「重新執行」） | “縮成三行” |
| （一直點「重新執行」） | “換成小學生也能聽懂的簡單說法” |
| （一直點「重新執行」） | “把語氣改得更鄭重一些” |

說明要改什麼，更容易靠近想要的方向。只點「重新執行」，就沒辦法選擇要變的是什麼。

### 核實出處

如果答案下方或句子之間看到「來源（출처）」按鈕，請點一下。右側會開啟相關連結。[^sources]
連結可能是網站，也可能是我上傳的檔案，或者我連線過的 Gmail·Docs。[^sources]
**並不是每個答案都有來源。** 沒有「來源」按鈕，就說明這個答案沒有連結。[^sources]

Google 也明確說過，Gemini 可能出錯。[^accuracy]

- **不要把它當作醫療·法律·金錢問題上的專家建議。**
- **關於人的答案尤其要再核實。** 可能會出現錯誤的內容。
- **Gemini 對它自己的說明也可能出錯。** 比如，對“你是怎麼訓練的？”或“你是怎麼標註來源的？”的回答，可能和實際不符。如果好奇某個功能，請看本指南或官方幫助文件。

看到錯誤的答案，請點答案下方的「回答不好（대답이 마음에 들지 않아요）」（大拇指向下），寫明哪裡錯了。[^accuracy] 不過，一旦傳送反饋，那場對話也會一起發給 Google（[第1章](01-getting-started.md#用不了的時候先試試這些)）。

## 親手試一試

1. 在新聊天裡發一個簡短的問題，然後在側邊選單裡把那場對話改名為“練習 — 今天的日期”。
2. 把那場對話置頂，再取消置頂。
3. 在「搜尋聊天」裡搜“練習”，確認那場對話有沒有出來。
4. 把一個答案用「匯出到 Docs」搬過去，看看 Google Drive 裡有沒有生成新文件。
5. 生成一個分享連結，然後在「設定」→「我的公開連結」裡把它刪掉。

**連續任務**（[準備讀書會](../00-common/practice-kit.md)）：請它把第2章整理的準備清單做成表格，再用「匯出到 Sheets」搬過去。把對話名稱改成“讀書會準備”。

## 小結

- 過去的對話，用側邊選單列表和「搜尋聊天」來找。個人賬號必須開啟「儲存活動記錄」，才能使用查詢·置頂·改名·刪除。
- 在對話的三個點選單裡做置頂·改名·刪除·分享對話。刪除之後，那場對話裡做出的 Canvas 成果也會一起被刪掉。
- 用答案下方三個點裡的「在新聊天中建立分支」，在對話中間分叉出去，原來的對話也原樣保留。
- 分享連結是拿到連結的任何人都能讀。只顯示生成那一刻的內容。到「設定」→「我的公開連結」裡刪除。
- 用答案下方的三個點搬到 Docs·Gmail 草稿，用表格下方的三個點搬到 Sheets。Gmail 只會儲存為草稿。
- 「重新執行」只能用於最近的答案。很多時候，說明要改什麼、請它修改會更快。
- 用「來源」核實依據，醫療·法律·金錢問題和關於人的答案要再確認。

## 術語整理

| 術語 | 中文名稱 | 一句話解釋 |
|---|---|---|
| Pin | 置頂 | 把對話固定在列表最上面 |
| Branch | 分支 | 從對話中間分叉出來的新對話。介面名稱「在新聊天中建立分支」 |
| Public Link | 公開連結 | 拿到連結的任何人都能讀對話的地址 |
| Export | 匯出 | 把答案搬到 Docs·Gmail·Sheets 這類其他應用 |
| Regenerate | 重新生成 | 對同一個問題重新生成答案。介面名稱「重新執行」 |
| Source | 來源 | 作為答案依據的網頁·檔案連結 |
| Keep Activity | 儲存活動記錄 | 把我的 Gemini 對話儲存在賬號裡的設定 |
