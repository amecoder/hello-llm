# 第11章 實踐課題——親手用一用 Gemini 的功能

> **一句話總結**：把第1～10章裡看過的 Gemini 的畫面和功能，彙總成 10 個**親手點一遍**的課題。
> 每個課題都有「確認有沒有做好」檢查清單，不用別人來打分，你自己就能確認。

畫面以 2026年10月的網頁版為準。Gemini 的選單名稱和位置經常變，如果畫面不一樣，請以畫面上看到的名稱為準。

## 怎樣做實踐課題

1. **開啟 Gemini（gemini.google.com）並登入。** 大部分課題要用到對話記錄和設定。
2. **照著課題裡的「要做的事」做。** 把灰色方框裡的提示詞複製下來傳送就行。
3. **把「確認有沒有做好」一項一項打勾。** 有沒打上勾的專案，就去讀「回頭再看的地方」裡的那一章，只把那部分重新做一遍。

課題不必按順序做。不過，**課題10請放在最後**做。它是用來整理練習留下的痕跡的課題。
課題8裡的「任務（작업）」是 **Google AI Pro、Ultra** 專用的，如果是免費套餐，只做聊天日程就行。其他選單也可能因賬號或套餐而看不到，或者還沒有開放。看不到的話，讀一讀就可以跳過。

關於該怎麼問（怎麼寫提示詞）的練習，在[第1階段第10章實踐課題](../00-common/10-practice.md)裡。這裡請把注意力放在**按鈕和選單**上。

不必一開始就全部做完。每天做兩三個課題就足夠了。

### 做練習時要守的三條

- **儘量在臨時聊天裡做。** 透過右上角的「臨時聊天（임시 채팅）」開啟的對話，不會留在對話列表裡，也不會用於 AI 訓練。不過，會儲存 72 小時（[第2章](02-screen-tour.md#臨時聊天-—-不留記錄的對話)）。[^screen][^hub]
  涉及記錄、技能、日程的課題（3、5、7、8），請在普通聊天裡做。因為在臨時聊天裡，不能重新開啟，也不能改名。
- **資料用假的。** 不要用真實的姓名、聯絡方式、公司資料，請用**我自己編出來的資料**。在普通聊天裡做的練習，在課題10裡整理。不該放進去的資訊，在[第1階段第9章](../00-common/09-safety.md#不要放進去的東西)裡。
- **不要點贊或點踩。** 一發送反饋，即使把「保留活動記錄（활동 기록 보관）」關了，那個對話也會用於改進服務（[第9章](09-privacy.md#會有人閱讀嗎-會用於-ai-訓練嗎)）。[^hub]

## 課題

### 課題1. 用臨時聊天建一個練習空間

**適合什麼時候**：想問一些不想留在記錄裡的問題時。

**要做的事**：點右上角的「臨時聊天」，傳送下面的內容。拿到回答後，點右上角的 × 關閉。

```
我第一次用 Gemini。推薦三個今天適合練習的問題。
```

**確認有沒有做好**

- ☐ 畫面中央出現了"臨時聊天不會顯示在最近的聊天裡……"這樣的提示[^screen]
- ☐ 想留下的回答，在關閉之前已經複製好了（沒有要留的回答就打勾）
- ☐ 關閉後，側邊選單的對話列表裡沒有這個對話

**回頭再看的地方**：[第2章 畫面一覽](02-screen-tour.md)

### 課題2. 在模型按鈕裡改變思考級別

**適合什麼時候**：對難題，想拿到想得更深入的回答時。

**要做的事**：在臨時聊天裡傳送下面的內容，然後在輸入框的模型按鈕裡把思考級別提高一檔，再發送同樣的問題。

```
每月存 30萬韓元、存 2 年，和一開始存入 600萬韓元、放 2 年，有什麼不同？
請把利息計算方式的差別，講到初中生也能聽懂。
```

**確認有沒有做好**

- ☐ 點了模型按鈕，確認了現在在用的模型和思考級別
- ☐ 改變思考級別之後，比較了回答的長度和講解順序有什麼不同
- ☐ 知道了依套餐不同，能選的專案也不同（免費套餐就只確認看得到的專案，然後打勾）

**回頭再看的地方**：[第2章 模型按鈕](02-screen-tour.md#模型按鈕-—-模型和思考級別)

### 課題3. 給對話改名，再找回來

**適合什麼時候**：之後需要重新找以前的對話時。

**要做的事**：在普通聊天裡傳送下面的內容。在側邊選單裡，點這個對話的三個點 →「重新命名（이름 변경）」，把標題改成"[練習] 讀書會準備物品"。然後在「搜尋聊天（채팅 검색）」裡輸入"練習"，找找看。

```
告訴我第一次來讀書會的人，最好準備的五樣東西。
```

**確認有沒有做好**

- ☐ 側邊選單裡的對話標題變成了"[練習] 讀書會準備物品"
- ☐ 透過「搜尋聊天」找到了這個對話
- ☐ 點「固定（고정）」把它釘在了列表最上面，又用「取消固定（고정 해제）」恢復了

**回頭再看的地方**：[第3章 對話管理](03-chats.md)

### 課題4. 上傳假通知，拿回表格

**適合什麼時候**：想整理很長的文件，或者想把它改成另一種樣子時。

**要做的事**：在記事本里寫一份下面這樣的假通知，儲存成檔案。透過輸入框的「+」→「上傳檔案（파일 업로드）」上傳，然後傳送提示詞。

```
11月讀書會通知
日期：11月22日 星期六 下午2點
地點：區立圖書館3樓研討室
閱讀書目：《小婦人》
準備物品：書、記筆記的本子、會費 5,000韓元
```

```
請從上傳的通知裡提取日期、地點、閱讀書目、準備物品，整理成表格。
不要使用其他應用，就在這個聊天裡用表格給我看。
```

**確認有沒有做好**

- ☐ 表格裡的日期、地點、會費，和通知一個字都不差
- ☐ 沒有編造通知裡沒有的內容（例：結束時間）
- ☐ 點了表格正下方的三個點，確認了有「匯出到 Sheets（Sheets로 내보내기）」（不點也可以）

**回頭再看的地方**：[第4章 檔案與創作](04-files-create.md) · [第3章 匯出到其他應用](03-chats.md#匯出到其他應用)

### 課題5. 寫入指示，看看回答會不會變

**適合什麼時候**：嫌每次都提同樣的要求（"簡短一點""做成表格"）太麻煩時。

**要做的事**：在「設定（설정）」→「個人智慧（개인 인텔리전스）」→「Gemini 要求事項（Gemini 요청 사항）」裡，新增下面的指示。在新的普通聊天裡隨便問個問題。

```
在回答的最前面加一行摘要，難懂的詞用括號解釋。
```

**確認有沒有做好**

- ☐ 新聊天的回答最前面加上了一行摘要
- ☐ 在「Gemini 要求事項」畫面裡，看到了我新增的指示
- ☐ 練習結束後，把這條指示刪掉，或者改成適合我的樣子

**回頭再看的地方**：[第5章 記憶與個性化設定](05-memory.md)

### 課題6. 打開出處，修改 Deep Research 計劃

**適合什麼時候**：想確認回答的依據，或者需要彙總許多資料的報告時。

**要做的事**：先發送下面的內容，打開回答裡的「出處（출처）」之一。然後點「+」→「更多工具（도구 더보기）」→「Deep Research」開啟它，傳送同樣的主題，出現計劃後，用「修改計劃（계획 수정）」改成"只用官方統計"。

```
告訴我最近 5 年韓國1人戶的比例是怎麼變化的，並附上出處。
```

**確認有沒有做好**

- ☐ 打開出處連結，看了回答裡的數字和原文是否一致
- ☐ Deep Research 計劃出來之後，用「修改計劃」加上了條件
- ☐ 如果不打算把報告拿到最後，就用暫停按鈕停下來了（Deep Research 很耗用量）

**回頭再看的地方**：[第6章 搜尋與 Deep Research](06-search.md)

### 課題7. 建立技能並呼叫

**適合什麼時候**：經常提同一個要求時。

**要做的事**：在「個性化設定（맞춤설정）」→「技能（스킬）」→「建立（만들기）」→「手動建立（수동으로 만들기）」裡，按下面的樣子建立一個技能。在新聊天裡輸入 `/`，選中這個技能，然後貼上一份假的會議筆記。

```
名稱：summarize-meeting-notes
說明：把會議紀要整理成決定事項、待辦事項、負責人。貼上會議紀要或會議筆記時使用。
指示：收到會議紀要後，按 1. 已決定的事 2. 待辦事項（事項 - 負責人 - 截止日期） 3. 下次還要再看的事 的順序整理。
沒有負責人或截止日期的話，不要編造，寫"需確認"。
```

**確認有沒有做好**

- ☐ 輸入 `/` 時，列表裡出現了我建立的技能（如果變成了 `@`，就用 `@`）
- ☐ 沒有負責人的待辦事項，顯示了"需確認"
- ☐ 練習結束後，用「更多（더보기）」→「停用（비활성화）」或「刪除（삭제）」整理掉了

**回頭再看的地方**：[第7章 技能與已連線的應用](07-skills-apps.md)

### 課題8. 設定日程，再在「已預約」裡刪掉

**適合什麼時候**：想每天、每週收到同樣的訊息時。

**要做的事**：在普通聊天裡傳送下面的內容。在側邊選單的「已預約（예약됨）」裡看看日程有沒有生成，再用「更多」刪掉。如果是付費套餐，也點輸入框下方的「任務」，發一個"幫我問問（물어봐 줘）"試試。聊天日程正在逐步開放，所以也可能還不能用。

```
每週一早上 8 點，把這周首爾的天氣概括成三行。
```

**確認有沒有做好**

- ☐ Gemini 用日程摘要（什麼時候、多久一次）回答了
- ☐ 在「已預約」裡找到了這個日程
- ☐ 練習結束，把日程刪掉了

**回頭再看的地方**：[第8章 交代任務](08-tasks.md)

### 課題9. 在手機上用嘴問

**適合什麼時候**：不方便打字，或者想用嘴練習時。

**要做的事**：在手機上安裝 Gemini 應用，用同一個 Google 賬號登入。點麥克風，說出下面的內容。如果是 Android，也點一下「Live」。

```
告訴我今天晚上，用冰箱裡的雞蛋、豆腐、大蔥能做的三道菜。
```

**確認有沒有做好**

- ☐ 我說的內容變成了文字，問題傳送出去了
- ☐ 電腦網頁的對話列表裡也能看到這個對話（如果是普通聊天的話）
- ☐ 用了 Live 的話，點「結束」之後，看到同一個對話以文字繼續（沒用 Live 就打勾）

**回頭再看的地方**：[第10章 語音與手機](10-voice-mobile.md)

### 課題10. 檢查並整理我的資料設定

**適合什麼時候**：練習結束時，以及每隔幾個月一次。

**要做的事**：開啟左下角的「設定」，按下面的檢查清單確認。

**確認有沒有做好**

- ☐ 在「活動（활동）」裡，「保留活動記錄」設成了我想要的那一邊（開或關）
- ☐ 自動刪除的期限（預設 18 個月），選成了適合我的
- ☐ 在「我的公開連結（내 공개 링크）」裡，把不再需要的連結刪掉了（沒有分享過對話就打勾）
- ☐ 在「個性化設定」→「聯結器（커넥터）」裡，把不需要的已連線應用「斷開連線（연결 해제）」了
- ☐ 刪掉了課題3、4、5、6、7裡做出的練習對話。就算斷開連線或刪除應用資料，對話記錄也還在，所以對話要另外刪除

**回頭再看的地方**：[第9章 個人資訊與安全](09-privacy.md) · [第3章 對話管理](03-chats.md) · [第7章 已連線的應用](07-skills-apps.md#已連線的應用-—-在-gemini-裡用-gmail·drive·日曆)

## 總結

- 功能光讀是不會熟練的。每個按鈕都親手點一遍。
- 練習儘量在臨時聊天裡做，涉及記錄、技能、日程的課題，用假資料在普通聊天裡做。
- 課題8裡的「任務」需要付費套餐。其他選單如果因賬號而看不到，讀一讀就跳過。
- 每個課題都用檢查清單自己確認，沒打上勾的部分，讀一讀「回頭再看的地方」再重做。
- 練習結束後，檢查「保留活動記錄」、自動刪除、公開連結、已連線的應用，並把練習用的對話整理掉。

這一章沒有新出現的術語。臨時聊天、技能、任務這些詞，在各章的「術語整理」裡。
