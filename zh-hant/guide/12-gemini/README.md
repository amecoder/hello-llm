# 第2階段 · Gemini 使用指南

如果說第1階段教你的是適用於任何 AI 的**怎麼問**，那麼第2階段就要熟悉 **Gemini 這項服務的介面和功能**。
比如按鈕在哪裡、怎麼整理對話、你的資訊是怎麼被使用的。

> **本指南依據 2026年10月30日確認的 Google 官方幫助和實際介面編寫。** Gemini 的選單名稱和功能經常變化。
> 截圖是付費套餐（Google AI Pro）的韓語網頁介面，所以免費賬號上可能有些選單看不到，或者處於鎖定狀態。
