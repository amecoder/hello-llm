# 第10章 語音與手機——開口提問，在手機上更快

> **一句話總結**：輸入框裡的**麥克風**，會把你說的話記成文字（聽寫）；**聲波符號**，讓你和 Claude 用說話的方式交流（語音模式）。
> 在手機上，用小元件、快捷指令、鎖屏介面能更快地開啟它，還可以把訊息、郵件草稿直接交給對應的應用。

畫面以 2026年10月的網頁版為準。手機應用和電腦應用的按鈕位置略有不同，設定選單的名稱也可能因畫面而異。

## 聽寫和語音模式

用說話來輸入的功能有兩種。名字很像，但做的事不一樣。[^dictation][^voice]

| | 聽寫（Dictation） | 語音模式（Voice mode） |
|---|---|---|
| 按鈕 | 輸入框右側的**麥克風** | 麥克風旁邊的**聲波符號** |
| 做什麼 | 把我說的話變成文字發出去 | 用嘴問，用耳朵聽 |
| Claude 的回答 | 以文字形式送來 | 以聲音形式送來 |
| 適合什麼時候 | 懶得打一大段問題時 | 手忙著的時候，邊說邊理思路時 |

如果準確的句子很重要，請用**聽寫**。我的問題和回答都會以文字留下，可以再讀。需要來回交談時，請用**語音模式**。

這兩個功能，免費套餐也能用。[^dictation][^voice]

## 試試聽寫

這一節講手機應用（iPhone、安卓）的聽寫。[^dictation] 電腦應用的 Cowork 裡也可以用聽寫。[^voice]

1. 在 Claude 應用裡開啟一個新聊天。
2. 點輸入框右側的**麥克風**。
3. 第一次用時，選擇要說的語言。
4. 像平時一樣說話。
5. 點箭頭髮送。不想傳送的話，點「X」。

請像下面這樣說說看。

```
這個週末，告訴我三個能和小學生孩子在家做的科學實驗。
材料只用廚房裡有的。
```

聽寫支援包括韓語在內的12種語言。英語以外的語言還是測試版（beta）。想換語言，點右上角的首字母，選「語音輸入語言（음성 입력 언어）」。[^dictation]

人名、地名可能會被記錯。傳送之後，請讀一遍聊天窗口裡記下來的我的問題。[^dictation]

### 在 Mac 電腦上——快速輸入

如果在 Mac 上用 Claude 桌面應用，請試試**連按兩下 Option 鍵**。不管你正在用哪個應用，Claude 的輸入框都會馬上開啟。[^quick] 不用中斷手頭的事就能提問。

- 可以拖選螢幕的一部分，作為截圖貼進去，也可以點應用視窗，把裡面的內容一起發過去。[^quick]
- 開啟聽寫快捷鍵後，按 Caps Lock 就能用說話來輸入。一開始它是關著的。[^quick]
- 包括免費套餐在內的所有套餐都可以用，但只限 Mac 桌面應用。應用即使在後臺，也必須處於開啟狀態。[^quick]
- 需要 Mac 的螢幕錄製之類的許可權。在「系統設定 > 隱私與安全性（시스템 설정 > 개인정보 보호 및 보안）」裡確認。[^quick]

看著陌生的表格或錯誤視窗，想馬上提問時，很方便。

```
剛貼上去的畫面裡這些數字，各是什麼意思，用簡單的話給我解釋一下。其中哪些是我需要留意的，也告訴我。
```

## 試試語音模式

語音模式還是**測試版**。網頁、電腦應用、手機應用裡都能用，但它是為了在手機上效果最好而做的。[^voice]

**在網頁、電腦應用上**

先看一下按鈕的位置。輸入框右下角的 ⑧ 處，麥克風（聽寫）和聲波符號（語音模式）並排放著。[^screen]

![Claude 網頁首頁。紅色編號 ①～⑩ 中，⑧ 指向輸入框右下角的麥克風（聽寫）和聲波符號（語音模式）](../../../guide/10-claude/assets/shot-01-home-marked.png)

這是把名字、對話標題換成示例後的畫面（免費套餐）。這一章用到的編號只有 ⑧ 一個。其餘的編號，在[第2章](02-screen-tour.md)裡說明。

1. 開啟一個新聊天。
2. 點聊天視窗右下角的**聲波符號**。
3. 一開口說話，我說的話就會自動出現在輸入框裡。說完後，Claude 會回答。
4. 想結束，點右下角的「停止（중지）」（Stop）。

**在手機應用上**

1. 點輸入框裡麥克風旁邊的**聲波符號**。
2. 挑一個喜歡的聲音。
3. 開始說話。[^voice]

### 兩種聽的方式

- **擴音模式**（hands-free）：一開始就是開著的方式。Claude 一直聽著，我停下話來，它就回答。在安靜的地方效果最好。
- **按鍵說話模式**（push-to-talk）：說話時一直按住按鈕，說完就鬆手。在嘈雜的地方，或者旁邊有別人在說話時，更準確。[^voice]

如果 Claude 往奇怪的方向走了，直接開口說話就行。Claude 會停下來聽。如果有好幾個問題，不要一股腦說完，一個一個地問。[^voice] 一次只問一個，回答也會變短，用耳朵聽就更輕鬆。

很適合開口說的請求。

```
下週我有面試。你來當面試官，一個一個地向我提問。
我回答之後，請簡短地說一個好的地方、一個要改的地方，然後進入下一個問題。
```

::: details 拿到的回答大致是這樣（示例——點選展開）
這是本指南做的示例。實際的回答會因服務和每次的情況而不同。

> 好的，我們開始面試。第一個問題。請您簡單做一下自我介紹，可以嗎？

我回答之後，會這樣接下去。

> 好的地方是，您一開始就清楚地說了應聘的理由。要改的地方是，經歷的故事稍微有點長。請只挑一個例子，簡短地說一說。那麼，第二個問題。工作中最有成就感的時刻是什麼時候？

**請確認有沒有拿對**：它是一次只問一個問題嗎？我回答之後，它是隻簡短地說一個好的地方、一個要改的地方嗎？它有沒有一下子甩出一整串問題？

:::

### 需要知道的幾點

- 語音對話也**計入套餐的用量限額**（[第1章](01-getting-started.md)）。
- 在同一個對話裡，文字和說話來回切換，**前面的內容也是接著的。** 像網址這樣要準確輸入的東西，中途用文字輸入就行。
- 它從文字聊天裡最後用的模型開始，對話中可以更換。不過 Claude Fable 目前還不能在語音模式中使用（2026-10-26 確認）。
- 已連線的工具（Gmail、Google 日曆等）在語音模式裡也能用。語音模式的幫助文件寫道，免費套餐可以連線一個工具。工具連線在[第7章](07-projects-tools.md)講。
- 在新畫面裡，包括 Claude 正在做任務的對話在內，任何對話都可以使用語音模式。[^voice][^cowork-voice-old]

## 更換聲音和語言

Claude 的聲音，只能在固定的幾種裡選。這是為了防止模仿或照搬某個人的聲音。[^voice]

- **網頁、電腦應用**：在「設定（설정）」→「通用（일반）」的「語音（음성）」裡。「語言（언어）」下面還有「風格（스타일）」和「速度（속도）」。[^screen][^voice-settings-name] 點一個聲音，可以先試聽。
- **手機應用**：語音模式中點左下角的設定按鈕，選擇聲音和語速。[^voice]

**要說的語言，需要另外設定。** 就算把應用介面換成韓語，語音語言也不會變。[^voice] 在這個畫面裡，在「設定」→「通用」→「語音」→ ③「語言」裡選。[^screen] 英語以外的語言是測試版。對話中請它"用韓語說"也可以。[^voice]

![「設定」→「通用」畫面。① 左側選單，②「顯示模式（화면 모드）」裡的「主題（테마）」，③「語音」裡的「語言」（韓語）上標有紅色編號](../../../guide/10-claude/assets/shot-09-settings-general-marked.png)

這是免費套餐的畫面。**紅色編號和下面列表的編號指的是同一個地方。**

- ① 左側選單裡選中了「通用」。
- ②「主題」：把畫面切換成亮色、暗色。和語音無關。
- ③「語言」：用語音說話時使用的語言。它下面接著「風格」「速度」。[^screen]

## 語音記錄與個人資訊

**語音對話也會以文字留下。** 用語音模式進行的對話，會變成文字記錄，像普通對話一樣儲存在聊天記錄裡。[^voice]

**聽寫的錄音不會保留。** 把說話變成文字之後，錄音就會刪除，也不會用於訓練。[^dictation] 不過，**轉換出來的文字**和普通對話一樣。遵循對話的儲存期限，如果你允許了訓練，就可能被用於訓練。[^dictation-privacy] 訓練設定，在[第9章](09-privacy.md)看過了。

用嘴說的對話，**旁邊的人也聽得到。** 我的問題和 Claude 的回答，都聽得到。

- 在地鐵、咖啡館、辦公室裡，請戴上耳機，或者用聽寫安靜地輸入。
- [第1階段第9章](../00-common/09-safety.md#不要放進去的東西)講過的**不該放進去的資訊，也不要出聲說出來。** 用嘴說的時候，比打字更容易不經意說出口。

## 在手機上更快——小元件、快捷指令、鎖屏介面

不用找到應用再開啟，也能叫出 Claude。這些全都**計入使用限額**。[^ios][^android]

### iPhone（iOS 18 及以上）

- **「向 Claude 提問」**（Ask Claude）：不用開啟應用就能提問。可以在 Spotlight 搜尋、Siri、分享選單裡使用。比如選中一段文字，透過分享選單直接發給 Claude。
- **小元件**：把 Claude 小元件放在主螢幕或今日視圖裡，一個按鈕就能開啟新聊天、聽寫、拍照發送。
- **「用 Claude 分析照片」**（Analyze Photo with Claude）：放進控制中心或鎖屏介面，不用解鎖就能拍照發送。
- **「Open Claude」**：放進鎖屏介面、控制中心、操作按鈕（Action button），直接開啟 Claude。[^ios][^lock]

「向 Claude 提問」和快捷指令，使用的是開啟應用時顯示的預設模型。[^ios]

### 用快捷指令做一個"摘要按鈕"

用 iPhone 的快捷指令應用，可以做出我自己的按鈕。照著幫助文件裡的例子試試。[^ios]

1. 在快捷指令應用裡點「+」，新建一個快捷指令。
2. 加入分享（Share）動作，選擇要接收的內容型別。
3. 加入「向 Claude 提問」動作。
4. 在裡面寫上提示詞。例：`請把下面這段文字概括成三行：[快捷指令輸入]`
5. 起個名字（例：「用 Claude 做摘要」），放進分享面板。

之後在任何應用裡，選中文字，點分享按鈕，選「用 Claude 做摘要」就行了。

<!-- 需要截圖：iPhone 快捷指令應用里加入「向 Claude 提問」動作的畫面 -->

### 安卓（Android 8.0 及以上）

長按主螢幕的空白處，在「小元件」裡找到 Claude 並放上去。有三個按鈕。[^android]

- **聊天按鈕**：直接開啟新對話。
- **相機按鈕**：拍照發給 Claude。
- **麥克風按鈕**：開啟新對話並開始聽寫。

## 和手機應用連線——訊息、郵件、日曆、地圖

手機應用裡的 Claude，可以和手機裡的其他應用連線來幫忙做事。所有套餐都可以。[^ios-apps][^android-apps]

| | iPhone | 安卓 |
|---|---|---|
| 訊息、郵件、日曆 | 可以 | 可以 |
| 位置、地圖 | 可以 | 可以 |
| 提醒事項 | 可以 | 不可以 |
| 鬧鐘、計時器 | — | 可以 |

**訊息和郵件，Claude 只做到草稿。** Claude 會給你看一張填好內容的卡片，點一下，訊息應用或郵件應用就會開啟。讀過內容、改好之後，**傳送由我自己**來按。Claude 不會讀已經收到的訊息或郵件，也不會直接進入通訊錄。[^ios-apps]

請像下面這樣拜託它。

```
幫我寫一封發給組長的郵件草稿，說明明天早上的會議，我因為要去醫院看病，會晚到30分鐘。
要簡短、禮貌。
```

草稿交給郵件應用之後，請確認收件人和內容再發送。和[第9章](09-privacy.md)裡看到的那種假的"已傳送"不同，在這裡，要我按下發送按鈕，才是真的發出去。

### 許可權由我來定

Claude 第一次要用位置或日曆時，會徵求你的同意。在允許一次（Allow once）、始終允許（Always allow）、不允許（Don't allow）裡選。[^ios-apps] 以後想更改，請到手機的設定裡找。

- **iPhone**：「設定」→「Claude」
- **安卓**：「設定」→「應用」→「Claude」→「許可權」[^ios-apps][^android-apps]

也有讀取健康資料的功能，但它是測試版，只限 Pro、Max 套餐，而且只在美國可用。[^ios-apps]

## 動手試試

**1. 同一個問題，兩種方法**

下面這個問題，一次用**麥克風（聽寫）**，一次在新聊天裡用**聲波符號（語音模式）**來問。

```
冰箱裡有雞蛋、豆腐、大蔥。告訴我兩道15分鐘內能做好的小菜。
```

然後問問自己。聽寫記下來的文字和我說的一樣嗎？聽回答和讀回答，哪一種更舒服？

**2. 試著插話**

在語音模式裡請它做一段長的講解，然後在 Claude 說話的過程中，說"等一下，再短一點"。確認 Claude 是不是停下來，然後簡短地重說一遍。

**3. 在手機上放一個快捷入口**

如果是 iPhone，就在主螢幕上放 Claude 小元件；如果是安卓，就放 Claude 小元件。點麥克風按鈕，確認聽寫是不是馬上開啟。

**連續任務**（[準備讀書會](../00-common/practice-kit.md)）：用語音模式說"陪我一起練習30秒左右的讀書會開場問候"。聽完我說的問候後，請它指出一個要改的地方。

## 總結

- 麥克風是**聽寫**：把說的話變成文字發出去，回答以文字送來。這一章按手機應用來講。
- 聲波符號是**語音模式**：用嘴問，用耳朵聽。這是測試版，在手機上效果最好。
- 語音模式預設是擴音，太吵的話改成按鍵說話。它計入使用限額。
- 要說的語言，和應用介面語言分開設定。在這個畫面裡是「設定」→「通用」→「語音」→「語言」。
- 語音對話會以文字記錄留下。聽寫的錄音會刪除，但轉換出來的文字，遵循訓練設定。
- iPhone 用「向 Claude 提問」、快捷指令、小元件、鎖屏介面，安卓用小元件，來更快地開啟。
- 訊息、郵件由 Claude 做草稿，傳送由我來做。許可權在手機設定裡更改。

## 術語整理

| 術語 | 中文名稱 | 一句話解釋 |
|---|---|---|
| Dictation | 聽寫 | 把說的話變成文字輸入的功能 |
| Voice mode | 語音模式 | 和 Claude 用說話來交流的功能 |
| Hands-free | 擴音 | 不用按按鈕，停下話來它就回答的方式 |
| Push-to-talk | 按鍵說話 | 只在按住按鈕期間才聽的方式 |
| Beta | 測試版 | 正式釋出前拿出來試用的功能 |
| Transcript | 文字記錄 | 把說過的內容轉成文字的記錄 |
| Widget | 小元件 | 放在主螢幕上的小快捷入口 |
| Shortcut | 快捷指令 | 把多個動作打包、一個按鈕就執行的 iPhone 功能 |
| Permission | 許可權 | 允許應用使用位置、日曆等的許可 |
