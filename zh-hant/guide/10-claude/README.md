# 第2階段 · Claude 使用指南

如果說在第1階段你學到的是對任何 AI 都管用的**提問方法**，那麼在第2階段，你要熟悉的是 **Claude 這項服務的介面和功能**。
比如按鈕在哪裡、怎樣整理對話、我的資訊會被怎樣使用。

> **本指南依據2026年10月26日確認的 Anthropic 官方幫助編寫。** Claude 的選單名稱和功能經常變化。
> 目前，把聊天和 Cowork 合在一起的新介面正在陸續推出，所以每個人看到的介面可能略有不同。
> 如果和你的介面不一樣，請以你介面上顯示的名稱為準。最新內容可以透過各章腳註裡的官方幫助連結檢視。
