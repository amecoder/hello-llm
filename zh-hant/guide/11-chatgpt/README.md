# 第2階段 · ChatGPT 使用指南

如果說第1階段教的是適用於任何 AI 的**提問方法**，那麼第2階段就是熟悉 **ChatGPT 這項服務的介面和功能**。
比如按鈕在哪裡、怎麼整理對話、你的資訊是怎麼被使用的。

> **本指南的介面以 2026 年 10 月的網頁介面（韓語，Plus 套餐）為準。** ChatGPT 的選單名稱和功能變化很快。
> 如果和你看到的不一樣，請以你螢幕上顯示的名稱為準，也可以透過各章腳註裡的 OpenAI 官方幫助連結檢視最新內容。
