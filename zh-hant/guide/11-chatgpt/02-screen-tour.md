# 第2章 熟悉介面 — 什麼在哪裡

> **一句話總結**：ChatGPT 的介面，你只要認得四個地方：**左邊的側邊選單**（以前的對話和功能）、**中間的輸入框**（提問的地方）、**上方的 Chat/Work 切換**、
> **左下角的賬號選單**（設定）。剛開始時，只用輸入框和「新聊天（새 채팅）」就足夠了。

介面以2026年10月的網頁版（Plus 套餐）為準。免費套餐或手機 App 的選單位置可能略有不同。

## 一眼看懂首頁

登入後，中間會看到「從哪裡開始呢？（어디서 시작할까요?）」這句話和輸入框。

![登入後的首頁，用紅色編號 ①~⑤ 標出。請看左邊的側邊選單（「新聊天（새 채팅）」「定時任務（예약）」「資料庫（라이브러리）」「外掛（플러그인）」「探索（탐색）」，以及「置頂會話（고정된 스레드）」「專案（프로젝트）」「最近（최근）」列表）、上方中間的「Chat」/「Work」切換、中間的輸入框以及下面的三個推薦](../../../guide/11-chatgpt/assets/shot-01-home-layout.png)

對話標題和賬號名稱已換成示例。**紅色編號和下表的編號對應同一個地方。**

| 編號 | 位置 | 名稱 | 作用 |
|---|---|---|---|
| ① | 左邊 | 側邊選單（側邊欄） | 開始新對話、以前的對話列表、通往各種功能的入口 |
| ② | 上方中間 | 「Chat」/「Work」 | 切換普通對話和長時間任務模式 |
| ③ | 中間 | 輸入框「向 ChatGPT 提問（ChatGPT에게 물어보세요）」 | 寫下問題的地方 |
| ④ | 輸入框下方 | 推薦 | 「幫我做圖片或貼紙（이미지나 스티커 만들어줘）」「寫作（글쓰기）」「網頁搜尋（웹 검색）」 |
| ⑤ | 左下角 | 賬號（名稱和套餐） | 設定、更改套餐、退出登入 |

如果不知道該問什麼，就先點輸入框下面的**推薦**吧。比如點「寫作（글쓰기）」，然後接著這樣寫：

```
幫我寫一條簡訊，告訴老顧客社群小菜店開業的訊息。三句話，語氣要溫暖。
```

::: details 得到的回答大致是這樣（示例 — 點選展開）
這是本指南製作的示例。實際的回答會因服務和每次情況而不同。

> 您好，我是○○小菜店。○月○日，我們終於開業啦。我們會用用心做好的小菜，熱情地迎接您。

**確認一下有沒有答好**：是不是正好三句話，在向老顧客通知開業的訊息？語氣溫暖嗎？店名和日期是我沒告訴它的，所以空著也沒關係。如果裡面出現了編造的日期，請改掉。

## 側邊選單 — 通往以前的對話和功能的入口

側邊選單的上半部分是功能按鈕，下半部分是對話列表。圖中的紅色編號就是下表的編號。

| 編號 | 專案 | 作用 | 詳細內容 |
|---|---|---|---|
| ① | 放大鏡（「搜尋（검색）」） | 查詢以前的對話 | [第3章](03-chats.md) |
| ② | 「新聊天（새 채팅）」 | 新開一個空白對話 | [第3章](03-chats.md) |
| ③ | 「定時任務（예약）」 | 集中檢視到約定時間執行的定時任務 | [第11章](11-expert.md#到點自動去做-—-定時任務) |
| ④ | 「資料庫（라이브러리）」 | 彙集你上傳或生成的檔案的地方（正在改成「Space」） | [第4章](04-files-images.md#資料庫-—-彙集上傳檔案的地方) |
| ⑤ | 「外掛（플러그인）」 | 查詢給 ChatGPT 增加功能的擴充套件 | [第7章](07-projects-plugins.md) |
| ⑥ | 「探索（탐색）」 | 瀏覽其他功能 | — |

**會話**（thread）是對一個對話的另一種叫法。「置頂會話（고정된 스레드）」的意思就是“固定住的對話”。

## Chat 和 Work — 是聊天，還是交辦任務

上方中間的「Chat」/「Work」是2026年7月新增的切換按鈕。[^rn-work]

- **Chat**：就是你一直以來熟悉的 ChatGPT。一問一答地對話。本指南大部分內容都以 Chat 為準。
- **Work**：把需要經過多個步驟的長時間任務交給它，然後拿到文件、表格、演示資料、報告這類**成品**的模式。

Work 在網頁和手機上，只有**付費套餐（不含 Free、Go）** 才能用。Free 和 Go 只能在電腦 App 上有限地使用。[^rn-work] 使用方法在[第7章](07-projects-plugins.md)裡講。

## 推理級別和思考 — 想得多深

在付費套餐裡，點輸入框右邊像「Medium」這樣的文字（按鈕名稱「選擇 ChatGPT 模型（ChatGPT 모델 선택）」），就會出現**「推理級別（추론 수준）」** 滑塊。
**推理**（reasoning）是在回答之前，一步一步地思考。滑塊決定這種思考持續多久。

![點了輸入框右邊「推理級別（추론 수준）」的介面。請看小窗口裡有「Medium」這個字，和一個可以左右移動的滑塊](../../../guide/11-chatgpt/assets/shot-03-model-menu-marked.png)

對話標題和賬號名稱已換成示例。① 點「推理級別（추론 수준）」按鈕後，會出現 ② 當前級別（「Medium」）和 ③ 滑塊。

| 級別 | 特點 | 可使用的套餐 |
|---|---|---|
| Instant（即時） | 馬上回答。適合輕鬆的問題 | 付費 |
| Medium（中等）· High | 想得更久。適合做計劃、比較、計算 | Plus 以上 |
| Extra High · Pro | 想得最深 | Pro·Business·Enterprise |

出處：OpenAI 幫助中心[^levels]

有兩點需要注意。

- **用話語說“想得更深一點”，級別也不會改變。** 即使保持在 Instant 的情況下這麼寫，也不會自動升高。請自己拖動滑塊。[^levels]
- **免費（Free）和 Go 套餐不是用滑塊，而是開啟「思考（생각하기）」。** 在 Go 套餐的手機 App 上，要在 + 選單裡選「Think harder」。[^go-think]

<!-- 需要截圖：在 Free 套餐網頁介面中開啟「思考（생각하기）」的位置 -->

**什麼時候要調高呢？** 不只是計算。像潤色一句短話這種簡單或風險小的事，用快速級別就夠了。條件有好幾個、要按標準比較各個選項、或者要找出我寫的計劃裡漏掉的假設時，請調高級別。[^academy-content]
```
請按預算、公共交通、下雨時的備選方案這三個標準，比較三個活動場地候選。
推薦其中一個，並告訴我怎樣減少它的缺點。
```

同一個問題，只改變級別再問一次。你馬上就能感受到快速回答和深入回答的差別。

```
月薪300萬韓元的上班族，想在3年內攢到2,000萬韓元，每個月要存多少？
請分成考慮定期存款利息和不考慮利息兩種情況，展示計算過程。
```

## 親自試一試

1. 在首頁點推薦的「寫作（글쓰기）」，把上面的小菜店簡訊示例貼進去傳送。
2. 點輸入框的 + 按鈕，把選單項逐個讀一遍（不用點進去），然後關閉。
3. 如果是付費使用者，把「推理級別（추론 수준）」調到最低發一次、調到 Medium 發一次，都發送上面的儲蓄計算問題，並比較回答。如果是免費使用者，則在關掉「思考（생각하기）」的狀態下發一次、開啟的狀態下發一次，然後比較。
4. 開啟賬號選單 →「設定（설정）」，找到「資料管理（데이터 관리）」在哪裡，然後點「返回應用（앱으로 돌아가기）」退出來。

**連續任務**（[籌備讀書會](../00-common/practice-kit.md)）：點推薦的「寫作（글쓰기）」，把示例檔案 memo-next-month.txt 的內容貼進去，傳送“請寫一份要發給全體會員群發簡訊的簡短通知草稿”。看看草稿是怎麼處理“地點還沒確定”這件事的。

## 小結

- 介面分為側邊選單、輸入框、Chat/Work 切換、賬號選單這四個地方。
- 在 + 按鈕裡選擇檔案、圖片、網頁搜尋、深度研究、草圖。
- 付費版用「推理級別（추론 수준）」滑塊，免費版用「思考（생각하기）」來決定思考深度。靠說話請求是改變不了的。
- 設定會以全屏開啟。和個人資訊有關的設定在「資料管理（데이터 관리）」裡。
