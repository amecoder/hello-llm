# 第4章 提示詞基礎

> **一句話總結**：好的提示詞，就像你寫給一位剛認識的能幹同事、請他幫忙做事的那段話。
> 他很聰明，但對你的情況一無所知。

## 什麼是提示詞

**提示詞（prompt）** 是你發給 AI 的請求。你在聊天框裡輸入的每一段話，都是提示詞。

在[第1章](01-what-is-llm.md)裡說過，AI“不瞭解我的情況”。所以提示詞的關鍵，就是
**把 AI 不知道的事告訴它**。

想象一下，你要把一件事交給新來的能幹同事。如果你只說“幫我寫份報告”，同事一定會反問你：
是什麼報告？誰來看？寫多長？因為這些他都不知道。
AI 大多不會反問，而是直接猜著寫。所以，一開始就告訴它吧。

## 好提示詞的5個要素

不用每次都把所有要素寫全。當你對回答不滿意時，把它當作檢查清單就行，看看缺了哪一項。

| 要素 | 問題 | 例子 |
|---|---|---|
| **1. 目標** | 你想要什麼？ | “幫我寫一封拒絕郵件” |
| **2. 背景** | 現在是什麼情況？ | “合作方要求把交貨期限推遲2周” |
| **3. 物件** | 誰來讀？ | “對方是合作了10年的合作方部長” |
| **4. 格式** | 想要什麼樣子？ | “五句話以內，禮貌的敬語” |
| **5. 條件** | 必須遵守或避免什麼？ | “保留對下次合作的期待。不要過分道歉” |

![目標（想要什麼）、背景（什麼情況）、物件（誰來讀）、格式（什麼樣子）、條件（要遵守或避免什麼）這五項合在一起，就成了好的提示詞。不必每次都寫全，回答不理想時把它當作檢查清單即可](../../../guide/00-common/assets/ch4-five-elements.svg)

把五個要素都放進去，就是這樣：

```
合作方要求把交貨期限推遲2周，但因為我們這邊的上市日程，很難答應。
請幫我寫一封回信。對方是合作了10年的合作方部長。
請用五句話以內、禮貌的敬語來寫，並保留對下次合作的期待。
不要過分道歉。
```

## 透過前後對比來掌握

### 例1. 摘要

**不夠好的提示詞**

```
幫我總結一下這篇文章。
```

**好的提示詞**

```
我想把下面這篇文章分享到公司的群聊裡。請總結成核心三句話，
讓忙碌的同事30秒內就能讀完，再補一句我們團隊（線上營銷）可以參考的地方。

[貼上文章]
```

好的提示詞多了四樣東西：背景（分享到群聊）、物件（忙碌的同事）、格式（三句話加一句話）、目標（我們團隊可以參考的地方）。

### 例2. 聽講解

**不夠好的提示詞**

```
匯率是什麼？
```

**好的提示詞**

```
我是第一次看經濟新聞的高中生。請用一個簡單的比喻解釋匯率是什麼。
再舉一個數字的例子，說明匯率上漲時出國旅遊為什麼會吃虧，
最後告訴我看新聞裡的匯率報道時，值得記住的三點。
```

好的提示詞多了兩樣東西：物件（第一次看經濟新聞的高中生）和格式（比喻加數字例子加三點）。

得到的回答大致會這樣不同。實際的回答會因服務而異，每次也不一樣。

| | 不夠好的提示詞得到的回答 | 好的提示詞得到的回答 |
|---|---|---|
| 第一句 | “匯率是一國貨幣與另一國貨幣的兌換比率，隨外匯市場的供求而…” | “匯率就是把我們的錢換成別國的錢時的‘價目表’。” |
| 例子 | 幾乎沒有 | “如果1美元從1,300韓元變成1,400韓元，住一晚100美元的酒店，就不是付13萬韓元，而是要付14萬韓元。” |
| 讀完之後 | 術語很多，但沒什麼實感 | 和自己的生活聯絡起來，馬上就懂 |

### 例3. 點子

**不夠好的提示詞**

```
幫我推薦店名。
```

**好的提示詞**

```
我打算在居民區開一家手工貝果小店，想給它起個名字。
顧客主要是早上上班路上的上班族，以及週末帶家人來的客人。
請推薦10個好叫的韓文或英文名字，並在每個後面用一句話說明給人什麼感覺。
帶有“貝果”這個詞的名字不要超過3個。
```

好的提示詞多了四樣東西：背景（社群和行業）、物件（顧客群）、格式（10個加一句話說明）、條件（詞語數量限制）。

## 馬上就能用的三個習慣

1. **試著用“我是○○，我想做○○”開頭。** 只這一句，背景和目標就都有了。
2. **想要的樣子，試著用數字來說。** 不說“短一點”，而說“三句話”；不說“多一點”，而說“10個”。
3. **不滿意時，不要從頭重寫，而是接著讓它修改。** 比如這樣說：
   “第二句話太生硬了。請改得再柔和一點。”

## 親自試一試

挑一件你最近真正在煩惱的事，填一填下面的空格，做出一個提示詞。

```
我是[我是誰]，我想[要做什麼]。
[說明情況]。
為了[誰來讀／為誰而做]，
請用[想要的格式和篇幅]來[想要的結果]。
[必須遵守或避免的事]。
```

然後，和不填空格、只用一句話問出來的結果比一比。哪一個更符合我的情況？哪一個需要修改得更少？

## 小結

- 提示詞的關鍵，是把 AI 不知道的我的情況告訴它。
- 把目標、背景、物件、格式、條件這五項當作檢查清單。
- 不需要一次完美。邊聊邊改就好。
