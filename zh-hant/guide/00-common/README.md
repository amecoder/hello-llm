# 第1階段 · 適用於所有 LLM 的通用指南

無論是 ChatGPT、Claude 還是 Gemini，這一階段學到的內容在哪裡都一樣適用。
建議按順序閱讀。每一節末尾的**小測驗**，可以讓你馬上檢查剛讀過的內容。

| 章 | 標題 | 你會了解到 |
|---|---|---|
| 1 | [LLM 是什麼](01-what-is-llm.md) | AI 是怎麼生成答案的，為什麼偶爾會答錯 |
| 2 | [為什麼這麼火](02-why-it-matters.md) | 到底是什麼變了，讓大家都在談論它 |
| 3 | [為什麼要學](03-why-learn.md) | 會用的人和不會用的人差在哪裡 |
| 4 | [提示詞基礎](04-prompt-basics.md) | 怎樣寫出能得到好答案的請求 |
| 5 | [提示詞模式](05-prompt-patterns.md) | Few-shot、CoT 等八個提問技巧和專業術語 |
| 6 | [在對話中不斷打磨](06-conversation.md) | 怎樣說清楚“請修改”，什麼時候該開啟新對話 |
| 7 | [結構化提示詞](07-structured-prompts.md) | 用 Markdown、XML 整理長請求，用提示詞編輯器親手做一做 |
| 8 | [元提示](08-meta-prompting.md) | 讓 AI 來寫提示詞、改提示詞的方法 |
| 9 | [安全使用](09-safety.md) | 核實幻覺、遮住個人資訊、版權、防範隱藏指令（提示詞注入） |
| 10 | [實踐任務集](10-practice.md) | 把所學用到自己工作中的 9 個任務和檢查表 |
| 11 | [像專家一樣使用](11-expert.md) | 判斷該交給 AI 什麼，交出去之前先試一試，把反覆要做的事積累下來 |

[連續任務 — 準備讀書會](practice-kit.md)是把同一個任務從第11章一直做到第2階段結束的實踐練習。你需要下載並使用虛構的示例檔案。

每一章出現過的提示詞，都按用途收集在[拿來就用的提示詞合集](prompt-library.md)裡。複製後，只改空白處就能用。

全部讀完後，可以在[理解度測驗](certificate.md)裡做 20 道題，看看你的 AI 理解水平（入門、中級、高階）。

如果想更深入地檢驗自己，可以在 [AI 知識水平測試](level-test.md)裡挑戰初級、中級、高階、專家四個級別。每個級別有 5 個科目、50 道題，通過後會開啟下一個級別。
