# 第3章 為什麼要學

> **一句話總結**：同樣是用 AI，“怎麼問”不同，結果會差很多，
> 而這個差距只要肯學，人人都能縮小。

## 同樣的工具，不同的結果

假設有兩個人，請同一個 AI 幫忙寫簡歷。

**A 的請求**

```
幫我寫簡歷。
```

AI 不知道 A 是誰。所以它給了一份姓名和經歷欄都空著的普通模板。
A 覺得“沒什麼用”，就關掉了視窗。

**B 的請求**

```
我在物流公司做了 5 年庫存管理，這次想應聘網店（電商）公司的運營團隊。
請根據下面我的經歷備忘，寫出簡歷裡「經歷概述」的部分，寫三行，
要突出對電商運營有幫助的經驗。

[經歷備忘]
- 用 Excel 每週管理 3 個倉庫的庫存資料
- 改進退貨處理流程，縮短了處理時間
- 負責培訓 4 名新員工
```

B 拿到了可以直接用的句子。然後接著要求把不滿意的地方改一改。

**兩個人的差別不在 AI，而在請求。** A 什麼都沒告訴 AI，B 告訴了它自己的經歷、要應聘的地方和想要的格式。
這種請求的文字叫作**提示詞（prompt）**。怎樣寫好提示詞，從[第4章](04-prompt-basics.md)開始學。

## 日常生活中這樣用

這不是隻給開發者或專家用的工具。下面都是普通人馬上就能用的例子。

| 情景 | 可以這樣請求 |
|---|---|
| 工作 | “把這封郵件改得禮貌但堅決，內容是日程很難推遲” |
| 合同·檔案 | “在這份全租·月租合同（租賃合同）裡，找出可能對租客不利的條款，用簡單的話解釋” |
| 學習 | “一元二次方程的求根公式為什麼是那樣推出來的，按初中生的水平一步一步講” |
| 生活 | “冰箱裡有雞蛋、豆腐、大蔥、泡菜。20 分鐘內能做好的晚餐選單 3 個” |
| 旅行 | “帶父母去釜山玩 2 晚 3 天，安排一個不用走太多路的行程” |
| 育兒 | “7 歲的孩子問‘為什麼會下雨？’，告訴我怎麼用孩子能懂的方式解釋” |

## 學了會有什麼變化

1. **省時間。** 寫初稿、整理這類原本很費時間的事，第一步可以縮短到幾分鐘。
2. **結果更好。** 拿到貼合自己情況的回答，需要修改的地方就少了。
3. **不容易被騙。** 知道 AI 是怎麼出錯的，就知道該核實哪裡。
4. **可以走向下一個階段。** 這本指南的最後，有和 AI 一起親手做出東西的階段。
   它的起點，就是現在學的“會問”。

## 糾正誤解

- **“AI 什麼都會自動做好”**——不是這樣。要告訴它你的情況和目標，它才能做好。
- **“要背很難的命令”**——沒有什麼特別的咒語。把平時拜託別人做事時說的話整理清楚就行。
- **“問一次不滿意，就沒用了”**——不需要一開始就完美。接著對話、讓它修改，才是正常的用法。
- **“AI 的回答是準確的”**——就像[第1章](01-what-is-llm.md)裡看到的，它可能出錯。重要的內容請核實。

## 親自試一試

把上面 A 和 B 的請求，真的都輸入一遍。
B 的請求裡的經歷備忘，換成你自己的真實經歷也可以。
把兩份回答並排放在一起比較。哪一份不用修改就能直接用？哪一份包含了我的經歷？

## 整理

- 結果的差異大多不是來自 AI，而是來自請求（提示詞）。
- 工作、檔案、學習、生活，在哪裡都能馬上用上。
- 不要指望一次就得到完美的回答，而是接著對話慢慢打磨。
