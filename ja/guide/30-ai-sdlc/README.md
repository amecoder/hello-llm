# ステップ4 · AI-SDLC ガイド

SDLC（ソフトウェア開発ライフサイクル）は、アイデアが実際に動くソフトウェアになるまでに通る段階です。ステップ4では、ステップ3で身につけたAIツールと一緒に、**小さなウェブページを1つ、企画からデプロイ・改善まで**作ってみます。
コードを知らなくても大丈夫です。このステップで学ぶのは、コードの書き方ではなく、**AIに何を渡し、何を受け取って確認するか**です。

> **このガイドは、2026年11月1日に確認したGitHub・Claude Code公式ドキュメントと、spec-kit・OpenSpecのリポジトリの説明をもとに書きました。** 機能と画面の名前はよく変わります。
> GitHubの無料アカウントがあれば十分です。AIツールは、ステップ3で使ったもの（Claude Code・Codex・Antigravity）をそのまま使います。
