# 第2章 なぜこれほど話題なのか

> **一言まとめ**: 専門家しか扱えなかったAIを、誰もが普段の言葉で使えるようになったからです。

## 突然現れたように見えますが

AIの研究は何十年も続けられてきました。今のLLMにつながる決定的なきっかけは、1本の論文です。
2017年にGoogleの研究チームが発表した「Attention Is All You Need」です。[^1]
この論文は、**トランスフォーマー（Transformer）**という仕組みを紹介しました。この仕組みのおかげで、大量の文章を効率よく学習させられるようになりました。
以前のやり方では、文章を頭から1単語ずつ順番に読む必要がありました。トランスフォーマーは、文の中の単語同士がどんな関係にあるかを**一度に**調べます。そのため、複数のコンピューターで手分けして速く学習させられるようになりました。
今使われているLLMのほとんどが、この仕組みをベースにしています。トランスフォーマーがどのように動くのかは、下の「動画でもっと見る」にある図解動画で見ることができます。

しかし、一般の人がAIを直接実感し始めたのは、それから5年後のことです。

## 2022年11月、ChatGPT

OpenAIは2022年11月30日、ChatGPTを無料で公開しました。[^2]
特別なインストールや勉強はいらず、ウェブサイトにアクセスしてチャットアプリのように話しかけるだけでした。

反応は爆発的でした。投資銀行UBSの分析によると、ChatGPTは公開から約2か月後の
2023年1月に、月間ユーザー数が約1億人に達したと推定されました。当時の基準で、
歴史上もっとも速く成長した消費者向けアプリに挙げられました。[^3]

その後、AnthropicのClaude、GoogleのGeminiなど、いくつもの会社が似たサービスを出し、競争が始まりました。

## 何がそんなに変わったのか

### 1. コンピューターに「普段の言葉」で仕事を頼める

以前はコンピューターに仕事をさせるには、プログラミング言語を学ぶか、決まったメニューやボタンの操作を覚える必要がありました。
LLMには、ただこう話しかければ大丈夫です。

```
この議事録から、誰が何をいつまでにやることにしたかを表にまとめて。
```

### 2. 1つだけでなく、ほぼすべての文章作業をこなす

翻訳機は翻訳だけ、スペルチェッカーはスペルチェックだけをしていました。
LLMが1つあれば、翻訳、要約、文章作成、質疑応答、アイデア出し、コード作成までできます。

### 3. 費用と手軽さ

ほとんどのサービスは無料で始められます。スマートフォンのアプリでも使えます。
秘書や家庭教師をつけるのに似たことを、誰もが試せるようになりました。

## そこで生まれた議論

話題になった理由には、期待だけでなく心配もあります。両方を知っておくと、バランスよく見ることができます。

| 議論 | 内容 |
|---|---|
| 仕事・雇用 | 文章作成・翻訳・相談のような仕事がAIに置き換わったり、大きく変わったりするのではないかという懸念 |
| 正確性 | [第1章](01-what-is-llm.md)で見たハルシネーション（もっともらしい嘘）のせいで、誤った情報が広まる問題 |
| 著作権 | AIが学習した文章・画像の権利や、AIが作った成果物の権利の問題 |
| 個人情報 | 会話に入力した内容がどのように保存され、使われるかについての心配 |
| 教育 | 学生が課題をAIに丸投げしてしまう問題 |

このガイドは、こうした心配事を見ないふりはしません。実際にどう気をつければよいかは、[第9章「安全に使う」](09-safety.md)で扱います。

## 自分で試してみよう

LLMに、この技術そのものについて聞いてみてください。答えをそのまま信じないでください。日付や数字が合っているか確認してみましょう。

```
ChatGPTが初めて公開された日付と、その後に似たサービスを出した会社を3つ教えて。
それぞれの出典も一緒に教えて。
```

LLMが答えた日付を、この章の脚注と比べてみてください。合っているかもしれませんし、間違っているかもしれません。
日付は脚注と同じかな？教えてくれた出典は本当にあるのかな？このように自分に問いかければ大丈夫です。
**「確認する習慣」が、このガイド全体でもっとも大切な習慣です。**

## まとめ

- 2017年のトランスフォーマー論文が技術的なきっかけ、2022年のChatGPT公開が普及のきっかけです。
- 変化の中心は、「普段の言葉でコンピューターにほぼすべての文章作業を頼める」ことです。
- 仕事・正確性・著作権・個人情報といった議論もあわせて知っておきましょう。
