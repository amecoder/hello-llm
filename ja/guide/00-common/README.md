# ステップ1・すべてのLLMに共通するガイド

ChatGPTでもClaudeでもGeminiでも、このステップで学ぶ内容はどこでも同じように使えます。
順番に読むことをおすすめします。各節の最後にある**確認クイズ**で、読んだ内容をすぐに振り返ることができます。

| 章 | タイトル | こんなことがわかります |
|---|---|---|
| 1 | [LLMとは何か](01-what-is-llm.md) | AIがどうやって答えを作るのか、なぜ時々間違えるのか |
| 2 | [なぜこれほど話題なのか](02-why-it-matters.md) | 何が変わったからみんなが話しているのか |
| 3 | [なぜ学ぶべきなのか](03-why-learn.md) | うまく使える人とそうでない人の違い |
| 4 | [プロンプトの基礎](04-prompt-basics.md) | 良い答えを引き出す依頼文の書き方 |
| 5 | [プロンプトのパターン](05-prompt-patterns.md) | Few-shot・CoTなど8つの依頼のコツと専門用語 |
| 6 | [会話を続けながら仕上げる](06-conversation.md) | 直してほしいと上手に伝える方法、新しい会話を始めるとき |
| 7 | [構造化プロンプト](07-structured-prompts.md) | Markdown・XMLで長い依頼を整理する、プロンプトエディタで実際に作ってみる |
| 8 | [メタプロンプティング](08-meta-prompting.md) | プロンプトをAIに作らせて、直させる方法 |
| 9 | [安全に使う](09-safety.md) | ハルシネーションの確認、個人情報の伏せ方、著作権、隠れた指示（プロンプトインジェクション）を防ぐ方法 |
| 10 | [実践課題集](10-practice.md) | 学んだことを自分の仕事で実際に使ってみる9つの課題とチェックリスト |
| 11 | [専門家のように使う](11-expert.md) | 何を任せるか判断し、任せる前に試し、繰り返す作業をためておく方法 |

[連続課題 — 読書会の準備](practice-kit.md)は、1つの課題を第11章からステップ2の最後まで続けて行う実践ワークです。架空のサンプルファイルをダウンロードして使います。

各章に出てきたプロンプトは、[すぐ使えるプロンプト集](prompt-library.md)に用途別でまとめてあります。コピーして空欄だけ書き換えて使ってください。

すべて読み終えたら、[理解度確認テスト](certificate.md)で20問を解いて、自分のAI理解レベル（入門・中級・上級）を確かめてみましょう。

さらに深く試したい方は、[AI知識レベルテスト](level-test.md)で初級・中級・上級・エキスパートの4段階に挑戦してみてください。レベルごとに5科目50問あり、合格すると次のレベルが開きます。
