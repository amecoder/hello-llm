# 第4章 プロンプトの基本

> **一言まとめ**: 良いプロンプトは、初めて会う有能な同僚に仕事を頼むときの文章と同じです。
> 相手は優秀ですが、あなたの事情はまったく知りません。

## プロンプトとは

**プロンプト（prompt）** は、AIに送る依頼文のことです。チャット欄に入力する文章はすべてプロンプトです。

[第1章](01-what-is-llm.md)で、AIは「あなたの状況を知らない」とお伝えしました。そのため、プロンプトで一番大切なのは
**AIが知らないことを教えてあげること**です。

新しく入った有能な同僚に仕事を頼む場面を想像してみてください。「報告書を書いて」とだけ言ったら、同僚は聞き返すはずです。
何の報告書なのか、誰が読むのか、どのくらいの長さで書くのかわからないからです。
AIはたいてい聞き返さず、推測してそのまま書いてしまいます。だからこそ、最初から教えてあげましょう。

## 良いプロンプトの5つの要素

毎回すべての要素を入れる必要はありません。返ってきた答えがいまいちだったときのチェックリストとして使ってください。足りない要素が何かを探せば大丈夫です。

| 要素 | 質問 | 例 |
|---|---|---|
| **1. 目的** | 何をしてほしいか？ | 「お断りのメールを書いて」 |
| **2. 背景** | どんな状況か？ | 「取引先から納期を2週間延ばしてほしいと頼まれた」 |
| **3. 相手** | 誰が読むか？ | 「相手は10年付き合いのある取引先の部長」 |
| **4. 形式** | どんな形で？ | 「5文以内で、丁寧な敬語」 |
| **5. 条件** | 守ること・避けることは？ | 「次の取引への期待は残して。謝りすぎないで」 |

![目的（何をしてほしいか）、背景（どんな状況か）、相手（誰が読むか）、形式（どんな形で）、条件（守ること・避けること）の5つが集まると良いプロンプトになる。毎回すべて入れる必要はなく、答えが物足りないときのチェックリストとして使う](../../../guide/00-common/assets/ch4-five-elements.svg)

5つの要素をすべて入れると、このようになります。

```
取引先から納期を2週間延ばしてほしいと頼まれたけれど、こちらの発売スケジュールの都合で
難しいという返信を書いて。相手は10年間付き合いのある取引先の部長だよ。
5文以内の丁寧な敬語で書いて、次の取引への期待は残してね。
謝りすぎないようにして。
```

## ビフォー・アフターで身につける

### 例1. 要約

**惜しいプロンプト**

```
この記事を要約して。
```

**良いプロンプト**

```
下の記事を会社のグループチャットで共有しようと思っているよ。忙しいメンバーが30秒以内に読めるよう、
要点を3行で要約して、うちのチーム（オンラインマーケティング）が参考にすべき点を1行付け加えて。

[記事を貼り付ける]
```

良いプロンプトには4つの要素が加わっています。背景（グループチャットで共有）、相手（忙しいメンバー）、形式（3行＋1行）、目的（チームが参考にすべき点）です。

### 例2. 説明してもらう

**惜しいプロンプト**

```
為替レートって何？
```

**良いプロンプト**

```
経済ニュースを初めて見る高校生だよ。為替レートとは何か、わかりやすい例え話で説明して。
円安になると海外旅行に行くときになぜ損をするのか、数字を使った例を1つ挙げて、
最後にニュースで為替の記事を見るときに知っておくとよいポイントを3つ教えて。
```

良いプロンプトには2つの要素が加わっています。相手（経済ニュースを初めて見る高校生）と形式（例え話＋数字の例＋3つのポイント）です。

返ってくる答えは、だいたい次のように変わります。実際の答えはサービスやその時々によって異なります。

| | 惜しいプロンプトの答え | 良いプロンプトの答え |
|---|---|---|
| 最初の1文 | 「為替レートとは、ある国の通貨と別の国の通貨の交換比率のことで、外国為替市場の需要と供給によって…」 | 「為替レートは、日本のお金を外国のお金に両替するときの『値札』のようなものです。」 |
| 例 | ほとんどなし | 「1ドルが1,300ウォンから1,400ウォンになると、100ドルのホテルに13万ウォンではなく14万ウォン払うことになります。」 |
| 読んだあと | 専門用語ばかりでピンとこない | 自分の生活と結びついてすぐに理解できる |

### 例3. アイデア出し

**惜しいプロンプト**

```
お店の名前を考えて。
```

**良いプロンプト**

```
近所の住宅街に開く、小さな手作りベーグル屋さんの名前をつけようとしているよ。
お客さんは主に、朝の通勤途中の会社員と週末の家族連れだよ。
呼びやすい日本語または英語の名前を10個提案して、それぞれどんな雰囲気か1行ずつ説明を添えて。
「ベーグル」という言葉が入る名前は3個以下にしてね。
```

良いプロンプトには4つの要素が加わっています。背景（場所・業種）、相手（客層）、形式（10個＋1行の説明）、条件（単語の制限）です。

## すぐに使える3つの習慣

1. **「私は○○なんだけど、○○しようとしているよ」から始めてみましょう。** この1文だけで、背景と目的が入ります。
2. **してほしい形は数字で伝えてみましょう。** 「短く」ではなく「3行で」、「たくさん」ではなく「10個」と言えば伝わります。
3. **気に入らなくても最初から書き直さず、続けて直してもらいましょう。** たとえばこのように伝えます。
   「2文目が少し堅すぎるよ。もう少し柔らかい表現に変えて。」

## やってみよう

最近実際に悩んでいることを1つ選び、下の空欄を埋めてプロンプトを作ってみましょう。

```
私は[自分が誰か]なんだけど、[何をしようと]しているよ。
[状況の説明]。
[誰が読むか／誰のためのものか]のために、
[希望する形式と分量]で[ほしい結果]をして。
[必ず守ること、または避けること]。
```

そのあと、空欄を使わずに1行だけで聞いた結果と比べてみてください。どちらがあなたの状況に合っていますか？ どちらが手直ししなくて済みますか？

## まとめ

- プロンプトで一番大切なのは、AIが知らないあなたの事情を教えることです。
- 目的・背景・相手・形式・条件の5つをチェックリストとして使います。
- 1回で完璧にする必要はありません。会話を続けながら直していきます。
