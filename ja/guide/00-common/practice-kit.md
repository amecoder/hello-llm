# 連続課題 — 地域の読書会を準備する

> **一言まとめ**: 章ごとにバラバラの練習をしても、終わったあとに手元に残るものがありません。このページの課題**1つ**を、ステップ1の第11章からステップ2の最後の章まで続けて取り組めば、最後に**案内文パッケージ**と**自分の一行ルール**が手元に残ります。
> サンプルファイルはすべて、このガイドが作った架空の資料です。実在の人物や場所とは関係ありません。

## 状況

あなたは地域の読書会「本の散歩道」の幹事です。メンバーは20人で、月に1回集まります。先週10月の集まりを終え、これから11月の集まりを準備しなければなりません。

幹事がやることは次のとおりです。

- 前回の集まりで決まったことと、やるべきことを整理する
- 11月の集まりの案内文を書く
- 会費の帳簿を整理して合計を出す
- 集まる場所を確認する

この作業を、AIと一緒に章ごとに少しずつ進めていきます。ご自身が実際にやっている仕事や作業があれば、それに置き換えても構いません。選ぶ基準は[第11章「最初に練習する作業を選ぶ」](11-expert.md#最初に練習する仕事を選ぶ)にあります。

## サンプルファイル

ファイル名をクリックすると、ダウンロードしたり開いたりできます。ブラウザで開いた場合は、内容をコピーしてチャット欄に貼り付けても構いません。

| ファイル | 内容 |
|---|---|
| [memo-next-month.txt](/practice/memo-next-month.txt) | 11月の集まりのメモ。整理されていない幹事のメモ |
| [minutes-last-meeting.txt](/practice/minutes-last-meeting.txt) | 10月の集まりの議事録。決まったこと・やること・決まらなかったこと |
| [members.csv](/practice/members.csv) | メンバー名簿（仮名）。出席と会費の支払い状況 |
| [fees.csv](/practice/fees.csv) | 10月の会費帳簿。収入と支出 |
| [memo-last-month.txt](/practice/memo-last-month.txt) | 10月の集まりのメモ。「答えを知っているテスト」用 |
| [last-notice.txt](/practice/last-notice.txt) | 先月実際に送った10月の案内文。「答えを知っているテスト」の正解 |

CSVファイルはExcelで開ける表ファイルです。メンバー名簿には連絡先を入れていません。実際の集まりの資料で試すときも、名前や連絡先は消すか仮の名前に変えてからアップロードしてください（[第9章](09-safety.md)）。

**わざと入れた落とし穴があります。** 会費帳簿には、間違えて2回書いた行と、金額が空欄の行があります。AIがこれを見つけ出すか、それともそのまま足してしまうか見てみましょう。

## 最後に手元に残るもの

課題を終えると、次の4つが手元に残ります。

1. **11月の集まりの案内文**: 日付・場所・課題本・会費・発表者がすべて入った文章
2. **会費の集計表**: 収入・支出・残高。重複や空欄の金額を正しく直したもの
3. **やることリスト**: 誰が、何を、いつまでにやるか
4. **自分の一行ルール**: 来月も使える案内文のルール。例：「案内文は3段落以内で、日付・場所・持ち物を一番上に書く」

**うまくできたか確認**

- ☐ 案内文の日付が、議事録で決めた「第3土曜日」と合っている
- ☐ 場所がまだ確定していない場合は、案内文にそのように書いた
- ☐ 会費の集計表の合計を、帳簿と直接照らし合わせて確認した。重複した行は1回だけ数えた
- ☐ やることリストに、議事録のやるべきこと3つがすべて入っている
- ☐ 自分の一行ルールを、カスタム指示やプロジェクトの指示に入れておいた

すべてチェックできたら、来月はご自身の実際の作業で同じ手順を試してみてください。
