# 第8章 メタプロンプティング — プロンプトをAIに作らせる

> **一言まとめ**: 良いプロンプトを全部自分で書かなくてもかまいません。思いつくままに書いた依頼をAIに渡して
> **「良いプロンプトに直して」** と頼めばいいのです。ただし、AIがまとめた結果は、送る前に必ず自分で一度読みましょう。

## メタプロンプティングとは

[第4章](04-prompt-basics.md)から[第7章](07-structured-prompts.md)まで、良い依頼の要素（目標・背景・相手・形式・条件）、いろいろなパターン、枠の分け方を学びました。
全部を覚えて毎回守るのは大変です。そこで、**プロンプトを書く作業そのものをAIに任せる**方法があります。

このように**プロンプトを作らせたり直させたりするプロンプト**を、**メタプロンプティング**（meta prompting）と呼びます。
「メタ」とは「それ自体についての」という意味です。質問についての質問、プロンプトについてのプロンプト、ということです。

AI会社もこの方法を使っています。ChatGPTを作ったOpenAIには、開発者向けの別の練習画面（Playground、ChatGPTとは別の開発者向けサイト）があります。
OpenAIは、その画面のGenerate（作成）ボタンが**メタプロンプト**（meta-prompt、良いプロンプトを作ったり直したりするよう指示するプロンプト）で動いていると公開しました。[^openai-gen]
AIが書いた指示文が、人が書いた指示文と同じくらい、ときにはそれ以上によく通じるという研究もあります。[^ape]

![メタプロンプティングの流れ：思いつくままに書いた自分の依頼 → AIが構造化プロンプトに整理 → 自分が読んで直し、空欄を埋める → 新しい会話に貼り付けて送る。AIには整理だけを任せ、送る前の確認は自分でする](../../../guide/00-common/assets/ch8-meta.svg)

この章では、使い道ごとに4つの方法を見ていきます。

| 方法 | こんなとき |
|---|---|
| 1. 整理だけ頼む | 言いたいことはあるのに、まとまっていないとき |
| 2. 質問されながら作る | 何を書けばいいのかさえわからないとき |
| 3. 通じなかったプロンプトを直す | 依頼したのに、ほしい答えが出なかったとき |
| 4. 使い回すひな形にする | 同じ種類の作業をよくするとき |

## 1. 整理だけ頼む

いちばん基本の方法です。思いつくままに書いた依頼を渡して、[第7章](07-structured-prompts.md)で学んだ枠に分けてもらいます。

**ステップ1 — 整理だけ頼む**

```
下の区切り線の間にある私の依頼を、マークダウンの見出しで整理したプロンプトに変えて。
背景は「## 状況」、やることは「## やること」、答えの形は「## 答えの形」の下に入れて。貼り付けた資料があれば「## 資料」の下に区切り線で囲んで入れて。
足りない情報があれば、[ここに○○を書いてください]のように空欄で示して。
まだ依頼は実行しないで、整理したプロンプトだけ見せて。

---
来週両親と行く済州島旅行の日程を作って お父さんは膝が悪くて
レンタカーあり 2泊3日 おいしいお店も入れて 雨なら行ける場所も
---
```

大事なのは次の2つの文です。
- **「空欄で示して」**: この言葉がないと、AIは足りない情報をそれらしく作って埋めてしまいます。
- **「まだ実行しないで」**: この言葉がないと、AIは整理した直後に旅行の日程まで作ってしまいます。

**ステップ2 — 空欄を埋めて送り直す**

AIが返してきたプロンプトの空欄（例：出発日、予算）を埋めましょう。そのあと**新しい会話**に貼り付けて送ります。
[第6章](06-conversation.md)で見たように、新しい会話に送れば、整理していた会話の跡が答えに混ざりません。

> マークダウンの見出しの代わりに「XMLタグで整理して」と変えてみましょう。同じ方法で、[第7章](07-structured-prompts.md)のXMLタグのプロンプトも作ってもらえます。
> 貼り付ける資料が長くて複数あるときは、そちらのほうがわかりやすくなります。

## 2. 質問されながら作る

何を書けばいいかわからないときは、AIに自分へ**質問してもらいましょう**。
[第5章](05-prompt-patterns.md)の「質問してもらう」（Flipped Interaction）パターンを、プロンプト作りに使うのです。

```
私は近所のお惣菜屋さんのPR文をAIに頼みたいんだ。
でも、どんな情報を渡せばいい答えが出るのかがわからない。
良いプロンプトを作るために必要なことを、私に1つずつ質問して。
質問が終わったら、私の答えを集めて、マークダウンの見出しで整理したプロンプトを作って。
```

AIは「お店の看板メニューは何ですか？」「その文はどこで使いますか？ チラシですか、インスタグラムですか？」のように、1つずつ聞いてきます。
答えているうちに、**自分では思いつかなかった条件**（文字数、口調、お客さんの層）が自然に埋まっていきます。

> **質問が延々と続くときは**：「質問は5個までにして」と、最初から数を決めておきましょう。

## 3. 通じなかったプロンプトを直す

依頼したのに、答えが的外れだったでしょうか？ そんなときは、**自分のプロンプトと受け取った答えをいっしょに**見せて、何が問題だったのかを聞いてみましょう。
答えだけを見せると、AIはどこが悪いのか推測するしかありません。

```
下の「私のプロンプト」で頼んだら、「受け取った答え」のような答えが出たよ。
私は小学生の子どもが読める易しい説明がほしかったのに、難しく出てきてしまった。

1. 私のプロンプトの何が足りなくてこうなったのか、短く説明して。
2. 直したプロンプトを見せて。変えた部分は太字にして。

## 私のプロンプト
---
光合成を説明して
---

## 受け取った答え
---
(受け取った答えを貼り付け)
---
```

この方法なら、**直したプロンプトといっしょに理由も学べます**。
上の例なら、「読む人（相手）を書いていなかった」という説明が返ってくるでしょう。これは[第4章](04-prompt-basics.md)の5要素のうちの1つです。
何度かやっていると、最初から書き忘れなくなります。

> **「ほしいもの」を必ず書きましょう。** 「答えがいまいち、直して」だけでは、AIは何を基準に直せばいいかわかりません。
> [第6章](06-conversation.md)の修正の依頼と同じです。何が、なぜ、どう変わってほしいのかを伝える必要があります。

## 4. 使い回すひな形にする

毎週の業務報告や、毎回の議事録まとめのように、**同じ作業を繰り返す**ことはありませんか？ それなら、うまく通じたプロンプトを**ひな形**（テンプレート、template）にしておきましょう。
ひな形は、変わる部分だけを空欄にして残したプロンプトです。

```
さっきの私たちの会話で、議事録をまとめた方法が気に入ったよ。
次も同じ方法で使えるように、毎回変わる部分は[会議の日付] [議事録の原文]のように
角かっこの空欄で残したプロンプトのひな形を作って。
```

AIが返してきたひな形は、メモ帳に保存しておきましょう。次からは、空欄を埋めるだけで新しい会話に送れます。
このように空欄を示す`[ ]`のような印を**プレースホルダー**（placeholder、空欄の目印）と呼びます。

> [第6章](06-conversation.md)の「引き継ぎメモ」が会話の内容を次の会話に渡すものだとしたら、ひな形は**頼み方**を次回も使えるように渡すものです。

## 注意すること

**1. AIが、自分の言っていない条件を差し込んでくる**

AIは整理しながら、「予算50万ウォン」「午前9時出発」のように、勝手な値を書き入れることがあります。
送る前に、整理されたプロンプトを最初から最後まで読んで、自分に問いかけましょう。「これは自分が言った内容か？」 **自分が言っていない内容**があれば、消すか直してください。
これがこの章でいちばん大切な習慣です。

**2. 長くなったからといって良くなったわけではない**

メタプロンプティングをすると、プロンプトはあっという間に何倍も長くなります。短い依頼には、かえって重荷になります。
「お昼のメニューをおすすめして」を整理させる必要はありません。長さではなく、結果が実際によくなったかどうかを基準に判断しましょう。

**3. 整理されたプロンプトも確認の対象**

AIが作ったプロンプトだからといって、正解とは限りません。そのプロンプトで受け取った答えが、やはり気に入らないこともあります。
そんなときは、3の方法でもう一度直させてもいいですし、自分で1〜2行直してもかまいません。一度で完璧なプロンプトを作る必要はありません。

## やってみよう

最近AIにした依頼の中で、**答えが物足りなかったもの**を1つ思い出してみましょう。
思い浮かばなければ、「光合成を説明して」や「自己紹介文を書いて」のような短い依頼をまず送ってみて、その答えから始めてもかまいません。

1. その依頼を3の方法でAIに見せて、何が足りなかったのかと、直したプロンプトをもらう。
2. 直したプロンプトの中で、**自分が言っていない内容**に印をつけてみる。何か所あるか？
3. 印をつけた部分を自分の考えどおりに直して新しい会話に送り、最初にもらった答えと比べてみる。
4. 結果がよかったら、4の方法でひな形を作ってメモ帳に保存しておく。

## まとめ

- メタプロンプティングは、プロンプトを作ったり直したりする作業をAIに任せること。
- まとまっていないときは整理だけ頼み、何を書くかわからないときは質問されながら作る。
- 通じなかったプロンプトは、受け取った答えとほしいものをいっしょに見せて直させる。
- よくする作業は、空欄のあるひな形にして使い回す。
- 送る前に、自分が言っていない内容が入っていないか必ず読む。

## 用語まとめ
| 用語 | 読み方 | 一言でいうと |
|---|---|---|
| Meta Prompting | メタプロンプティング | AIにプロンプトを作らせたり整えさせたりすること |
| Meta-prompt | メタプロンプト | 良いプロンプトを作ったり直したりするよう指示するプロンプト |
| Flipped Interaction | フリップド・インタラクション（質問してもらう） | AIに自分へ質問させるパターン（[第5章](05-prompt-patterns.md)） |
| Prompt Template | プロンプトテンプレート（ひな形） | 変わる部分だけを空欄にして使い回すプロンプト |
| Placeholder | プレースホルダー（空欄の目印） | あとで埋める空欄を示す印。例：`[会議の日付]` |
