# 第3章 なぜ学ぶべきか

> **一行まとめ**: 同じAIを使っても「どう聞くか」によって結果が大きく変わります。
> その差は、学べば誰でも縮められます。

## 同じ道具、違う結果

2人の人が、全く同じAIに履歴書作りの手伝いを頼むとしましょう。

**Aさんの依頼**

```
履歴書を書いて。
```

AIはAさんが誰なのか知りません。そのため、名前や経歴の欄が空欄になっている、ありふれた見本を出します。
Aさんは「たいして役に立たないな」と思って画面を閉じます。

**Bさんの依頼**

```
私は物流会社で5年間、在庫管理をしてきました。今回、ネットショップ（EC）会社の運営チームに応募しようと思っています。
下の私の経歴メモをもとに、EC運営に役立つ経験が際立つように、
履歴書の「職務要約」の部分を3行で書いてください。

[経歴メモ]
- 倉庫3か所の在庫データをExcelで週次管理
- 返品処理の手順を改善し、処理期間を短縮
- 新人4名の教育を担当
```

Bさんはすぐに使える文章を受け取ります。そして、気に入らない部分を直してほしいと続けて依頼します。

**2人の差は、AIではなく「依頼のしかた」にありました。** Aさんは何も伝えませんでしたが、Bさんは経歴や応募先、希望する形式を伝えました。
この依頼文を**プロンプト（prompt）**と呼びます。プロンプトの上手な書き方は[第4章](04-prompt-basics.md)から学びます。

## 日常ではこのように使います

開発者や専門家だけのための道具ではありません。下はすべて、一般の人がすぐに使える例です。

| 場面 | このように依頼してみてください |
|---|---|
| 職場 | 「このメールを丁寧だけれどきっぱりと、日程の延期は難しいという内容に直して」 |
| 契約・書類 | 「この賃貸借契約書の中で、借主に不利になりそうな条項を見つけて、わかりやすい言葉で説明して」 |
| 勉強 | 「二次方程式の解の公式がなぜそうなるのか、中学生の目線で1ステップずつ説明して」 |
| 生活 | 「冷蔵庫に卵、豆腐、長ねぎ、キムチがあるよ。20分以内に作れる夕食のメニューを3つ教えて」 |
| 旅行 | 「両親を連れて行く2泊3日の釜山旅行、あまり歩かない日程で組んで」 |
| 育児 | 「7歳の子どもに『どうして雨が降るの？』と聞かれたんだけど、子どもの目線で説明する方法を教えて」 |

## 学ぶと何が変わるのか

1. **時間が減ります。** 下書きを書く、整理するなど、時間がかかっていた仕事の最初のステップを数分に短縮できます。
2. **結果が良くなります。** 自分の状況に合った答えが返ってくるので、手直しする手間が減ります。
3. **だまされにくくなります。** AIが間違えるパターンを知っていれば、どこを確認すべきかがわかります。
4. **次のステップへ進めます。** このガイドの最後には、AIと一緒に自分で何かを作るステップまで用意されています。
   その出発点が、今学ぶ「上手な聞き方」です。

## 誤解を解く

- **「AIが勝手に全部やってくれる」** — そうではありません。あなたの状況と目標を伝えてこそ、きちんと動きます。
- **「難しい命令文を覚えなければならない」** — 特別な呪文はありません。人に仕事を頼むときに話す言葉をうまく整理すれば十分です。
- **「一度聞いてイマイチなら使いものにならない」** — 最初から完璧である必要はありません。会話を続けながら直してもらうのが通常の使い方です。
- **「AIの答えは正確だ」** — [第1章](01-what-is-llm.md)で見たように、間違えることがあります。重要な内容は確認してください。

## 実際にやってみる

上のAさんとBさんの依頼を、実際に両方とも入力してみてください。
Bさんの依頼にある経歴メモは、あなたの実際の経験に書き換えても構いません。
2つの答えを並べて比べてみてください。直さずにすぐ使えるのはどちらでしょうか？あなたの経歴が反映されているのはどちらでしょうか？

## まとめ

- 結果の差は、ほとんどの場合AIではなく依頼（プロンプト）から生まれる。
- 職場・書類・勉強・生活のどこででもすぐに使える。
- 一度で完璧な答えを期待するより、会話を続けながら整えていく。
