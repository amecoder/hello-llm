# 第11章 実習課題 — Geminiの機能を実際に使ってみる

> **一言まとめ**: 第1〜10章で見たGeminiの画面と機能を、**自分の手で1回ずつ押してみる**課題を10個集めました。
> 課題ごとに「うまくいったか確認」のチェックリストがあるので、誰かに採点してもらわなくても、自分で確認できます。

画面は2026年10月のWeb版を基準にしています。Geminiはメニューの名前や位置がよく変わるので、画面が違うときは、画面に見える名前に従ってください。

## 実習課題の進め方

1. **Gemini（gemini.google.com）を開いてログインします。** 課題の大部分は、会話の履歴と設定を使います。
2. **課題の「やってみること」に沿って行います。** 灰色のボックスのプロンプトをコピーして送れば大丈夫です。
3. **「うまくいったか確認」を1つずつチェックします。** チェックできなかった項目があれば、「見直す場所」の章を読んで、その部分だけやり直してみましょう。

課題は、順番どおりにやらなくても構いません。ただし、**課題10は最後に**行ってください。練習した跡を片付ける課題です。
課題8の「タスク（작업）」は**Google AI Pro・Ultra**専用なので、無料プランならチャットの予約だけやってみてください。そのほかのメニューも、アカウントやプランによって、またはまだ開放されていなくて、見えないことがあります。見えなければ、読むだけにして先へ進んでください。

どう聞けばいいか（プロンプトの書き方）の練習は、[ステップ1 第10章 実習課題](../00-common/10-practice.md)にあります。ここでは、**ボタンとメニュー**に集中してください。

最初からすべてやりきる必要はありません。1日に課題を2〜3個ずつで十分です。

### 実習で守る3つのこと

- **できるだけ一時チャットで行います。** 右上の「一時チャット（임시 채팅）」で開いた会話は、会話一覧に残らず、AIの学習にも使われません。ただし、72時間は保管されます（[第2章](02-screen-tour.md#一時チャット-—-記録が残らない会話)）。[^screen][^hub]
  履歴・スキル・予定を扱う課題（3・5・7・8）は、通常のチャットで行ってください。一時チャットでは、開き直したり名前を変えたりできないからです。
- **資料は偽物を作ります。** 実際の名前・連絡先・会社の資料のかわりに、**自分で作り上げた資料**を使ってください。通常のチャットで行った練習は、課題10で片付けます。入れてはいけない情報は、[ステップ1 第9章](../00-common/09-safety.md#入れてはいけないもの)にあります。
- **「いいね」「よくないね」は押しません。** フィードバックを送ると、「アクティビティの保存（활동 기록 보관）」をオフにしてあっても、その会話がサービスの改善に使われます（[第9章](09-privacy.md#人が読むのか-aiの学習に使われるのか)）。[^hub]

## 課題

### 課題1. 一時チャットで練習スペースを作る

**こんなとき**: 記録に残したくない質問をしてみたいとき。

**やってみること**: 右上の「一時チャット（임시 채팅）」を押して、下を送ります。答えをもらったら、右上の×で閉じます。

```
私はGeminiを初めて使います。今日練習するとよい質問を3つおすすめして。
```

**うまくいったか確認**

- ☐ 画面の中央に、「一時チャットは最近のチャットに表示されず…（임시 채팅은 최근 채팅에 표시되지 않으며…）」という案内が出た[^screen]
- ☐ 残したい答えは、閉じる前にコピーしておいた（残したい答えがなければチェック）
- ☐ 閉じたあと、サイドメニューの会話一覧にこの会話がない

**見直す場所**: [第2章 画面を見て回る](02-screen-tour.md)

### 課題2. モデルボタンで思考レベルを変えてみる

**こんなとき**: 難しい質問に、より深く考えた答えがほしいとき。

**やってみること**: 一時チャットで下を送ったあと、入力欄のモデルボタンで思考レベルを1段階上げて、同じ質問をもう一度送ります。

```
毎月30万ウォンずつ2年間貯めるのと、最初に600万ウォンを入れて2年間置いておくのとでは、何が違うのか、
利息の計算方法の違いを、中学生にもわかるように説明して。
```

**うまくいったか確認**

- ☐ モデルボタンを押して、いま使っているモデルと思考レベルを確認した
- ☐ 思考レベルを変えたあと、答えの長さや説明の順番がどう変わったか比べた
- ☐ プランによって選べる項目が違うことがわかった（無料なら、見える項目だけ確認してチェック）

**見直す場所**: [第2章 モデルボタン](02-screen-tour.md#モデルボタン-—-モデルと思考レベル)

### 課題3. 会話の名前を変えて、もう一度探す

**こんなとき**: 過去の会話を、あとでもう一度探したいとき。

**やってみること**: 通常のチャットで下を送ります。サイドメニューで、この会話の点3つ→「名前を変更（이름 변경）」で、タイトルを「[練習] 読書会の準備物」に変えます。そのあと、「チャットを検索（채팅 검색）」に「練習」を入れて探してみます。

```
読書会に初めて来る人が持ってくるとよい準備物を、5つだけ教えて。
```

**うまくいったか確認**

- ☐ サイドメニューの会話のタイトルが「[練習] 読書会の準備物」に変わった
- ☐ 「チャットを検索（채팅 검색）」で、この会話を見つけた
- ☐ 「固定（고정）」を押して一覧のいちばん上に貼り付けてから、「固定を解除（고정 해제）」で元に戻した

**見直す場所**: [第3章 会話の管理](03-chats.md)

### 課題4. 偽のお知らせ文をアップロードして表で受け取る

**こんなとき**: 長い文書を整理したり、別の形に変えたりしたいとき。

**やってみること**: メモ帳に、下のような偽のお知らせ文を書いて、ファイルで保存します。入力欄の「＋」→「ファイルをアップロード（파일 업로드）」でアップロードして、プロンプトを送ります。

```
11月の読書会のご案内
日付: 11月22日 土曜日 午後2時
場所: 区立図書館 3階 セミナー室
読む本: 『若草物語』
持ち物: 本、メモ用のノート、会費5,000ウォン
```

```
アップロードしたお知らせ文から、日付・場所・読む本・持ち物を取り出して、表に整理して。
ほかのアプリは使わず、このチャットに表で見せて。
```

**うまくいったか確認**

- ☐ 表の日付・場所・会費が、お知らせ文と一字一句同じである
- ☐ お知らせ文にない内容（例: 終わる時刻）を、作り話で書いていない
- ☐ 表のすぐ下の点3つを押して、「Sheetsにエクスポート（Sheets로 내보내기）」があることを確認した（押さなくても構わない）

**見直す場所**: [第4章 ファイルと作成](04-files-create.md) · [第3章 ほかのアプリにエクスポートする](03-chats.md#ほかのアプリにエクスポートする)

### 課題5. 指示を入れて、答えが変わるか見る

**こんなとき**: 毎回同じお願い（「短く」「表で」）をするのが面倒なとき。

**やってみること**: 「設定（설정）」→「パーソナルインテリジェンス（개인 인텔리전스）」→「Geminiへのリクエスト（Gemini 요청 사항）」に、下の指示を追加します。新しい通常のチャットで、適当な質問をしてみます。

```
答えのいちばん最初に一行の要約を付けて、難しい言葉はカッコで説明を付けて。
```

**うまくいったか確認**

- ☐ 新しいチャットの答えのいちばん最初に、一行の要約が付いた
- ☐ 「Geminiへのリクエスト（Gemini 요청 사항）」の画面に、自分が追加した指示が見えた
- ☐ 練習が終わったら、この指示を削除するか、自分に合うように直した

**見直す場所**: [第5章 記憶とカスタマイズ](05-memory.md)

### 課題6. 出典を開いて、Deep Researchの計画を直す

**こんなとき**: 答えの根拠を確認したいとき、または複数の資料を集めた報告書が必要なとき。

**やってみること**: まず下を送って、答えの「出典（출처）」を1つ開いてみます。そのあと、「＋」→「その他のツール（도구 더보기）」→「Deep Research」をオンにして、同じテーマを送り、計画が出たら、「計画を修正（계획 수정）」で「公式の統計だけを使って」と直します。

```
最近5年間で、日本の一人暮らし世帯の割合がどう変わったか、出典とあわせて教えて。
```

**うまくいったか確認**

- ☐ 出典のリンクを開いて、答えの数字が原文と同じか見た
- ☐ Deep Researchの計画が出たときに、「計画を修正（계획 수정）」で条件を足した
- ☐ 報告書を最後まで受け取るつもりがなければ、停止ボタンで止めた（Deep Researchは使用量を多く使う）

**見直す場所**: [第6章 検索とDeep Research](06-search.md)

### 課題7. スキルを作って呼び出して使う

**こんなとき**: 同じお願いをよくするとき。

**やってみること**: 「パーソナライズ（맞춤설정）」→「スキル（스킬）」→「作成（만들기）」→「手動で作成（수동으로 만들기）」で、下のようにスキルを作ります。新しいチャットで`/`を打ってスキルを選んでから、偽の会議メモを貼り付けます。

```
名前: summarize-meeting-notes
説明: 議事録を、決定事項・やること・担当者に整理する。議事録や会議メモを貼り付けたときに使う。
指示: 議事録を受け取ったら、1. 決まったこと 2. やること（やること - 担当者 - 期限） 3. 次にもう一度見ることの順に整理して。
担当者や期限がなければ、作り話をせずに「要確認」と書いて。
```

**うまくいったか確認**

- ☐ `/`を打ったとき、作ったスキルが一覧に見えた（`@`に変わっていたら`@`）
- ☐ 担当者がいないやることに、「要確認」と出た
- ☐ 練習が終わったら、「その他（더보기）」→「無効にする（비활성화）」または「削除（삭제）」で片付けた

**見直す場所**: [第7章 スキルとつないだアプリ](07-skills-apps.md)

### 課題8. 予定を入れて「予約済み」で削除する

**こんなとき**: 毎日・毎週、同じ知らせを受け取りたいとき。

**やってみること**: 通常のチャットで下を送ります。サイドメニューの「予約済み（예약됨）」で予定ができたか見て、「その他（더보기）」で削除します。有料プランなら、入力欄の下の「タスク（작업）」を押して、「聞いて」も送ってみます。チャットの予定は少しずつ開放されている途中なので、まだ使えないこともあります。

```
毎週月曜の朝8時に、今週のソウルの天気を3行で要約して。
```

**うまくいったか確認**

- ☐ Geminiが、予定の要約（いつ・どのくらいの頻度で）で答えた
- ☐ 「予約済み（예약됨）」で、この予定を見つけた
- ☐ 練習が終わったので、予定を削除した

**見直す場所**: [第8章 仕事を任せる](08-tasks.md)

### 課題9. スマホで声で聞いてみる

**こんなとき**: 文字を打つのが難しいとき、または声で練習したいとき。

**やってみること**: スマホにGeminiアプリをインストールして、同じGoogleアカウントでログインします。マイクを押して、下の内容を話します。Androidなら、「Live」も押してみます。

```
今夜、冷蔵庫にある卵、豆腐、長ねぎで作れる料理を3つ教えて。
```

**うまくいったか確認**

- ☐ 話した内容が文字に変わって、質問が送られた
- ☐ パソコンのWebの会話一覧にも、この会話が見えた（通常のチャットだった場合）
- ☐ Liveを使ったなら、「終了（종료）」を押したあと、同じ会話が文字で続くのを見た（Liveを使わなかったならチェック）

**見直す場所**: [第10章 音声とスマホ](10-voice-mobile.md)

### 課題10. 自分のデータの設定を点検して片付ける

**こんなとき**: 実習を終えたとき、そして数か月に一度。

**やってみること**: 左下の「設定（설정）」を開いて、下のチェックリストのとおりに確認します。

**うまくいったか確認**

- ☐ 「アクティビティ（활동）」で、「アクティビティの保存（활동 기록 보관）」が自分の望む側（オン・オフ）になっている
- ☐ 自動削除の期間（初期設定は18か月）を、自分に合うように選んだ
- ☐ 「自分の公開リンク（내 공개 링크）」で、もう必要のないリンクを削除した（共有した会話がなければチェック）
- ☐ 「パーソナライズ（맞춤설정）」→「コネクタ（커넥터）」で、必要のない接続済みのアプリを「接続を解除（연결 해제）」した
- ☐ 課題3・4・5・6・7で作った練習の会話を削除した。接続を切ったりアプリのデータを削除したりしても会話の履歴は残るので、会話も別に削除する

**見直す場所**: [第9章 プライバシーと安全](09-privacy.md) · [第3章 会話の管理](03-chats.md) · [第7章 つないだアプリ](07-skills-apps.md#連携アプリ-—-gmail・drive・カレンダーをgeminiで)

## まとめ

- 機能は、読むだけでは手に馴染まない。ボタンを1回ずつ、自分で押してみる。
- 実習はできるだけ一時チャットで行い、履歴・スキル・予定を扱う課題は、偽の資料で通常のチャットで行う。
- 課題8の「タスク（작업）」は、有料プランが必要である。ほかのメニューも、アカウントによって見えなければ、読むだけにして先へ進む。
- 課題ごとにチェックリストで自分で確認し、チェックできなかった部分は、「見直す場所」を読んでやり直してみる。
- 実習が終わったら、「アクティビティの保存（활동 기록 보관）」・自動削除・公開リンク・つないだアプリを点検し、練習の会話を片付ける。

この章で新しく出てきた用語はありません。一時チャット・スキル・タスクのような言葉は、各章の「用語まとめ」にあります。
