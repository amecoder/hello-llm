# 第3章 会話の管理 — 探す・整理する・共有する・エクスポートする

> **一言まとめ**: 過去の会話は、サイドメニューから**探して、固定して、名前を変えて、削除できます。**
> 他の人に見せるときは**共有リンク**を、ドキュメントやメールに移すときは**エクスポート**を使います。共有リンクは、リンクを持っている人なら誰でも読めるという点だけは、必ず覚えておいてください。

画面は2026年10月のWeb版を基準にしていて、図は有料プラン（Google AI Pro）の韓国語画面です。スマホアプリは、メニューの位置が少し違うことがあります。

## 過去の会話を探す

過去の会話は、左のサイドメニューの会話一覧に集まります（[第2章](02-screen-tour.md)）。[^recent]
会話が増えると、一覧をたどって探すのは大変です。そんなときは、サイドメニューの上のほうの「チャットを検索（채팅 검색）」（虫眼鏡）を押して、探す言葉を入れてからEnterを押してください。[^recent][^screen]

たとえば、先週キムジャン（白菜キムチ作り）の材料を聞いたなら、「キムジャン」で探してみましょう。検索欄は、画面の上のほうに別に開きます。[^screen]

**個人アカウントでは、「アクティビティの保存（활동 기록 보관）」がオンになっていないと、会話の検索・固定・名前の変更・削除が使えません。**[^recent]
「アクティビティの保存（활동 기록 보관）」は、自分の会話をアカウントに残しておく設定です。18歳以上なら、最初からオンになっています。「設定（설정）」→「アクティビティ（활동）」を押すと開く「Geminiアプリのアクティビティ（Gemini 앱 활동）」ページにあります。オフにする方法と、オフにしたときに変わる点は、[第9章](09-privacy.md#「アクティビティを保存」のオンとオフ)で扱います。[^activity]

会社・学校のアカウントは、管理者が記録を管理します。このときは、自分で会話を削除できません。[^recent]

## 固定・名前の変更・削除

よく開く会話は**固定**しておきましょう。会話一覧でその会話にマウスを乗せると、右側に点が3つ（⋮）出てきます。押すと、会話のメニューが開きます。[^recent][^screen]

![サイドメニューの会話一覧で「[연습] 독서 모임 준비물」という会話の右側の点3つ（①）を押すと開くメニュー（②）— 「会話を共有（대화 공유）」「固定（고정）」「名前を変更（이름 변경）」「ノートブックに追加（노트북에 추가）」「削除（삭제）」。ほかの会話のタイトルは例に変えた画面である](../../../guide/12-gemini/assets/shot-08-chat-menu-marked.png)

練習用に作った会話で撮影していて、ほかの会話のタイトルは例に変えた画面です。①点3つを押すと、②メニューが開きます。[^screen]

| メニュー | すること |
|---|---|
| 「固定（고정）」 | 会話を一覧のいちばん上に貼り付けておく（固定したあとは「固定を解除（고정 해제）」） |
| 「名前を変更（이름 변경）」 | 会話のタイトルを変える |
| 「削除（삭제）」 | 会話を削除する |
| 「会話を共有（대화 공유）」 | 公開リンクを作る（下の「会話を共有する」） |
| 「ノートブックに追加（노트북에 추가）」 | 会話をノートブックにまとめる（ノートブックは第6章） |

出典: Googleヘルプと実際の画面[^recent][^screen]

会話を開いている状態なら、右上の点3つのボタン（画面読み上げ用の名前は「会話アクションメニューを開く（대화 작업 메뉴 열기）」）からも、同じことができます。[^screen]

![会話画面の右上の点3つのボタン（①、「会話アクションメニューを開く（대화 작업 메뉴 열기）」）を押すと開くメニュー（②）— 「会話を共有（대화 공유）」「固定（고정）」「名前を変更（이름 변경）」「PDFをダウンロード（PDF 다운로드）」「Docsにエクスポート（Docs로 내보내기）」「ノートブックに追加（노트북에 추가）」「削除（삭제）」](../../../guide/12-gemini/assets/shot-09-top-menu-marked.png)

このメニュー（②）には、サイドメニューにはない「PDFをダウンロード（PDF 다운로드）」と「Docsにエクスポート（Docs로 내보내기）」もあります。[^screen]

「11月の読書会のお知らせ」のように、**日付や仕事の名前が入ったタイトル**に変えておくと、一覧で見分けやすくなります。

**削除する前に知っておくことが2つあります。**[^recent]

- **会話を削除すると、「Geminiアプリのアクティビティ（Gemini 앱 활동）」からも一緒に削除されます。** 自分の会話の記録からも消えます。
- **その会話で作ったものも一緒に削除されます。** Canvasで作った文書やアプリのような成果物が、一緒に消えます（Canvasは[第4章](04-files-create.md)）。

ですから、その会話で作った文書をこれからも使うなら、削除する前に[エクスポート](#ほかのアプリにエクスポートする)で移しておきましょう。

## 会話を分岐して続ける — ブランチ

長い会話の途中で、**別の方向へ一度行ってみたくなるとき**があります。たとえば、旅行の日程を組んでいて、「雨が降ったらどうしよう？」を別に聞きたい場合です。

そんなときは、その時点の答えの下にある「その他のオプション（옵션 더보기）」（点3つ）を押して、「新しいチャットでブランチを作成（새 채팅에서 브랜치 생성）」を選んでください。[^screen][^recent] その時点から分かれた**新しい会話**が開きます。元の会話はそのまま残っているので、あとで戻って続けられます。[^recent]

![答えの下のツール行（①: 「いい回答（대답이 마음에 들어요）」「よくない回答（대답이 마음에 들지 않아요）」「再実行（다시 실행）」「コピー（복사）」「その他のオプション（옵션 더보기）」）で「その他のオプション」を押したメニュー。②「新しいチャットでブランチを作成（새 채팅에서 브랜치 생성）」、③「Docsにエクスポート（Docs로 내보내기）」「Gmailの下書きを作成（Gmail 초안 작성）」に赤い番号がついている。そのほかに「読み上げ（듣기）」「法的問題を報告（법적 문제 신고）」「思考プロセスを表示（사고 단계 표시）」がある](../../../guide/12-gemini/assets/shot-10-answer-menu-marked.png)

①答えの下のツール行のいちばん右の点3つを押すと、メニューが開きます。②がブランチ、③は下の「ほかのアプリにエクスポートする」で使います。[^screen]

ブランチにすると、元の会話が脇道の質問で散らかりません。[ステップ1 第6章](../00-common/06-conversation.md)で学んだ「話題が変わったら新しい会話」を、前の内容を失わずに行う方法です。

**この2つは別々に削除されます。** 分かれてできた会話を削除しても元の会話は残り、元の会話を削除しても分かれてできた会話は残ります。[^recent]

## 会話を共有する — 公開リンク

会話を他の人に見せるには、**公開リンク**を作ります。会話のメニュー（サイドメニューの点3つ、または右上の点3つ）で「会話を共有（대화 공유）」を選んでください。上の会話メニューの図にあります。[^screen] リンク（g.co/gemini/share/…）が作られます。[^share]

**リンクを持っている人なら誰でも、その会話を読めます。** 自分が直接送っていない人でも、リンクさえあれば読めて、さらに広められます。[^share]
ですから、共有する前に、会話全体に一度目を通してください。リンクは**会話全体**を見せます。アップロードした写真は、受け取った人がダウンロードすることもできます。[^share]

知っておくことは次のとおりです。[^share]

- **自分の名前は付きません。** リンクのアドレスや共有ページに、自分の名前やアカウントは表示されません。
- **リンクを作った時点のまま見えます。** そのあとに会話を直したり続けて書いたりしても、共有ページは変わりません。直した内容を見せるには、リンクを新しく作ってください。
- **作った成果物も一緒に見えます。** Canvasの文書、画像、動画も、共有ページに入ります。
- **受け取った人が続きを会話できます。** リンクを開いた人が、「このチャットを続ける（이 채팅 계속하기）」で会話を続けられます。ただし、Gemで作った会話と、18歳未満の場合はできません。また、**自分がGoogle AIの有料プランで作った会話なら、受け取る人も有料プランである必要が**あります。

### 共有したリンクを削除する

共有をやめたいときは、「設定（설정）」→「自分の公開リンク（내 공개 링크）」に行って、そのリンクを削除してください。「すべてのリンクを削除（모든 링크 삭제）」で、一度に削除することもできます。[^share][^screen]

リンクを削除しても、残るものがあります。[^share]

- **ほかの場所に投稿した文章はそのままです。** カフェ（コミュニティ）やメッセンジャーにリンクを貼った投稿は、その場所で別に消す必要があります。
- **自分の会話は削除されません。** リンクだけが消えて、会話は自分の一覧にそのまま残ります。

逆に、**会話を削除すると、その会話のリンクも一緒に消えます。** リンクは、会話が自分の記録に残っている間だけ開きます。[^share]

共有する前に次のように聞くと、うっかり入れた個人情報を探すのに役立ちます。ただし、AIがすべて見つけてくれるとは信じず、最後は自分で読んでください（[ステップ1 第9章](../00-common/09-safety.md)）。

```
この会話を他の人に共有しようと思っています。これまでの会話に、名前、電話番号、住所、会社名のように、
他の人に見られると困る情報がないか探して、リストで教えてください。
```

## ほかのアプリにエクスポートする

答えをドキュメントやメールに移したいときは、**エクスポート**を使いましょう。自分でコピーして貼り付けなくても、新しいドキュメントやメールの下書きがすぐにできます。
答えの下の「その他のオプション（옵션 더보기）」（点3つ）を押すと、「Docsにエクスポート（Docs로 내보내기）」と「Gmailの下書きを作成（Gmail 초안 작성）」があります（上の図の③）。[^screen][^export]

| メニュー | ある場所 | 結果 |
|---|---|---|
| 「Docsにエクスポート（Docs로 내보내기）」 | 答えの下の点3つ | Google Driveに新しいドキュメントができる |
| 「Gmailの下書きを作成（Gmail 초안 작성）」 | 答えの下の点3つ | Gmailに新しいメールの下書きができる |
| 「Sheetsにエクスポート（Sheets로 내보내기）」 | 表の下の点3つ | 答えの中の表がGoogleスプレッドシートに行く |

出典: Googleヘルプと実際の画面[^export][^screen]

「Sheetsにエクスポート（Sheets로 내보내기）」は、表のすぐ下の小さな点3つ（…）を押すと出てきます。表がある答えでだけ見えて、画像が入った表はエクスポートできません。[^export][^screen]

![表のすぐ下の小さな点3つ（①）を押すと開くメニュー（②）— 「Sheetsにエクスポート（Sheets로 내보내기）」「コピー（복사）」。その下の③は、答え全体のツール行である](../../../guide/12-gemini/assets/shot-11-table-menu-marked.png)

①表の下の点3つと、③答えの下の点3つは、別のメニューです。表だけを移すなら、①を押してください。[^screen]
「Gmailの下書きを作成（Gmail 초안 작성）」には、Gmailアカウントが必要です。メールがそのまま送られるのではなく、**下書き**として保存されるので、宛先と内容を確認してから、自分で送ってください。[^export]

たとえば、次のように受け取った表を「Sheetsにエクスポート（Sheets로 내보내기）」で移せば、すぐに並べ替えたり直したりできます。

```
来月の読書会の準備物を表にして。列は、準備物、担当者、予想費用にして。
ほかのアプリは使わず、このチャットに表で見せて。
```

2行目を付けたのには理由があります。このガイドが1行目だけを送ったとき、Geminiは会話の中に表を見せませんでした。かわりに、Google Sheetsにつなごうとして止まりました。[^screen] 表をまず会話の中で確認したいなら、2行目のようにはっきり伝えてください。

エクスポートした文書とメールは、そのサービス（Docs・Gmail）の規約とポリシーに従います。[^export]

## 答えをもらい直す・確認する

答えが気に入らなければ、**もらい直してみましょう。** 答えの下の「再実行（다시 실행）」（丸い矢印）を押すと、同じ質問に新しい答えを作ります。[^screen][^regen] いちばん新しい答えでだけできます。[^regen]
もらい直したあとは、答えの下の矢印で前後の答えを行き来して、比べられます。[^regen]

**何が気に入らないかわかっているなら、直してほしいと伝えてみましょう。** 会話を続けながら、長さ、言葉のやさしさ、口調を変えてほしいと頼めます。[^regen] 質問はよかったのに、答えがたまたまいまひとつだったなら、「再実行」が合っています（[ステップ1 第6章](../00-common/06-conversation.md)）。

| 惜しい頼み方 | よりよい頼み方 |
|---|---|
| （「再実行」だけを押し続ける） | 「3行に縮めて」 |
| （「再実行」だけを押し続ける） | 「小学生にもわかるやさしい言葉に変えて」 |
| （「再実行」だけを押し続ける） | 「口調をもっと丁寧に変えて」 |

何を変えるかを伝えれば、ほしい方向に近づきやすくなります。「再実行」だけを押すと、何が変わるかを選べません。

### 出典を確認する

答えの下や文の間に「出典（출처）」ボタンが見えたら、押してみましょう。右側に関連するリンクが開きます。[^sources]
リンクは、ウェブサイトのこともあれば、自分がアップロードしたファイルや、つないであるGmail・Docsのこともあります。[^sources]
**すべての答えに出典が付くわけではありません。** 「出典」ボタンがなければ、その答えにはリンクがないという意味です。[^sources]

Googleも、Geminiが間違えることがあるとはっきり言っています。[^accuracy]

- **医療・法律・お金の問題の専門家のアドバイスとして信じないでください。**
- **人についての答えは、とくにもう一度確認してください。** 間違った内容が出ることがあります。
- **Gemini自身についての説明も、間違っていることがあります。** たとえば、「あなたはどう学習したの？」や「出典はどうやって付けているの？」への答えが、実際と違うことがあります。機能が気になるときは、このガイドや公式ヘルプを見てください。

間違った答えを見たら、答えの下の「よくない回答（대답이 마음에 들지 않아요）」（親指を下に向けたマーク）を押して、何が間違っているか書いてください。[^accuracy] ただし、フィードバックを送ると、その会話も一緒にGoogleに行きます（[第1章](01-getting-started.md#うまくいかないときに最初にすること)）。

## 実際にやってみる

1. 新しいチャットで短い質問を1つ送り、サイドメニューでその会話の名前を「練習 — 今日の日付」に変える。
2. その会話を固定してから、固定を解除する。
3. 「チャットを検索（채팅 검색）」で「練習」を探して、その会話が出てくるか確認する。
4. 答えを1つ「Docsにエクスポート（Docs로 내보내기）」で移し、Google Driveに新しいドキュメントができたか見る。
5. 共有リンクを1つ作ってから、「設定（설정）」→「自分の公開リンク（내 공개 링크）」で削除する。

**続きの課題**（[読書会の準備](../00-common/practice-kit.md)）: 第2章で整理した準備リストを表にしてほしいと頼んだあと、「Sheetsにエクスポート（Sheets로 내보내기）」で移す。会話の名前は「読書会の準備」に変えておく。

## まとめ

- 過去の会話は、サイドメニューの一覧と「チャットを検索（채팅 검색）」で探す。個人アカウントは、「アクティビティの保存（활동 기록 보관）」がオンでないと、検索・固定・名前の変更・削除が使えない。
- 会話の点3つのメニューで、固定・名前の変更・削除・会話の共有をする。削除すると、その会話で作ったCanvasの成果物も一緒に削除される。
- 答えの下の点3つの「新しいチャットでブランチを作成（새 채팅에서 브랜치 생성）」で会話の途中から分かれても、元の会話はそのまま残る。
- 共有リンクは、リンクを持っている人なら誰でも読める。作った時点の内容だけが見える。「設定（설정）」→「自分の公開リンク（내 공개 링크）」で削除する。
- 答えの下の点3つからDocs・Gmailの下書きへ、表の下の点3つからSheetsへ移す。Gmailは下書きとしてだけ保存される。
- 「再実行（다시 실행）」は、いちばん新しい答えでだけできる。何を変えるかを伝えて直してもらうほうが早いことが多い。
- 「出典（출처）」で根拠を確認し、医療・法律・お金の問題と、人についての答えはもう一度確認する。

## 用語まとめ

| 用語 | 読み方 | 一言でいうと |
|---|---|---|
| Pin | ピン（固定） | 会話を一覧のいちばん上に貼り付けておくこと |
| Branch | ブランチ（分岐） | 会話の途中から分かれてできた新しい会話。画面での名前は「新しいチャットでブランチを作成（새 채팅에서 브랜치 생성）」 |
| Public Link | パブリック リンク（公開リンク） | リンクを持っている人なら誰でも会話を読めるアドレス |
| Export | エクスポート | 答えをDocs・Gmail・Sheetsのような他のアプリに移すこと |
| Regenerate | リジェネレート（再生成） | 同じ質問に答えを新しく作ること。画面での名前は「再実行（다시 실행）」 |
| Source | ソース（出典） | 答えの根拠になったウェブページ・ファイルのリンク |
| Keep Activity | キープ アクティビティ（アクティビティの保存） | 自分のGeminiの会話をアカウントに残しておく設定 |
