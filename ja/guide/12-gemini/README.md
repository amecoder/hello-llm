# ステップ2・Gemini利用ガイド

ステップ1では、どのAIにも通じる**上手な頼み方**を学びました。ステップ2では、**Geminiというサービスの画面と機能**を覚えます。
ボタンがどこにあるか、会話をどう整理するか、自分の情報がどう使われるか、といったことです。

> **このガイドは、2026年10月30日に確認したGoogle公式ヘルプと実際の画面をもとに書きました。** Geminiはメニュー名や機能がよく変わります。
> 画像は有料プラン（Google AI Pro）の韓国語Web画面なので、無料アカウントでは一部のメニューが表示されなかったり、使えなかったりすることがあります。
> 自分の画面と違うときは、画面に表示されている名前に従ってください。最新の内容は、各章の脚注にある公式ヘルプのリンクで確認できます。
