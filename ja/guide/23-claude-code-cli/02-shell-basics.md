# 第2章 ターミナルの基本

<Badge type="tip" text="必須" /> このステップを進めるなら、必ず読んでください。

> **一言まとめ**: ターミナルでどうしても必要なコマンドは、ほんのいくつかです。`pwd` で今いる場所を見て、`ls` で何があるかを見て、`cd` で移動します。この章の最後に、練習用フォルダを作ってメモを入れます。

この章の内容は、Claude Codeではなく、ターミナルそのものの基本的な使い方です。MacとLinuxは同じコマンドを使います。Windows PowerShellは、違う部分を並べて書きました。このWindowsのコマンドは実行していません。

覚える必要はありません。このページを横に開いておいて、まねしてみてください。2〜3回使ううちに、手が覚えます。

## プロンプトを読む

ターミナルを開くと、先頭に少し文字が見えて、カーソルが点滅しています。これを**プロンプト**（Prompt）といいます。「コマンドを待っています」という印です。AIに書く文章もプロンプトと呼びますが、ここではターミナルの待ち受けの印のことです。

形はパソコンによって違います。下は、ソヨンという人の例です。

```text
seoyeon@macbook ~ %
seoyeon@laptop:~$
PS C:\Users\seoyeon>
```

1行目はMac、2行目はLinux、3行目はWindows PowerShellのよくある形です。読み方は簡単です。ユーザー名とパソコンの名前が出て、今いるフォルダが出て、最後に `%`、`$`、`>` のような記号が来ます。

**この最後の記号は、自分で入力する文字ではありません。** 記号のあとにコマンドを入力してEnterを押すと、実行されます。結果が出たあとにまたプロンプトが見えたら、次のコマンドを受け付ける準備ができたということです。

コマンドは、英語の入力状態で入力します。`pwd` が `ｐｗｄ` や `ぷｗｄ` のようになったら、入力の切り替えキー（日本語キーボードなら半角/全角キー）を押して、もう一度入力してください。Macはふつう、`Caps Lock` や `Ctrl + Space` で切り替えます。

何も表示されないコマンドもあります。エラーではありません。静かに成功していることが多いのです。

## 今どこにいて、何があるか — pwdとls

ターミナルは、いつも**どこか1つのフォルダの中に**います。エクスプローラーやFinderで、フォルダを1つ開いているのと同じです。

`pwd` は、今いるフォルダを教えてくれます。「print working directory（作業フォルダを表示して）」の略です。

```bash
pwd
```

Macなら、こんなふうに表示されます。名前は自分のパソコンによって違います。

```text
/Users/seoyeon
```

`ls` は、今のフォルダに何があるかを見せてくれます。「list（一覧）」の略です。

```bash
ls
```

この2つのコマンドは、PowerShellでも同じ名前で使えます。ただし、表示の形は少し違います。

この2つのコマンドは、何も変えません。迷子になったと思ったら、いつでも入力してみてください。

## パスと ~

**パス**（Path、経路）は、ファイルやフォルダの住所です。MacとLinuxは `/` で、Windowsは `\` でフォルダを区切ります。日本語のキーボードや画面では、`\` が `¥` に見えることがあります。同じ文字です。

| OS | 自分のホームフォルダのパスの例 |
|---|---|
| Mac | `/Users/seoyeon` |
| Linux | `/home/seoyeon` |
| Windows | `C:\Users\seoyeon` |

**ホームフォルダ**は、自分のアカウントの出発点になるフォルダです。ターミナルを開くと、ふつうはここから始まります。この住所を短く書く記号が `~`（チルダ）です。だから `~/hello-ai-연습` は、「自分のホームフォルダの中の hello-ai-연습 フォルダ」という意味です。[^win-home]

パスの書き方は2つあります。

- **フルの住所**: `~/hello-ai-연습/터미널` のように、どこで入力しても同じ場所を指します。
- **今の場所が基準**: `inbox` のように書くと、「今のフォルダの中の inbox」です。

`..` は1つ上のフォルダを表します。`.` は今のフォルダです。

名前にスペースがあるときは、`"自分のメモ"` のように引用符で囲みます。ターミナルは、スペースを「ここから次の言葉が始まる」と読むからです。この講座のフォルダ名にスペースを入れていないのも、そのためです。

## コマンドの読み方

コマンドは、いくつかの単語でできています。単語はスペースで区切られます。初めて見るコマンドでも、順番に区切って読むと意味が見えてきます。

```bash
ls -la ~
```

この例は、Mac・Linuxのコマンドです。Windows PowerShellでは `ls -Force ~` と書きます。

| かけら | 名前 | 意味 |
|---|---|---|
| `ls` | コマンド名 | 何をするか: 一覧を見る |
| `-la` | オプション | どうやるか: 隠しファイルまで詳しく |
| `~` | 対象 | どこでやるか: ホームフォルダ |

オプションは、コマンドの動きを変えるスイッチです。Mac・Linuxには、2つの形があります。

- **短いオプション**: `-` 1つと文字1つです。`-l` と `-a` をくっつけて `-la` と書けます。
- **長いオプション**: `--` 2つと単語です。`--version` のように、意味がわかりやすくなります。

PowerShellは、`-Force` のように `-` 1つに単語を付けます。同じ意味のオプションでも、名前が違うことがあります。だから上の `ls -la ~` は、PowerShellでは `ls -Force ~` と書きます。`claude` と `git` のオプションは、どのOSでも同じです。

オプションのあとに値が付くこともあります。たとえば `--max-turns 10` は、「回数の上限は10」という意味です。このオプションは今覚えなくてかまいません。

引用符で囲んだ部分は、ひとかたまりです。`claude -p "メモを要約して"` では、引用符の中はスペースがあっても1つの単語として扱います。

すべてのコマンドを覚える必要はありません。この講座のコマンドは、[コマンド辞典](command-reference.md)にまとめてあります。知らないかけらが見えたら、調べてみてください。

## 移動する・作る・コピーする — cd、mkdir、cp

`cd` は、別のフォルダに移動します。「change directory（フォルダを変える）」の略です。下の練習用フォルダは、この章の最後に作ります。今は読むだけにしてください。

```bash
cd ~/hello-ai-연습
cd ..
cd ~
```

上から順に、練習用フォルダに行く、1つ上に行く、ホームフォルダに行く、です。PowerShellでも、そのまま使えます。

`mkdir` は、新しいフォルダを作ります。「make directory（フォルダを作る）」の略です。MacとLinuxでは、`mkdir -p` と書くと、途中のフォルダまで一度に作ります。PowerShellの `mkdir` は、`-p` がなくてもそうします。実際のコマンドは、この章の最後の実習で入力してみます。

`cp` は、ファイルをコピーします。「copy（コピー）」の略です。**何を、どこへ**の順に書きます。

いまひとつの例です。どこへコピーするかが抜けています。

```bash
cp メモ.txt
```

よい例です。何を、どこへが、どちらもそろっています。

```bash
cp メモ.txt inbox/
```

コピーなので、元のファイルはそのまま残ります。ただし、同じ名前のファイルがすでにあると、何も言わずに上書きすることがあります。コピーする前に、`ls` で一度見てください。

## 手が楽になるキー

コマンドを全部覚えて、全部入力する必要はありません。下の5つさえ知っていれば、ずっと楽になります。

**貼り付けとコピー。** ターミナルでは、ふだんとキーが少し違います。コピーするときは、ターミナルの文字をマウスでドラッグして選んでから押します。

| やること | Mac | Linux | Windows PowerShell |
|---|---|---|---|
| 貼り付け | `Cmd + V` | `Ctrl + Shift + V`[^paste] | `Ctrl + V`、右クリック[^paste-win] |
| コピー | `Cmd + C` | `Ctrl + Shift + C` | 選んでから `Ctrl + C`、右クリック |

プログラムによって少し違うことがあります。このページのコマンドは、コピーして貼り付けてもかまいません。打ち間違いが減ります。貼り付けたあと、まだ実行されていなければ、Enterをもう一度押してください。

今やってみてください。上の `pwd` をコピーしてターミナルに貼り付け、Enterを押します。

**上矢印キー。** さっき入力したコマンドが、もう一度出てきます。何回か押すと、もっと前のコマンドに戻ります。少しだけ直して実行し直すときに便利です。さっき入力した `pwd` がまた出てくるか、押してみてください。

**Tab。** 名前の最初の部分だけ入力してTabを押すと、残りを埋めてくれます。`cd ~/Doc` まで入力して、Tabを押してみてください。`Documents` フォルダがなければ、`ls` に表示される別のフォルダ名で試してください。長いハングルのファイル名で特に役立ちます。ハングルでうまく埋まらないときは、名前をコピーして貼り付ければ大丈夫です。

**Ctrl+C。** 動いているコマンドを止めます。ターミナルが固まったように見えたら、まず押してみてください。下のコマンドは30秒待ちます。Mac、Linux、PowerShellのどれでも使えます。

```bash
sleep 30
```

待たずに `Ctrl + C` を押してみてください。プロンプトがすぐに戻ってきます。Macでも `Cmd` ではなく `Ctrl` です。文字を選んでいない状態のCtrl+Cは、「止まれ」です。Windowsでは、文字を選んでいる状態のときだけコピーになります。

## やってみよう

練習用フォルダを作って、メモを入れてみます。このフォルダは、この講座でずっと使います。

**1. 練習用フォルダを作って、中に入ります。**

Mac・Linuxでは、こう入力します。

```bash
mkdir -p ~/hello-ai-연습/터미널/inbox
cd ~/hello-ai-연습/터미널
pwd
ls
```

Windows PowerShellでは、こう入力します。

```powershell
mkdir $HOME\hello-ai-연습\터미널\inbox
cd $HOME\hello-ai-연습\터미널
pwd
ls
```

Mac・Linuxのコマンドの `-p` は、途中のフォルダまで一度に作るためのオプションです。このオプションがないと、`hello-ai-연습` フォルダがないときにエラーになります。`$HOME` は、PowerShellでホームフォルダを指す名前です。`pwd` の結果が `터미널` で終わり、`ls` に `inbox` が見えれば成功です。

**2. 練習用のメモをダウンロードします。**

ブラウザで下のリンクを右クリックして、「名前を付けてリンク先を保存」を選びます。ブラウザによって名前は少し違います。保存先は、ダウンロードフォルダのままにしておいてください。

- [회의-2026-10-27-주간회의.txt](/practice/notes/inbox/회의-2026-10-27-주간회의.txt)

すべて作り話のメモです。日付や曜日も物語のために作ったものなので、実際のカレンダーとは合いません。あとの章で、Claudeがこの点を指摘することがあります。間違ったことを言っているわけではないので、驚かなくて大丈夫です。

**3. メモをinboxにコピーします。**

Mac・Linuxでは、こう入力します。

```bash
cp ~/Downloads/회의-2026-10-27-주간회의.txt inbox/
```

Windows PowerShellでは、こう入力します。

```powershell
cp $HOME\Downloads\회의-2026-10-27-주간회의.txt inbox\
```

Macでは、Finderに「ダウンロード」と表示されていても、実際のフォルダ名は `Downloads` です。Linuxを日本語で使っていると、`~/ダウンロード` になっていることがあります。そのときは、`~/Downloads` を `~/ダウンロード` に変えて入力してください。

**4. ちゃんと入ったか確かめます。**

```bash
ls inbox
cat inbox/회의-2026-10-27-주간회의.txt
```

`cat` は、ファイルの中身を画面に表示します。PowerShellでハングルが文字化けしたら、こう入力します。

```powershell
Get-Content -Encoding UTF8 inbox\회의-2026-10-27-주간회의.txt
```

自分に聞いてみてください。`pwd` の結果は、思っていたフォルダか？　`ls inbox` にメモのファイルが見えるか？　どちらもそうなら、次の章に進む準備はできています。

**つまずいたら**: `No such file or directory` や「見つかりません」という言葉が出たら、たいていは場所か名前が違っています。`pwd` で場所を確かめ、`ls ~/Downloads` でファイルが本当にあるかを確かめてください。

## まとめ

- プロンプトは「コマンドを待っている」という印。最後の記号は入力しない。
- `pwd` は今の場所、`ls` は一覧を見せる。何も変えないので、よく使う。
- `~` は自分のホームフォルダ、`..` は1つ上。
- `cd` は移動、`mkdir` はフォルダ作り、`cp` は「何を、どこへ」のコピー。
- 上矢印キーは前のコマンド、Tabは名前の補完、Ctrl+Cは停止。

## 用語まとめ

| 用語 | 読み方 | 一言でいうと |
|---|---|---|
| Prompt | プロンプト | ターミナルがコマンドを待っているという印 |
| Path | パス | ファイルやフォルダの住所（経路） |
| Home | ホーム | 自分のアカウントの出発点になるフォルダ（短く書くと `~`） |
| `pwd` | ピーダブリューディー | 今いるフォルダを表示するコマンド |
| `ls` | エルエス | フォルダの中の一覧を表示するコマンド |
| `cd` | シーディー | 別のフォルダに移動するコマンド |
| `mkdir` | メイクディレクトリ | 新しいフォルダを作るコマンド |
| `cp` | シーピー | ファイルをコピーするコマンド |
| `cat` | キャット | ファイルの中身を画面に表示するコマンド |
