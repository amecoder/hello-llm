# コマンド辞典

> **一言まとめ**: この講座に出てくるコマンドを1か所に集めました。知らないコマンドが出てきたら、ここで探してください。覚える必要はありません。

コマンドの読み方は[2章](02-shell-basics.md)にあります。短く言うと、**名前 · オプション · 対象** の順です。オプションは `-` や `--` で始まります。

まず、どこに入力するのかを見てください。カーソルのすぐ前の記号が `%`、`$`、`>` ならターミナルで、`❯` ならClaudeの入力欄です。行の先頭に `>` や `dquote>`、`heredoc>` だけが見えるなら、入力がまだ終わっていない状態です。`Ctrl + C` を押して、もう一度貼り付けてください。この辞典の表は、ほとんどがターミナルに入力するコマンドです。最後の節だけ、Claudeの入力欄に入力します。

## 記号

| 記号 | 意味 | 例 |
|---|---|---|
| `~` | 自分のホームフォルダ | `cd ~` |
| `.` | 今いるフォルダ | `git add .` |
| `..` | 1つ上のフォルダ | `cd ..` |
| `*` | 何文字でも（なくてもよい） | `inbox/meeting-*.txt` |
| `\|` | 前のコマンドの出力を後のコマンドに渡す | `cat メモ.txt \| claude -p "要約して"` |
| `>` | 出力をファイルに保存（上書き） | `claude -p "要約して" > 要約.txt` |
| `>>` | 出力をファイルの最後に付け足す | `echo 2行目 >> メモ.txt` |
| `<<'EOF'` | `EOF` の行の前までを、そのまま入力として渡す | 下の説明 |
| `"…"` | スペースがあっても1つのかたまりにまとめる | `claude -p "2語以上"` |
| `;` | 前のコマンドのあとに次のコマンドを続けて実行 | `pwd; ls` |
| `2>/dev/null` | エラーの文字を画面に出さない | `ls ないフォルダ 2>/dev/null` |
| `$?` | 直前のコマンドの終了コード | `echo $?` |

`>` はファイルの中身を消して新しく書きます。消えては困るファイルには使わないでください。`<<'EOF'` はMac・Linux専用です。Windows PowerShellでは、メモ帳でファイルを作ります。

いくつかの章で使う次の形は、ファイルを1つ作るひとまとまりです。

```bash
cat > メモ.txt <<'EOF'
1行目
2行目
EOF
```

`cat > メモ.txt` は、受け取った内容を `メモ.txt` に保存します。`<<'EOF'` は、`EOF` だけの行が出てくるまでを内容として渡します。だから、ファイルには真ん中の2行だけが入ります。`EOF` は「ここで終わり」という印です。引用符を付けたので、`$HOME` のような文字も置き換わらず、そのまま保存されます。

## フォルダとファイル

この表はMac・Linuxの場合です。PowerShellも `ls`、`cd`、`cp`、`mv`、`rm` のような名前を受け付けますが、オプションが違います。だから `ls -la` や `rm -rf` は、PowerShellでそのまま使わないでください。PowerShellのコマンドは、下の節に別にまとめました。

| コマンド | すること |
|---|---|
| `pwd` | 今いるフォルダを見る |
| `ls` | フォルダの中の一覧を見る |
| `ls -la` | 隠しファイルまで詳しく見る |
| `ls -a` | 隠しファイルまで見る |
| `cd フォルダ` | そのフォルダに移る |
| `mkdir フォルダ` | フォルダを作る |
| `mkdir -p あ/い/う` | 途中のフォルダまで一度に作る |
| `cp 元 先` | ファイルのコピー |
| `mv 元 先` | ファイルの移動 |
| `cat ファイル` | ファイルの中身を見る |
| `rm ファイル` | ファイルを消す |
| `rm -f ファイル` | ないファイルでもエラーを出さずに消す |
| `rm -rf フォルダ` | フォルダを中身ごと消す |
| `echo 文字` | 文字を出力する |
| `sleep 30` | 30秒待つ |
| `source ファイル` | ファイルの設定を今のウィンドウに反映 |
| `bash ファイル` | ファイルに書かれたコマンドを順に実行 |
| `fg` | `Ctrl + Z` で止めたプログラムに戻る |

`mkdir -p` の `-p` は、parents（親）の略です。フォルダがすでにあってもエラーになりません。

`rm` はごみ箱を通りません。`-r` はフォルダの中まで全部、`-f` は聞かずに消すという意味です。`rm -rf` は元に戻せません。入力するときは、フォルダ名を必ずもう一度読んでください。

## インストールに使うコマンド

| コマンド | すること |
|---|---|
| `curl アドレス` | インターネットのアドレスの内容を受け取る |
| `curl -fsSL アドレス \| bash` | インストール用のファイルを受け取って、すぐ実行 |
| `irm アドレス \| iex` | PowerShellで受け取って、すぐ実行 |

`-fsSL` は、4つのオプションをくっつけて書いたものです。

- `-f`: サーバーがエラーを出したら、エラーページを渡しません。
- `-s`: 進み具合の表示を隠します。
- `-S`: `-s` を使っても、エラーは見せます。
- `-L`: アドレスが移っていたら、移った先についていきます。

`irm` はファイルを受け取り、`iex` はその内容を実行します。[^irm] 上の表の2行は、どちらも**受け取った内容をそのまま実行**します。だから、信用できるアドレスにだけ使います。

## Windows PowerShellのコマンド

| コマンド | すること |
|---|---|
| `$HOME` | 自分のホームフォルダ |
| `ls -Force` | 隠しファイルまで見る |
| `mkdir フォルダ -Force` | フォルダがすでにあってもエラーを出さずに進む |
| `Get-Content -Encoding UTF8 ファイル` | ハングルが文字化けしないようにファイルを見る |
| `Copy-Item 元 先` | ファイルのコピー |
| `Move-Item 元 先` | ファイルの移動 |
| `Remove-Item ファイル` | ファイルを消す |
| `Write-Output 文字` | 文字を出力する |
| `notepad ファイル` | メモ帳でファイルを開く |
| `foreach (…) { … }` | 一覧の項目ごとに `{ }` の中を実行 |
| `if ($LASTEXITCODE -eq 0) { … } else { … }` | 成功なら前、失敗なら後ろを実行 |

`$LASTEXITCODE` は、終わったばかりのプログラムの終了コードです。`-eq 0` は「0と同じなら」という意味です。0は成功を表します。

## claudeのコマンド

ターミナルに入力します。最初の単語が `claude` です。

| コマンド | すること |
|---|---|
| `claude` | 会話を始める |
| `claude --version` | バージョンを見る |
| `claude --permission-mode manual` | 手動モードで始める |
| `claude -c` | このフォルダのいちばん最近の会話を続ける |
| `claude -r` | 過去の会話を選んで開く |
| `claude --resume 名前` | 名前を付けた会話をすぐ開く |
| `claude --safe-mode` | 自分の設定をオフにして始める |
| `claude purge` | このフォルダの保存された記録と状態を消す（練習では使わない） |
| `claude -p "依頼"` | 一度聞いて終わる |
| `claude --worktree 名前` | 別の作業フォルダで始める |
| `claude doctor` | インストールの状態を点検 |
| `claude update` | 最新バージョンにアップデート |
| `claude mcp add --transport http 名前 アドレス` | リモートのMCPサーバーを追加 |
| `claude mcp list` | MCPサーバーの一覧と接続の状態 |
| `claude mcp remove 名前` | MCPサーバーを消す |

`-r` は `--resume` の短い名前です。`claude purge` は元に戻すのが難しいです。練習のつもりで実行しないでください。

`-p` といっしょに使うオプションです。

| コマンド | 意味 |
|---|---|
| `claude -p "依頼" --allowedTools "Read,Write"` | 聞かずに使ってよいツールを決める |
| `claude -p "依頼" --max-turns 10` | 仕事を続ける回数の上限 |
| `claude -p "依頼" --output-format json` | 答えをJSON形式で出力 |

`--allowedTools` の `Read` はファイルの読み取り、`Write` はファイルの書き込みです。`--transport http` は、HTTPの方式で接続するリモートのサーバーという意味です。

## gitのコマンド

| コマンド | すること |
|---|---|
| `git --version` | Gitがあるかを見る |
| `git init` | このフォルダの記録を始める |
| `git config user.name "名前"` | 記録に書かれる名前を決める |
| `git config user.email "メール"` | 記録に書かれるメールを決める |
| `git config core.quotePath false` | ハングルのファイル名をそのまま表示する |
| `git add .` | 今いるフォルダの変更を、次の記録に入れる |
| `git status --short` | 変更の状態を短く見る |
| `git commit -m "説明"` | 説明を付けて記録を残す |
| `git reset` | 次の記録に入れたものを取り消す |
| `git log --oneline` | 記録を1行ずつ見る |

`-m` は、message（メッセージ）の略です。`--short` は、一覧を短く見せるという意味です。

## Claudeの入力欄のコマンド

`claude` を起動したあと、入力欄に入力します。よく使うものだけを集めました。全部の一覧は、入力欄で `/` を入力すると見られます。

| コマンド | すること |
|---|---|
| `/help` | ヘルプ |
| `/exit` | 終わる |
| `/rename 名前` | セッションに名前を付ける |
| `/resume` | 過去の会話を開く |
| `/context` | コンテキストを何が占めているかを見る |
| `/compact` | 会話を要約して短くする |
| `/clear` | 空の会話で新しく始める |
| `/rewind` | 巻き戻しメニューを開く |
| `/permissions` | 許可のルールを見る |
| `/usage` | 使用量を見る |
| `/model` | モデルを選ぶ |

ショートカットキーは[5章](05-input-commands.md)にあります。

[^irm]: Claude Code公式ドキュメント、「Terminal guide for new users」。"`irm` fetches the file and `iex` runs it." https://code.claude.com/docs/en/terminal-guide （確認日 2026-11-06）
