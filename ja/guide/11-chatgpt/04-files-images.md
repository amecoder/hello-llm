# 第4章 ファイル・写真と画像づくり — 見せて、描いてもらう

> **一言まとめ**: 言葉で説明しにくいものは**写真やファイルをアップロード**して見せ、必要な絵は**作ってもらう**ように頼めば大丈夫です。
> アップロードしたファイルは「ライブラリ（라이브러리）」に集まり、あとで再利用できます。無料プランは、1日にアップロードできるファイルの数が少なくなっています。

画面は2026年10月のWeb版（Plusプラン）が基準です。無料プランやスマホアプリは、メニューの位置が少し違うことがあります。

## 写真・ファイルをアップロードする

入力欄の左にある＋ボタンを押して、「写真とファイルを追加（사진 및 파일 추가）」を選びましょう。そのあと、自分のパソコンからファイルを選べば大丈夫です。[^files]
ファイルが入力欄の上に付いたら、そのファイルで何をするのか、質問を一緒に書いて送ります。

![入力欄の＋メニューを開いた画面。いちばん上の「사진 및 파일 추가 — 컴퓨터에서 업로드」（写真とファイルを追加 — コンピュータからアップロード）と、その下の「ライブラリから取り込む（라이브러리에서 가져오기）」「画像を生成（이미지 생성）」「スケッチ（스케치）」の項目を見てください](../../../guide/11-chatgpt/assets/shot-02-plus-menu-marked.png)

会話のタイトルとアカウント名は、例として変更した画面です。この章で使うのは、①＋ボタン、②「写真とファイルを追加」、③「ライブラリから取り込む」、④「画像を生成」、⑧「スケッチ」です。

アップロードできるものは次のとおりです。[^files]

| 種類 | 例 |
|---|---|
| 写真・絵 | レシートの写真、画面のキャプチャ、手書きメモの写真 |
| 文書 | PDF、Word（DOCX）、テキスト（TXT） |
| 表 | Excel（XLSX・XLS）、CSV |
| 発表資料 | PowerPoint（PPTX） |
| 音声（有料のみ） | WAV、MP3、M4Aの録音ファイル |

動画も添付できます。無料プランでも使えます。ただし、使えるかどうかは、機器やアップロードの方法によって違います。また、ChatGPTが動画全体や音声をすべて理解できないことがあります。[^image-faq]

Googleドキュメント（`.gdoc`）は、そのままアップロードできません。Googleドキュメントから、PDFやWordでダウンロードしてからアップロードしましょう。[^files]
PDFを会話に直接アップロードすると、文章だけでなく、**中の図や図表まで**読みます。[^files]

ファイルをアップロードして「見て」と言うだけではなく、何がほしいのかを一緒に書いてみましょう。ずっとよい答えが返ってきます。

```
添付したPDFは、うちのマンションの管理費の請求書です。
先月より大きく上がった項目を3つ探して表で見せて、なぜ上がったと考えられるか、思い当たる理由を1行ずつ書いてください。
確実でない内容には「推測」と書いてください。
```

ファイルでできることは、要約だけではありません。以前うまく書けた文書を**お手本**としてアップロードして、自分の下書きを同じ構成と口調に直してもらってみましょう。原本と自分の要約を一緒にアップロードすると、**食い違っている事実や、原本にない内容**も見つけられます。[^academy-content]
```
1つ目のファイルは公式のお知らせ（原本）で、2つ目のファイルは私が書いた要約です。
私の要約の中から、原本と違う事実・数字、原本にない内容をすべて見つけてください。
```

::: details 返ってくる答えはだいたいこんな感じ（例 — クリックして開く）
このガイドが作った例です。実際の答えは、サービスやそのときによって変わります。

> 原本と比べたところ、違うところが3か所あります。
>
> | 私の要約 | 原本 | 違い |
> |---|---|---|
> | 「締切 ○月○日」 | 「締切 ○月△日」 | 締切の日付が違う |
> | 「参加費 ○○円」 | （原本にない） | 原本にない内容 |
> | 「誰でも申し込み可」 | 「○○の住民のみ申し込み可」 | 対象が違う |
>
> 残りの内容は、原本と同じです。

**うまくいったか確認しましょう**: 原本と違う事実・数字を漏れなく見つけたか？ 原本にない内容が別に示されたか？ 答えが指摘したところを、実際の原本ファイルと一度照らし合わせてみましょう。

:::

写真なら、こう書きます。

```
添付した写真は冷蔵庫の中です。見える材料だけで30分以内に作れる夕食のメニューを2つ、おすすめしてください。
```

> 身分証、契約書、診療記録のような個人情報を含むファイルは、アップロードする前に隠すか、取り除きましょう。原則は[ステップ1 9章](../00-common/09-safety.md)で扱いました。

写真をアップロードするときは、次のことも知っておきましょう。[^image-faq]

- **写真の中のハングルは、読み間違えることがあります。** 韓国語や日本語のようにローマ字でない文字は、英語より正確さが落ちます。文字が大きく見えるように撮り、数字は原本と照らし合わせましょう。
- **CTやX線のような医療画像の読影には使わないでください。** 向いていない用途です。
- 見せたいところがあれば、写真編集アプリで**丸をつけて**アップロードしてみましょう。その部分により注目させることができます。

## アップロードできる量 — プランごとの上限

ファイルには、サイズと個数の上限があります。公式ヘルプに書かれた値は次のとおりです。[^files]

| 上限 | 値 |
|---|---|
| ファイル1つのサイズ（文書・発表資料） | 512MBまで |
| 文書1つの文章量 | 200万トークンまで |
| 表ファイル（CSVなど） | 約50MB（内容によって異なる） |
| 写真1枚 | 20MBまで |
| アップロードする個数 | 3時間に80個まで（混雑時はさらに低くなることがある） |
| **無料（Free）プラン** | **1日3個まで** |
| 自分のアカウント全体の保存容量 | 25GBまで |
| 音声ファイル | **有料のみ**アップロードできる |

**トークン**（token）は、AIが文章を細かく分けて読む単位です。200万トークンは、とても長い分量です。ふつうの業務文書なら、この上限に引っかかることはめったにありません。

無料プランでまずぶつかるのは、**1日3個**です。複数のファイルについて聞く必要があるなら、どうしても必要なファイルからアップロードしましょう。
写真が複数枚なら、1枚につなげてアップロードするのも一つの方法です。その分、個数を節約できます。
上限の数字はよく変わるので、上の値は確認日の時点のものとして見てください。

## ライブラリ — アップロードしたファイルをまとめておく場所

自分がアップロードしたファイルと、ChatGPTが作ったファイルは、サイドメニューの「ライブラリ」に**自動で保存**されます。ライブラリはWebで使います。[^library]
前回アップロードしたファイルをまた使いたいときは、＋ボタン→「ライブラリから取り込む」を押しましょう。ファイルをもう一度アップロードする必要はありません。

<!-- 스크린샷 필요: 옆 메뉴 「라이브러리」를 연 화면 (웹, 예시 파일만 보이게) -->

ライブラリに入れられる容量は、プランによって違います。[^library]

| プラン | ライブラリの容量 |
|---|---|
| Free | 500MB |
| Go | 4GB |
| Plus · Business | 20GB |
| Pro | 100GB |

知っておきたい点です。

- **会話を削除しても、ライブラリのファイルは残ります。** ファイルをなくすには、ライブラリで別に削除してください。[^delete]
- 削除したファイルは、「最近削除した項目（최근 삭제된 항목）」から復元できる場合があります。そして、30日以内に完全に削除されるよう予約されます。[^library]
- **一時チャット**（[3章](03-chats.md)）でアップロードしたファイルは、ライブラリに保存されません。[^library]
- **会話の中のダウンロードリンクは、すぐ切れます。** ChatGPTが作ったファイルはすぐに保存しておき、「Download failed」のように失敗したら、作り直してほしいと頼みましょう。[^errors]

> **ライブラリは「Space」（スペース）に変わりつつあります。** Spaceがライブラリの代わりになり、プロジェクトはそのまま残ります。[^space] Spaceでは、ファイルのほかに、複数の人が一緒に直す**ページ**（page、文書）も作れます。2026年10月24日の時点では、このガイドの画面ではまだ「ライブラリ」と表示されていました。サイドメニューに「Space」が表示されていたら、この節のライブラリと同じ場所だと思えば大丈夫です。

## 画像を作る

ChatGPTは、文章だけでなく絵も作ります。＋ボタン→「画像を生成」を押すか、最初の画面のおすすめ「이미지나 스티커 만들어줘」（画像やステッカーを作って）を押しましょう。そのあと、ほしい絵を説明すれば大丈夫です。一時チャットでは「画像を生成」がオフになっているので、通常のチャットで行いましょう（[3章](03-chats.md)）。

![「画像を生成」でお惣菜屋さんの絵を作った画面。右上に送った依頼が、下に水彩画と、絵の上の「編集（편집）」ボタンが見える](../../../guide/11-chatgpt/assets/shot-25-image-gen.png)

*下の例のプロンプトから、最後の「文字」の行だけを除いて送った画面です。文字を指定しなかったところ、看板に「우리동네 반찬가게」（うちの町のお惣菜屋さん）と自分で書きました。会話と絵は、撮影したあとに削除しました。*[^screen-image]

絵を頼むときも、ステップ1で学んだプロンプトの原則がそのまま通用します（[ステップ1 4章](../00-common/04-prompt-basics.md)）。次の4つを入れてみましょう。その分、ほしい絵に近づきます。

| 入れるもの | 例 |
|---|---|
| 何を | お惣菜屋さんの前に立つ笑顔のおばあさん |
| どんな雰囲気で | あたたかい水彩画、絵本のタッチ |
| どう配置するか | 正方形、真ん中に人物、背景はシンプルに |
| 文字 | 上のほうに「今日のおかず」 |

```
町のお惣菜屋さんの宣伝用の絵を作ってください。
- 内容: お店の前で、おかずのお皿を持って笑うおばあさん
- 雰囲気: あたたかい水彩画、絵本のタッチ
- 形: 正方形、おばあさんは真ん中、背景はシンプルに
- 文字: 上のほうに「今日のおかず」と大きく
```

最初の絵が気に入らなくても大丈夫です。文章を直すときのように、**直したいところだけを指定して**もう一度頼みましょう。「背景を夜に変えて、残りはそのままにして」のように言えば大丈夫です（[ステップ1 6章](../00-common/06-conversation.md)）。

### 参考写真を使う

言葉で説明しにくい様子は、**参考写真**を一緒にアップロードすれば大丈夫です。「写真とファイルを追加」で写真を付けて、何を真似してほしいかを伝えましょう。

```
添付した写真は、うちのお店の看板です。この看板の色と文字の雰囲気を生かして、
お盆休みの休業のお知らせポスターを作ってください。休業日: 10月5日〜7日。
```

設定→「パーソナライズ（개인 맞춤 설정）」画面には、「参考写真（참고 사진）」「全身の参考写真（전신 참고 사진）」の項目もあります。パーソナライズは[5章](05-memory.md)で扱います。

ChatGPTが作った絵には、**C2PA**（絵がどのように作られたかを記録しておく国際標準のタグ）が入っています。[^faq] 目には見えず、絵のファイルの中に一緒に保存される情報です。

AIで作った絵の権利と、他人の写真や作品をアップロードするときの注意は、[ステップ1 9章](../00-common/09-safety.md)で確認しましょう。

## スケッチ — 自分で描いて見せる

＋ボタン→「スケッチ」は、画面に**自分で絵を描いて、画像として貼り付ける**機能です。画面の説明は「그림을 그려 이미지로 첨부하세요」（絵を描いて画像として添付してください）です。

![「スケッチエディタ（스케치 편집기）」画面。上にはポインタ・ペン・文字・図形・消しゴムのツール、下には色選びと青い確認ボタンがあり、ペンで四角を3つ描いてある](../../../guide/11-chatgpt/assets/shot-26-sketch.png)

*描いた絵は貼り付けずに閉じました。閉じるときに「변경 사항을 삭제할까요?」（変更を破棄しますか？）と、もう一度聞かれます。*[^screen-sketch]

上手に描く必要はありません。言葉で説明しにくい**配置や形**を、ざっくり描いて見せれば大丈夫です。
たとえば、チラシの配置を四角と矢印で描いて貼り付け、こう頼んでみましょう。

```
添付したスケッチはチラシの配置です。上の大きな四角にお店の名前、真ん中の丸に看板メニューの写真、
下の小さな四角3つに価格を入れます。この配置どおりにチラシの絵を作ってください。
```

## 実際にやってみよう

1. 家にあるレシートやメモをスマホで撮ってパソコンに移し、「写真とファイルを追加」でアップロードして、「書かれている内容を表に整理して」と頼む（名前・カード番号は隠す）。
2. サイドメニューの「ライブラリ」を開いて、いまアップロードした写真が保存されているか確認する。
3. 「画像を生成」で上のお惣菜屋さんの絵を作り、「背景を春の雰囲気に変えて、残りはそのままにして」と一度直してみる。
4. 「スケッチ」で四角を3つ描いて貼り付け、「この配置で誕生日の招待状を作って」と頼む。

**続きの課題**（[読書会の準備](../00-common/practice-kit.md)）: サンプルファイルのminutes-last-meeting.txtを「写真とファイルを追加」でアップロードして、「決めたこと・やること・まだ決まっていないことを表に分けて。やることには担当と期限を書いて、期限がないものは『期限未定』と書いて」と送ります。やることが3つともそろっているか、議事録と照らし合わせます。

## まとめ

- ＋ボタン→「写真とファイルを追加」で、写真・文書・表・発表資料をアップロードする。音声ファイルは有料のみ使える。
- ファイルだけをアップロードせず、何がほしいのかを一緒に書く。
- 無料プランは1日3個までアップロードできる。写真は20MB、文書は512MBまで。
- 写真の中のハングルや数字は読み間違えることがあるので、原本と照らし合わせる。
- アップロードしたファイルは「ライブラリ」（「Space」に変わりつつある）に自動で保存され、会話を削除しても残る。
- 絵は「画像を生成」で、内容・雰囲気・配置・文字を入れて頼み、参考写真や「スケッチ」で見せられる。

## 用語まとめ

| 用語 | 読み方 | 一言でいうと |
|---|---|---|
| Upload | アップロード | 自分の機器のファイルをサービスに送ること |
| Token | トークン | AIが文章を細かく分けて読む単位 |
| MB · GB | メガバイト · ギガバイト | ファイルサイズの単位。1GBはおよそ1,000MB |
| Library | ライブラリ | アップロードしたり作ったりしたファイルをまとめておく場所 |
| Image Generation | イメージ・ジェネレーション（画像生成） | 言葉で説明した絵をAIが描いてくれる機能 |
| Reference Image | リファレンス・イメージ（参考写真） | 絵を作るときに真似するお手本の写真 |
| Sketch | スケッチ | 自分でざっくり描いた絵 |
| Space | スペース | ライブラリの代わりになる、ファイル・ページの空間 |
| C2PA | シーツーピーエー | 写真・絵がどのように作られたかを記録しておく国際標準のタグ |
