# 第9章 音声で会話する — 音声入力と音声会話

> **一言まとめ**: 入力欄の右には、声で入力するためのボタンが2つあります。**マイク**は自分の声を文字にして書き起こしてくれ（音声入力）、
> **青い波形のボタン**は、ChatGPTと電話のように声でやりとりさせてくれます（音声会話）。声も会話の記録のように保存されることがあるので、場所と内容を選んで使いましょう。

画面は2026年10月のWeb版（Plusプラン）が基準です。無料プランやスマホアプリは、メニューの位置が少し違うことがあります。

## 2つのボタンの違い — 音声入力と音声会話

![ChatGPTの最初の画面。中央の入力欄「ChatGPT에게 물어보세요」（ChatGPTに質問してください）の右端に、灰色のマイクボタンと、青い丸の中に波形が入ったボタンが並んでいる。画面の下には「새로운 한국어 음성」（新しい韓国語の音声）の案内と「새 음성 사용해 보기」（新しい音声を試す）ボタンが見える](../../../guide/11-chatgpt/assets/shot-01-home-voice.png)

会話のタイトルとアカウント名は、例として変更した画面です。①マイクが音声入力、②青い波形のボタンが音声会話で、③下のほうは新しい韓国語の音声の案内です。

| | ① マイク — 音声入力（Dictation） | ② 青い波形のボタン — 音声会話（Voice） |
|---|---|---|
| すること | 自分の声を**文字に変えて入力欄に入れる** | ChatGPTと**声でやりとりする**。答えも声で届く |
| 送る前に | 書き起こされた文を**読んで直してから**自分で送る | 直す間もなく、そのまま会話が続く |
| 向いているとき | 長い質問を手で打つのが面倒なとき、正確な文が大事なとき | 考えを話しながら整理するとき、手がふさがっているとき、会話の練習 |

選ぶ基準は簡単です。やりとりが必要なときや、アイデアを話しながらほぐしたいときは**音声会話**を使いましょう。録音した声を文字で確認し、直してから送りたいときは**音声入力**を使いましょう。[^voice]

音声入力は、こうやってみましょう。マイクを押して、下のように話します。そのあと、入力欄に書かれた文を確認し、間違った文字を直して送ります。

```
来週の土曜日に両親を連れて行けそうな、ソウル近郊の日帰りの場所を3つおすすめして。
歩く距離が短いところで。
```

人の名前や地名は、書き起こしを間違えやすいです。だから、送る前に一度読んでみることが、音声入力の長所です。

## 音声会話をやってみる

1. 入力欄の右にある**青い波形のボタン**を押します。スマホアプリでは、メッセージ入力行の音声アイコンです。[^voice]
2. 初めて使うとき、ブラウザがマイクを使ってよいかたずねたら、許可します。許可しないと、自分の声が入りません。
3. ふだん話すように話します。終わったら、画面の終了ボタンで会話を終えます。

<!-- 스크린샷 필요: 웹에서 파란 물결 버튼을 눌러 음성 대화가 진행 중인 화면(종료 버튼 위치 포함) -->

音声会話は、**一度に1つだけ**できます。[^voice] 声でやるときも、ステップ1で学んだコツがそのまま通用します。誰のためのものか、どんな形で受け取りたいかを伝えましょう（[ステップ1 4章](../00-common/04-prompt-basics.md)）。

声でやってみるのによい依頼を、2つあげます。

```
私は来週、会社の面接があります。あなたが面接官になって、質問を1つずつしてください。
私が答えたら、よかった点を1つ、直す点を1つだけ短く言って、次の質問に進んでください。
```

```
英会話の練習をしたいです。カフェで注文する場面で、短く会話してください。
私の発音や文が不自然なら、日本語で短く教えてください。
```

::: details 返ってくる答えはだいたいこんな感じ（例 — クリックして開く）
このガイドが作った例です。実際の答えは、サービスやそのときによって変わります。

> Hi! Welcome. What can I get for you today?

自分が「I want one coffee.」と言うと、こう続きます。

> Sure! What size would you like?
> 「I want」でも通じますが、「Can I get a coffee?」と言うともっと自然ですよ。

**うまくいったか確認しましょう**: 1、2文ずつ短くやりとりしているか？ 不自然なところを日本語で短く教えてくれるか？ 説明が長くなったら、「もっと短く言って」と言ってみましょう。

:::

答えが長すぎたら、声ですぐに「もっと短く言って」と言えば大丈夫です。文章で会話するときに直してもらっていた方法（[ステップ1 6章](../00-common/06-conversation.md)）と同じです。

運転中は、**CarPlay**（カープレイ、iPhoneを車の画面につなぐApple機能）でも、ChatGPTと声で会話できます。すべてのプランで、世界中で使えます。iOS 26.4以上のiPhoneが必要です。ただし、**地図・車両情報・現在地は見られません。** そのため、道案内アプリの代わりには使えません。[^carplay]

## 音声の方式と音声スタイル

### 3つの方式

音声会話の方式は3つです。[^voice]

- **ライブ（Live）**: 聞くことと話すことを同時にします。そのため、ChatGPTが話している最中に割り込めます。動画・画面の共有はできません。
- **高度（Advanced）**: 以前からあるリアルタイム方式です。スマホアプリで、カメラの映像や画面を見せながら会話できます。
- **標準（Standard）**: 自分の声をいったん文章に書き起こしてから答えます。1回ずつ順番にやりとりします。

動画・画面の共有が必要なら、スマホアプリの高度方式を使いましょう。たとえば、故障した家電をカメラで映しながら、「このランプはどういう意味？」とたずねられます。

### 方式と声を選ぶ

Webでは、アカウント名→「設定」→**「音声スタイル（음성 스타일）」**で、声と言語を選びます。2026年10月23日のWeb（Plus）の画面で開いてみたところ、「音声スタイル」には次の項目がありました。

![設定の「音声スタイル」画面。いちばん上に声の選択、「言語（언어）」（韓国語）、「音声入力 — 音声入力を有効にする（받아쓰기 — 받아쓰기 활성화）」のスイッチ、「最近の録音 — 最近20件の録音がこの機器に保存されています（최근 녹음 — 최근 20개의 녹음이 이 기기에 저장되어 있습니다）」がある](../../../guide/11-chatgpt/assets/shot-13-voice-style-marked.png)

画像の赤い番号が、下の表の番号です。

| 番号 | 項目 | 画面の説明 |
|---|---|---|
| ① | 音声スタイル | 音声チャットと読み上げに使う声を選ぶ |
| ② | 言語 | 声で会話する言語（例: 韓国語） |
| ③ | 音声入力を有効にする | チャットの入力欄で音声入力（マイクボタン）を使うかどうかを決める |
| ④ | 最近の録音 | 最近の録音20件が**この機器に**保存されているという案内 |

ライブ方式には、韓国語の声として**ヘッサル**（Haetsal）と**ハヌル**（Hanul）が加わりました。[^voice] 最初の画面の下に「새로운 한국어 음성」（新しい韓国語の音声）の案内が表示されていたら、「새 음성 사용해 보기」（新しい音声を試す）を押してみましょう。どの方式と声を選べるかは、プランによって違うことがあります。上のキャプチャの「Cove」のように、声の名前は英語で表示されることもあります。別の声を使うには、「音声スタイル」の欄（①）を押して、一覧から選べば大丈夫です。

::: details ライブ・高度・標準の方式はどこで選びますか？（クリックして開く）
ヘルプは、設定の音声の項目でライブ・高度・標準の中から選ぶと案内しています。[^voice] ところが、2026年10月のWeb画面の設定の左側の一覧には、「音声」ではなく「音声スタイル」という項目が表示されていて、ライブ・高度・標準を選ぶ欄は、この画面には**表示されていませんでした。** スマホアプリやプランによって違うかもしれません。

## どれだけ使えるか

音声会話のライブ方式は、**直近24時間に使った時間**で上限を数えます。上限に達すると、ChatGPTが知らせてくれます。[^voice]

| プラン | 24時間あたりの使用量（2026-10-23確認） |
|---|---|
| Free | 限定的に利用 |
| Go | 3時間 |
| Plus | 3時間 |
| Pro | ランクによって15時間、または不正利用防止の条件のもとで無制限 |

> この数字はよく変わります。最新の値は、脚注のヘルプのリンクで確認してください。

## 声の記録とプライバシー

### 声も保存される

録音が残る期間は、方式によって違います。

- **ライブ・高度**: 音声の録音の断片が、会話の記録と一緒に30日間保管されます。
- **標準**: 文章に書き起こしたあと、録音は削除されます。
- **音声入力（マイク）**: 録音は、その会話が履歴に残っている間、保管されます。会話を削除すると、30日以内に一緒に削除されます。ただし、セキュリティ上・法的な理由や、学習への共有に同意した場合などの例外があります。[^dictation]

録音そのものは、自分が別に共有を許可しないかぎり、学習には使われません。「自分の音声録音を含める（내 오디오 녹음 포함）」（Include your audio recordings）の設定を別にオンにして初めて、録音が学習に使われます。ただし、**書き起こされた文**は、通常のチャットと同じく「モデル改善のためのデータ学習を許可（모델 개선을 위한 데이터 학습 허용）」の設定に従います。[^voice] この設定は[8章](08-privacy.md)で扱いました。

### 公共の場で気をつけること

声での会話は、**隣の人にも聞こえます。** 自分の質問だけでなく、ChatGPTの返事もスピーカーから出ます。

- 電車・カフェ・オフィスでは、イヤホンを使うか、音声会話のかわりに**音声入力**で静かに入力しましょう。
- 名前・電話番号・住所・病院の記録のように、[ステップ1 9章](../00-common/09-safety.md#入れてはいけないもの)で見た**入れてはいけない情報は、声に出して言うのもやめましょう。** 声で話すときは、文字で打つときより、うっかり言ってしまいやすいです。
- 他の人が一緒にいる場で、その人の声や会話が一緒に録音されないようにしましょう。
- 音声会話では、連携したアプリ（[7章](07-projects-plugins.md#連携したアプリの権限を決める)）が使えないことがあります。使えなければ、同じ頼みごとを文章で入力してみましょう。[^apps-voice]

**会議を書き起こさせるときは、参加者全員に先に知らせて、同意を得てください。** Macのコンピュータアプリの**Meetingsプラグイン**（Pro・Businessプラン、試験版）は、会議を書き起こして、要約とやることを作ってくれます。アプリが表示する同意の案内は自分にしか見えず、ほかの参加者には届きません。ノートが完成すると、録音は削除されて、もう一度聞くことはできません。[^meetings]

## 実際にやってみよう

**1. 同じ質問を、2つの方法で**

下の質問を、1回は**マイク（音声入力）**で、もう1回は**新しいチャットで青い波形のボタン（音声会話）**でやってみます。

```
冷蔵庫に卵、豆腐、長ねぎがあります。15分以内に作れるおかずを2つ教えて。
```

そして、2つのことを自分に聞いてみましょう。音声入力で入力欄に書かれた文は、自分が話したことと同じか？ 音声会話では、答えを聞くのと読むのとでは、どちらが楽か？

**2. 割り込んでみる**

音声会話で長い説明を頼んだあと、ChatGPTが話している途中に「ちょっと待って、もっと短く」と言ってみます。ライブ方式は、話している最中も自分の声を聞いているので、割り込んだ依頼が反映されるか確認してみましょう。

**続きの課題**（[読書会の準備](../00-common/practice-kit.md)）: 音声会話で「読書会の最初のあいさつを、30秒くらいで一緒に練習して」と言います。自分が話したあいさつを聞いて、直す点をひとつ指摘してもらいましょう。

## まとめ

- マイクは**音声入力**: 声を文字に変えて入力欄に入れ、自分が確認してから送る。
- 青い波形のボタンは**音声会話**: 声でやりとりする。一度に1つだけできる。
- 方式はライブ・高度・標準の3つ。Webでは「設定」→「音声スタイル」で声と言語を選ぶ（ライブ・高度・標準の欄は、画面によって表示されないことがある）。動画・画面の共有は、スマホアプリの高度方式だけでできる。
- 使用上限は24時間が基準で、プランごとに違い、よく変わる。
- ライブ・高度の録音は30日間保管され、音声入力の録音は会話が残っている間保管される。会議を書き起こさせるときは、全員の同意を先に得る。書き起こされた文は、学習の設定に従う。公共の場では、音声入力かイヤホンを使い、個人情報は話さない。

## 用語まとめ

| 用語 | 読み方 | 一言でいうと |
|---|---|---|
| Dictation | ディクテーション（音声入力） | 声を文字に変えて入力欄に入れる機能 |
| Voice | ボイス（音声会話） | ChatGPTと声でやりとりする機能 |
| Live | ライブ | 聞くことと話すことを同時にする音声方式 |
| Advanced | アドバンスト（高度） | 動画・画面の共有ができる音声方式 |
| Standard | スタンダード（標準） | 書き起こしてから順番に答える音声方式 |
| Transcript | トランスクリプト（書き起こした文） | 話した内容を文字に移した記録 |
| CarPlay | カープレイ | iPhoneを車の画面につないで使うApple機能 |
