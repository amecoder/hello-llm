# ステップ2・ChatGPT利用ガイド

ステップ1では、どのAIにも通じる**上手な頼み方**を学びました。ステップ2では、**ChatGPTというサービスの画面と機能**を覚えます。
ボタンがどこにあるか、会話をどう整理するか、自分の情報がどう使われるか、といったことです。

> **このガイドの画面は、2026年10月のWeb画面（韓国語、Plusプラン）が基準です。** ChatGPTはメニュー名や機能がよく変わります。
> 自分の画面と違うときは、画面に表示されている名前に従い、各章の脚注にあるOpenAI公式ヘルプのリンクで最新の内容を確認してください。
