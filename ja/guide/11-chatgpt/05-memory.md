# 第5章 記憶とカスタマイズ — 毎回自己紹介しなくてすむように

> **一言まとめ**: ChatGPTは、自分が教えたことを覚えておく**メモリ**と、いつも守ってほしいことを書いておく
> **カスタム指示**で、回答を自分に合わせます。何が記憶されるのかを確認し、不要なら削除する方法まで身につけます。

画面は2026年10月のWeb版（Plusプラン）を基準にしています。無料プランやスマホアプリでは、メニューの位置が少し異なる場合があります。

## なぜ記憶とカスタマイズが必要なのか

[ステップ1 第4章](../00-common/04-prompt-basics.md)で、よいプロンプトには**文脈**（どんな状況か）を入れる必要があると学びました。
ただ、「私は町のお惣菜屋の店主で、お客さんは主に40〜60代」のような文脈を、新しいチャットのたびに書き直すのは面倒です。

ChatGPTには、この手間を減らしてくれる機能が2つあります。

| 機能 | 役割 | たとえ |
|---|---|---|
| **メモリ**（memory、記憶） | 会話で知った自分についての情報を覚えておき、次の会話で使う | 常連さんの好みを覚えているお店の主人 |
| **カスタム指示**（custom instructions） | 自分で書いておいた「いつも守ってほしいこと」を、すべての新しい会話に適用する | お店の壁に貼っておく注文のメモ |

ステップ1の[第6章](../00-common/06-conversation.md)で、「新しい会話は、基本的に最初から始まる」と言いました。この2つの機能をオンにしておくと、新しい会話も、自分をある程度知った状態で始まります。

## メモリをオンにして確認する

メモリの設定は、**アカウントメニュー → 「設定（설정）」 → 「パーソナライズ（개인 맞춤 설정）」**にあります。[^memory]
一番上の「ChatGPTメモリ（ChatGPT 메모리）」の欄に、2行が見えます。

![パーソナライズの画面。赤い番号は、①メモリを有効にする、②メモリの要約を管理、③自分の文体を参照、④参照用の写真、⑤基本のスタイルとトーン、⑥温かさ。一番上の「ChatGPTメモリ」欄の「メモリを有効にする（메모리 활성화）」スイッチと、「メモリの要約（메모리 요약）」の横の「管理（관리）」ボタン、その下の「自分の文体を参照（내 문체 참고）」スイッチ、一番下の「基本のスタイルとトーン（기본 스타일 및 톤）」と「温かさ（따뜻함）」の選択ボタンを見る](../../../guide/11-chatgpt/assets/shot-06-personalization-marked.png)

- **①「メモリを有効にする」** — オンにしておくと、ChatGPTがチャット・ファイル・連携したアプリをもとに、回答を自分に合わせます。オフにすると、記憶を使いません。
- **②「メモリの要約」 → 「管理」** — ChatGPTが自分について知った内容を、ひと目で見られます。画面の説明にも、「항상 기억해 두었으면 하는 정보는 사용자 지정 지침에 입력하라」（いつも覚えておいてほしい情報は、カスタム指示に入力してください）と書かれています。[^screen]

### 何を見て自分を覚えているのか

ChatGPTは、自分に合わせた回答を作るとき、**過去のチャット、保存されたメモリ、カスタム指示、ライブラリのファイル、連携したアプリ**（例: Gmail）を参照します。
どの回答が何を参照したのか気になったら、回答の下の「出典（출처）」を確認してみてください。[^memory]

### 保存されたメモリとチャット履歴の参照は違う

メモリは、2つに分かれます。[^memory]

- **保存されたメモリ**（saved memories） — 「これを覚えておいて」と言ったように、別に書き留めた情報です。チャット履歴とは別に保存されます。例: 「私はベジタリアンです。覚えておいて」
- **チャット履歴の参照**（reference chat history） — 別に書き留めておかなくても、過去の会話から必要な情報を、そのつど取り出して使います。たとえば、先週の会話で話した子どもの年齢を、今日の回答に反映します。

保存されたメモリを参照しないようにオフにすると、チャット履歴の参照も一緒にオフになります。[^memory]

自分で覚えさせてみるには、次のように言ってみましょう。

```
覚えておいて: 私はソウルでお惣菜屋をやっていて、お客さんは主に40〜60代です。
宣伝の文句を頼んだら、このお客さん層に合わせて書いてください。
```

## 記憶を削除する方法

記憶された内容が間違っている、またはもう使ってほしくないなら、削除しましょう。**「メモリの要約」 → 「管理」**で選べるのは、2つです。[^memory]

| ボタン | 役割 |
|---|---|
| 「二度と言及しない（다시 언급하지 않기）」 | その内容を、今後の回答で取り出さないようにする（ボタンが見える項目でのみ） |
| 「削除してメモリをオフにする（삭제하고 메모리 끄기）」 | 記憶を削除し、メモリ機能もオフにする |

混乱しやすい点が2つあります。[^memory]

- **チャットを削除しても、保存されたメモリは残ります。** ある会話から作られた保存されたメモリは、その会話を削除しても別に残ります。ですから、メモリも自分で削除する必要があります。
- **チャット履歴の参照をオフにすると**、過去の会話から記憶しておいた情報は、30日以内にOpenAIのシステムから削除されるよう予約されます。元のチャットは、そのまま残ります。

連携したアプリ（[第7章](07-projects-plugins.md#連携したアプリの権限を決める)）も同じです。Gmailのようなアプリとの接続を切っても、**そのアプリから取り込んで、すでに会話やメモリに入った内容は削除されません。** 今後読めなくなるだけです。残った内容は、上の方法で別に削除してください。[^apps]

## カスタム指示 — いつも守ってほしいこと

メモリはChatGPTが自分で覚えるもので、**カスタム指示**は自分で直接書いておくものです。
Webでは、「パーソナライズ」画面の「カスタム指示（사용자 지정 지침）」のリンクから入ります。
スマホアプリでは、設定の「ChatGPTのカスタマイズ（ChatGPT 맞춤 설정）」にあり、「カスタマイズを有効にする（맞춤 설정 사용）」をオンにして初めて適用されます。[^ci]

書ける文字数は、プランによって異なります。[^ci]

| プラン | 最大文字数 |
|---|---|
| Free・Go | 1,500字 |
| Plus・Pro・Business・Enterprise・Edu | 5,000字（2026-07-15に増加）[^rn] |

たとえば、次のように書いてみましょう。[ステップ1 第4章](../00-common/04-prompt-basics.md)の5つの要素のうち、毎回同じもの（文脈・相手・条件）だけを選んで入れる、と考えればよいでしょう。

```
私は町でお惣菜屋を経営している50代の店主です。パソコンの用語はよく分かりません。
- 回答は丁寧な言葉づかいで、難しい言葉はかっこで説明してください。
- 最初に結論を1行で言って、そのあとで説明してください。
- はっきりしないことは作り話をせず、分からないと言ってください。
```

話し方だけを書く必要はありません。**助けてもらい方**も書いておけます。OpenAI Academyの講座が例に挙げている指示を日本語にすると、次のようになります。[^academy-content]
```
- 私がアドバイスを求めたら、はっきりした推薦を1つして、長所と短所、そしてあなたが仮定したことも一緒に教えてください。
- はっきりしないことは、はっきりしないと言ってください。推測せず、どんな情報があれば回答がもっと良くなるかを教えてください。
```

指示を直したあとは、**新しいチャットを開いて**確認しましょう。すでに進行中の会話にもすぐに適用されるのかは、ヘルプの中でも説明が食い違っています。新しい会話から確実に適用される、と考えておくのが安全です。[^ci]
また、カスタム指示に書いた情報も、モデルの改善に使われることがあります。望まないなら、学習の設定をオフにすれば大丈夫です（[第8章](08-privacy.md)）。[^ci]

## 話し方を決める — 基本のスタイルとトーン、温かさ、自分の文体を参照

「パーソナライズ」画面の下のほうに、回答の話し方を決める欄があります。[^screen] 番号は、この章の「メモリをオンにして確認する」の節の図の番号です。

| 番号 | 画面での名前 | 役割 |
|---|---|---|
| ⑤ | 「基本のスタイルとトーン」 | 回答全体の雰囲気を選ぶ（例: 「プロフェッショナル（전문적）」） |
| ⑥ | 「温かさ」 | 回答がどれくらい親しみやすく聞こえるかを選ぶ（最初は「デフォルト（기본값）」） |
| ③ | 「自分の文体を参照」（「ライティング（글쓰기）」欄） | オンにすると、ChatGPTがチャット・ライブラリのファイル・連携したアプリを参照して、**自分の文体で**文章を書く |

たとえば、「自分の文体を参照」をオンにして、次のように頼んでみることができます。

```
常連のお客さんに送る、今週のお惣菜のお知らせのメッセージを書いてください。いつも私が使っている話し方で。
```

::: details 受け取る回答は、だいたいこんな感じ（例 — 押して開く）
このガイドが作った例です。実際の回答は、サービスやそのときどきによって異なります。

> こんにちは〜 今週のお惣菜のお知らせです。○曜日には（お惣菜の名前）が新しく出ます。いつもありがとうございます！

**うまく受け取れたか確認してみましょう**: いつも自分が使っている話し方に似ていますか？ 今週のお惣菜は自分が教えていないので、空欄になっていてもかまいません。お惣菜の名前を作り出して入れていたら、自分のメニューに書き換えてください。

:::

話し方は、カスタム指示に「仲のよいご近所さんに話すように書いて」のように書いてもかまいません。大まかな雰囲気はメニューで選び、細かいルールは指示に書く、と使い分けると楽です。

## 一時チャットで記憶を使うかを選ぶ

自分を知らない状態で回答を受け取りたいことがあります。たとえば、家族へのプレゼントをこっそり調べたいときや、自分の好みが混ざらない一般的な回答を知りたいときです。
そんなときは、右上の「一時チャット（임시 채팅）」ボタンを押してください。そして、**最初のメッセージを送る前に**、右上の①「パーソナライズあり（개인화됨）」を押して、「パーソナライズなし（개인화되지 않음）」に切り替えれば大丈夫です。[^screen][^temp]

![一時チャットの画面。右上の「パーソナライズあり」を押すと、「パーソナライズあり — このチャットは、メモリ、プラグイン、カスタム指示を参照できます」と「パーソナライズなし — このチャットでは、メモリ、プラグイン、カスタム指示を無視します」の2つが表示される](../../../guide/11-chatgpt/assets/shot-19-temporary-personal-marked.png)

| 選ぶもの | 保存されたメモリ・指示 | 新しいメモリ |
|---|---|---|
| ②「パーソナライズあり」（最初の選択） | 参照して答える | 作らない |
| ③「パーソナライズなし」 | 無視する | 作らない |

どちらの場合でも、**一時チャットでやり取りした内容は、新しくメモリに保存されません。** 会話を始めたあとは、この選択を変えられません。[^temp]
ですから、「パーソナライズなし」で始めた一時チャットで「私のこと覚えてる？」と聞いて、知らないと言われるのは正常です。一時チャットのそのほかの特徴（履歴・保管期間）は、[第3章](03-chats.md#履歴を残さない-—-一時チャット)で扱います。

> 以前は、一時チャットならメモリと指示が常にオフでしたが、いまは選べるように変わりました。自分の画面と違っていたら、画面に従ってください。

## 実際にやってみよう

1. 「設定」 → 「パーソナライズ」 → 「メモリの要約」 → 「管理」を開いて、ChatGPTがいま自分について何を知っているかを読んでみる。間違った内容があれば、削除する。
2. 「カスタム指示」に、上の例のように、自分についての文脈1行とルール3行を書く。
3. 新しいチャットで、「週末にやるとよいことを3つおすすめして」とだけ送る。指示の話し方と形式が守られているかを見る。
4. 「一時チャット」をオンにして「パーソナライズなし」に切り替えてから、同じ質問を送る。2つの回答がどう違うかを比べてみる。

**続きの課題**（[読書会の準備](../00-common/practice-kit.md)）: お知らせの文章にいつも求めるルールを1行、「カスタム指示」に入れてみる。例: 「お知らせを書くときは、日付・場所・持ち物を一番上に置いて。」 この1行は、第7章でプロジェクトの指示に移してもかまいません。

## まとめ

- メモリは、ChatGPTが会話から自分を覚える機能、カスタム指示は、自分で書いておくルールだ。
- メモリは、「保存されたメモリ」と「チャット履歴の参照」の2つに分かれ、「メモリの要約」 → 「管理」で確認して削除する。
- チャットを削除しても、保存されたメモリは残る。メモリは別に削除する。
- カスタム指示は、Free・Goが1,500字、Plus以上が5,000字まで。直したあとは、新しいチャットで確認する。
- 一時チャットは、新しいメモリを作らない。保存されたメモリ・指示まで除きたいなら、最初のメッセージの前に「パーソナライズなし」を選ぶ。

## 用語まとめ

| 用語 | 読み方 | 一言でいうと |
|---|---|---|
| Memory | メモリー | 会話で知った自分についての情報を覚えておく機能 |
| Saved Memories | セーブドメモリーズ（保存されたメモリ） | 別に書き留めた記憶。チャットを削除しても残る |
| Reference Chat History | リファレンスチャットヒストリー（チャット履歴の参照） | 過去の会話から必要な情報を取り出して使うこと |
| Custom Instructions | カスタムインストラクションズ（カスタム指示） | すべての新しい会話に適用される、自分で書いておいたルール |
| Personalization | パーソナライゼーション（パーソナライズ） | メモリ・指示・話し方をまとめた設定画面 |
