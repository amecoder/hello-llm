# 第6章 検索とディープリサーチ — 最新情報を出典つきでもらう

> **一言まとめ**: 今日起きたことや頻繁に変わる情報は**ウェブ検索**で、複数の資料を比べる必要がある大きな質問は
> **ディープリサーチ**で聞きます。どちらの場合も、ついてきた出典を自分で開いて確かめるところまでがひとまとまりです。

画面は2026年10月のWeb版（Plusプラン）を基準にしています。無料プランやスマホアプリでは、メニューの位置が少し異なることがあります。

## ウェブ検索 — ChatGPTにインターネットを調べさせる

AIは、学習した時点までの内容しか知りません。そのため、「今週の天気」や「昨日発表された政策」のような最近のことは、ただ聞くだけだと間違えやすくなります。
**ウェブ検索**（web search）は、ChatGPTがインターネットで最新の資料を探して読んだうえで答える機能です。

ウェブ検索は、Freeを含むすべてのプランで使えます。ログインしていない状態でも使えます。
必要だと判断したときは、ChatGPTが**自分で**検索することもあります。[^search]
必ず検索させたいときは、入力欄の左にある**+ボタン→「ウェブ検索（웹 검색）」**を選んでから質問してください。[^screen]

![入力欄の①+ボタンを押すと開くメニュー。赤い番号の⑤「ウェブ検索（웹 검색）」と⑦「ディープリサーチ（심층 리서치）」を見る](../../../guide/11-chatgpt/assets/shot-02-plus-menu-marked.png)

会話のタイトルとアカウント名は、例として書き換えた画面です。この章で使うのは、①+ボタン、⑤「ウェブ検索」、⑦「ディープリサーチ」です。

```
今週末のソウルの天気を教えてください。土曜日と日曜日に分けて、
参考にしたサイトも一緒に見せてください。
```

### 横のメニューの「検索」とは違う

横のメニューの一番上にある虫眼鏡「検索（검색）」は、**自分のチャット・プロジェクト・ファイル**だけを探します。インターネットは探しません。[^find]
「先月書いた履歴書の会話はどこにいったかな？」のようなものは、横のメニューの「検索」で探してください。「今年の最低賃金はいくらかな？」のようなものは、ウェブ検索で聞けばOKです。横のメニューの検索は、[第3章](03-chats.md)で扱っています。

## 出典を確認する習慣

ウェブ検索でもらった答えには、文の終わりに**引用**（citation、どこから持ってきたかを示す表示）が小さな名札のようについています。たとえば「国立中央博物館 +1（국립중앙박물관 +1）」は、そのサイトとほかの出典1か所を参考にしたという意味です。参考にしたサイトの一覧は、「出典（출처）」で見られます。[^search]

![一時チャットでウェブ検索を使い、「国立中央博物館の観覧時間を教えて」と聞いた画面。答えの文の終わりに「国立中央博物館 +1（국립중앙박물관 +1）」のような小さな出典表示がついていて、答えの下にコピー・読み上げ・応答の再生成・追加アクションのボタンがある](../../../guide/11-chatgpt/assets/shot-15-web-search-marked.png)

*会話のタイトルとアカウント名は、例として書き換えた画面です。* ①文の終わりの小さな名札が出典表示です。③答えの下には、コピー・読み上げ・再生成・その他のボタンがあります。2026年10月23日のWeb画面では、この出典表示を押すと**元のウェブページが新しいタブで開きました。** ②2つ目の段落の `**금요일(10월 23일)**` のように太字の記号がそのまま見えているのは、[ステップ1 第7章](../00-common/07-structured-prompts.md)で見たマークダウンの記号が表に出てしまった場合です。

ところが、OpenAI自身も、検索結果と引用は**不完全だったり、古かったり、間違っていたりすることがある**と明らかにしています。[^search]
リンクがついているというだけでは、確認されたことになりません。[ステップ1 第9章](../00-common/09-safety.md)で学んだとおり、数字・日付・名前は、リンクを自分で開いて原文と照らし合わせましょう。
リンクを開いたら、下の4つを自分に問いかけてみてください。

| 確認すること | 見方 |
|---|---|
| リンクは開くか？ | 出典を押して、実際のページが出るか見る |
| 原文にその言葉があるか？ | 答えの数字や文が、ページにそのままあるか探す |
| いつ書かれた文章か？ | ページの作成日を見て、古い情報でないか確認する |
| 誰が書いた文章か？ | 公的機関や会社のページか、個人のブログかを見る |

出典が気に入らなければ、こう頼み直すことができます。

```
さっきの答えから個人ブログの出典を除いて、政府や公的機関のサイトだけを参考にして、もう一度教えてください。
それぞれの内容に、どのページから持ってきたかをつけてください。
```

## 検索するときにChatGPTが知ること

飲食店や病院のように「自分の近く」が大事な質問をすると、位置情報が使われます。
ChatGPTは、インターネットのアドレス（IPアドレス、インターネットにつながった機器ごとについている番号）から**おおよその位置**を推測します。
機器の正確な位置を知らせる機能は、別にオンにする必要があります。最初はオフになっています（「設定（설정）」→「データ管理（데이터 관리）」→「位置情報（위치）」）。[^search][^screen]

また、ChatGPTは私の質問を検索語に書き直して、外部の検索会社に送ります。このとき、私のIPアドレスやアカウント情報は一緒に送りません。[^search]
ただし、メモリがオンになっていると、その検索語を私に合わせて変えることがあります。「パーソナライズ（개인 맞춤 설정）」の画面にそう書かれています（[第5章](05-memory.md)）。[^screen]

## 買い物をするとき — 比較は任せて、価格は自分で確認

物を買おうとして聞くと、答えに**商品カード**（product card、写真・価格・販売元がついた商品の一覧）が出ることがあります。商品を一つ以上選んで「Research」を押すと、**ショッピングリサーチ**（shopping research）が始まります。
ChatGPTが、好きなブランド、サイズ、何をより重視するかを聞き返してきます。そして数分後に、選ぶときに見るポイント・おすすめ商品・比較表が入った**購入ガイド**（buyer’s guide）をくれます。[^shop-research]
この機能が韓国の画面でも出るかどうかは、ヘルプに書かれていません。このガイドを書くときも確認できませんでした。

```
通勤用のバックパックを探しています。予算は10万ウォン、15インチのノートパソコンが入って、雨の日にも使います。
3つだけ選んで比較表で見せてください。各販売元の価格は自分で確認できるように、リンクをつけてください。
```

::: details もらえる答えはだいたいこんな感じです（例 — 押して開く）
このガイドが作った例です。実際の答えは、サービスやそのときによって異なります。

> 条件（10万ウォン以下、15インチのノートパソコン、雨の日）に合わせて、3つ選びました。
>
> | 製品 | 価格 | ノートパソコン用の仕切り | 雨に強いか | 販売元 |
> |---|---|---|---|---|
> | （製品A） | ○○ウォン | 15インチが入る | 防水生地 | （販売元のリンク） |
> | （製品B） | ○○ウォン | 15インチが入る | 生活防水 | （販売元のリンク） |
> | （製品C） | ○○ウォン | 15インチが入る | 生活防水 | （販売元のリンク） |
>
> 価格は販売元によって変わることがあるので、リンクで直接確認してください。

**うまくもらえたか確認しましょう**: ちょうど3つか？ 私の3つの条件が表で全部見えるか？ リンクを押したとき、同じ製品が出るか？ 価格はリンクで直接見たか？

:::

知っておくことです。

- **広告か？** 違います。商品の結果は、ChatGPTが別に選んだものです。広告は別に表示されます。[^shop]
- **私の会話は店に渡るか？** ショッピングリサーチでやり取りした会話は、販売元と共有されません。[^shop-research]
- **最初に見える価格** — 一番最初に出た販売元の価格です。いちばん安い値段とは限りません。[^shop]
- **「コスパ」のような表示、レビューの要約** — ChatGPTが作ったものなので、保証ではありません。レビューもOpenAIが検証したものではありません。[^shop]
- **「Try on」（試着）** — 服やアクセサリーを自分の写真に着せてみる機能です。実際のサイズやフィット感を保証するものではありません。アップロードした写真は次に使うために保存されるので、消したいときは設定から消してください。[^shop]

**支払いの前に、販売元のサイトで最終価格・税金・送料、在庫とサイズ、返品のルールを自分で確認してください。**[^shop-research] 価格と在庫は頻繁に変わるので、ChatGPTが見せたものと違うことがあります。

## ディープリサーチ — レポートを任せる

**ディープリサーチ**（deep research）は、ChatGPTが複数の資料を時間をかけて探して読み、引用つきの**レポート**にまとめてくれる機能です。
手早く知りたい事実は、検索で聞きましょう。深さと丁寧さが必要なときに、ディープリサーチを使えばOKです。[^dr]

| こんなとき | 選ぶもの | 例 |
|---|---|---|
| 答えが1、2行で終わる | ウェブ検索 | 「今日の為替レートを教えて」 |
| 複数の資料を比べてまとめる必要がある | ディープリサーチ | 「1人営業の店向けカード端末3種の比較レポート」 |

### 始め方

次のどちらかで始めてください。[^dr][^screen]

- 入力欄の**+ボタン→「ディープリサーチ（심층 리서치）」**
- 入力欄に `/Deepresearch` と入力

### 進む流れ

1. **質問を送る** — 何を、誰のために、どんな形でほしいかを詳しく書くほどよくなります。
2. **調査計画を先に見る** — ChatGPTが「こういう順番で調べます」という計画を見せてくれます。この計画は自分で直せます。
3. **調査している間に口を挟める** — 進行中に、方向を変えたり、加えたい内容を伝えたりできます。
4. **引用つきのレポートを受け取る** — Markdown・Word・PDFの形式でダウンロードできます。[^dr]

> **一時チャットではディープリサーチを使えません。** 2026年10月のWeb画面では、一時チャットの+メニューに「ディープリサーチ」がありませんでした。「画像を作成（이미지 생성）」も薄く表示されて使えなくなっていました。ディープリサーチは、通常のチャットで始めてください。

下は、この節の後ろに出てくる配達アプリの手数料の例を実際に送ったときの画面です。**赤い番号は、図の下の一覧の番号と同じ場所です。**

![ディープリサーチを送った直後に出た調査計画のカード。①調べる5つのステップ、②「編集（편집）」ボタン、③「キャンセル（취소）」と数字が減っていく「開始（시작）」ボタン](../../../guide/11-chatgpt/assets/shot-20-dr-plan-marked.png)

- ① 何をどんな順番で調べるかを見せる計画です。
- ② 計画を直したいときは「編集（편집）」を押します。
- ③ 「開始」の横の数字は、自動で始まるまで減っていく数字です。2026年10月27日の画面では、何も押さなかったところ、数字が全部減ったあとに調査が始まりました。やめたいときは「キャンセル（취소）」を押してください。[^screen-dr]

計画が気に入らなければ、始まる前に「編集」を押してください。調査がとんでもない方向に進む前に、軌道修正できます。

![調査が進行中のカード。①「更新（업데이트）」ボタン、②終わったステップにはチェックマーク、③ここまでの検索数「検索70件（검색 70건）」、④進行バーと停止ボタン](../../../guide/11-chatgpt/assets/shot-21-dr-progress-marked.png)

- ① 調査中に方向を変えたり、加えたい内容があったりしたら、「更新（업데이트）」を押します。
- ② 終わったステップには、チェックマークがつきます。
- ③ ここまでに検索した回数です。
- ④ 進行バーです。右の■ボタンで止められます。[^screen-dr]

調査はそのままにして、ほかのことをしてもかまいません。この例は、終わるまで6分ほどかかりました。[^screen-dr]

![完成したレポート。①「リサーチ完了まで6m · 引用19件 · 検索295件（리서치 완료까지 6m · 인용 19개 · 검색 295건）」、②レポートのタイトル、③ダウンロードボタン、④拡大表示ボタン、⑤文の終わりの引用番号](../../../guide/11-chatgpt/assets/shot-22-dr-report-marked.png)

- ① かかった時間、引用した出典の数、検索の数が出ます。
- ② レポートのタイトルです。レポートは、会話の中の文書カードとして届きます。
- ③ ダウンロード、④拡大表示のボタンです。
- ⑤ 文の終わりの小さな数字が引用です。数字をたどって、出典を開いてみてください。[^screen-dr]

レポートの最初の段落に、`**배달의민족·쿠팡이츠가…**` のようにアスタリスクがそのまま見えるところがあります。太字の記号が表に出てしまったものです（[ステップ1 第7章](../00-common/07-structured-prompts.md)）。

下の図の①ダウンロードボタン（上の図の③）を押すと、②メニューに「内容をコピー（내용 복사）」、「マークダウンとしてエクスポート（마크다운으로 내보내기）」、「Wordとしてエクスポート（Word로 내보내기）」、「PDFとしてエクスポート（PDF로 내보내기）」が出ます。[^screen-dr]

![①ダウンロードボタンを押すと開いた②メニュー。「内容をコピー（내용 복사）」、「マークダウンとしてエクスポート（마크다운으로 내보내기）」、「Wordとしてエクスポート（Word로 내보내기）」、「PDFとしてエクスポート（PDF로 내보내기）」](../../../guide/11-chatgpt/assets/shot-22-dr-download-marked.png)

通常のチャットで行った調査なので、この会話はチャット一覧に残ります。残したくなければ、見終わったあとに[第3章](03-chats.md)の方法で削除してください。

特定のサイトだけを調べさせたり、先に見させたりすることもできます。入力欄のSites → Manage sitesで決めます。ただし、この名前はヘルプに載っているもので、韓国語の画面での名前はまだ確認できていません。[^dr]

```
町の総菜屋が使える配達アプリの手数料を比較するレポートを書いてください。
- 対象: 店を1軒運営している店主
- 比較すること: 仲介手数料、決済手数料、広告費
- 形式: 最初に一行の結論、次に比較表、最後に出典の一覧
- 2026年の資料を優先し、日付がわからない資料は別に表示してください
```

レポートも、検索結果と同じように、出典を開いて確認してください。レポートが長くてもっともらしいほど、確認を飛ばしやすくなります。とくに結論に使われている数字から確認してみましょう。

## 上限は画面で確認

ディープリサーチは、使える回数がプランごとに違います。残りの回数は、**アプリの中の表示**で確認してください。
月の上限は、最初に使った日から30日ごとに補充されます。[^dr]
具体的な回数はヘルプに載っておらず、頻繁に変わります。そのため、このガイドには書いていません。使う前に画面で確認してください。

## 実際にやってみよう

1. 通常のチャットで+ボタン→「ウェブ検索」を選び、「私の町の今月の文化イベントを教えて」と聞く。
2. 答えについた出典を2つ自分で開き、イベントの日付が原文と同じか確認する。
3. 上の配達アプリの手数料の例を自分の仕事に合わせて書き換え、ディープリサーチで送る。調査計画が出たら、一か所直してほしいと頼んでみる。
4. もらったレポートの結論に使われている数字を一つ選び、出典で探してみる。

**続きの課題**（[読書会の準備をする](../00-common/practice-kit.md)）: ウェブ検索で「私の町の区立図書館のセミナー室の借り方」を探す。町の名前は自分で入れる。運営時間と申し込み方法は、出典を開いて自分で確認する。

## まとめ

- 最新情報は、ウェブ検索で聞く。ChatGPTが自分で検索することもあるし、+ボタン→「ウェブ検索」で自分でオンにすることもできる。
- 横のメニューの「検索」は自分の会話を探すもので、インターネット検索ではない。
- 引用と出典も間違っていることがある。リンクを開いて原文と照らし合わせる。
- ショッピングの結果は広告ではないが、最初の価格が最安値とは限らない。支払いの前に、販売元で価格・送料・返品のルールを確認する。
- 大きな質問は、ディープリサーチに任せる。計画を先に見て直すことができ、レポートはMarkdown・Word・PDFでもらえる。
- ディープリサーチの回数はプランごとに違うので、画面で確認する。

## 用語のまとめ

| 用語 | 読み方 | 一言の意味 |
|---|---|---|
| Web Search | ウェブサーチ | ChatGPTがインターネットで最新の資料を探して答える機能 |
| Citation | サイテーション | 答えの内容をどこから持ってきたかを示す表示 |
| Source | ソース | 答えが参考にしたウェブページ |
| IP Address | アイピーアドレス | インターネットにつながった機器ごとについている番号。おおよその位置がわかる |
| Deep Research | ディープリサーチ | 複数の資料を時間をかけて調べ、引用つきのレポートにまとめる機能 |
| Buyer’s Guide | バイヤーズガイド | 選ぶときに見るポイント・おすすめ商品・比較表をまとめた文章 |
| Shopping Research | ショッピングリサーチ | 選んだ商品について聞き返して比較し、購入ガイドにまとめる機能 |
