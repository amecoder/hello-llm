# 第2章 画面を見て回る — どこに何があるか

> **一言まとめ**: ChatGPTの画面は、**左のサイドメニュー**（過去の会話と機能）、**中央の入力欄**（質問する場所）、**上のChat/Work切り替え**、
> **左下のアカウントメニュー**（設定）の4か所だけ知っていれば大丈夫です。最初は、入力欄と「新しいチャット（새 채팅）」だけ使えば十分です。

画面は2026年10月のWeb版（Plusプラン）を基準にしています。無料プランやスマホアプリは、メニューの位置が少し違うことがあります。

## 最初の画面を一目で見る

ログインすると、中央に「どこから始めましょうか？（어디서 시작할까요?）」という文言と入力欄が見えます。

![ログイン後の最初の画面。赤い番号①〜⑤で示している。左にサイドメニュー（「新しいチャット（새 채팅）」「予約（예약）」「ライブラリ（라이브러리）」「プラグイン（플러그인）」「探索（탐색）」と、「固定されたスレッド（고정된 스레드）」「プロジェクト（프로젝트）」「最近（최근）」の一覧）、上の中央に「Chat」/「Work」の切り替え、中央の入力欄とその下のおすすめ3つに注目してください](../../../guide/11-chatgpt/assets/shot-01-home-layout.png)

会話のタイトルとアカウント名は、例に変えた画面です。**赤い番号は、下の表の番号と同じ場所です。**

| 番号 | 位置 | 名前 | すること |
|---|---|---|---|
| ① | 左 | サイドメニュー（サイドバー） | 新しい会話の開始、過去の会話の一覧、いろいろな機能への入り口 |
| ② | 上の中央 | 「Chat」/「Work」 | 通常の会話と長い作業のモードを切り替える |
| ③ | 中央 | 入力欄「ChatGPTに聞いてみましょう（ChatGPT에게 물어보세요）」 | 質問を書く場所 |
| ④ | 入力欄の下 | おすすめ | 「画像やステッカーを作って（이미지나 스티커 만들어줘）」「文章作成（글쓰기）」「ウェブ検索（웹 검색）」 |
| ⑤ | 左下 | アカウント（名前とプラン） | 設定、プランの変更、ログアウト |

何を聞けばいいかわからなければ、入力欄の下の**おすすめ**から押してみましょう。たとえば、「文章作成（글쓰기）」を押して、こう続けて書いてみてください。

```
近所の惣菜屋のオープンを常連のお客さんに知らせるメッセージを書いて。3文で、あたたかい口調で。
```

::: details 返ってくる答えはだいたいこんな感じ（例 — クリックで開く）
このガイドが作った例です。実際の答えは、サービスやそのときによって変わります。

> こんにちは、○○惣菜です。○月○日、ついにお店をオープンします。心を込めて作ったお惣菜で、あたたかくお迎えしますね。

**うまく受け取れたか確認しましょう**: 常連のお客さんにオープンを知らせる、ちょうど3文になっていますか？ 口調はあたたかいですか？ お店の名前と日付は、こちらから伝えていないので、空欄でも構いません。作り話の日付が入っていたら、直してください。

:::

## ChatとWork — 会話するか、仕事を任せるか

上の中央の「Chat」/「Work」は、2026年7月に登場した切り替えボタンです。[^rn-work]

- **Chat**: これまで知っているChatGPTです。聞いて答えをもらいながら会話します。このガイドの大部分は、Chatを基準にしています。
- **Work**: 複数のステップを踏む長い作業を任せて、文書・表・発表資料・報告書のような**完成した成果物**を受け取るモードです。

Workは、Webとスマホでは**有料プラン（FreeとGoを除く）**でだけ使えます。FreeとGoは、パソコンのアプリでだけ、制限つきで使えます。[^rn-work] 使い方は[第7章](07-projects-plugins.md)で扱います。

## 推論レベルと考える機能 — どのくらい深く考えるか

有料プランでは、入力欄の右の「Medium」のような文字（ボタン名は「ChatGPTモデルを選択（ChatGPT 모델 선택）」）を押すと、**「推論レベル（추론 수준）」**のスライダーが出てきます。
**推論**（reasoning）は、答える前に段階を踏んで考えることです。スライダーは、その思考をどのくらい長く行うかを決めます。

![入力欄の右の「推論レベル（추론 수준）」を押した画面。小さなウィンドウの中に「Medium」という文字と、左右に動くスライダーがあることに注目してください](../../../guide/11-chatgpt/assets/shot-03-model-menu-marked.png)

会話のタイトルとアカウント名は、例に変えた画面です。①「推論レベル」ボタンを押すと、②いまのレベル（「Medium」）と③スライダーが出てきます。

| レベル | 性格 | 使えるプラン |
|---|---|---|
| Instant（即時） | すぐ答える。軽い質問向け | 有料 |
| Medium（中） · High | より長く考える。計画・比較・計算向け | Plus以上 |
| Extra High · Pro | いちばん深く考える | Pro・Business・Enterprise |

出典: OpenAIヘルプ[^levels]

知っておくことが2つあります。

- **言葉で「もっと深く考えて」と言っても、レベルは変わりません。** Instantのままそう書いても、自動では上がりません。スライダーを自分で動かしてください。[^levels]
- **無料（Free）・Goプランは、スライダーのかわりに「考える（생각하기）」をオンにします。** Goプランのスマホアプリでは、「＋」メニューの「Think harder」を選びます。[^go-think]

<!-- スクリーンショット必要: Freeプランのウェブ画面で「考える（생각하기）」をオンにする位置 -->

**いつ上げるか？** 計算のときだけではありません。短い文の推敲のように、単純だったり負担が小さかったりする仕事には、速いレベルで十分なことがあります。条件がいくつもあるとき、選択肢を基準に合わせて比べるとき、自分が書いた計画から抜けている前提を探すときは、レベルを上げてみましょう。[^academy-content]
```
イベント会場の候補3か所を、予算・公共交通機関・雨の日の代案、この3つの基準で比べて。
1か所をおすすめして、そこの弱点をどう減らせるかも教えて。
```

同じ質問を、レベルだけ変えて聞いてみましょう。速い答えと深い答えの違いが、すぐにわかります。

```
月給300万ウォンの会社員が3年以内に2,000万ウォンを貯めるには、毎月いくらずつ貯めればいいか、
定期預金の利息を考えた場合と考えない場合に分けて、計算の過程を見せて。
```

## 実際にやってみる

1. 最初の画面で、おすすめの「文章作成（글쓰기）」を押して、上の惣菜屋のメッセージの例を貼り付けて送る。
2. 入力欄の「＋」ボタンを押して、メニューの項目を1つずつ読み（押さなくても構いません）、閉じる。
3. 有料なら、「推論レベル（추론 수준）」をいちばん低くして1回、Mediumにして1回、上の貯蓄計算の質問を送って、答えを比べる。無料なら、「考える（생각하기）」をオフにして1回、オンにして1回、比べる。
4. アカウントメニュー→「設定（설정）」を開いて、「データ管理（데이터 관리）」がどこにあるか探しておき、「アプリに戻る（앱으로 돌아가기）」で出る。

**続きの課題**（[読書会の準備](../00-common/practice-kit.md)）: おすすめの「文章作成（글쓰기）」を押して、例のファイルmemo-next-month.txtの内容を貼り付け、「会員全員へのグループメッセージで送る短いお知らせの下書きを書いて」と送る。場所がまだ確定していないことを、下書きがどう扱うか見る。

## まとめ

- 画面は、サイドメニュー、入力欄、Chat/Workの切り替え、アカウントメニューの4か所に分かれている。
- 「＋」ボタンで、ファイル・画像・ウェブ検索・ディープリサーチ・スケッチを選ぶ。
- 有料は「推論レベル（추론 수준）」のスライダー、無料は「考える（생각하기）」で、思考の深さを決める。言葉で頼んでも変わらない。
- 設定は全画面で開く。プライバシーに関する設定は、「データ管理（데이터 관리）」にある。

## 用語まとめ

| 用語 | 読み方 | 一言でいうと |
|---|---|---|
| Sidebar | サイドバー（サイドメニュー） | 画面の左に縦に付いたメニュー |
| Thread | スレッド | 会話1つを呼ぶ別の言い方 |
| Reasoning | リーズニング（推論） | 答える前に段階を踏んで考えること |
| Instant | インスタント | ほとんど考えずにすぐ答えるレベル |
| Plugin | プラグイン | ChatGPTに機能を足す拡張（[第7章](07-projects-plugins.md)） |
| Work | ワーク | 長い作業を任せて、完成した成果物を受け取るモード（[第7章](07-projects-plugins.md)） |
