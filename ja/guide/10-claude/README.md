# ステップ2・Claude 利用ガイド

ステップ1では、どのAIにも通じる**上手な聞き方**を学びました。ステップ2では、**Claudeというサービスの画面と機能**を身につけます。
ボタンがどこにあるか、会話をどう整理するか、自分の情報がどう使われるか、といったことです。

> **このガイドは、2026年10月26日に確認したAnthropicの公式ヘルプをもとに書きました。** Claudeはメニューの名前や機能がよく変わります。
> 今はチャットとCoworkを一つにした新しい画面が順次配信されているため、人によって画面が少し違うことがあります。
> 自分の画面と違うときは、画面に表示されている名前に従ってください。最新の内容は、各章の脚注にある公式ヘルプのリンクで確認できます。
