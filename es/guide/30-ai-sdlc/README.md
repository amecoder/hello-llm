# Etapa 4 · Guía de AI-SDLC

El SDLC (ciclo de vida del desarrollo de software) es el conjunto de fases por las que pasa una idea hasta convertirse en un software que funciona de verdad. En la etapa 4 crearás, junto con las herramientas de IA que aprendiste en la etapa 3, **una pequeña página web, desde la planificación hasta la publicación y la mejora.**
No pasa nada si no sabes programar. Lo que se aprende en esta etapa no es a escribir código, sino **qué entregarle a la IA y qué recibir de vuelta para comprobarlo.**

> **Esta guía se escribió con la documentación oficial de GitHub y Claude Code consultada el 1 de noviembre de 2026 y con las explicaciones de los repositorios de spec-kit y OpenSpec.** Las funciones y los nombres de las pantallas cambian a menudo.
> Basta con una cuenta gratuita de GitHub. Las herramientas de IA son las mismas que usaste en la etapa 3 (Claude Code, Codex y Antigravity).
