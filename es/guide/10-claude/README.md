# Etapa 2 · Guía de uso de Claude

Si en la etapa 1 aprendiste **a preguntar bien**, algo que sirve con cualquier IA, en la etapa 2 te familiarizas con **la pantalla y las funciones del servicio llamado Claude**.
Por ejemplo: dónde está cada botón, cómo organizar tus conversaciones y cómo se usa tu información.

> **Esta guía se escribió a partir de la ayuda oficial de Anthropic consultada el 2026-10-26.** Los nombres de los menús y las funciones de Claude cambian con frecuencia.
> Ahora se está desplegando poco a poco una pantalla nueva que une el chat y Cowork, así que la pantalla puede variar un poco de una persona a otra.
> Si tu pantalla es distinta, sigue los nombres que veas en ella. Para ver lo más reciente, consulta los enlaces a la ayuda oficial de las notas al pie de cada capítulo.
