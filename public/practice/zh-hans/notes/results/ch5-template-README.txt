# 模板使用方法

1. 复制要用的模板，用新名字保存到 `notes/` — 命名规则写在每个模板最上面的注释里。
2. 把 `{{ }}` 的位置全部填上。没有可写的内容时不要删栏，写上 `（备忘中没有）`。
3. 按下面的检查清单从上往下打勾。

| 模板 | 什么时候 | 栏目 |
|---|---|---|
| `minutes.md` | 会议刚结束 | 决定的事 · 待办事项 · 下次要讨论的事 · 下次会议 |
| `study-notes.md` | 看了课程·书的那天 | 一句话总结 · 核心内容 · 新学的词 · 注意事项 · 要提的问题 · 要试的事 · 试过的结果 |
| `weekly-review.md` | 周五 | 做得好的 · 可惜的 · 下周要做的 (KPT) |

## 检查清单

**通用**
- [ ] 栏目名称和顺序与模板相同（没有删栏 — 没有可写的内容就写 `（备忘中没有）`）
- [ ] 一个 `{{` 也没有剩下（在编辑器里搜索 `{{`）
- [ ] 日期带着星期，文件名里的日期和标题里的日期相同
- [ ] 数字·名字·日期和原始备忘对照过一次（防止 10/30 价格写成 6,000韩元 那样的错误）

**会议纪要**
- [ ] 每条决定的事都写全了"做什么·多少/怎么做·到什么时候"
- [ ] 待办事项表的每一行都有负责人和期限（空着就是会上没定 → 放到下次要讨论的事）
- [ ] 原始备忘里的待办事项全部搬进了表格（原始备忘里"要做～"的行数 = 表格行数）
- [ ] 写了下次会议的日期

**学习笔记**
- [ ] 核心内容没有照抄，是用自己的话写的，有 3 条以上
- [ ] 不懂的词全部连同意思放在了「新学的词」表里
- [ ] 要试的事是写明"什么时候 · 做什么"的行动（"好好写写看" ✗ → "周一的 Instagram 文案里加上角色+格式" ✓）

**每周回顾 (KPT)**
- [ ] 正文栏目只有做得好的 / 可惜的 / 下周要做的三个，并且是这个顺序
- [ ] 三栏都至少写了 1 条
- [ ] 做得好的·可惜的都各自写了"为什么"
- [ ] 下周要做的是带日期的行动，并且至少和一条可惜的事相关联
