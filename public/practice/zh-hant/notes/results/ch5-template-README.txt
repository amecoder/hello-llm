# 模板使用方法

1. 複製要用的模板，用新名字儲存到 `notes/` — 命名規則寫在每個模板最上面的註釋裡。
2. 把 `{{ }}` 的位置全部填上。沒有可寫的內容時不要刪欄，寫上 `（備忘中沒有）`。
3. 按下面的檢查清單從上往下打勾。

| 模板 | 什麼時候 | 欄目 |
|---|---|---|
| `minutes.md` | 會議剛結束 | 決定的事 · 待辦事項 · 下次要討論的事 · 下次會議 |
| `study-notes.md` | 看了課程·書的那天 | 一句話總結 · 核心內容 · 新學的詞 · 注意事項 · 要提的問題 · 要試的事 · 試過的結果 |
| `weekly-review.md` | 週五 | 做得好的 · 可惜的 · 下週要做的 (KPT) |

## 檢查清單

**通用**
- [ ] 欄目名稱和順序與模板相同（沒有刪欄 — 沒有可寫的內容就寫 `（備忘中沒有）`）
- [ ] 一個 `{{` 也沒有剩下（在編輯器裡搜尋 `{{`）
- [ ] 日期帶著星期，檔名裡的日期和標題裡的日期相同
- [ ] 數字·名字·日期和原始備忘對照過一次（防止 10/30 價格寫成 6,000韓元 那樣的錯誤）

**會議紀要**
- [ ] 每條決定的事都寫全了"做什麼·多少/怎麼做·到什麼時候"
- [ ] 待辦事項表的每一行都有負責人和期限（空著就是會上沒定 → 放到下次要討論的事）
- [ ] 原始備忘裡的待辦事項全部搬進了表格（原始備忘裡"要做～"的行數 = 表格行數）
- [ ] 寫了下次會議的日期

**學習筆記**
- [ ] 核心內容沒有照抄，是用自己的話寫的，有 3 條以上
- [ ] 不懂的詞全部連同意思放在了「新學的詞」表裡
- [ ] 要試的事是寫明"什麼時候 · 做什麼"的行動（"好好寫寫看" ✗ → "週一的 Instagram 文案裡加上角色+格式" ✓）

**每週回顧 (KPT)**
- [ ] 正文欄目只有做得好的 / 可惜的 / 下週要做的三個，並且是這個順序
- [ ] 三欄都至少寫了 1 條
- [ ] 做得好的·可惜的都各自寫了"為什麼"
- [ ] 下週要做的是帶日期的行動，並且至少和一條可惜的事相關聯
