# study-notes — 學習筆記 → 學習總結

## 什麼時候用

- 要把看課程·書·影片時記下的 `inbox/study-YYYY-MM-DD-topic.txt` 整理成學習筆記的時候
- 例："把 10/28 提示詞課程的筆記做成學習筆記"

## 要讀的檔案（按順序）

1. `CLAUDE.md` — 這個資料夾的 5 條整理規則
2. `templates/README.md` — 模板使用方法和檢查清單
3. `templates/study-notes.md` — 要用的模板
4. 原始筆記 `inbox/study-YYYY-MM-DD-topic.txt` — **只讀取。絕不修改。**

## 要用的模板

把 `templates/study-notes.md` 原樣複製，只填 `{{ }}` 的位置。不改變欄目名稱·順序（1. 一句話總結 → 2. 核心內容 → 3. 新學的詞 → 4. 注意事項 → 5. 要提的問題 → 6. 要試的事 → 7. 試過的結果）。

各欄的填法：

- **開頭** — 出處·時長·原始備忘路徑。備忘裡沒有就寫 `（備忘中沒有）`。
- **1. 一句話總結** — 用一句話概括整份筆記。
- **2. 核心內容** — 3~7 條，不要照抄筆記，用簡單的話重新寫。筆記裡有例子就配上。
- **3. 新學的詞** — 把筆記裡出現的術語和意思做成表格。筆記裡沒有意思的話不要編造，在意思欄寫 `（備忘中沒有）` — 這個術語也列進第 5 欄要提的問題。
- **4. 注意事項** — 筆記裡寫的容易弄錯的地方。
- **5. 要提的問題** — 筆記裡寫的不懂的東西·問號。沒有的話按模板註釋寫 `（沒有）`。
- **6. 要試的事** — 把筆記裡寫的應用計劃寫成 `- 什麼時候：做什麼` 的形式。備忘裡沒有"什麼時候"的話寫 `- （備忘中沒有）：做什麼`。
- **7. 試過的結果** — 按模板註釋，一開始寫 `（還沒試過）`。只有筆記裡寫了試過的結果時，才連同日期填上。
- 沒有可寫內容的欄不要刪，寫上 `（備忘中沒有）`。

日期：標題按模板寫成 `2026-10-28(週二)`，正文寫成 `10/28(週二)` 這樣的月/日 + 括號星期。星期要對照日曆確認（`date -j -f %Y-%m-%d 2026-10-28 +%a`）。

**備忘裡沒有的內容不要編造。** "用自己的話"重新寫只是換個說法，不是補充筆記裡沒有的知識。

## 儲存位置

- `notes/study-YYYY-MM-DD-topic.md`（日期·主題取自原始筆記的檔名）
- 例：`inbox/study-2026-10-28-prompt-lecture.txt` → `notes/study-2026-10-28-prompt-lecture.md`
- 如果已經有同名檔案，覆蓋之前先問使用者。

## 完成後要核對的檢查清單

重新開啟儲存的檔案，從上往下確認。只要有一項 ✗，就改好後再確認一遍。

**通用**
- [ ] 欄目名稱和順序與模板相同（沒有刪掉的欄 — 沒有可寫的內容就寫 `（備忘中沒有）`）
- [ ] 一個 `{{` 也沒有剩下（`grep -n '{{' notes/study-....md` 的結果為空）
- [ ] 日期帶著星期，檔名裡的日期和標題裡的日期相同
- [ ] 數字·名字·日期和原始筆記對照過一次
- [ ] 沒有編造筆記裡沒有的內容
- [ ] 沒有修改 `inbox/` 裡的原件（`git status inbox/` 裡沒有這次工作造成的改動）

**學習筆記**
- [ ] 核心內容沒有照抄，是用簡單的話寫的，有 3 條以上（筆記裡不到 3 條的話，有多少寫多少，並告訴使用者）
- [ ] 筆記裡出現的不懂的詞全部連同意思放在了「新學的詞」表裡
- [ ] 要試的事是寫明"什麼時候 · 做什麼"的行動（"好好寫寫看" ✗ → "週一的 Instagram 文案裡加上角色+格式" ✓）
- [ ] 試過的結果是 `（還沒試過）`，或者是筆記裡寫的日期·結果

最後告訴使用者儲存路徑，以及留成 `（備忘中沒有）` 的欄目列表。
