# 様式の使い方

1. 使う様式をコピーして、`notes/`に新しい名前で保存する — 名前のルールは各様式のいちばん上のコメントにある。
2. `{{ }}` の部分をすべて埋める。書くことがなければ欄を消さずに、`（メモになし）`と書く。
3. 下のチェックリストを上から確認する。

| 様式 | いつ | 欄 |
|---|---|---|
| `minutes.md` | 会議が終わった直後 | 決めたこと · やること · 次に話し合うこと · 次回の会議 |
| `study-notes.md` | 講義や本を見た日 | ひとこと要約 · 要点 · 新しく知った言葉 · 注意すること · 質問すること · やってみること · やってみた結果 |
| `weekly-review.md` | 金曜日 | よかったこと · 惜しかったこと · 来週やること (KPT) |

## チェックリスト

**共通**
- [ ] 欄の名前と順番が様式と同じ (欄を消していない — 書くことがなければ `（メモになし）`)
- [ ] `{{`がひとつも残っていない (エディタで `{{` を検索)
- [ ] 日付に曜日がついていて、ファイル名の日付とタイトルの日付が同じ
- [ ] 数字・名前・日付を元のメモと一度照らし合わせた (10/30の値段6,000ウォンの誤りのようなミスを防ぐ)

**議事録**
- [ ] 決めたことごとに「何を・いくら/どのように・いつまでに」が全部入っている
- [ ] やること表のすべての行に担当と期限がある (空欄なら会議で決まっていないこと → 次に話し合うことへ)
- [ ] 元のメモのやることが表に全部移されている (元のメモの「〜する」の行数 = 表の行数)
- [ ] 次回の会議の日付が書かれている

**勉強ノート**
- [ ] 要点を写さずに自分の言葉で書き、3つ以上ある
- [ ] わからない言葉は全部「新しく知った言葉」の表に意味といっしょにある
- [ ] やってみることが「いつ · 何を」できる行動になっている (「上手に書いてみる」✗ → 「月曜日のインスタ投稿に役割+形式を入れる」✓)

**週間振り返り (KPT)**
- [ ] 本文の欄がよかったこと / 惜しかったこと / 来週やることの3つだけで、この順番になっている
- [ ] 3つの欄すべてに1つ以上書かれている
- [ ] よかったこと・惜しかったことに、それぞれ「なぜ」がついている
- [ ] 来週やることが日付のある行動で、惜しかったことのうち少なくとも1つとつながっている
