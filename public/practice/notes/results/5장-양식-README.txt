# 양식 사용법

1. 쓸 양식을 복사해 `notes/`에 새 이름으로 저장한다 — 이름 규칙은 각 양식 맨 위 주석에 있다.
2. `{{ }}` 자리를 모두 채운다. 쓸 게 없으면 칸을 지우지 말고 `(메모에 없음)`이라고 쓴다.
3. 아래 점검표를 위에서부터 체크한다.

| 양식 | 언제 | 칸 |
|---|---|---|
| `회의록.md` | 회의 끝난 직후 | 결정한 것 · 할 일 · 다음에 논의할 것 · 다음 회의 |
| `공부노트.md` | 강의·책을 본 날 | 한 줄 요약 · 핵심 내용 · 새로 안 말 · 주의할 것 · 질문할 것 · 해볼 것 · 해본 결과 |
| `주간회고.md` | 금요일 | 잘한 것 · 아쉬운 것 · 다음 주에 할 것 (KPT) |

## 점검표

**공통**
- [ ] 칸 이름과 순서가 양식과 같다 (칸을 지우지 않았다 — 쓸 게 없으면 `(메모에 없음)`)
- [ ] `{{`가 하나도 남아 있지 않다 (편집기에서 `{{` 검색)
- [ ] 날짜에 요일이 붙어 있고, 파일명 날짜와 제목 날짜가 같다
- [ ] 숫자·이름·날짜를 원본 메모와 한 번 대조했다 (10/30 가격 6,000원 오류 같은 실수 방지)

**회의록**
- [ ] 결정한 것마다 "무엇을·얼마/어떻게·언제까지"가 다 들어 있다
- [ ] 할 일 표의 모든 줄에 담당과 기한이 있다 (빈칸이면 회의에서 안 정한 것 → 다음에 논의할 것으로)
- [ ] 원본 메모의 할 일이 표에 전부 옮겨졌다 (원본에서 "~하기" 줄 수 = 표 줄 수)
- [ ] 다음 회의 날짜가 적혀 있다

**공부 노트**
- [ ] 핵심 내용을 베끼지 않고 내 말로 썼고, 3개 이상이다
- [ ] 모르는 말은 전부 '새로 안 말' 표에 뜻과 함께 있다
- [ ] 해볼 것이 "언제 · 무엇을" 할 수 있는 행동이다 ("잘 써 보기" ✗ → "월요일 인스타 글에 역할+형식 넣기" ✓)

**주간 회고 (KPT)**
- [ ] 본문 칸이 잘한 것 / 아쉬운 것 / 다음 주에 할 것 세 개뿐이고 이 순서다
- [ ] 세 칸 모두 1개 이상 적혀 있다
- [ ] 잘한 것·아쉬운 것에 각각 "왜"가 붙어 있다
- [ ] 다음 주에 할 것이 날짜가 있는 행동이고, 아쉬운 것 중 최소 하나와 이어진다
