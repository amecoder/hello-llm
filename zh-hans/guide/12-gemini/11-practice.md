# 第11章 实践课题——亲手用一用 Gemini 的功能

> **一句话总结**：把第1～10章里看过的 Gemini 的画面和功能，汇总成 10 个**亲手点一遍**的课题。
> 每个课题都有「确认有没有做好」检查清单，不用别人来打分，你自己就能确认。

画面以 2026年10月的网页版为准。Gemini 的菜单名称和位置经常变，如果画面不一样，请以画面上看到的名称为准。

## 怎样做实践课题

1. **打开 Gemini（gemini.google.com）并登录。** 大部分课题要用到对话记录和设置。
2. **照着课题里的「要做的事」做。** 把灰色方框里的提示词复制下来发送就行。
3. **把「确认有没有做好」一项一项打勾。** 有没打上勾的项目，就去读「回头再看的地方」里的那一章，只把那部分重新做一遍。

课题不必按顺序做。不过，**课题10请放在最后**做。它是用来整理练习留下的痕迹的课题。
课题8里的「任务（작업）」是 **Google AI Pro、Ultra** 专用的，如果是免费套餐，只做聊天日程就行。其他菜单也可能因账号或套餐而看不到，或者还没有开放。看不到的话，读一读就可以跳过。

关于该怎么问（怎么写提示词）的练习，在[第1阶段第10章实践课题](../00-common/10-practice.md)里。这里请把注意力放在**按钮和菜单**上。

不必一开始就全部做完。每天做两三个课题就足够了。

### 做练习时要守的三条

- **尽量在临时聊天里做。** 通过右上角的「临时聊天（임시 채팅）」打开的对话，不会留在对话列表里，也不会用于 AI 训练。不过，会保存 72 小时（[第2章](02-screen-tour.md#临时聊天-—-不留记录的对话)）。[^screen][^hub]
  涉及记录、技能、日程的课题（3、5、7、8），请在普通聊天里做。因为在临时聊天里，不能重新打开，也不能改名。
- **资料用假的。** 不要用真实的姓名、联系方式、公司资料，请用**我自己编出来的资料**。在普通聊天里做的练习，在课题10里整理。不该放进去的信息，在[第1阶段第9章](../00-common/09-safety.md#不要放进去的东西)里。
- **不要点赞或点踩。** 一发送反馈，即使把「保留活动记录（활동 기록 보관）」关了，那个对话也会用于改进服务（[第9章](09-privacy.md#会有人阅读吗-会用于-ai-训练吗)）。[^hub]

## 课题

### 课题1. 用临时聊天建一个练习空间

**适合什么时候**：想问一些不想留在记录里的问题时。

**要做的事**：点右上角的「临时聊天」，发送下面的内容。拿到回答后，点右上角的 × 关闭。

```
我第一次用 Gemini。推荐三个今天适合练习的问题。
```

**确认有没有做好**

- ☐ 画面中央出现了"临时聊天不会显示在最近的聊天里……"这样的提示[^screen]
- ☐ 想留下的回答，在关闭之前已经复制好了（没有要留的回答就打勾）
- ☐ 关闭后，侧边菜单的对话列表里没有这个对话

**回头再看的地方**：[第2章 画面一览](02-screen-tour.md)

### 课题2. 在模型按钮里改变思考级别

**适合什么时候**：对难题，想拿到想得更深入的回答时。

**要做的事**：在临时聊天里发送下面的内容，然后在输入框的模型按钮里把思考级别提高一档，再发送同样的问题。

```
每月存 30万韩元、存 2 年，和一开始存入 600万韩元、放 2 年，有什么不同？
请把利息计算方式的差别，讲到初中生也能听懂。
```

**确认有没有做好**

- ☐ 点了模型按钮，确认了现在在用的模型和思考级别
- ☐ 改变思考级别之后，比较了回答的长度和讲解顺序有什么不同
- ☐ 知道了依套餐不同，能选的项目也不同（免费套餐就只确认看得到的项目，然后打勾）

**回头再看的地方**：[第2章 模型按钮](02-screen-tour.md#模型按钮-—-模型和思考级别)

### 课题3. 给对话改名，再找回来

**适合什么时候**：之后需要重新找以前的对话时。

**要做的事**：在普通聊天里发送下面的内容。在侧边菜单里，点这个对话的三个点 →「重命名（이름 변경）」，把标题改成"[练习] 读书会准备物品"。然后在「搜索聊天（채팅 검색）」里输入"练习"，找找看。

```
告诉我第一次来读书会的人，最好准备的五样东西。
```

**确认有没有做好**

- ☐ 侧边菜单里的对话标题变成了"[练习] 读书会准备物品"
- ☐ 通过「搜索聊天」找到了这个对话
- ☐ 点「固定（고정）」把它钉在了列表最上面，又用「取消固定（고정 해제）」恢复了

**回头再看的地方**：[第3章 对话管理](03-chats.md)

### 课题4. 上传假通知，拿回表格

**适合什么时候**：想整理很长的文档，或者想把它改成另一种样子时。

**要做的事**：在记事本里写一份下面这样的假通知，保存成文件。通过输入框的「+」→「上传文件（파일 업로드）」上传，然后发送提示词。

```
11月读书会通知
日期：11月22日 星期六 下午2点
地点：区立图书馆3楼研讨室
阅读书目：《小妇人》
准备物品：书、记笔记的本子、会费 5,000韩元
```

```
请从上传的通知里提取日期、地点、阅读书目、准备物品，整理成表格。
不要使用其他应用，就在这个聊天里用表格给我看。
```

**确认有没有做好**

- ☐ 表格里的日期、地点、会费，和通知一个字都不差
- ☐ 没有编造通知里没有的内容（例：结束时间）
- ☐ 点了表格正下方的三个点，确认了有「导出到 Sheets（Sheets로 내보내기）」（不点也可以）

**回头再看的地方**：[第4章 文件与创作](04-files-create.md) · [第3章 导出到其他应用](03-chats.md#导出到其他应用)

### 课题5. 写入指示，看看回答会不会变

**适合什么时候**：嫌每次都提同样的要求（"简短一点""做成表格"）太麻烦时。

**要做的事**：在「设置（설정）」→「个人智能（개인 인텔리전스）」→「Gemini 要求事项（Gemini 요청 사항）」里，添加下面的指示。在新的普通聊天里随便问个问题。

```
在回答的最前面加一行摘要，难懂的词用括号解释。
```

**确认有没有做好**

- ☐ 新聊天的回答最前面加上了一行摘要
- ☐ 在「Gemini 要求事项」画面里，看到了我添加的指示
- ☐ 练习结束后，把这条指示删掉，或者改成适合我的样子

**回头再看的地方**：[第5章 记忆与个性化设置](05-memory.md)

### 课题6. 打开出处，修改 Deep Research 计划

**适合什么时候**：想确认回答的依据，或者需要汇总许多资料的报告时。

**要做的事**：先发送下面的内容，打开回答里的「出处（출처）」之一。然后点「+」→「更多工具（도구 더보기）」→「Deep Research」打开它，发送同样的主题，出现计划后，用「修改计划（계획 수정）」改成"只用官方统计"。

```
告诉我最近 5 年韩国1人户的比例是怎么变化的，并附上出处。
```

**确认有没有做好**

- ☐ 打开出处链接，看了回答里的数字和原文是否一致
- ☐ Deep Research 计划出来之后，用「修改计划」加上了条件
- ☐ 如果不打算把报告拿到最后，就用暂停按钮停下来了（Deep Research 很耗用量）

**回头再看的地方**：[第6章 搜索与 Deep Research](06-search.md)

### 课题7. 创建技能并调用

**适合什么时候**：经常提同一个要求时。

**要做的事**：在「个性化设置（맞춤설정）」→「技能（스킬）」→「创建（만들기）」→「手动创建（수동으로 만들기）」里，按下面的样子创建一个技能。在新聊天里输入 `/`，选中这个技能，然后粘贴一份假的会议笔记。

```
名称：summarize-meeting-notes
说明：把会议纪要整理成决定事项、待办事项、负责人。粘贴会议纪要或会议笔记时使用。
指示：收到会议纪要后，按 1. 已决定的事 2. 待办事项（事项 - 负责人 - 截止日期） 3. 下次还要再看的事 的顺序整理。
没有负责人或截止日期的话，不要编造，写"需确认"。
```

**确认有没有做好**

- ☐ 输入 `/` 时，列表里出现了我创建的技能（如果变成了 `@`，就用 `@`）
- ☐ 没有负责人的待办事项，显示了"需确认"
- ☐ 练习结束后，用「更多（더보기）」→「停用（비활성화）」或「删除（삭제）」整理掉了

**回头再看的地方**：[第7章 技能与已连接的应用](07-skills-apps.md)

### 课题8. 设定日程，再在「已预约」里删掉

**适合什么时候**：想每天、每周收到同样的消息时。

**要做的事**：在普通聊天里发送下面的内容。在侧边菜单的「已预约（예약됨）」里看看日程有没有生成，再用「更多」删掉。如果是付费套餐，也点输入框下方的「任务」，发一个"帮我问问（물어봐 줘）"试试。聊天日程正在逐步开放，所以也可能还不能用。

```
每周一早上 8 点，把这周首尔的天气概括成三行。
```

**确认有没有做好**

- ☐ Gemini 用日程摘要（什么时候、多久一次）回答了
- ☐ 在「已预约」里找到了这个日程
- ☐ 练习结束，把日程删掉了

**回头再看的地方**：[第8章 交代任务](08-tasks.md)

### 课题9. 在手机上用嘴问

**适合什么时候**：不方便打字，或者想用嘴练习时。

**要做的事**：在手机上安装 Gemini 应用，用同一个 Google 账号登录。点麦克风，说出下面的内容。如果是 Android，也点一下「Live」。

```
告诉我今天晚上，用冰箱里的鸡蛋、豆腐、大葱能做的三道菜。
```

**确认有没有做好**

- ☐ 我说的内容变成了文字，问题发送出去了
- ☐ 电脑网页的对话列表里也能看到这个对话（如果是普通聊天的话）
- ☐ 用了 Live 的话，点「结束」之后，看到同一个对话以文字继续（没用 Live 就打勾）

**回头再看的地方**：[第10章 语音与手机](10-voice-mobile.md)

### 课题10. 检查并整理我的数据设置

**适合什么时候**：练习结束时，以及每隔几个月一次。

**要做的事**：打开左下角的「设置」，按下面的检查清单确认。

**确认有没有做好**

- ☐ 在「活动（활동）」里，「保留活动记录」设成了我想要的那一边（开或关）
- ☐ 自动删除的期限（默认 18 个月），选成了适合我的
- ☐ 在「我的公开链接（내 공개 링크）」里，把不再需要的链接删掉了（没有分享过对话就打勾）
- ☐ 在「个性化设置」→「连接器（커넥터）」里，把不需要的已连接应用「断开连接（연결 해제）」了
- ☐ 删掉了课题3、4、5、6、7里做出的练习对话。就算断开连接或删除应用数据，对话记录也还在，所以对话要另外删除

**回头再看的地方**：[第9章 个人信息与安全](09-privacy.md) · [第3章 对话管理](03-chats.md) · [第7章 已连接的应用](07-skills-apps.md#已连接的应用-—-在-gemini-里用-gmail·drive·日历)

## 总结

- 功能光读是不会熟练的。每个按钮都亲手点一遍。
- 练习尽量在临时聊天里做，涉及记录、技能、日程的课题，用假资料在普通聊天里做。
- 课题8里的「任务」需要付费套餐。其他菜单如果因账号而看不到，读一读就跳过。
- 每个课题都用检查清单自己确认，没打上勾的部分，读一读「回头再看的地方」再重做。
- 练习结束后，检查「保留活动记录」、自动删除、公开链接、已连接的应用，并把练习用的对话整理掉。

这一章没有新出现的术语。临时聊天、技能、任务这些词，在各章的「术语整理」里。
