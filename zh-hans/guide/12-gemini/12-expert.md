# 第12章 像专家一样使用——选功能、积累、检查

> **一句话总结**：用得好，靠的不只是多认识几个按钮。靠的是这种能力：**按事情选合适的功能，把重复的东西积累下来，并按事情的分量检查结果**。
> 本章讲的是，如何把第1～11章学到的 Gemini 功能，按你的事情**组合起来使用**。

本章几乎不讲新功能。主题是：前面章节学到的 Gemini 功能，什么时候用、怎么用。

怎么判断该交给它什么、交出去之前怎么拿已知答案的事来测试这类**对任何 AI 都管用的方法**，在[第1阶段第11章「像专家一样使用」](../00-common/11-expert.md)里。先读过那一章，这一章会更容易。本章只是把那些方法对应到 Gemini 的功能和菜单上。

## 按事情选合适的功能

别先挑菜单。先看看眼前的事情是什么样子。这样，该用的功能自然就定下来了（[第1阶段第11章「先看事情的样子」](../00-common/11-expert.md#先看事情的样子)）。

| 如果是这样的事 | 就用这个 | 详见 |
|---|---|---|
| 提问、润色、一起想 | 普通对话 | [第1阶段](../00-common/) |
| 需要仔细推敲 | 调高模型按钮里的思考等级 | [第2章](02-screen-tour.md#模型按钮-—-模型和思考级别) |
| 不想留下记录的提问 | 临时聊天 | [第2章](02-screen-tour.md#临时聊天-—-不留记录的对话) |
| 一起修改文档或小应用 | Canvas | [第4章](04-files-create.md#canvas-—-一起修改文档和应用) |
| 收集大量资料写成报告 | Deep Research | [第6章](06-search.md#deep-research——拿到长篇调查报告) |
| 长期收集同一个主题的资料 | 笔记本 | [第6章](06-search.md#笔记本——按主题收集资料和对话) |
| 总是重复同样的请求 | 技能 | [第7章](07-skills-apps.md#技能-—-把常做的请求保存起来) |
| 在我的邮件、文件里查找 | 已连接的应用 | [第7章](07-skills-apps.md#已连接的应用-—-在-gemini-里用-gmail·drive·日历) |
| 经过多个步骤，最后拿到成果 | 任务（付费） | [第8章](08-tasks.md#任务——不是聊天-而是把整件事交出去) |
| 每到固定时间就重复 | 日程 | [第8章](08-tasks.md#在定好的时间自动运行——日程) |

这张表是把前面各章的内容集中到一处。

大部分情况下，最上面一行，也就是普通对话，一个就够了。越往下，用量花得越多（Deep Research、任务），或者交出去的个人信息越多（已连接的应用、任务）。**只在真的需要时，才往下走一行。**

## 把重复的事积累下来

用着用着，你会发现自己总在重复同样的话。把重复的东西写下来一次，以后 Gemini 一开始就知道了。

能放的地方有四个。不必一开始就全用。按下面的顺序，等需要了再加一个。什么时候不该做成模板，在[第1阶段第11章「把重复的事积累下来」](../00-common/11-expert.md#把重复的事积累下来)里。

1. **所有对话都提同样的请求** → 写进「Gemini 请求事项（Gemini 요청 사항）」里，作为指令（[第5章](05-memory.md#指令-—-不用每次都说)）。
2. **要不断翻看同一个主题的资料** → 把这些资料收进笔记本（[第6章](06-search.md#笔记本——按主题收集资料和对话)）。
3. **每次都要解释同样的顺序** → 把这个顺序做成技能（[第7章](07-skills-apps.md#怎样写好技能)）。
4. **每到固定时间就做同样的事** → 设置日程（[第8章](08-tasks.md#在定好的时间自动运行——日程)）。

指令和技能分不清的话，请这样记。**指令是一直遵守的规则，技能是只在合适的情境下才拿出来用的步骤。** Gemini 会看技能的名称和说明，来判断现在要不要用。[^write]

### 把做好的技能开关对比一下

对做好的技能，请把同一个请求发两次来对比。一次开着技能，一次用「停用（비활성화）」关掉。[^skills] 对比和修改的要领，在[第1阶段第11章「把做好的模板测试一下再修改」](../00-common/11-expert.md#把做好的模板测试一下再修改)里。

对比的时候，请问问自己。

- 开着技能的回答，是不是更接近我想要的样子？
- 在不需要技能的问题里，技能有没有插进来捣乱？

如果会插进来，就把技能说明里**什么时候用**写得更窄一些（[第7章](07-skills-apps.md#写名称·说明·指令)）。

## 把表格和数字交给它

上传表格文件，Gemini 会帮你分析并画图表（[第4章](04-files-create.md#上传文件)）。

```
附件的表是附近小店过去三个月按品类记录的销售情况。请按品类算出合计，按从大到小的顺序做成表格，并画一张柱状图。
再用一行一行的文字写出计算用的方法。
```

像最后一行那样，**让它同时写出计算方法**，就更容易找出哪里错了。

做数字分析，最让人担心的是结果能不能信。请先用**已经算好的过去的资料**对一下。在你知道答案的资料上能对上，以后再交新资料时，就能多信几分。方法和例子在[第1阶段第11章「把表格和数字交给它」](../00-common/11-expert.md#把表格和数字交给它)里。
重要的计算，请用电子表格或手算再确认一遍。把表格用「导出到 Sheets（Sheets로 내보내기）」转过去，就可以马上重新计算（[第3章](03-chats.md#导出到其他应用)）。

## 按事情的分量检查

不用把所有回答检查到同样的程度。**错了会损失得越大**，就看得越仔细（[第1阶段第11章「按事情的分量检查」](../00-common/11-expert.md#按事情的分量检查)）。

| 事情的分量 | 例子 | 这样检查 |
|---|---|---|
| 轻 | 推荐晚饭菜单 | 读一遍，觉得怪就跳过 |
| 中 | 聚会通知 | 只把日期、场地、金额和原件对一下 |
| 重 | 合同、健康、钱 | 打开出处看，再请专家确认 |

把这份指南里学过的检查工具再汇总一下，就是这样。

- 打开回答下面的**「来源」**，和原文对一对（[第6章](06-search.md#核实回答的依据)）。
- 已连接应用给出的回答，要打开**原来的邮件、文件**看看（[第7章](07-skills-apps.md#好好提问的要领)）。
- 任务要仔细读**征求许可的界面**，并看着它运行（[第8章](08-tasks.md#交出去之前——安全守则)）。
- 医疗、法律、金融方面的判断，不要交给 Gemini（[第9章](09-privacy.md#不能做的事-不能轻信的事)）。

## 亲自动手试试

1. 想出这周做过的三件事，在上面的「按事情选合适的功能」表里，分别找出它们属于哪一行。
2. 找出过去一周里你对 Gemini 提过两次以上的请求，决定是放进指令，还是做成技能。
3. 把第7章做的技能开着发一次、关着发一次同样的请求，对比结果。
4. 上传一份你已经知道合计的家庭账本表，让它重新计算合计，看是否和你知道的数值相同。

**贯穿始终的作业**（[筹备读书会](../00-common/practice-kit.md)）：上传作业里的账本文件，让它算出会费合计。确认是否和作业说明里写的合计一致；不一致的话，到 Gemini 写出的计算方法里找一找哪里错了。

## 小结

- 先看事情的样子，再看菜单。大部分情况下普通对话就够了，只在需要时才下到 Deep Research、任务这样的功能。
- 重复的东西，按指令 → 笔记本 → 技能 → 日程的顺序，等需要了再一个一个积累。
- 指令是一直遵守的规则，技能是只在合适的情境下才用的步骤。做好的技能要开关对比一下。
- 表格和数字，要让它同时写出计算方法，并先用已知答案的资料对一遍。
- 检查按事情的分量来做。重要的事要打开出处，并请专家确认。
