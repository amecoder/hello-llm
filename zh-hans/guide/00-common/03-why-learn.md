# 第3章 为什么要学

> **一句话总结**：同样是用 AI，“怎么问”不同，结果会差很多，
> 而这个差距只要肯学，人人都能缩小。

## 同样的工具，不同的结果

假设有两个人，请同一个 AI 帮忙写简历。

**A 的请求**

```
帮我写简历。
```

AI 不知道 A 是谁。所以它给了一份姓名和经历栏都空着的普通模板。
A 觉得“没什么用”，就关掉了窗口。

**B 的请求**

```
我在物流公司做了 5 年库存管理，这次想应聘网店（电商）公司的运营团队。
请根据下面我的经历备忘，写出简历里「经历概述」的部分，写三行，
要突出对电商运营有帮助的经验。

[经历备忘]
- 用 Excel 每周管理 3 个仓库的库存数据
- 改进退货处理流程，缩短了处理时间
- 负责培训 4 名新员工
```

B 拿到了可以直接用的句子。然后接着要求把不满意的地方改一改。

**两个人的差别不在 AI，而在请求。** A 什么都没告诉 AI，B 告诉了它自己的经历、要应聘的地方和想要的格式。
这种请求的文字叫作**提示词（prompt）**。怎样写好提示词，从[第4章](04-prompt-basics.md)开始学。

## 日常生活中这样用

这不是只给开发者或专家用的工具。下面都是普通人马上就能用的例子。

| 情景 | 可以这样请求 |
|---|---|
| 工作 | “把这封邮件改得礼貌但坚决，内容是日程很难推迟” |
| 合同·文件 | “在这份全租·月租合同（租赁合同）里，找出可能对租客不利的条款，用简单的话解释” |
| 学习 | “一元二次方程的求根公式为什么是那样推出来的，按初中生的水平一步一步讲” |
| 生活 | “冰箱里有鸡蛋、豆腐、大葱、泡菜。20 分钟内能做好的晚餐菜单 3 个” |
| 旅行 | “带父母去釜山玩 2 晚 3 天，安排一个不用走太多路的行程” |
| 育儿 | “7 岁的孩子问‘为什么会下雨？’，告诉我怎么用孩子能懂的方式解释” |

## 学了会有什么变化

1. **省时间。** 写初稿、整理这类原本很费时间的事，第一步可以缩短到几分钟。
2. **结果更好。** 拿到贴合自己情况的回答，需要修改的地方就少了。
3. **不容易被骗。** 知道 AI 是怎么出错的，就知道该核实哪里。
4. **可以走向下一个阶段。** 这本指南的最后，有和 AI 一起亲手做出东西的阶段。
   它的起点，就是现在学的“会问”。

## 纠正误解

- **“AI 什么都会自动做好”**——不是这样。要告诉它你的情况和目标，它才能做好。
- **“要背很难的命令”**——没有什么特别的咒语。把平时拜托别人做事时说的话整理清楚就行。
- **“问一次不满意，就没用了”**——不需要一开始就完美。接着对话、让它修改，才是正常的用法。
- **“AI 的回答是准确的”**——就像[第1章](01-what-is-llm.md)里看到的，它可能出错。重要的内容请核实。

## 亲自试一试

把上面 A 和 B 的请求，真的都输入一遍。
B 的请求里的经历备忘，换成你自己的真实经历也可以。
把两份回答并排放在一起比较。哪一份不用修改就能直接用？哪一份包含了我的经历？

## 整理

- 结果的差异大多不是来自 AI，而是来自请求（提示词）。
- 工作、文件、学习、生活，在哪里都能马上用上。
- 不要指望一次就得到完美的回答，而是接着对话慢慢打磨。
