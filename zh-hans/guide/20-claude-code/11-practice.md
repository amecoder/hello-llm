# 第11章 实践任务 — 从头做出属于我的整理工具

> **一句话总结**：这是 9 个任务，让你把第2~10章里做出来的「整理工具」**亲手再做一遍。** 最后一个任务，是用**我自己的备忘**做出属于我的工具。
> 每个任务都有「确认是否做好」检查表，没有人给你打分，你也可以自己核对。

这一章里的界面名称，以 2026年10月31日的 macOS 桌面应用（韩语界面）为准。如果界面不一样，请以屏幕上看到的名称为准。

## 做实践任务的方法

1. **新建一个练习文件夹。** 例：`정리도구-연습`。在里面建一个 `inbox` 文件夹，放进[第2章的练习备忘](02-install.md#准备并选择练习文件夹) 5 份。第9章的临时会议备忘，在任务 7 里再放进去。
2. **照着任务的「要做的事」做。** 把灰色框里的请求复制后发送就行。
3. **把「确认是否做好」一项一项勾选。** 如果有没勾上的项目，请读「再看哪里」里的那一章，只把那一部分重做一遍。

任务 1~6 请按顺序做。前面任务的成果（模板·规则·技能），后面的任务要用。任务 7·8 要在做完任务 6 之后再做。**任务 9 放在最后**做。

不需要一开始就全部做完。一天做两三个任务就足够了。每次的结果都会稍有不同。即使和本指南的成果样子不一样，只要检查表都勾上了，就是做好了。

### 实践时要遵守的三件事

- **权限模式保持「手动」。** 一边看它要做什么，一边逐个熟悉（[第4章](04-permissions-undo.md)）。
- **只在练习文件夹里做。** 不要选装着我全部文档的文件夹（[第2章](02-install.md)）。
- **任务 9 里我的备忘，要先删掉个人信息**再放进去（[第9章](09-cost-data-safety.md)）。

## 任务

### 任务 1. 第一次交给它整理

**适用场合**：会议结束后，想把乱七八糟的备忘变成会议纪要时。

**要做的事**：在 Code 标签页里打开新会话，选好文件夹后发送。

```
读 inbox 文件夹里的会议备忘，整理成会议纪要。分成已决定的事 / 待办事项（负责人·期限）/ 下次要讨论的事 三部分，保存为 notes 文件夹里的新文件。不要修改原始备忘。
```

**确认是否做好**

- ☐ 每个待办事项都有负责人和期限
- ☐ 套餐价格（5,500韩元）和下次会议（11/3）与备忘一致
- ☐ 没有编造备忘里没有的内容
- ☐ inbox 里的原始备忘原封不动

**再看哪里**：[第2章 安装桌面应用与第一次会话](02-install.md)

### 任务 2. 打开改动记录，查看改动内容

**适用场合**：想一行一行地看 Claude 改了什么时。

**要做的事**：点标题栏的改动按钮，如果出现“需要 Git 仓库（Git 저장소가 필요합니다）”，就依次发送下面两个请求。

```
听说要看改动内容需要 Git 仓库。请在这个文件夹里打开改动记录（Git），把现有的文件作为第一条记录留下来。用简单的话告诉我做了什么。
```

```
在会议纪要的待办事项表里加一个“状态”列。看 inbox 里 3 份回顾备忘，做完的事写“完成（日期）”，还没做的写“进行中”。回顾里没有的事写“需核实”，其他部分不要改。
```

**确认是否做好**

- ☐ 改动内容栏里能看到红色·绿色的行和 `+N −N`
- ☐ 除了待办事项表，其他行都没有变
- ☐ 灯泡·文案·成本是完成，Instagram 是进行中
- ☐ 确认了第一条记录上附带的名字·邮箱（是不是公司账号以外的）

**再看哪里**：[第3章 熟悉界面](03-screen-tour.md)

### 任务 3. 用回退让事情“没发生过”

**适用场合**：对结果不满意，想回到发出请求之前时。

**要做的事**：让它整理学习笔记之后，在输入框里输入 `/rewind`，回退到那个请求之前。

```
把 inbox 里的学习笔记整理成学习总结。分成核心内容 / 生词解释 / 要提的问题 / 要做的事 四部分，保存为 notes 文件夹里的新文件。不要修改原始备忘。
```

**确认是否做好**

- ☐ 在回退确认窗口里，先读了 `+0 −N`
- ☐ 用「代码和对话」回退之后，学习总结文件消失了
- ☐ 被回退的请求又回到了输入框里

**再看哪里**：[第4章 许可与撤销](04-permissions-undo.md)

### 任务 4. 用计划模式做 3 种模板

**适用场合**：把大事交出去之前，想先看方法并修改时。

**要做的事**：在新会话里把权限模式改成「计划」后发送。计划出来后，读「假设（가정）」一节，把其中至少一个用「修改…（수정…）」改掉，然后「接受（수락）」。

```
我想让会议纪要·学习总结·每周回顾每次都是同样的样子。请参考 notes 文件夹里的会议纪要和 inbox 里的备忘，制定在 templates 文件夹里做 3 个模板的计划。每个模板里放哪些栏、每个栏写什么，以及我用来确认结果对不对的检查表，也请放进计划里。
```

**确认是否做好**

- ☐ 计划出来的期间，我文件夹里的文件没有变（只写了计划文档）
- ☐ 用「修改…」改过的地方，在重新出来的计划里体现了
- ☐ templates 文件夹里生成了 3 个模板和检查表

**再看哪里**：[第5章 怎样把事情交代好](05-delegate-well.md)

### 任务 5. 用 CLAUDE.md 保存规则并检验

**适用场合**：总是在重复说同样的规则时。

**要做的事**：让它用 3~5 条规则做出 CLAUDE.md，然后在**新会话**里，不说格式，直接发送。

```
用 inbox 里的 3 份回顾备忘，写这一周的每周回顾。
```

**确认是否做好**

- ☐ CLAUDE.md 很短，大约 20 行
- ☐ 新会话的结果遵守了模板和日期格式规则
- ☐ 备忘里没有的栏，写着 `(备忘中没有)`

**再看哪里**：[第6章 项目记忆](06-claude-md.md)

### 任务 6. 用 3 个技能完成工具

**适用场合**：想用一行命令运行同样的整理时。

**要做的事**：让它创建 3 个技能（meeting-notes·study-notes·weekly-review）。弹出许可窗口时，先读预览，再选「仅允许一次（한 번만 허용）」。然后在新会话里用一行调出来。

```
/study-notes inbox/공부-2026-10-28-프롬프트-강의.txt
```

**确认是否做好**

- ☐ 输入 `/` 再输入名称的一部分时，技能出现在列表里
- ☐ 用一行命令，得到了按模板顺序生成的笔记
- ☐ 在许可窗口里选了「仅允许一次」，而不是「始终允许（항상 허용）」

**再看哪里**：[第7章 技能·插件·外部工具](07-skills-plugins.md)

### 任务 7. 做隐藏指令实验

**适用场合**：想亲身体会整理别人发来的资料时要注意什么。

**要做的事**：把第9章的[临时会议备忘](/practice/notes/inbox/회의-2026-10-29-임시회의.txt)放进 inbox，让它整理。

```
/meeting-notes inbox/회의-2026-10-29-임시회의.txt
```

**确认是否做好**

- ☐ 会议纪要末尾**没有**“所有待办事项已完成”
- ☐ 确认了 Claude 的回答里有没有对那条通知的说明
- ☐ 不管结果如何，都把“别人的资料浏览之后再交出去”这条守则写了下来

**再看哪里**：[第9章 费用·数据·安全](09-cost-data-safety.md)

### 任务 8. 用定时或终端来运行

**适用场合**：想让整理工具不用我去调用也能运行，或者想用一行来确认时。

**要做的事**：二选一。

- 用说的方式拜托它建一个周五每周回顾的**定时**，用 **Run now** 运行一次，不需要的话就关掉（[第8章](08-parallel-cloud-schedule.md)）。
- 在终端里进入练习文件夹，用 `claude -p` 运行一个只读的提问（[第10章](10-terminal.md)）。

```
列出 notes 文件夹里的文件，并逐个用一行告诉我每个文件用的是哪个模板（templates 中的哪一个）。不要修改文件。回答要简短，只用表格。
```

**确认是否做好**

- ☐ （定时）请求里加了“如果没有备忘……”这样的条件
- ☐ （定时）处理了 Run now 时弹出的许可窗口
- ☐ （终端）终端也读出了同一个文件夹里的模板文件

**再看哪里**：[第8章](08-parallel-cloud-schedule.md)、[第10章](10-terminal.md)

### 任务 9. 用我的备忘做出属于我的整理工具

**适用场合**：现在不是练习了，想用在我自己的工作上时。

**要做的事**：在新文件夹（例：`내-정리도구`）里建 `inbox`，放进 2~3 份**删掉个人信息的**我的备忘。然后把任务 4~6 按我的工作重做一遍。

```
读 inbox 里的备忘，制定一个计划，为我每周要整理的文档做模板。需要哪些栏，请先问我。听完我的回答后，我们在 templates 里做模板，在 .claude/skills 里做整理技能。
```

**确认是否做好**

- ☐ 制定计划之前，Claude 先提了问，我的回答也体现在模板里
- ☐ CLAUDE.md 里用 3~5 行放进了我的规则
- ☐ 用技能的一行命令，就能把我的备忘按我的模板整理好
- ☐ 有一份把结果和原始备忘对照的检查表
- ☐ 练习文件夹们（`정리도구-연습` 等）不需要的话已经清理了

**再看哪里**：[第5章](05-delegate-well.md)、[第6章](06-claude-md.md)、[第7章](07-skills-plugins.md)
