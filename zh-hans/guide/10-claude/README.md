# 第2阶段 · Claude 使用指南

如果说在第1阶段你学到的是对任何 AI 都管用的**提问方法**，那么在第2阶段，你要熟悉的是 **Claude 这项服务的界面和功能**。
比如按钮在哪里、怎样整理对话、我的信息会被怎样使用。

> **本指南依据2026年10月26日确认的 Anthropic 官方帮助编写。** Claude 的菜单名称和功能经常变化。
> 目前，把聊天和 Cowork 合在一起的新界面正在陆续推出，所以每个人看到的界面可能略有不同。
> 如果和你的界面不一样，请以你界面上显示的名称为准。最新内容可以通过各章脚注里的官方帮助链接查看。
