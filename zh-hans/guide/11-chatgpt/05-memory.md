# 第5章 记忆与个性化设置——不用每次都介绍自己

> **一句话总结**：ChatGPT 靠两样东西让回答贴合我：一是把我告诉它的事记下来的**记忆**，二是写下希望它始终遵守的事的
> **自定义指令**。本章还会学到：怎么看它记住了什么，不需要时怎么删掉。

界面以2026年10月的网页版（Plus 套餐）为准。免费套餐或手机应用里，菜单的位置可能略有不同。

## 为什么需要记忆和个性化设置

你在[第1阶段 第4章](../00-common/04-prompt-basics.md)学到过，好的提示词里要有**背景**（是什么样的情境）。
可是像"我是小区里一家小菜店的老板，顾客主要是40～60岁的人"这样的背景，每开一个新聊天就重写一遍，很麻烦。

ChatGPT 有两个功能，可以省下这份功夫。

| 功能 | 作用 | 比方 |
|---|---|---|
| **记忆**（memory） | 把从对话中了解到的关于我的信息记下来，下次对话时使用 | 记得老顾客口味的店主 |
| **自定义指令**（custom instructions） | 把我亲手写下的"始终要遵守的事"用在每一个新对话上 | 贴在店里墙上的订单备忘 |

第1阶段[第6章](../00-common/06-conversation.md)说过"新对话默认是从头开始的"。把这两个功能打开，新对话开始时也会多少了解我一点。

## 打开记忆并检查

记忆设置在**账号菜单 → 「设置」 → 「个性化设置（개인 맞춤 설정）」**里。[^memory]
最上面的「ChatGPT 记忆」一栏里，能看到两行。

![个性化设置界面。红色编号 ① 启用记忆，② 管理记忆摘要，③ 参考我的文风，④ 参考照片，⑤ 基本风格和语气，⑥ 温暖度。请看最上面「ChatGPT 记忆」一栏里的「启用记忆」开关和「记忆摘要」旁的「管理」按钮，下面的「参考我的文风」开关，以及最下面的「基本风格和语气」和「温暖度」选择按钮](../../../guide/11-chatgpt/assets/shot-06-personalization-marked.png)

- **① 「启用记忆（메모리 활성화）」**——打开后，ChatGPT 会根据聊天、文件、已连接的应用，让回答贴合我。关闭后就不使用记忆。
- **② 「记忆摘要（메모리 요약）」 → 「管理（관리）」**——可以一眼看到 ChatGPT 对我了解了什么。界面说明里也写着，"希望始终记住的信息，请输入到自定义指令里"。[^screen]

### 它根据什么来记住我

ChatGPT 在做出贴合我的回答时，会参考**过去的聊天、保存的记忆、自定义指令、资料库文件、已连接的应用**（例如 Gmail）。
想知道某个回答参考了什么，请查看回答下面的「来源」。[^memory]

### 保存的记忆和参考聊天记录不一样

记忆分成两种。[^memory]

- **保存的记忆**（saved memories）——就像你说"这个请记住"那样，另外记下来的信息。它和聊天记录分开保存。例："我是素食者。请记住"
- **参考聊天记录**（reference chat history）——即使没有另外记下来，它也会在需要时从过去的对话里取出信息来用。比如，把上周对话里说过的孩子的年龄，用在今天的回答里。

把"参考保存的记忆"关掉的话，参考聊天记录也会一起关掉。[^memory]

想亲手让它记一件事，请这样说。

```
请记住：我在首尔开小菜店，顾客主要是40～60岁的人。
我请你写宣传文案的时候，请按这个顾客群来写。
```

## 删除记忆的方法

记住的内容不对，或者不想再用了，就把它删掉。在 **「记忆摘要」 → 「管理」** 里可以选的有两项。[^memory]

| 按钮 | 作用 |
|---|---|
| 「不再提及（다시 언급하지 않기）」 | 让它以后不再在回答里提到这条内容（仅限显示这个按钮的条目） |
| 「删除并关闭记忆（삭제하고 메모리 끄기）」 | 删除记忆，同时把记忆功能也关掉 |

容易搞混的点有两个。[^memory]

- **删除聊天，保存的记忆也还在。** 在某个对话中生成的保存的记忆，即使删掉那个对话，也会单独留着。所以记忆也要自己去删。
- **关闭参考聊天记录**，从过去对话中记住的信息，会被安排在30天内从 OpenAI 系统中删除。原来的聊天则原样保留。

已连接的应用（[第7章](07-projects-plugins.md#设置已连接应用的权限)）也一样。即使断开 Gmail 这类应用的连接，**从那个应用取来、已经进入对话或记忆里的内容也不会被删除。** 只是以后读不到了而已。留下来的内容，请用上面的方法另外删除。[^apps]

## 自定义指令——希望它始终遵守的事

记忆是 ChatGPT 自己记的，而**自定义指令**是我亲手写下的。
在网页上，点「个性化设置」界面里的「自定义指令」链接进入。
手机应用在设置的「自定义 ChatGPT（ChatGPT 맞춤 설정）」里，要打开「启用自定义（맞춤 설정 사용）」才会生效。[^ci]

能写的字数，因套餐而异。[^ci]

| 套餐 | 最多字数 |
|---|---|
| Free · Go | 1,500字 |
| Plus · Pro · Business · Enterprise · Edu | 5,000字（2026-07-15 增加）[^rn] |

比如可以这样写。可以这么理解：[第1阶段 第4章](../00-common/04-prompt-basics.md)的五个要素里，只挑每次都相同的（背景、对象、条件）放进去。

```
我是经营小区小菜店的50多岁老板。我不懂电脑术语。
- 请用敬语回答，难懂的词用括号解释。
- 先用一句话说结论，再做说明。
- 不确定的内容不要编造，请直接说不知道。
```

不只是语气，也可以写下**希望得到帮助的方式**。把 OpenAI Academy 课程里举的指令例子翻译成中文，是这样的。[^academy-content]
```
- 我向你征求建议时，请给出一个明确的推荐，并同时告诉我优缺点和你所做的假设。
- 不确定的事请说不确定。不要猜测，并告诉我有什么信息能让答案更好。
```

修改指令之后，请**开一个新聊天**来确认。对于已经在进行的对话是否立刻生效，帮助文档里的说法也不一致。稳妥的想法是：新对话开始才一定生效。[^ci]
另外，写在自定义指令里的信息也可能被用来改进模型。不希望这样的话，把训练设置关掉就行（[第8章](08-privacy.md)）。[^ci]

## 设定语气——基本风格和语气、温暖度、参考我的文风

「个性化设置」界面的下半部分，有设定回答语气的栏目。[^screen] 编号是本章「打开记忆并检查」一节图中的编号。

| 编号 | 界面名称 | 作用 |
|---|---|---|
| ⑤ | 「基本风格和语气（기본 스타일 및 톤）」 | 选择回答的整体氛围（例：「专业」） |
| ⑥ | 「温暖度（따뜻함）」 | 选择回答听起来有多亲切（一开始是「默认」） |
| ③ | 「参考我的文风（내 문체 참고）」（「写作」栏） | 打开后，ChatGPT 会参考聊天、资料库文件、已连接的应用，**用我的文风**来写文章 |

比如可以打开「参考我的文风」，然后这样拜托它。

```
请写一条给老顾客的本周小菜通知短信。用我平时说话的语气。
```

::: details 收到的回答大概是这样（示例——点击展开）
这是本指南编的示例。实际的回答会因服务和当时的情况而不同。

> 您好～ 给您说说这周的小菜消息。○曜日会有（小菜名称）上新哦。一直都谢谢您来光顾！

**检查一下有没有收好**：和我平时说话的语气像吗？这周有哪些小菜我没有告诉它，所以留空也没关系。如果它编了小菜名字放进去，请换成我自己的菜单。

:::

语气也可以写在自定义指令里，比如"像对亲近的邻居说话一样写"。分工起来会比较方便：大的氛围用菜单选，细致的规则写进指令。

## 在临时聊天里选择要不要使用记忆

有时候你想在它不认识我的状态下得到回答。比如悄悄打听给家人的礼物，或者想看一个不掺杂我个人喜好的一般性回答。
这时请点右上角的「临时聊天」按钮。然后**在发送第一条消息之前**，点右上角 ① 的「个性化（개인화됨）」，换成「不个性化（개인화되지 않음）」就可以了。[^screen][^temp]

![临时聊天界面。点右上角的「个性化」，会出现「个性化——此聊天可以参考记忆、插件、自定义指令」和「不个性化——此聊天会忽略记忆、插件、自定义指令」两项](../../../guide/11-chatgpt/assets/shot-19-temporary-personal-marked.png)

| 选项 | 保存的记忆、指令 | 新记忆 |
|---|---|---|
| ② 「个性化」（一开始的选择） | 参考后回答 | 不生成 |
| ③ 「不个性化」 | 忽略 | 不生成 |

无论选哪一项，**在临时聊天里聊的内容都不会新存进记忆。** 对话开始后，就不能更改这个选择了。[^temp]
所以，在以「不个性化」开始的临时聊天里问"你还记得我吗？"，它不认识才是正常的。临时聊天的其他特点（记录、保留期限）在[第3章](03-chats.md#不留记录——临时聊天)里讲。

> 以前，只要是临时聊天，记忆和指令就一直是关的，现在改成了可以选择。如果和你的界面不同，请以界面为准。

## 亲自动手试试

1. 打开「设置」 → 「个性化设置」 → 「记忆摘要」 → 「管理」，读一读 ChatGPT 现在对我了解什么。有不对的内容就删掉。
2. 在「自定义指令」里，像上面的示例那样，写一行关于我的背景，再写三行规则。
3. 在新聊天里只发"请推荐周末可以做的三件事"。看看指令里的语气和格式有没有被遵守。
4. 打开「临时聊天」，换成「不个性化」，然后发同样的问题。对比一下两个回答有什么不同。

**连续任务**（[筹备读书会](../00-common/practice-kit.md)）：把你对通知一直希望遵守的一行规则，放进「自定义指令」里。例："写通知时，请把日期、场地、携带物品放在最上面。"这一行在第7章也可以移到项目指令里。

## 小结

- 记忆是 ChatGPT 在对话中记住我的功能，自定义指令是我亲手写下的规则。
- 记忆分为「保存的记忆」和「参考聊天记录」两种，在「记忆摘要」 → 「管理」里查看和删除。
- 删除聊天，保存的记忆也还在。记忆要另外删除。
- 自定义指令，Free、Go 最多 1,500字，Plus 及以上最多 5,000字。修改之后，在新聊天里确认。
- 临时聊天不会生成新记忆。想连保存的记忆、指令也排除，要在第一条消息之前选「不个性化」。

## 术语解释

| 术语 | 中文名称 | 一句话解释 |
|---|---|---|
| Memory | 记忆 | 把从对话中了解到的关于我的信息记下来的功能 |
| Saved Memories | 保存的记忆 | 另外记下来的记忆。删除聊天后仍会保留 |
| Reference Chat History | 参考聊天记录 | 从过去的对话中取出需要的信息来用 |
| Custom Instructions | 自定义指令 | 我写下的、适用于所有新对话的规则 |
| Personalization | 个性化设置 | 汇集记忆、指令、语气的设置界面 |
