# 第1章 开始使用 — 试用、注册、选择套餐

> **一句话总结**：ChatGPT 不用注册就能直接试用。想保存对话、上传文件，就免费注册；
> 只有免费版不够用时，才需要考虑付费套餐。

界面以2026年10月的网页版（Plus 套餐）为准。免费套餐或手机 App 的菜单位置可能略有不同。

## 不登录先试试

打开 ChatGPT 的网址（chatgpt.com）。不注册也可以直接在中间的输入框「向 ChatGPT 提问（ChatGPT에게 물어보세요）」里提问。
韩国属于可以使用 ChatGPT 的**支持国家**（正式提供该服务的国家）。[^countries]

![登录前的首页。红色编号 ① 输入框，② 登录和注册按钮，③ 侧边菜单。请看中间「今天想做点什么？（오늘은 무엇을 해볼까요?）」下面的输入框、右上角的「登录（로그인）」「免费注册（무료로 회원가입）」按钮，以及左边侧边菜单里的「新聊天（새 채팅）」「图片（이미지）」「插件（플러그인）」「查看套餐与价格（플랜 및 가격 보기）」等](../../../guide/11-chatgpt/assets/shot-00-logged-out-marked.png)

① 直接在中间的输入框里提问；② 通过右上角的「登录（로그인）」「免费注册（무료로 회원가입）」进入账号；③ 左边的侧边菜单里有「新聊天（새 채팅）」「查看套餐与价格（플랜 및 가격 보기）」这样的菜单。

不登录使用时，有两个限制。[^home]

- **一次只能进行1个对话。**
- **不会保存记录。** 关掉窗口后，就再也找不回聊过的内容。

你可以先不登录试用，感受一下是什么样的。打算长期用的话，注册会更好。如果是第一次用，可以这样问：

```
你能帮我做哪些事？请举五个上班族马上就能用上的例子。
```

::: details 得到的回答大致是这样（示例 — 点击展开）
这是本指南制作的示例。实际的回答会因服务和每次情况而不同。

> 我挑了五件上班族马上就能用上的事。
>
> 1. **润色邮件**：把你写的邮件贴进来，我帮你改得更礼貌。
> 2. **总结会议纪要**：把很长的笔记整理成五行摘要和待办清单。
> 3. **搭报告框架**：你告诉我要点，我先帮你列出目录。
> 4. **问 Excel 函数**：说出你想做的计算，我告诉你该用哪个函数。
> 5. **想点子**：活动名称或发言顺序，我可以给你几个方案。
>
> 如果有想试的，请告诉我。

**确认一下有没有答好**：正好是五个吗？每一个都适合马上用到我的工作上吗？如果有喜欢的，就用那个编号接着继续请它帮忙。

:::

## 注册并登录

如果是第一次用，点右上角的「免费注册（무료로 회원가입）」（上图 ②）。已经有账号的话，点「登录（로그인）」就行。
进入的方式有两种。[^login]

| 方式 | 说明 |
|---|---|
| 邮箱和密码 | 用你自己的邮箱地址创建账号 |
| **社交登录**（用其他公司的账号代为登录） | 用 Google、Microsoft、Apple 账号进入 |

![在未登录的界面点「免费注册（무료로 회원가입）」后弹出的「登录或注册（로그인 또는 회원가입）」窗口。有用 Google 账号、Apple 账号、手机号码继续的按钮，以及邮箱地址栏](../../../guide/11-chatgpt/assets/shot-23-signup.png)

*这是2026-10-28的网页界面。这个窗口里没有看到 Microsoft 按钮，而是「使用手机号码继续（휴대 전화 번호로 계속하기）」。*[^screen-signup]

有四点需要注意。

1. **邮箱相同就是同一个账号。** 即使一开始是用邮箱注册的，之后用同一地址的 Google 账号登录，进入的也是同一个账号。[^login]
2. **小心 Apple 的“隐藏邮件地址”。** 用 Apple 注册时，如果选了隐藏真实地址的假地址，之后只能用同一个 Apple ID 进入原来的账号。用真实邮箱登录，会打开**另一个新账号**。[^login]
3. **个人使用请用个人邮箱注册。** 用公司邮箱注册的话，离职时可能就进不去账号了。[^home]
4. **账号不会自动合并。** 如果用另一个邮箱进入、生成了新账号，对话记录和订阅也是各管各的。觉得“我订阅了却显示免费版”“对话不见了”时，请先看看是不是用注册时的账号登录的。接收付款收据的邮箱，也可能和账号邮箱不一样。[^cantlogin]

## 套餐一览

ChatGPT 从免费到公司用，有多种**套餐**（plan，按付费多少，可用的功能和用量不同的使用方式）。[^pricing]

| 套餐 | 适合谁 | 韩国价格（每月） |
|---|---|---|
| Free（免费） | 第一次试用的人、偶尔使用的人 | ₩0 |
| Go | 免费版额度经常不够的人 | ₩13,000 |
| Plus | 每天使用、需要深入思考的回答的人 | ₩29,000 |
| Pro | 用得非常多的人（分为3档） | ₩159,000起 |
| Business · Enterprise · Edu | 以公司、机构、学校为单位使用的地方 | 另议 |

价格是在韩国打开 OpenAI 价格页面时显示的数值，**经常变动。** 付款前请到[价格页面](https://openai.com/chatgpt/pricing)亲自确认。[^pricing]
Business 是以前叫「Team」的公司用套餐，在2025年8月29日改了名字。[^business]

### 各套餐有什么不同

比起数字，了解**“有什么不同”** 会更容易选择。

| 不同之处 | 免费（Free） | 付费 |
|---|---|---|
| **文字对话** | 日常的文字对话没有次数限制[^free] | 各功能的额度更宽裕 |
| **广告** | Free 和 Go 里，回答下方可能会出现广告 | Plus 以上没有广告 |
| **选择思考深度** | 打开「思考（생각하기）」，让它想得更深 | Plus 以上可以选择「推理级别（추론 수준）」（[第2章](02-screen-tour.md)） |
| **上传文件** | 每天最多3个（[第4章](04-files-images.md)） | 可以上传多得多 |
| **Work**（交付长时间任务的模式） | 网页和手机上不能用 | 可以使用（[第7章](07-projects-plugins.md)） |

免费版的“没有次数限制”只适用于日常的文字对话。它有防止滥用的机制。文件、图片、语音这类功能另有额度。[^free]

如果你担心广告，请看官方说明。[^ads] 据说广告**不会影响 ChatGPT 回答的内容**。广告主看不到我的对话。
**临时聊天**（不留在记录里的对话，[第3章](03-chats.md)）里不会出现广告。广告于2026年2月在美国开始测试，正在逐步扩大到一些国家。
韩国是否也会出现，在官方说明里没有确认到。

## 改成付费之前要知道的事

不需要一开始就付费。**先用免费版，经常碰到额度上限时再升级**是最稳妥的。付款前，请务必了解下面这些。

- **只能按月付费。** Go、Plus、Pro 都没有一次付1年的年付方式。[^go]
- **删除 App 后订阅仍会继续。** 即使在手机上删除 ChatGPT App，扣费也不会停止。不想再用的话，必须自己取消订阅。[^pro]
- **取消要在开始订阅的地方进行。** 在网页上付的款，就在网页上取消；通过 App Store 或 Google Play 付的款，就在那个商店取消。在 ChatGPT 手机 App 里不能取消。必须在下次扣款日**至少24小时前**取消，下个月的费用才不会被扣。[^promo]
- **免费试用结束后会自动扣费。** 通过邀请朋友或活动获得的免费试用、折扣期结束后，会用你登记的付款方式继续付费订阅。如果不打算继续用，请在期限结束前取消。折扣码只能用一次，不能叠加使用。[^trial]
- **付了款却显示免费版，请不要再次付款。** 先看看是不是用付款的那个账号登录的。如果是手机 App，请在设置里点恢复购买（Restore purchases）。这个菜单的韩语界面名称没有确认到。[^plus]
- **Go 不能使用旧版模型。** 旧版模型（上一代 AI 模型）不包含在 Go 里，语音对话的额度也和免费版一样。[^go]

还有一种叫**积分**（Credit，和套餐分开、提前买好的额外用量）的东西。设置 →「用量（사용량）」页面里有这样的提示：“达到使用上限后仍想继续使用 Work 和 Codex，请购买积分或打开自动充值。”[^screen-usage]
买了积分，套餐并不会改变。**从购买之日起12个月**后就会失效。除非有支付错误、未经授权使用这类例外，原则上**不能退款。** 如果打开「自动充值（자동 충전）」，当余额低于你设定的标准时，会自动用登记的默认付款方式付款。[^credits]
如果只是普通对话，不需要积分。

如果不知道哪个套餐合适，可以把你的使用习惯告诉 ChatGPT，问问它。不过，价格和条件请以价格页面为准，而不是 AI 的回答（[第1阶段第9章](../00-common/09-safety.md)）。

```
我每天用 ChatGPT 3~4次，主要用来润色公司邮件和总结会议纪要。
偶尔也会上传 PDF 文件来做总结。我想先免费用着，请告诉我在什么时候需要付费，
并给出3条我自己可以判断的标准。
```

## 手机和电脑 App

除了网页浏览器，ChatGPT 还可以用手机 App 和电脑 App。不需要在每台设备上新建账号。**用同一个账号登录**就行。在其他设备上聊过的对话能不能看到，请在下面「亲自试一试」的第4条里确认。

- **手机 App**：在上方的下拉菜单（点一下展开的列表）里选择 Chat 或 Work。[^work]
- **电脑 App**：在一个新 App 里同时使用 Chat、Work、Codex。旧 App 可能以「ChatGPT Classic」的名字保留着。[^desktop] Mac 版 App 需要 macOS 14 以上。[^macos]
- **KakaoTalk**：在韩国，也可以在 KakaoTalk 里使用 ChatGPT（见下面的说明）。[^kakao]

手机 App 在2026年3月简化了侧边菜单。图片之类的功能被移到了聊天列表上方的横条里。
之后可能又有变化。如果和本指南的网页界面位置不同，请找名称相近的按钮。[^rn]

下载 App 时，请在应用商店搜索“ChatGPT”，然后确认**开发者名称**。iPhone（App Store）上应显示「OpenAI OpCo, LLC」，安卓（Google Play）上应显示「OpenAI」。因为名字相似的其他 App 很多。[^appfaq]

**KakaoTalk 里的 ChatGPT** 是 Kakao 和 OpenAI 共同打造的服务。**只在韩国**可用。不需要另外安装 App。点 KakaoTalk「聊天」标签页最上面的「ChatGPT」就能开始。用韩国手机号注册的最新版 KakaoTalk 里会显示。[^kakaofaq]

- 如果已经有 ChatGPT 账号，请把它连接起来。在 KakaoTalk 里聊过的对话记录，在 ChatGPT 里也能看到。没有账号的话，可以用 Kakao 账号注册。在 KakaoTalk 里注册的账号，在 ChatGPT App 里也可以直接使用。
- 对 OpenAI 来说，它是**第三方服务**（由其他公司参与运营的服务）。所以请把 OpenAI 和 Kakao 的条款、隐私说明**两份都**读一读。[^kakaofaq]

## 用不了时先做这些

回答可能会卡住，可能会弹出错误提示，也可能反复出现“确认你是真人”的验证。遇到这些情况，请按下面的顺序试试。这是把 OpenAI 帮助中心的错误排查说明整理成了适合新手的版本。[^errors]

1. **先看看是不是服务出了故障。** 如果 status.openai.com（OpenAI 服务状态页面）上有故障通报，等着就行。人多的时段，本来也会变慢。[^slow]
2. **等30~60秒。** 有时回答会结束得比较晚。如果还是卡住不动、而且对话已经很长，就在**新聊天**里重新问一次。
3. 用**隐身窗口**（incognito，不留浏览记录、不带扩展程序打开的浏览器窗口）打开试试。换一个浏览器也可以。
4. 暂时关掉 **VPN**（改变上网地址的程序）。偶尔弹出“确认你是真人”的验证（**验证码**，CAPTCHA）是正常的。如果每次都弹出，原因可能是 VPN 或浏览器扩展程序。[^captcha]
5. **如果只有在公司 Wi-Fi 下用不了**，换成手机流量试试。那时能用的话，就是公司网络的问题。请问问信息部门的同事。[^network]
6. 如果看到**达到额度上限的提示**或可以再次使用的时间，请等到那个时间。也可以选其他功能。[^feature]

把 App 删了再重装，**使用额度也不会重置。**[^mobile] 如果还是不行，请联系 help.openai.com 的客服。把错误提示原样写下来发过去就行。截图发送时，请注意不要露出密码或其他个人信息。

## 亲自试一试

1. 不登录，进入 chatgpt.com，问一句“你能帮我做哪些事？”。
2. 把浏览器完全关掉再重新打开，确认刚才的对话还在不在（登录前的对话，只有在同一个浏览器里、此刻还在访问期间才能看到）。[^home]
3. 用个人邮箱注册，再问一次同样的问题，然后看看左边侧边菜单的「最近（최근）」里有没有出现这段对话。
4. 在手机上安装 App，用同一个账号登录，确认能不能看到在电脑上聊过的对话。

**接下来的练习**（[筹备读书会](../00-common/practice-kit.md)）：保持登录状态，问：“我是社区读书会的总务。请把筹备下个月聚会要做的事列成清单。”把得到的清单，和练习结束后我实际做的事对比一下。

## 小结

- 不登录也能用，但一次只能有一个对话，也不会留下记录。
- 注册可以用邮箱，或 Google、Microsoft、Apple 账号。邮箱相同就是同一个账号。
- 各套餐在有无广告、选择思考深度、文件额度、能否使用 Work 上有所不同。价格请到价格页面确认。
- 删除 App 后订阅仍会继续。不想再用的话，要在开始订阅的地方（网页、应用商店、Google Play）于扣款日24小时前取消。免费试用结束后也会自动扣费。
- 下载 App 时，要确认开发者名称（App Store「OpenAI OpCo, LLC」，Google Play「OpenAI」）。KakaoTalk 里的 ChatGPT 只在韩国可用。
- 用不了时，依次试：服务状态 → 等待或开新聊天 → 隐身窗口 → 关掉 VPN → 换一个网络。

## 术语表

| 术语 | 中文名称 | 一句话解释 |
|---|---|---|
| Supported Country | 支持国家 | 正式提供服务的国家 |
| Social Login | 社交登录 | 用 Google、Apple 这类其他公司的账号代为登录的方式 |
| Plan | 套餐 | 按付费多少，功能和用量不同的使用方式 |
| Subscription | 订阅 | 每月自动扣费的使用合约 |
| Legacy Model | 旧版模型 | 新模型推出后仍保留的上一代 AI 模型 |
| Temporary Chat | 临时聊天 | 不留在记录里的对话（[第3章](03-chats.md)） |
| Credit | 积分 | 套餐额度用完后，为了继续使用 Work 这类功能而另外买下的用量 |
| CAPTCHA | 验证码 | 为了确认你是真人而出的简单小测试 |
| Incognito Window | 隐身窗口 | 不留浏览记录、不带扩展程序打开的浏览器窗口 |
| VPN | 虚拟专用网络 | 改变上网地址，让你看起来像从别处访问的程序 |
