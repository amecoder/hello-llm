# 第2阶段 · ChatGPT 使用指南

如果说第1阶段教的是适用于任何 AI 的**提问方法**，那么第2阶段就是熟悉 **ChatGPT 这项服务的界面和功能**。
比如按钮在哪里、怎么整理对话、你的信息是怎么被使用的。

> **本指南的界面以 2026 年 10 月的网页界面（韩语，Plus 套餐）为准。** ChatGPT 的菜单名称和功能变化很快。
> 如果和你看到的不一样，请以你屏幕上显示的名称为准，也可以通过各章脚注里的 OpenAI 官方帮助链接查看最新内容。
