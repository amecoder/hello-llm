# 第2章 熟悉界面 — 什么在哪里

> **一句话总结**：ChatGPT 的界面，你只要认得四个地方：**左边的侧边菜单**（以前的对话和功能）、**中间的输入框**（提问的地方）、**上方的 Chat/Work 切换**、
> **左下角的账号菜单**（设置）。刚开始时，只用输入框和「新聊天（새 채팅）」就足够了。

界面以2026年10月的网页版（Plus 套餐）为准。免费套餐或手机 App 的菜单位置可能略有不同。

## 一眼看懂首页

登录后，中间会看到「从哪里开始呢？（어디서 시작할까요?）」这句话和输入框。

![登录后的首页，用红色编号 ①~⑤ 标出。请看左边的侧边菜单（「新聊天（새 채팅）」「定时任务（예약）」「资料库（라이브러리）」「插件（플러그인）」「探索（탐색）」，以及「置顶会话（고정된 스레드）」「项目（프로젝트）」「最近（최근）」列表）、上方中间的「Chat」/「Work」切换、中间的输入框以及下面的三个推荐](../../../guide/11-chatgpt/assets/shot-01-home-layout.png)

对话标题和账号名称已换成示例。**红色编号和下表的编号对应同一个地方。**

| 编号 | 位置 | 名称 | 作用 |
|---|---|---|---|
| ① | 左边 | 侧边菜单（侧边栏） | 开始新对话、以前的对话列表、通往各种功能的入口 |
| ② | 上方中间 | 「Chat」/「Work」 | 切换普通对话和长时间任务模式 |
| ③ | 中间 | 输入框「向 ChatGPT 提问（ChatGPT에게 물어보세요）」 | 写下问题的地方 |
| ④ | 输入框下方 | 推荐 | 「帮我做图片或贴纸（이미지나 스티커 만들어줘）」「写作（글쓰기）」「网页搜索（웹 검색）」 |
| ⑤ | 左下角 | 账号（名称和套餐） | 设置、更改套餐、退出登录 |

如果不知道该问什么，就先点输入框下面的**推荐**吧。比如点「写作（글쓰기）」，然后接着这样写：

```
帮我写一条短信，告诉老顾客社区小菜店开业的消息。三句话，语气要温暖。
```

::: details 得到的回答大致是这样（示例 — 点击展开）

> 您好，我是○○小菜店。○月○日，我们终于开业啦。我们会用用心做好的小菜，热情地迎接您。

**确认一下有没有答好**：是不是正好三句话，在向老顾客通知开业的消息？语气温暖吗？店名和日期是我没告诉它的，所以空着也没关系。如果里面出现了编造的日期，请改掉。

## Chat 和 Work — 是聊天，还是交办任务

上方中间的「Chat」/「Work」是2026年7月新增的切换按钮。[^rn-work]

- **Chat**：就是你一直以来熟悉的 ChatGPT。一问一答地对话。本指南大部分内容都以 Chat 为准。
- **Work**：把需要经过多个步骤的长时间任务交给它，然后拿到文档、表格、演示资料、报告这类**成品**的模式。

Work 在网页和手机上，只有**付费套餐（不含 Free、Go）** 才能用。Free 和 Go 只能在电脑 App 上有限地使用。[^rn-work] 使用方法在[第7章](07-projects-plugins.md)里讲。

## 推理级别和思考 — 想得多深

在付费套餐里，点输入框右边像「Medium」这样的文字（按钮名称「选择 ChatGPT 模型（ChatGPT 모델 선택）」），就会出现**「推理级别（추론 수준）」** 滑块。
**推理**（reasoning）是在回答之前，一步一步地思考。滑块决定这种思考持续多久。

![点了输入框右边「推理级别（추론 수준）」的界面。请看小窗口里有「Medium」这个字，和一个可以左右移动的滑块](../../../guide/11-chatgpt/assets/shot-03-model-menu-marked.png)

对话标题和账号名称已换成示例。① 点「推理级别（추론 수준）」按钮后，会出现 ② 当前级别（「Medium」）和 ③ 滑块。

| 级别 | 特点 | 可使用的套餐 |
|---|---|---|
| Instant（即时） | 马上回答。适合轻松的问题 | 付费 |
| Medium（中等）· High | 想得更久。适合做计划、比较、计算 | Plus 以上 |
| Extra High · Pro | 想得最深 | Pro·Business·Enterprise |

出处：OpenAI 帮助中心[^levels]

有两点需要注意。

- **用话语说“想得更深一点”，级别也不会改变。** 即使保持在 Instant 的情况下这么写，也不会自动升高。请自己拖动滑块。[^levels]
- **免费（Free）和 Go 套餐不是用滑块，而是打开「思考（생각하기）」。** 在 Go 套餐的手机 App 上，要在 + 菜单里选「Think harder」。[^go-think]

<!-- 需要截图：在 Free 套餐网页界面中打开「思考（생각하기）」的位置 -->

**什么时候要调高呢？** 不只是计算。像润色一句短话这种简单或风险小的事，用快速级别就够了。条件有好几个、要按标准比较各个选项、或者要找出我写的计划里漏掉的假设时，请调高级别。[^academy-content]
```
请按预算、公共交通、下雨时的备选方案这三个标准，比较三个活动场地候选。
推荐其中一个，并告诉我怎样减少它的缺点。
```

同一个问题，只改变级别再问一次。你马上就能感受到快速回答和深入回答的差别。

```
月薪300万韩元的上班族，想在3年内攒到2,000万韩元，每个月要存多少？
请分成考虑定期存款利息和不考虑利息两种情况，展示计算过程。
```

## 账号菜单和设置页面

点左下角你的名字，会打开**账号菜单**。

![点了左下角账号名称的界面。请看「升级套餐（플랜 업그레이드）」「个人设置（개인 설정）」「个人资料（프로필）」「设置（설정）」「帮助（도움말）」「退出登录（로그아웃）」这些项目](../../../guide/11-chatgpt/assets/shot-04-profile-menu-marked.png)

对话标题和账号名称已换成示例。① 点你的名字后，会出现 ② 「升级套餐（플랜 업그레이드）」③ 「个人设置（개인 설정）」④ 「个人资料（프로필）」⑤ 「设置（설정）」⑥ 「帮助（도움말）」⑦ 「退出登录（로그아웃）」。

在这里点「设置（설정）」，**设置会以全屏打开**。左边是菜单列表，右边是内容。点「返回应用（앱으로 돌아가기）」就回到对话界面。

![设置页面的左侧列表。「个人（개인）」下面有「常规（일반）」「外观（모양）」「通知（알림）」「个人资料（프로필）」「安全与登录（보안 및 로그인）」「账号（계정）」「已归档的聊天（보관된 채팅）」…… 「数据管理（데이터 관리）」，表格里讲到的菜单上标有红色编号 ①~⑩](../../../guide/11-chatgpt/assets/shot-05-settings-marked.png)

|---|---|---|---|

| ② | 「外观（모양）」 | 浅色界面、深色界面、文字对比度、强调色 | — |
| ③ | 「安全与登录（보안 및 로그인）」 | 多重验证、查看已登录的设备、账号 PIN（打开上锁对话的4位数字）、锁定模式 | [第8章](08-privacy.md#保护账号)、[第3章](03-chats.md) |
| ④ | 「已归档的聊天（보관된 채팅）」 | 查看归档起来的对话 | [第3章](03-chats.md) |

| ⑥ | 「语音风格（음성 스타일）」 | 语音对话的声音 | [第9章](09-voice.md) |
| ⑦ | 「存储空间（저장 공간）」 | 上传的文件占用的容量 | [第4章](04-files-images.md) |
| ⑧ | 「个性化设置（개인 맞춤 설정）」 | 记忆、自定义指令、说话风格 | [第5章](05-memory.md) |
| ⑨ | 「用量（사용량）」 | 剩余的使用额度、积分 | [第1章](01-getting-started.md#改成付费之前要知道的事) |

## 亲自试一试

1. 在首页点推荐的「写作（글쓰기）」，把上面的小菜店短信示例贴进去发送。
2. 点输入框的 + 按钮，把菜单项逐个读一遍（不用点进去），然后关闭。
3. 如果是付费用户，把「推理级别（추론 수준）」调到最低发一次、调到 Medium 发一次，都发送上面的储蓄计算问题，并比较回答。如果是免费用户，则在关掉「思考（생각하기）」的状态下发一次、打开的状态下发一次，然后比较。
4. 打开账号菜单 →「设置（설정）」，找到「数据管理（데이터 관리）」在哪里，然后点「返回应用（앱으로 돌아가기）」退出来。

**连续任务**（[筹备读书会](../00-common/practice-kit.md)）：点推荐的「写作（글쓰기）」，把示例文件 memo-next-month.txt 的内容贴进去，发送“请写一份要发给全体会员群发短信的简短通知草稿”。看看草稿是怎么处理“地点还没确定”这件事的。

## 小结

- 界面分为侧边菜单、输入框、Chat/Work 切换、账号菜单这四个地方。
- 在 + 按钮里选择文件、图片、网页搜索、深度研究、草图。
- 付费版用「推理级别（추론 수준）」滑块，免费版用「思考（생각하기）」来决定思考深度。靠说话请求是改变不了的。
- 设置会以全屏打开。和个人信息有关的设置在「数据管理（데이터 관리）」里。
