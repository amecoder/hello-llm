# 第4阶段 · AI-SDLC 指南

SDLC（软件开发生命周期）是一个想法变成真正能运行的软件，所要经过的阶段。第4阶段里，我们会和第3阶段学过的 AI 工具一起，**把一个小网页从规划做到发布、改进**。
不懂代码也没关系。这个阶段要学的不是怎么写代码，而是**交给 AI 什么，又拿回什么来确认**。

> **本指南依据 2026年11月1日确认的 GitHub、Claude Code 官方文档，以及 spec-kit、OpenSpec 仓库里的说明写成。** 功能和画面名称经常变化。
> 有 GitHub 免费账号就够了。AI 工具直接用第3阶段用过的（Claude Code、Codex、Antigravity）。
