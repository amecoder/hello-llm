# 11장. 실습 과제 — 나만의 정리 도구 처음부터 만들기

> **한 줄 요약**: 2~10장에서 만든 「정리 도구」를 **내 손으로 한 번씩 다시** 만들어 보는 과제 9개입니다. 마지막 과제는 **내 메모**로 나만의 도구를 만드는 것입니다.
> 과제마다 「잘 됐는지 확인」 점검표가 있어서, 누가 채점해 주지 않아도 스스로 확인할 수 있습니다.

이 장의 화면 이름은 2026년 10월 31일 macOS 데스크톱 앱(한국어 화면) 기준입니다. 화면이 다르면 화면에 보이는 이름을 따르세요.

## 실습 과제를 하는 법

1. **연습 폴더를 새로 만듭니다.** 예: `정리도구-연습`. 그 안에 `inbox` 폴더를 만들고 [2장의 연습 메모](02-install.md#연습-폴더-준비하고-고르기) 5개를 넣습니다. 9장의 임시회의 메모는 과제 7에서 넣습니다.
2. **과제의 「해 볼 것」을 따라 합니다.** 회색 상자의 요청을 복사해 보내면 됩니다.
3. **「잘 됐는지 확인」을 하나씩 체크합니다.** 체크하지 못한 항목이 있으면 「다시 볼 곳」의 장을 읽고 그 부분만 다시 해 보세요.

과제 1~6은 순서대로 하세요. 앞 과제의 결과(양식·규칙·스킬)를 뒤 과제가 씁니다. 과제 7·8은 과제 6까지 끝낸 뒤에 합니다. **과제 9는 맨 마지막에** 합니다.

처음부터 다 해낼 필요는 없습니다. 하루에 과제 두세 개씩이면 충분합니다. 결과는 매번 조금씩 다릅니다. 이 가이드의 결과와 모양이 달라도, 점검표를 다 체크하면 잘된 것입니다.

### 실습할 때 지킬 세 가지

- **권한 모드는 「수동」으로 둡니다.** 무엇을 하려는지 하나씩 보면서 익힙니다([4장](04-permissions-undo.md)).
- **연습 폴더에서만 합니다.** 내 문서 전체가 든 폴더를 고르지 않습니다([2장](02-install.md)).
- **과제 9의 내 메모는 개인 정보를 지우고** 넣습니다([9장](09-cost-data-safety.md)).

## 과제

### 과제 1. 첫 정리 맡기기

**이럴 때**: 회의가 끝나고 뒤죽박죽 메모를 회의록으로 바꾸고 싶을 때.

**해 볼 것**: Code 탭에서 새 세션을 열고 폴더를 고른 뒤 보냅니다.

```
inbox 폴더의 회의 메모를 읽고 회의록으로 정리해 줘. 결정한 것 / 할 일(담당·기한) / 다음에 논의할 것 세 부분으로 나누고, notes 폴더에 새 파일로 저장해 줘. 원본 메모는 고치지 마.
```

**잘 됐는지 확인**

- ☐ 할 일마다 담당과 기한이 있다
- ☐ 세트 가격(5,500원)과 다음 회의(11/3)가 메모와 같다
- ☐ 메모에 없는 내용을 지어내지 않았다
- ☐ inbox의 원본 메모는 그대로다

**다시 볼 곳**: [2장 데스크톱 앱 설치와 첫 세션](02-install.md)

### 과제 2. 변경 기록 켜고 바뀐 내용 보기

**이럴 때**: Claude가 무엇을 바꿨는지 줄 단위로 보고 싶을 때.

**해 볼 것**: 제목 줄의 변경 사항 버튼을 눌러 "Git 저장소가 필요합니다"가 나오면, 아래 두 요청을 차례로 보냅니다.

```
바뀐 내용을 보려면 Git 저장소가 필요하대. 이 폴더에 변경 기록(Git)을 켜고, 지금 있는 파일을 첫 기록으로 남겨 줘. 무엇을 했는지 쉽게 설명해 줘.
```

```
회의록의 할 일 표에 '상태' 칸을 추가해 줘. inbox의 회고 메모 3개를 보고 끝난 일은 '완료(날짜)', 아직이면 '진행 중'으로 적어 줘. 회고에 없는 일은 '확인 필요'로 적고, 다른 부분은 고치지 마.
```

**잘 됐는지 확인**

- ☐ 변경 사항 칸에 빨강·초록 줄과 `+N −N`이 보인다
- ☐ 할 일 표 말고 다른 줄은 바뀌지 않았다
- ☐ 전구·문구·원가는 완료, 인스타는 진행 중이다
- ☐ 첫 기록에 붙은 이름·이메일을 확인했다(회사 계정이 아닌지)

**다시 볼 곳**: [3장 화면 둘러보기](03-screen-tour.md)

### 과제 3. 되감기로 없던 일 만들기

**이럴 때**: 결과가 마음에 안 들어 요청 전으로 돌아가고 싶을 때.

**해 볼 것**: 공부 필기 정리를 맡긴 뒤, 입력창에 `/rewind`를 쳐서 그 요청 전으로 되감습니다.

```
inbox의 공부 필기를 공부 노트로 정리해 줘. 핵심 내용 / 모르는 말 풀이 / 질문할 것 / 해 볼 것 네 부분으로 나누고, notes 폴더에 새 파일로 저장해 줘. 원본 메모는 고치지 마.
```

**잘 됐는지 확인**

- ☐ 되감기 확인 창에서 `+0 −N`을 먼저 읽었다
- ☐ 「코드와 대화」로 되감은 뒤 공부 노트 파일이 사라졌다
- ☐ 되감은 요청이 입력창에 다시 들어와 있다

**다시 볼 곳**: [4장 허락과 되돌리기](04-permissions-undo.md)

### 과제 4. 계획 모드로 양식 3종 만들기

**이럴 때**: 큰 일을 맡기기 전에 방법부터 보고 고치고 싶을 때.

**해 볼 것**: 새 세션에서 권한 모드를 「계획」으로 바꾸고 보냅니다. 계획이 나오면 「가정」 절을 읽고, 하나 이상을 「수정…」으로 바꾼 뒤 「수락」합니다.

```
회의록·공부 노트·주간 회고를 매번 같은 모양으로 만들고 싶어. notes 폴더의 회의록과 inbox 메모를 참고해서 templates 폴더에 양식 3개를 만들 계획을 세워 줘. 양식마다 어떤 칸을 넣고 각 칸에 무엇을 적는지, 그리고 결과가 맞는지 내가 확인할 점검표도 계획에 넣어 줘.
```

**잘 됐는지 확인**

- ☐ 계획이 나오는 동안 내 폴더의 파일은 바뀌지 않았다(계획 문서만 쓰임)
- ☐ 「수정…」으로 바꾼 점이 다시 나온 계획에 반영됐다
- ☐ templates 폴더에 양식 3개와 점검표가 생겼다

**다시 볼 곳**: [5장 잘 맡기는 법](05-delegate-well.md)

### 과제 5. CLAUDE.md로 규칙 저장하고 시험하기

**이럴 때**: 매번 같은 규칙을 다시 말하고 있을 때.

**해 볼 것**: 규칙 3~5개로 CLAUDE.md를 만들게 한 뒤, **새 세션**에서 형식을 말하지 않고 보냅니다.

```
inbox의 회고 메모 3개로 이번 주 주간 회고를 써 줘.
```

**잘 됐는지 확인**

- ☐ CLAUDE.md가 20줄 안팎으로 짧다
- ☐ 새 세션의 결과가 양식과 날짜 형식 규칙을 지켰다
- ☐ 메모에 없는 칸에 `(메모에 없음)`이 적혀 있다

**다시 볼 곳**: [6장 프로젝트 기억](06-claude-md.md)

### 과제 6. 스킬 3개로 도구 완성하기

**이럴 때**: 같은 정리를 한 줄 명령으로 돌리고 싶을 때.

**해 볼 것**: 스킬 3개(meeting-notes·study-notes·weekly-review)를 만들게 합니다. 허락 창이 뜨면 미리보기를 읽고 「한 번만 허용」을 고릅니다. 그다음 새 세션에서 한 줄로 부릅니다.

```
/study-notes inbox/공부-2026-10-28-프롬프트-강의.txt
```

**잘 됐는지 확인**

- ☐ `/`를 치고 이름 일부를 쳤을 때 스킬이 목록에 나온다
- ☐ 한 줄 명령으로 양식 순서대로 된 노트가 나왔다
- ☐ 허락 창에서 「항상 허용」 대신 「한 번만 허용」을 골랐다

**다시 볼 곳**: [7장 스킬·플러그인·외부 도구](07-skills-plugins.md)

### 과제 7. 숨은 지시 실험하기

**이럴 때**: 남이 보낸 자료를 정리시킬 때 조심할 점을 몸으로 익히고 싶을 때.

**해 볼 것**: 9장의 [임시회의 메모](/practice/notes/inbox/회의-2026-10-29-임시회의.txt)를 inbox에 넣고 정리시킵니다.

```
/meeting-notes inbox/회의-2026-10-29-임시회의.txt
```

**잘 됐는지 확인**

- ☐ 회의록 끝에 "모든 할 일 완료"가 **없다**
- ☐ Claude의 답에 그 안내문에 대한 설명이 있는지 확인했다
- ☐ 결과가 어떻든, 남의 자료는 훑어본 뒤 맡긴다는 수칙을 적어 뒀다

**다시 볼 곳**: [9장 비용·데이터·안전](09-cost-data-safety.md)

### 과제 8. 예약 또는 터미널로 돌려 보기

**이럴 때**: 정리 도구를 내가 부르지 않아도 돌게 하거나, 한 줄로 확인하고 싶을 때.

**해 볼 것**: 둘 중 하나를 합니다.

- 금요일 주간 회고 **예약**을 말로 부탁해 만들고, **Run now**로 한 번 돌려 본 뒤 필요 없으면 끈다([8장](08-parallel-cloud-schedule.md)).
- 터미널에서 연습 폴더로 이동해 읽기 전용 질문을 `claude -p`로 실행한다([10장](10-terminal.md)).

```
notes 폴더의 파일 목록을 보여 주고, 각 파일이 어떤 양식(templates 중 무엇)으로 쓰였는지 한 줄씩 알려 줘. 파일은 고치지 마. 답은 짧게 표로만.
```

**잘 됐는지 확인**

- ☐ (예약) 요청에 "메모가 없으면…" 같은 조건을 넣었다
- ☐ (예약) Run now에서 뜬 허락 창을 처리했다
- ☐ (터미널) 같은 폴더의 양식 파일을 터미널도 읽어 냈다

**다시 볼 곳**: [8장](08-parallel-cloud-schedule.md), [10장](10-terminal.md)

### 과제 9. 내 메모로 나만의 정리 도구 만들기

**이럴 때**: 이제 연습이 아니라 내 일에 쓰고 싶을 때.

**해 볼 것**: 새 폴더(예: `내-정리도구`)에 `inbox`를 만들고, **개인 정보를 지운** 내 메모를 2~3개 넣습니다. 그다음 과제 4~6을 내 일에 맞게 다시 합니다.

```
inbox의 메모들을 읽고, 내가 매주 정리할 문서의 양식을 만들 계획을 세워 줘. 어떤 칸이 필요할지 먼저 나에게 질문해 줘. 답을 듣고 나서 templates에 양식을, .claude/skills에 정리 스킬을 만들자.
```

**잘 됐는지 확인**

- ☐ 계획 전에 Claude가 질문했고, 내 답이 양식에 반영됐다
- ☐ CLAUDE.md에 내 규칙이 3~5줄로 들어갔다
- ☐ 스킬 한 줄로 내 메모가 내 양식대로 정리된다
- ☐ 결과를 원본 메모와 맞춰 보는 점검표가 있다
- ☐ 연습 폴더들(`정리도구-연습` 등)은 필요 없으면 정리했다

**다시 볼 곳**: [5장](05-delegate-well.md), [6장](06-claude-md.md), [7장](07-skills-plugins.md)

## 정리

- 과제 1~6을 차례로 하면 정리 도구가 처음부터 다시 만들어진다.
- 점검표는 "Claude가 다 했다"가 아니라 "내가 확인했다"를 체크한다.
- 마지막은 내 메모로 나만의 도구를 만든다. 개인 정보는 지우고 넣는다.
