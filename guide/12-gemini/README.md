# 2단계 · Gemini 사용 가이드

1단계에서 어떤 AI에든 통하는 **잘 묻는 법**을 배웠다면, 2단계에서는 **Gemini라는 서비스의 화면과 기능**을 익힙니다.
버튼이 어디 있는지, 대화를 어떻게 정리하는지, 내 정보가 어떻게 쓰이는지 같은 것입니다.

> **이 가이드는 2026년 10월 30일에 확인한 Google 공식 도움말과 실제 화면을 바탕으로 썼습니다.** Gemini는 메뉴 이름과 기능이 자주 바뀝니다.
> 그림은 유료 요금제(Google AI Pro) 한국어 웹 화면이라, 무료 계정에서는 일부 메뉴가 안 보이거나 잠겨 있을 수 있습니다.
> 내 화면과 다르면 화면에 보이는 이름을 따르세요. 최신 내용은 각 장의 각주에 있는 공식 도움말 링크에서 확인하면 됩니다.
