# 11장. 실습 과제 — Gemini 기능을 직접 써 보기

> **한 줄 요약**: 1~10장에서 본 Gemini의 화면과 기능을 **내 손으로 한 번씩 눌러 보는** 과제 10개를 모았습니다.
> 과제마다 「잘 됐는지 확인」 점검표가 있어서, 누가 채점해 주지 않아도 스스로 확인할 수 있습니다.

화면은 2026년 10월 웹 기준입니다. Gemini는 메뉴 이름과 위치가 자주 바뀌니, 화면이 다르면 화면에 보이는 이름을 따르세요.

## 실습 과제를 하는 법

1. **Gemini(gemini.google.com)를 열고 로그인합니다.** 과제 대부분은 대화 기록과 설정을 씁니다.
2. **과제의 「해 볼 것」을 따라 합니다.** 회색 상자의 프롬프트를 복사해 보내면 됩니다.
3. **「잘 됐는지 확인」을 하나씩 체크합니다.** 체크하지 못한 항목이 있으면 「다시 볼 곳」의 장을 읽고 그 부분만 다시 해 보세요.

과제는 순서대로 하지 않아도 됩니다. 단, **과제 10은 맨 마지막에** 하세요. 연습한 흔적을 정리하는 과제입니다.
과제 8의 「작업」은 **Google AI Pro·Ultra** 전용이라, 무료라면 채팅 일정만 해 보세요. 그 밖의 메뉴도 계정이나 요금제에 따라, 또는 아직 열리지 않아 안 보일 수 있습니다. 안 보이면 읽기만 하고 넘어가세요.

어떻게 물어야 하는지(프롬프트 쓰는 법) 연습은 [1단계 10장 실습 과제](../00-common/10-practice.md)에 있습니다. 여기서는 **버튼과 메뉴**에 집중하세요.

처음부터 다 해낼 필요는 없습니다. 하루에 과제 두세 개씩이면 충분합니다.

### 실습할 때 지킬 세 가지

- **되도록 임시 채팅에서 합니다.** 오른쪽 위 「임시 채팅」으로 연 대화는 대화 목록에 남지 않고 AI 학습에도 쓰이지 않습니다. 단, 72시간은 보관됩니다([2장](02-screen-tour.md#임시-채팅-—-기록이-남지-않는-대화)).[^screen][^hub]
  기록·스킬·일정을 다루는 과제(3·5·7·8)는 일반 채팅에서 하세요. 임시 채팅에서는 다시 열거나 이름을 바꿀 수 없기 때문입니다.
- **자료는 가짜로 만듭니다.** 실제 이름·연락처·회사 자료 대신 **내가 지어낸 자료**를 쓰세요. 일반 채팅에서 한 연습은 과제 10에서 정리합니다. 넣지 말아야 할 정보는 [1단계 9장](../00-common/09-safety.md#넣지-말아야-할-것)에 있습니다.
- **좋아요·싫어요는 누르지 않습니다.** 피드백을 보내면 「활동 기록 보관」을 꺼 두었어도 그 대화가 서비스 개선에 쓰입니다([9장](09-privacy.md#사람이-읽나-ai-학습에-쓰이나)).[^hub]

## 과제

### 과제 1. 임시 채팅으로 연습 공간 만들기

**이럴 때**: 기록에 남기고 싶지 않은 질문을 해 보고 싶을 때.

**해 볼 것**: 오른쪽 위 「임시 채팅」을 누르고 아래를 보냅니다. 답을 받으면 오른쪽 위 ×로 닫습니다.

```
나는 Gemini를 처음 써 봐. 오늘 연습할 만한 질문 세 가지를 추천해 줘.
```

**잘 됐는지 확인**

- ☐ 화면 가운데에 "임시 채팅은 최근 채팅에 표시되지 않으며…"라는 안내가 떴다[^screen]
- ☐ 남기고 싶은 답은 닫기 전에 복사해 뒀다(남길 답이 없었다면 체크)
- ☐ 닫은 뒤 옆 메뉴 대화 목록에 이 대화가 없다

**다시 볼 곳**: [2장 화면 둘러보기](02-screen-tour.md)

### 과제 2. 모델 버튼에서 사고 수준 바꿔 보기

**이럴 때**: 어려운 질문에 더 깊이 생각한 답을 받고 싶을 때.

**해 볼 것**: 임시 채팅에서 아래를 보낸 뒤, 입력창의 모델 버튼에서 사고 수준을 한 단계 올려 같은 질문을 다시 보냅니다.

```
월 30만 원씩 2년 모으는 것과, 처음에 600만 원을 넣고 2년 두는 것은 무엇이 다른지
이자 계산 방식의 차이를 중학생도 알 수 있게 설명해 줘.
```

**잘 됐는지 확인**

- ☐ 모델 버튼을 눌러 지금 쓰는 모델과 사고 수준을 확인했다
- ☐ 사고 수준을 바꾼 뒤 답의 길이나 설명 순서가 어떻게 달라졌는지 비교했다
- ☐ 요금제에 따라 고를 수 있는 항목이 다르다는 것을 알았다(무료라면 보이는 항목만 확인하고 체크)

**다시 볼 곳**: [2장 모델 버튼](02-screen-tour.md#모델-버튼-—-모델과-사고-수준)

### 과제 3. 대화 이름 바꾸고 다시 찾기

**이럴 때**: 지난 대화를 나중에 다시 찾아야 할 때.

**해 볼 것**: 일반 채팅에서 아래를 보냅니다. 옆 메뉴에서 이 대화의 점 세 개 → 「이름 변경」으로 제목을 "[연습] 독서 모임 준비물"로 바꿉니다. 그다음 「채팅 검색」에 "연습"을 넣어 찾아봅니다.

```
독서 모임에 처음 오는 사람이 챙기면 좋은 준비물을 다섯 가지만 알려 줘.
```

**잘 됐는지 확인**

- ☐ 옆 메뉴 대화 제목이 "[연습] 독서 모임 준비물"로 바뀌었다
- ☐ 「채팅 검색」으로 이 대화를 찾았다
- ☐ 「고정」을 눌러 목록 맨 위에 붙였다가 「고정 해제」로 되돌렸다

**다시 볼 곳**: [3장 대화 관리](03-chats.md)

### 과제 4. 가짜 공지문 올리고 표로 받기

**이럴 때**: 긴 문서를 정리하거나 다른 모양으로 바꾸고 싶을 때.

**해 볼 것**: 메모장에 아래 같은 가짜 공지문을 써서 파일로 저장합니다. 입력창 「+」 → 「파일 업로드」로 올리고 프롬프트를 보냅니다.

```
11월 독서 모임 안내
날짜: 11월 22일 토요일 오후 2시
장소: 구립도서관 3층 세미나실
읽을 책: 「작은 아씨들」
준비물: 책, 메모할 공책, 회비 5,000원
```

```
올린 공지문에서 날짜·장소·읽을 책·준비물을 뽑아서 표로 정리해 줘.
다른 앱은 쓰지 말고 이 채팅에 표로 보여 줘.
```

**잘 됐는지 확인**

- ☐ 표의 날짜·장소·회비가 공지문과 글자 하나까지 같다
- ☐ 공지문에 없는 내용(예: 끝나는 시각)을 지어내지 않았다
- ☐ 표 바로 아래 점 세 개를 눌러 「Sheets로 내보내기」가 있는 것을 확인했다(누르지 않아도 된다)

**다시 볼 곳**: [4장 파일과 만들기](04-files-create.md) · [3장 다른 앱으로 내보내기](03-chats.md#다른-앱으로-내보내기)

### 과제 5. 지침 넣고 답이 바뀌는지 보기

**이럴 때**: 매번 같은 부탁("짧게", "표로")을 하기 귀찮을 때.

**해 볼 것**: 「설정」 → 「개인 인텔리전스」 → 「Gemini 요청 사항」에 아래 지침을 추가합니다. 새 일반 채팅에서 아무 질문이나 해 봅니다.

```
답의 맨 앞에 한 줄 요약을 붙이고, 어려운 말은 괄호로 풀어 줘.
```

**잘 됐는지 확인**

- ☐ 새 채팅의 답 맨 앞에 한 줄 요약이 붙었다
- ☐ 「Gemini 요청 사항」 화면에 내가 추가한 지침이 보였다
- ☐ 연습이 끝나면 이 지침을 지우거나 내게 맞게 고쳤다

**다시 볼 곳**: [5장 기억과 맞춤 설정](05-memory.md)

### 과제 6. 출처 열어 보고 Deep Research 계획 고치기

**이럴 때**: 답의 근거를 확인하거나, 여러 자료를 모은 보고서가 필요할 때.

**해 볼 것**: 먼저 아래를 보내고 답의 「출처」를 하나 열어 봅니다. 그다음 「+」 → 「도구 더보기」 → 「Deep Research」를 켜고 같은 주제를 보낸 뒤, 계획이 나오면 「계획 수정」으로 "공식 통계만 써 줘"라고 고칩니다.

```
최근 5년 동안 한국의 1인 가구 비율이 어떻게 바뀌었는지 출처와 함께 알려 줘.
```

**잘 됐는지 확인**

- ☐ 출처 링크를 열어 답의 숫자가 원문과 같은지 봤다
- ☐ Deep Research 계획이 나왔을 때 「계획 수정」으로 조건을 더했다
- ☐ 보고서를 끝까지 받을 생각이 없다면 멈춤 버튼으로 멈췄다(Deep Research는 사용량을 많이 쓴다)

**다시 볼 곳**: [6장 검색과 Deep Research](06-search.md)

### 과제 7. 스킬 만들어 불러 쓰기

**이럴 때**: 같은 부탁을 자주 할 때.

**해 볼 것**: 「맞춤설정」 → 「스킬」 → 「만들기」 → 「수동으로 만들기」에서 아래처럼 스킬을 만듭니다. 새 채팅에서 `/`를 치고 스킬을 고른 뒤 가짜 회의 메모를 붙여 넣습니다.

```
이름: summarize-meeting-notes
설명: 회의록을 결정 사항·할 일·담당자로 정리한다. 회의록이나 회의 메모를 붙여 넣었을 때 쓴다.
지침: 회의록을 받으면 1. 결정된 것 2. 할 일(할 일 - 담당자 - 마감일) 3. 다음에 다시 볼 것 순서로 정리해.
담당자나 마감일이 없으면 지어내지 말고 "확인 필요"라고 적어.
```

**잘 됐는지 확인**

- ☐ `/`를 쳤을 때 만든 스킬이 목록에 보였다(`@`로 바뀌었다면 `@`)
- ☐ 담당자가 없는 할 일에 "확인 필요"라고 나왔다
- ☐ 연습이 끝나면 「더보기」 → 「비활성화」 또는 「삭제」로 정리했다

**다시 볼 곳**: [7장 스킬과 연결된 앱](07-skills-apps.md)

### 과제 8. 일정 걸고 「예약됨」에서 지우기

**이럴 때**: 매일·매주 같은 소식을 받고 싶을 때.

**해 볼 것**: 일반 채팅에서 아래를 보냅니다. 옆 메뉴 「예약됨」에서 일정이 생겼는지 보고, 「더보기」로 지웁니다. 유료 요금제라면 입력창 아래 「작업」을 눌러 '물어봐 줘'도 보내 봅니다. 채팅 일정은 점차 열리는 중이라 아직 안 될 수도 있습니다.

```
매주 월요일 아침 8시에 이번 주 서울 날씨를 세 줄로 요약해 줘.
```

**잘 됐는지 확인**

- ☐ Gemini가 일정 요약(언제·얼마나 자주)으로 답했다
- ☐ 「예약됨」에서 이 일정을 찾았다
- ☐ 연습이 끝나 일정을 지웠다

**다시 볼 곳**: [8장 일 맡기기](08-tasks.md)

### 과제 9. 휴대폰에서 말로 물어보기

**이럴 때**: 타자를 치기 어렵거나, 말로 연습하고 싶을 때.

**해 볼 것**: 휴대폰에 Gemini 앱을 설치하고 같은 Google 계정으로 로그인합니다. 마이크를 누르고 아래를 말합니다. Android라면 「Live」도 눌러 봅니다.

```
오늘 저녁에 냉장고에 있는 달걀, 두부, 대파로 만들 수 있는 요리 세 가지 알려 줘.
```

**잘 됐는지 확인**

- ☐ 말한 내용이 글자로 바뀌어 질문이 보내졌다
- ☐ 컴퓨터 웹의 대화 목록에도 이 대화가 보였다(일반 채팅이었다면)
- ☐ Live를 썼다면 「종료」를 누른 뒤 같은 대화가 글로 이어지는 것을 봤다(Live를 안 썼다면 체크)

**다시 볼 곳**: [10장 음성과 휴대폰](10-voice-mobile.md)

### 과제 10. 내 데이터 설정 점검하고 정리하기

**이럴 때**: 실습을 마쳤을 때, 그리고 몇 달에 한 번.

**해 볼 것**: 왼쪽 아래 「설정」을 열고 아래 점검표대로 확인합니다.

**잘 됐는지 확인**

- ☐ 「활동」에서 「활동 기록 보관」이 내가 원하는 쪽(켜짐·꺼짐)으로 되어 있다
- ☐ 자동 삭제 기간(기본 18개월)을 내게 맞게 골랐다
- ☐ 「내 공개 링크」에서 더 이상 필요 없는 링크를 지웠다(공유한 대화가 없었다면 체크)
- ☐ 「맞춤설정」 → 「커넥터」에서 필요 없는 연결된 앱을 「연결 해제」했다
- ☐ 과제 3·4·5·6·7에서 만든 연습 대화를 지웠다. 연결을 끊거나 앱 데이터를 지워도 대화 기록은 남으니 대화도 따로 지운다

## 정리

- 기능은 읽기만 해서는 손에 익지 않는다. 버튼을 한 번씩 직접 눌러 본다.
- 실습은 되도록 임시 채팅에서 하고, 기록·스킬·일정을 다루는 과제는 가짜 자료로 일반 채팅에서 한다.
- 과제 8의 「작업」은 유료 요금제가 필요하다. 다른 메뉴도 계정에 따라 안 보이면 읽기만 하고 넘어간다.
- 과제마다 점검표로 스스로 확인하고, 체크하지 못한 부분은 「다시 볼 곳」을 읽고 다시 해 본다.
- 실습이 끝나면 「활동 기록 보관」·자동 삭제·공개 링크·연결된 앱을 점검하고, 연습 대화를 정리한다.

이 장에서 새로 나온 용어는 없습니다. 임시 채팅·스킬·작업 같은 말은 각 장의 「용어 정리」에 있습니다.
