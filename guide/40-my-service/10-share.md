# 10장. 사람들에게 알리기

<Badge type="tip" text="필수" /> 이 단계를 따라가려면 꼭 읽으세요.

> **한 줄 요약**: 만든 것을 쓰게 하려면 **알려야** 합니다. 게임은 링크 미리보기 그림과 자랑 문구, 가게는 메뉴판과 홍보 문구 요청문, 업무 도구는 한 장짜리 사용 설명을 만듭니다.
> 재테크 대시보드는 알리지 않는 트랙입니다. 보여 줄 때는 숫자를 가립니다.

## 링크 미리보기 그림

메신저에 링크를 붙이면 제목과 그림이 담긴 **미리보기 카드**가 뜰 때가 있습니다. 이 카드는 페이지에 숨겨 둔 몇 줄의 표시를 읽어 만듭니다. 이 표시를 **Open Graph 태그**(오픈 그래프 태그)라고 합니다.

꼭 필요한 것은 넷입니다. 제목(`og:title`), 종류(`og:type`), 그림(`og:image`), 주소(`og:url`)입니다. 그림을 넣으면 그림이 무엇을 보여 주는지 적는 설명(`og:image:alt`)도 넣습니다.[^ogp]

```text
이 게임의 index.html 에 링크 미리보기용 Open Graph 태그를 넣어 줘.
og:title, og:type, og:image, og:url, og:image:alt 를 넣고, 주소는 https://내아이디.github.io/저장소이름/ 기준으로.
미리보기 그림 og-image.png 도 만들어 줘. 크기는 1200×630, 게임 제목이 크게 보이게.
```

예시 게임 「별똥별 받기」는 게임 화면처럼 꾸민 HTML 페이지를 하나 만들고, 그 화면을 브라우저로 찍어 그림을 만들었습니다. 그림 도구가 없어도 AI가 이렇게 만들 수 있습니다.

카카오톡은 미리보기 정보를 **따로 저장해 둡니다.** 그림을 바꿨는데 예전 그림이 계속 뜨면, 카카오 개발자 사이트의 [도구] > [초기화 도구] > [OG 캐시] 메뉴에서 지울 수 있습니다. 그림 용량이 5MB를 넘어도 안 뜹니다.[^kakao]

## 자랑 문구와 공유 버튼

게임을 끝낸 친구가 **다른 친구에게 다시 보내게** 만들면 저절로 퍼집니다. 끝 화면에 「친구에게 자랑하기」 버튼을 둡니다.

휴대폰에서는 이 버튼이 기기의 **공유 창**(카카오톡·문자 등을 고르는 창)을 엽니다. 브라우저의 공유 기능(Web Share API)이 그 일을 합니다.[^share] 이 기능은 **https 주소에서만** 동작하고, 지원하지 않는 브라우저도 있습니다.[^share-https] 그래서 예시 게임은 공유 창이 안 되면 **자랑 문구를 복사**하게 만들었습니다.

```text
끝 화면에 「친구에게 자랑하기」 버튼을 넣어 줘.
휴대폰에서는 공유 창을 열고, 공유 창이 안 되는 곳에서는 문구를 복사하고 「복사했어요」라고 알려 줘.
문구는 「별똥별 받기에서 132점! 너도 해 볼래?」처럼 점수와 게임 주소가 들어가게.
```

문구에는 **점수와 주소**가 꼭 들어가게 하세요. 받은 친구가 「나도 이겨 볼까」 하고 누를 이유가 됩니다.

## 가게 홍보 — 메뉴판과 요청문

가게 트랙의 알리기는 둘입니다.

**메뉴판 인쇄**: 3장에서 요청한 대로 메뉴판 탭을 인쇄하면 메뉴판만 깔끔하게 나옵니다. 가격을 바꾸면 다시 인쇄하면 됩니다. 매장에 붙이는 메뉴판이 늘 도구와 같아집니다.

**홍보 문구 요청문**: 예시 꽃집 도구는 AI를 직접 부르지 않습니다. 대신 메뉴를 고르면 **AI 채팅에 붙여 넣을 요청문**을 만들어 줍니다. 사장님은 그 글을 복사해 평소 쓰는 ChatGPT·Claude·Gemini에 붙여 넣습니다. 이렇게 하면 도구에 인증키도 비용도 필요 없습니다.

요청문은 이런 모양입니다(예시 꽃집 도구에서 계기를 「빼빼로데이 주간」, 말투를 「다정하게」로 두고 메뉴 두 개를 골랐을 때 나온 그대로입니다).

```text
우리 가게 「모퉁이 꽃집」의 홍보 문구를 써 줘.
- 계기: 빼빼로데이 주간
- 소개할 메뉴:
- 생일 꽃다발 (35,000원)
- 책상 위 작은 화분 (12,000원)
- 말투: 다정하게
- 길이: 문자 한 통(90자 안팎) 1개, 인스타그램 글(3~4줄, 해시태그 3개) 1개
- 지키기: 가격은 위에 적은 그대로 쓰고, 없는 할인이나 효능을 지어내지 말 것
- 문자 맨 앞에 (광고)를, 끝에 무료 수신거부 안내 자리를 [수신거부 안내] 로 비워 둘 것
```

「지어내지 말 것」은 AI가 없는 할인이나 효능을 그럴듯하게 덧붙이는 것을 막습니다. 「(광고)」와 수신거부 자리는 8장의 광고 문자 규칙 때문입니다. 받은 문구는 **동의한 손님에게만**, 정해진 시간에 보냅니다.

## 업무 도구 — 한 장짜리 사용 설명

회사 동료는 도구를 왜 써야 하는지부터 궁금해합니다. 긴 설명서보다 **한 장짜리 사용 설명**이 낫습니다. 담을 것은 넷입니다.

- 이 도구가 무엇을 대신하나(예: 「비품 신청 엑셀 파일 대신」)
- 주소와 여는 법(회사 계정으로 로그인)
- 입력하는 법 세 줄
- 막히면 누구에게 묻나

```text
SPEC.md를 보고 회사 동료에게 보낼 한 장짜리 사용 설명을 써 줘.
이 도구가 무엇을 대신하는지, 여는 법, 입력하는 법 세 줄, 막히면 물어볼 곳(빈칸으로)을 넣어 줘.
전문 용어는 쓰지 말고, 메일 본문에 그대로 붙일 수 있게.
```

7장에서 다른 사람이 막혔던 곳이 있으면, 그 부분을 설명에 꼭 넣으세요. 한 사람이 막힌 곳은 다른 사람도 막힙니다.

## 직접 해 보기

1. 내 트랙 상자를 따라 한다.
2. 실제로 한 사람에게 보내거나 붙여 본다. 게임은 친구, 가게는 매장 벽, 업무는 동료 한 명.
3. 받은 사람의 반응을 한 줄 적어 둔다. 11장에서 다음 버전 목록에 씁니다.

::: details 업무 트랙
「업무 도구 — 한 장짜리 사용 설명」의 프롬프트로 설명을 받고, 동료 한 명에게 웹 앱 주소와 함께 보냅니다. 설명에 내 이름과 연락처를 넣을지는 회사 관례를 따릅니다.
:::

::: details 가게 트랙
1. 메뉴판을 인쇄해 붙인다.
2. 홍보 문구 탭에서 메뉴를 골라 요청문을 만들고, AI 채팅에 붙여 넣어 문구를 받는다.
3. 받은 문구에 없는 할인·행사가 들어가 있지 않은지 읽어 본다. 있으면 지우라고 한다.
4. 보낼지 정하기 전에 8장의 동의·시간 규칙을 다시 본다.
:::

::: details 게임 트랙
1. 「링크 미리보기 그림」의 프롬프트로 태그와 그림을 넣고, 커밋·푸시한다.
2. 나에게 보내는 카카오톡 대화방에 주소를 붙여, 미리보기 카드가 뜨는지 본다.
3. 「자랑 문구와 공유 버튼」의 프롬프트로 버튼을 넣는다. 휴대폰 공개 주소에서 한 판 하고 눌러 본다.
4. 친구 한 명에게 보낸다.
:::

::: details 재테크 트랙
이 트랙은 알리지 않습니다. 대신 대시보드를 누군가에게 **보여 줄 때**의 규칙을 정합니다.

- 캡처를 보낼 때는 금액을 가린다. 비율(%)만 보여 줘도 충분할 때가 많다.
- 화면에 「투자 조언이 아닙니다」 문구를 둔다. 예시 대시보드도 이 문구를 둔다.
- 주식시세 자료를 불러온 화면은 공개하지 않는다(8장).
:::

## 정리

- 링크 미리보기는 Open Graph 태그(제목·종류·그림·주소, 그림 설명)로 만든다. 카카오톡은 미리보기를 따로 저장하니 바꾸면 캐시를 지운다.
- 자랑 버튼은 휴대폰 공유 창을 열고, 안 되면 문구를 복사한다. 문구에 점수와 주소를 넣는다.
- 가게는 메뉴판을 인쇄하고, 홍보 문구는 요청문을 만들어 AI 채팅에 붙여 넣는다. 지어내지 말라고 하고, 광고 규칙을 지킨다.
- 업무 도구는 한 장짜리 사용 설명을 보낸다.

## 용어 정리

| 용어 | 읽는 법 | 한 줄 뜻 |
|---|---|---|
| Open Graph | 오픈 그래프 | 링크 미리보기 카드에 쓰이는 페이지 정보 표시 방식 |
| Preview card | 프리뷰 카드 | 메신저에 링크를 붙이면 뜨는 제목·그림 카드 |
| Cache | 캐시 | 다시 쓰려고 따로 저장해 둔 복사본 |
| Web Share API | 웹 셰어 에이피아이 | 웹 페이지가 기기의 공유 창을 여는 기능 |
