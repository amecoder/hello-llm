# 5단계 · 내 서비스 만들기

4단계에서는 연습용 할 일 보드를 만들었습니다. 5단계에서는 **내가 정말 쓰고 싶은 것**을 만듭니다. 매일 켜 쓰는 가게 관리 도구, 친구에게 보내는 게임, 나만 보는 재테크 대시보드, 회사 동료와 쓰는 업무 도구 같은 것입니다.
코드를 몰라도 괜찮습니다. 4단계처럼 AI가 만들고, 나는 무엇을 만들지 정하고 확인합니다. 이번에는 거기에 **진짜 사용자·진짜 데이터·지켜야 할 규칙**이 더해집니다.

## 네 트랙 — 내 것을 하나 고르세요

장마다 개념은 한 번만 설명합니다. 장 끝 「직접 해 보기」는 트랙별 상자로 나뉘어 있습니다. **내 트랙 상자만 펼쳐 읽으면 됩니다.**

| 트랙 | 이런 분 | 만드는 것 | 어디에서 쓰나 |
|---|---|---|---|
| 업무 | 엑셀로 일하는 직장인 | 입력 양식·목록·합계가 있는 업무 도구 | 회사 구글 계정 안 |
| 가게 | 작은 가게 사장님 | 예약·메뉴판·손님 명단·홍보 문구 | 매장 컴퓨터 |
| 게임 | 취미로 만드는 사람 | 친구에게 보내는 브라우저 게임 | 인터넷 공개 주소 |
| 재테크 | 내 돈 흐름을 보고 싶은 사람 | 화려한 차트 대시보드 | 내 컴퓨터 |

## 미리 보는 예시

이 가이드를 쓰면서 세 트랙의 예시를 실제로 만들었습니다. 내 결과와 모양이 달라도 괜찮습니다.

- 게임: **별똥별 받기** — [예시 페이지](https://amecoder.github.io/star-catcher/) · [저장소](https://github.com/amecoder/star-catcher)
- 가게: **모퉁이 꽃집 매장 도구** — 내 컴퓨터에서만 쓰는 도구라 공개 주소가 없습니다. 장마다 화면 설명으로 보여 줍니다
- 재테크: **내 돈 대시보드** — 마찬가지로 내 컴퓨터 전용입니다

가게 이름·손님·종목·숫자는 모두 지어낸 것입니다. 업무 트랙은 회사 계정마다 설정이 달라 예시를 만들지 않았습니다. 공식 문서를 따라 쓰는 순서만 안내합니다.
