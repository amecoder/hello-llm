# 8장. 안전과 법

<Badge type="tip" text="필수" /> 이 단계를 따라가려면 꼭 읽으세요.

> **한 줄 요약**: 진짜 데이터에는 규칙이 따라옵니다. **비밀값은 코드 밖에**, **손님 정보는 적게 모으고 동의를 기록**, **광고 문자는 미리 동의받은 사람에게만**, **공공 자료와 부품은 이용 조건대로** 씁니다.
> 이 장은 법률 자문이 아닙니다. 실제로 영업에 쓰기 전에는 마지막 절의 점검표를 보고, 필요하면 전문가에게 확인하세요.

이 장의 법령은 2026년 11월 13일 국가법령정보센터의 현행 원문으로 확인했습니다.

## 비밀값은 코드 밖에

**비밀값**은 남이 알면 내 이름으로 무언가를 할 수 있는 값입니다. 비밀번호, 그리고 4장에서 받은 ECOS **인증키** 같은 것입니다. 4단계 9장에서 본 원칙 그대로, 비밀값은 저장소에 올리지 않습니다([4단계 9장](../30-ai-sdlc/09-safety.md)).

5단계에서 한 가지를 더 지킵니다. **코드 파일에도 적지 않습니다.** 비공개 저장소라도, 코드를 남에게 보여 주거나 공개로 바꾸는 순간 함께 나갑니다. 그래서 4장에서 받기 스크립트를 만들 때 인증키를 환경 변수로 넣게 했습니다. 실행할 때만 이렇게 넣습니다.

```bash
ECOS_API_KEY=내인증키 node tools/fetch-ecos.mjs
```

`ECOS_API_KEY=내인증키` 는 이 명령 한 번에만 쓰는 값을 넣는다는 뜻입니다. `node tools/fetch-ecos.mjs` 는 받기 스크립트를 실행합니다. 키는 명령을 친 그 순간에만 쓰이고, 파일 어디에도 남지 않습니다.

ECOS 인증키는 **남에게 주면 안 됩니다.** 약관은 인증키를 양도·증여하면 서비스를 중단할 수 있다고 정합니다.[^ecos-transfer] 친구에게 대시보드를 복사해 줄 때도 키는 각자 받게 하세요.

AI가 코드를 만든 뒤 한 번 물어보세요.

```text
이 폴더의 모든 파일에서 인증키·비밀번호·토큰처럼 보이는 값이 코드에 직접 적힌 곳을 찾아 줘.
있으면 환경 변수에서 읽도록 바꾸는 방법을 알려 줘. 찾은 값은 화면에 그대로 다시 쓰지 마.
```

## 손님 정보와 광고 문자

가게 트랙의 손님 명단은 매장 컴퓨터 안에만 있어도 **개인정보**입니다. 지킬 것은 셋입니다.

**적게 모읍니다.** 쓰지 않을 칸은 만들지 않습니다(5장). 모은 것이 적을수록 잃어버려도 피해가 작습니다.

**처리방침을 정합니다.** 개인정보 보호법은 개인정보를 처리하는 사람이 **개인정보 처리방침**(무엇을 왜 모으고 언제 지우는지 적은 글)을 정하도록 합니다.[^privacy-policy] 처리방침을 정하지 않거나 공개하지 않으면 1천만 원 이하의 과태료 대상입니다.[^privacy-fine] 내 가게에 어떻게 적용되는지는 개인정보보호위원회 안내를 확인하세요.

**광고 문자는 미리 동의받은 사람에게만 보냅니다.** 정보통신망법은 영리 목적의 광고성 정보를 보내려면 받는 사람의 **사전 동의**를 받게 합니다. 그리고 **밤 9시부터 다음 날 아침 8시까지** 보내려면 따로 또 동의를 받아야 합니다(전자우편은 예외).[^ad-night] 이를 어기면 3천만 원 이하의 과태료 대상입니다.[^ad-fine]

그래서 예시 꽃집 도구는 이렇게 만들었습니다.

- 손님마다 **홍보 동의 여부와 동의한 날**을 따로 적는다. 동의를 거두면 날짜를 지운다.
- 홍보 문구 탭에 **동의한 손님 수**를 보여 주고, 동의하지 않은 손님에게는 보내지 않는다고 적어 둔다.
- 「밤 9시~아침 8시에 보내려면 따로 동의를 받아야 합니다」 안내를 늘 띄우고, 지금이 그 시간대면 그렇다고 덧붙인다.
- 문자 자동 발송은 처음 버전에서 뺐다. 보내는 일은 사장님이 직접 한다.

## 데이터와 부품의 이용 조건

남이 만든 자료와 부품에는 **이용 조건**이 있습니다. 공짜라고 마음대로 써도 된다는 뜻은 아닙니다.

| 쓰는 것 | 조건 | 그래서 |
|---|---|---|
| 한국은행 ECOS 자료 | ECOS 제공 정보임을 표시[^ecos-mark] | 화면에 「출처: ECOS(한국은행)」 |
| 금융위원회 주식시세(공공데이터포털) | 제3자 제공·재배포 금지[^stock-ban] | 예시 저장소에 넣지 않음 |
| 차트 부품 Apache ECharts | Apache 2.0 라이선스 | 라이선스·NOTICE 파일을 함께 둠 |

주식시세 자료는 무료로 받을 수 있지만, 상업적 목적이든 아니든 **남에게 주거나 다시 배포하는 것이 금지**입니다.[^stock-ban] 나 혼자 보는 대시보드에 불러오는 것과, 그 자료를 담은 파일이나 화면을 남에게 공개하는 것은 다릅니다. 그래서 예시 대시보드는 지어낸 종목과 가격만 담았습니다.

부품의 라이선스는 4단계 9장에서 본 것처럼 AI에게 확인하게 합니다. 「폴더에 넣은 부품마다 라이선스 이름과, 함께 둬야 하는 파일이 있는지 알려 줘」라고 물으면 됩니다.

## 실제 영업에 쓰기 전 점검표

이 가이드의 예시는 지어낸 가게와 지어낸 데이터로 만든 연습입니다. 내 결과물을 실제 영업이나 공개 서비스로 키우려면, 그 전에 아래를 확인하세요. **하나라도 「모르겠다」면 멈추고 확인합니다.**

- ☐ 손님 정보를 모으나? → 개인정보 처리방침을 정하고 공개했나?(위 절)
- ☐ 광고 문자를 보내나? → 미리 동의받았나? 밤 9시~아침 8시는 따로 동의받았나?
- ☐ 인터넷으로 물건이나 서비스를 파나? → **통신판매업 신고** 대상인지 확인했나? 직전 해 거래가 50회 미만이거나 간이과세자이면 신고가 면제되지만,[^mail-order] 면제돼도 다른 의무는 그대로입니다.[^mail-order-other]
- ☐ 게임을 공개하나? → 영리를 목적으로 하지 않고 만든 게임은 등급분류를 받지 않아도 됩니다. 단, 청소년이용불가 기준에 해당하는 내용이 있으면 예외입니다.[^game]
- ☐ 남에게 투자 정보를 보여 주나? → 이 과정은 내 데이터를 보는 법만 다룹니다. 남에게 무엇을 사고팔지 알려 주는 서비스로 키우려면 먼저 전문가에게 확인하세요.
- ☐ 회사 데이터를 옮기나? → 회사 규칙에서 허락됐나?

## 직접 해 보기

1. 「비밀값은 코드 밖에」의 프롬프트로 내 폴더를 점검한다.
2. 내 트랙 상자를 따라 한다.
3. 「실제 영업에 쓰기 전 점검표」에서 내 트랙에 해당하는 줄에 답을 적어 `점검표.md` 로 저장한다. 해당 없는 줄은 「해당 없음」이라고 적는다.

::: details 업무 트랙
회사 데이터를 구글 시트로 옮기기 전에 회사 규칙을 확인하고, 그 결과를 점검표에 적습니다. 웹 앱의 접근 설정(5장)이 「같은 도메인」 이하인지 다시 봅니다.

시트에 동료의 이름·연락처가 들어가면 그것도 개인정보입니다. 꼭 필요한 칸만 둡니다.
:::

::: details 가게 트랙
AI에게 처리방침 초안을 받아 보세요. 초안은 출발점일 뿐, 그대로 쓰지 말고 개인정보보호위원회 안내와 대조합니다.

```text
SPEC.md의 손님 명단 칸을 보고, 작은 꽃집의 개인정보 처리방침 초안을 써 줘.
무엇을 모으는지, 왜 모으는지, 언제 지우는지, 홍보 동의를 어떻게 받고 거두는지 들어가게.
법 조항 번호는 지어내지 말고, 확인이 필요한 곳은 「확인 필요」라고 표시해 줘.
```

「지어내지 말고」를 붙이면 그럴듯한 조항 번호를 꾸며 내는 일을 줄일 수 있습니다.
:::

::: details 게임 트랙
게임 안에 남의 그림·음악·캐릭터를 넣지 않았는지 봅니다. AI에게 「이 게임에 쓴 그림·글꼴·소리마다 어디서 왔고 어떤 라이선스인지 표로 알려 줘」라고 물어 확인합니다.

점검표에서는 「게임을 공개하나?」 줄을 답합니다.
:::

::: details 재테크 트랙
1. 받기 스크립트를 실행할 때 인증키를 환경 변수로 넣는지 확인한다.
2. 화면에 「출처: ECOS(한국은행)」가 보이는지 확인한다.
3. 폴더에 주식시세 자료 파일이 들어 있다면, 남에게 폴더를 건넬 때 빼야 한다는 것을 SPEC.md에 적는다.
:::

## 정리

- 비밀값은 저장소에도 코드에도 적지 않는다. 실행할 때 환경 변수로 넣는다. ECOS 인증키는 남에게 주지 않는다.
- 손님 정보는 적게 모으고, 처리방침을 정한다. 광고 문자는 미리 동의받은 사람에게만, 밤 9시~아침 8시는 따로 동의받는다.
- 공공 자료와 부품은 이용 조건대로 쓴다. 주식시세 자료는 남에게 다시 배포하지 않는다.
- 실제 영업에 쓰기 전에 점검표를 확인한다.

## 용어 정리

| 용어 | 읽는 법 | 한 줄 뜻 |
|---|---|---|
| Secret | 시크릿 | 남이 알면 내 이름으로 무언가를 할 수 있는 값(비밀값) |
| API key | 에이피아이 키 | 자료 창구를 쓸 때 나를 알리는 값(인증키) |
| Privacy policy | 프라이버시 폴리시 | 개인정보를 무엇을 왜 모으고 언제 지우는지 적은 글(처리방침) |
| Opt-in | 옵트인 | 미리 동의한 사람에게만 보내는 방식 |
| License | 라이선스 | 남이 만든 것을 쓸 때 지킬 조건 |
