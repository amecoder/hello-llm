# 4장. 데이터는 어디에

<Badge type="tip" text="필수" /> 이 단계를 따라가려면 꼭 읽으세요.

> **한 줄 요약**: 데이터를 두는 곳은 크게 넷입니다. **브라우저 저장소, 파일, 구글 시트, 데이터베이스**입니다. 처음 버전은 앞의 셋으로 충분합니다.
> 브라우저 저장소는 편하지만 그 브라우저에만 있습니다. 그래서 **파일로 내보내고 다시 넣는 길**을 함께 만듭니다.

## 데이터를 두는 네 곳

화면에 적은 예약, 게임 최고 기록, 거래 기록은 어딘가에 저장돼야 다음에 열었을 때 남아 있습니다. 두는 곳마다 성질이 다릅니다.

| 두는 곳 | 어디에 있나 | 같이 볼 수 있나 | 이 가이드의 트랙 |
|---|---|---|---|
| 브라우저 저장소 | 지금 쓰는 브라우저 안 | 아니요 | 게임·가게·재테크 |
| 파일 | 내 컴퓨터 폴더 | 파일을 건네면 | 가게(백업)·재테크(거래 기록) |
| 구글 시트 | 구글 계정 | 공유한 사람끼리 | 업무 |
| 데이터베이스 | 인터넷의 서버 | 로그인한 사람끼리 | 이 단계에서는 쓰지 않음 |

데이터베이스는 여러 사람이 각자 휴대폰으로 같은 자료를 고칠 때 필요합니다. 손님이 직접 예약하는 페이지가 그런 예입니다. 대신 가입, 로그인, 접근 규칙, 무료 한도까지 함께 따라옵니다. 그래서 이 단계의 처음 버전에서는 쓰지 않고, 12장에서 「다음 크기의 일」로 소개합니다.

## 브라우저 저장소의 성질

**브라우저 저장소**(localStorage, 로컬 스토리지)는 브라우저가 사이트마다 따로 주는 작은 저장 공간입니다. 가입도 서버도 없이 바로 씁니다. 예시 게임의 최고 기록, 꽃집 도구의 예약, 대시보드에 불러온 거래 기록이 모두 여기에 저장됩니다.

알아 둘 성질이 셋 있습니다.

- **기한 없이 남습니다.** 창을 닫았다 열어도 그대로입니다.[^ls-expire]
- **그 브라우저에만 있습니다.** 크롬에 적은 예약은 엣지에서 안 보입니다. 다른 컴퓨터에서도 안 보입니다. 주소마다 따로 저장되기 때문입니다.[^ls-origin]
- **지워질 수 있습니다.** 「인터넷 사용 기록 삭제」에서 사이트 데이터까지 지우면 함께 사라집니다.

그리고 하나 더 있습니다. 가게·재테크 도구처럼 **파일을 더블클릭해서 연 페이지**에서는 브라우저 저장소가 어떻게 동작할지 정해져 있지 않고, 브라우저마다 다를 수 있습니다.[^ls-file] 그래서 내가 쓰는 브라우저에서 **새로 고침해도 남는지 직접 확인**해야 합니다(7장).

이 성질 때문에 브라우저 저장소만 믿으면 안 됩니다. 자료가 중요하면 **파일로 내보내는 버튼**을 함께 만드세요. 예시 꽃집 도구에는 「백업」 탭이 있어, 자료 전체를 파일 하나로 내려받고 그 파일로 되돌릴 수 있습니다(9장).

## 파일로 넣고 빼기

파일은 내 손에 쥘 수 있는 데이터입니다. 복사해 두면 백업이 되고, 엑셀로 열어 볼 수도 있습니다.

재테크 트랙은 거래 기록을 **CSV 파일**(쉼표로 칸을 나눈 표 파일)로 넣습니다. 이때 정할 것은 **첫 줄**입니다. 첫 줄은 칸 이름입니다. 예시 대시보드는 이렇게 정했습니다.

```text
날짜,종목,구분,수량,단가
2026-01-05,가상전자,매수,20,68500
```

첫 줄을 SPEC.md에 적어 두면 AI가 그 모양대로 읽게 만듭니다. 그리고 **틀린 파일이 들어왔을 때 어떻게 알려 줄지**도 함께 요청하세요. 진짜 데이터는 늘 조금씩 틀립니다. 칸 이름이 다르거나, 날짜를 `1/5` 처럼 적거나, 숫자에 쉼표가 들어 있습니다.

```text
거래 기록 CSV를 불러오는 버튼을 만들어 줘. 첫 줄은 「날짜,종목,구분,수량,단가」야.
틀린 파일이면 화면에 쉬운 말로 알려 줘. 몇 번째 줄의 어느 칸이 왜 틀렸는지까지.
「70,000」처럼 쉼표가 든 숫자는 읽을 수 있게 해 줘.
불러온 자료는 이 브라우저에만 저장하고, 「저장한 내 자료 지우기」 버튼도 만들어 줘.
```

예시 대시보드에 `구분` 칸이 「사기」로 적힌 파일을 넣으면 「거래 기록 2번째 줄: 구분은 매수 또는 매도로 적어 주세요.」라고 알려 줍니다. 어디를 고칠지 알면 혼자서도 고칩니다.

## 밖에서 가져오는 자료

내 자료 말고 **공공 자료**를 함께 보고 싶을 때가 있습니다. 예를 들어 재테크 대시보드에 한국은행 기준금리를 겹쳐 보는 것입니다.

한국은행의 경제통계시스템 ECOS는 자료를 프로그램으로 받을 수 있는 **Open API**(프로그램끼리 자료를 주고받는 창구)를 줍니다. 쓰려면 조건이 있습니다.

- **인증키를 신청해야 합니다.**[^ecos-key] 비영리로 쓰면 자동으로 발급됩니다.[^ecos-auto]
- 인증키 이용 기간은 **발급일부터 2년**이고, 2년 단위로 연장합니다.[^ecos-period]
- 자료를 쓰면 **ECOS에서 제공된 정보임을 표시**해야 합니다.[^ecos-source]
- 키 없이 맛보기로 쓰는 `sample` 키는 **10건까지만** 받을 수 있습니다(2026-11-16 실제로 호출해 확인).

그런데 대시보드 화면에서 ECOS를 바로 부르면 브라우저가 막습니다. 브라우저는 다른 주소의 응답을 읽기 전에, 그 응답에 「읽어도 된다」는 표시가 있는지 봅니다. 이 규칙을 **CORS**(코어스)라고 합니다. ECOS 응답에는 이 표시가 없었습니다(2026-11-16 확인).

그래서 순서를 둘로 나눕니다.

1. 작은 **받기 스크립트**가 내 인증키로 자료를 받아 CSV 파일로 저장한다.
2. 대시보드는 그 CSV 파일을 「파일로 넣고 빼기」처럼 불러온다.

```text
한국은행 ECOS Open API에서 기준금리 월별 자료를 받아 indicator.csv 로 저장하는 스크립트를 만들어 줘.
첫 줄은 「날짜,지표,값」.
인증키는 코드에 적지 말고 ECOS_API_KEY 라는 환경 변수에서 읽어 줘. 없으면 sample 키로 10건만 받아.
대시보드에는 이 파일을 불러오는 버튼과, 화면 아래에 「출처: ECOS(한국은행)」 표시를 넣어 줘.
```

인증키를 코드에 적지 않는 이유는 8장에서 다룹니다. **환경 변수**(프로그램을 실행할 때 밖에서 넣어 주는 값)로 넣으면 키가 파일에 남지 않습니다.

## 직접 해 보기

1. SPEC.md의 「자료는 어디에」를 보고, 내 트랙이 위 표의 어디에 해당하는지 확인한다.
2. 아래 트랙 상자의 요청을 보낸다.
3. 자료를 몇 개 넣고 **새로 고침**한다. 남아 있으면 성공이다. 창을 닫았다 다시 열어서도 확인한다.
4. 커밋한다.

::: details 업무 트랙
구글 시트를 하나 만들고 첫 줄에 칸 이름을 적습니다(예: `날짜, 이름, 품목, 수량`). 시트 이름도 정합니다(예: `신청`). 이 시트가 데이터베이스 역할을 합니다.

구글 시트 하나에는 셀을 **2천만 개 또는 100MB**까지 담을 수 있습니다.[^sheets-limit] 업무 도구 대부분에는 넉넉합니다. 입력 양식에서 시트로 저장하는 코드는 6장에서 Apps Script로 붙입니다.

⚠️ 지어낸 데이터로 먼저 해 보세요. 회사 자료를 옮기는 것은 회사 규칙을 확인한 뒤입니다.
:::

::: details 가게 트랙
요청 예:

```text
예약·메뉴·손님 명단을 이 브라우저 저장소에 저장해 줘.
「백업」 탭을 만들어서, 자료 전체를 파일 하나로 내려받는 버튼과 그 파일로 되돌리는 버튼을 넣어 줘.
마지막으로 백업한 날짜도 보여 줘.
```

손님 명단은 매장 컴퓨터 안에만 있어도 **개인정보**입니다. 무엇을 적고 언제 지울지는 8장에서 정합니다.
:::

::: details 게임 트랙
게임에 저장할 것은 보통 **내 최고 기록** 하나입니다. 「최고 기록을 이 기기의 브라우저 저장소에 저장해 줘」면 충분합니다.

친구끼리 겨루는 점수판은 모두의 점수를 한곳에 모아야 하니 데이터베이스가 필요합니다. 처음 버전에서는 빼 두세요(2장).
:::

::: details 재테크 트랙
「파일로 넣고 빼기」와 「밖에서 가져오는 자료」의 요청을 차례로 보냅니다.

ECOS 인증키는 [ECOS Open API 서비스](https://ecos.bok.or.kr/api/)에서 신청합니다. 키를 받기 전에는 `sample` 키로 10건만 받아 모양을 확인하세요. 받은 키는 남에게 주거나 빌려주면 안 됩니다(8장).

진짜 거래 기록을 넣기 전에 **지어낸 기록**으로 먼저 해 보세요. 계산이 맞는지 손으로 검산하기 쉽습니다.
:::

## 정리

- 데이터는 브라우저 저장소·파일·구글 시트·데이터베이스에 둔다. 이 단계의 처음 버전은 앞의 셋이다.
- 브라우저 저장소는 그 브라우저에만 있고 지워질 수 있다. 파일로 내보내고 되돌리는 버튼을 함께 만든다.
- 파일은 첫 줄(칸 이름)을 정하고, 틀린 파일을 쉬운 말로 알려 주게 한다.
- 공공 자료는 이용 조건(인증키·출처 표시)을 지킨다. 화면에서 바로 못 부르면 받기 스크립트로 파일을 만든다.

## 용어 정리

| 용어 | 읽는 법 | 한 줄 뜻 |
|---|---|---|
| localStorage | 로컬 스토리지 | 브라우저가 사이트마다 주는 작은 저장 공간 |
| Database | 데이터베이스 | 서버에 자료를 모아 두고 여럿이 함께 쓰는 곳 |
| Open API | 오픈 에이피아이 | 프로그램끼리 자료를 주고받도록 열어 둔 창구 |
| CORS | 코어스 | 브라우저가 다른 주소의 응답을 읽어도 되는지 확인하는 규칙 |
| Environment variable | 인바이런먼트 배리어블 | 프로그램을 실행할 때 밖에서 넣어 주는 값(환경 변수) |
