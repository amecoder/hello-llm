# 2장. 터미널 기초

> **한 줄 요약**: 터미널에서 꼭 필요한 명령은 몇 개뿐입니다. `pwd`로 어디 있는지 보고, `ls`로 무엇이 있는지 보고, `cd`로 옮겨 다닙니다. 이 장 끝에서 연습 폴더를 만들고 메모를 넣습니다.

이 장의 내용은 Claude Code가 아니라 터미널 자체의 기본 사용법입니다. 맥과 리눅스는 같은 명령을 씁니다. Windows PowerShell은 다른 부분을 나란히 적었습니다. 이 Windows 명령은 실행해 보지 않았습니다.

외울 필요는 없습니다. 이 페이지를 옆에 열어 두고 따라 해 보세요. 두세 번 쓰다 보면 손이 기억합니다.

## 프롬프트 읽기

터미널을 열면 맨 앞에 글자가 조금 보이고 커서가 깜빡입니다. 이것을 **프롬프트**(Prompt)라고 합니다. "명령을 기다리고 있어요"라는 표시입니다. AI에게 쓰는 글도 프롬프트라고 부르지만, 여기서는 터미널의 대기 표시를 뜻합니다.

모양은 컴퓨터마다 다릅니다. 아래는 서연이라는 사람의 예시입니다.

```text
seoyeon@macbook ~ %
seoyeon@laptop:~$
PS C:\Users\seoyeon>
```

첫 줄은 맥, 둘째 줄은 리눅스, 셋째 줄은 Windows PowerShell의 흔한 모양입니다. 읽는 법은 간단합니다. 사용자 이름과 컴퓨터 이름이 나오고, 지금 있는 폴더가 나오고, 맨 끝에 `%`, `$`, `>` 같은 기호가 옵니다.

**이 끝 기호는 내가 치는 글자가 아닙니다.** 기호 뒤에 명령을 치고 Enter를 누르면 실행됩니다. 결과가 나온 뒤 프롬프트가 다시 보이면 다음 명령을 받을 준비가 끝난 것입니다.

명령은 영어 입력 상태로 칩니다. `pwd`가 `ㅔㅈㅇ`처럼 나오면 한/영 키를 누르고 다시 치세요. 맥은 보통 `Caps Lock`이나 `Ctrl + Space`로 바꿉니다.

아무것도 안 나오는 명령도 있습니다. 오류가 아닙니다. 조용히 성공한 경우가 많습니다.

## 지금 어디 있고 무엇이 있나 — pwd와 ls

터미널은 언제나 **어떤 폴더 하나 안에** 있습니다. 탐색기나 Finder에서 폴더 하나를 열어 둔 것과 같습니다.

`pwd`는 지금 있는 폴더를 알려 줍니다. "print working directory(작업 폴더를 보여 줘)"의 줄임말입니다.

```bash
pwd
```

맥이라면 이런 식으로 나옵니다. 이름은 내 컴퓨터에 따라 다릅니다.

```text
/Users/seoyeon
```

`ls`는 지금 폴더에 무엇이 있는지 보여 줍니다. "list(목록)"의 줄임말입니다.

```bash
ls
```

두 명령은 PowerShell에서도 같은 이름으로 쓸 수 있습니다. 다만 보여 주는 모양은 조금 다릅니다.

이 두 명령은 무엇도 바꾸지 않습니다. 길을 잃었다 싶으면 언제든 쳐 보세요.

## 경로와 ~

**경로**(Path)는 파일이나 폴더의 주소입니다. 맥과 리눅스는 `/`로, Windows는 `\`로 폴더를 구분합니다. 한국어 키보드와 화면에서는 `\`가 `₩`로 보일 수 있습니다. 같은 글자입니다.

| 운영체제 | 내 집 폴더의 경로 예 |
|---|---|
| 맥 | `/Users/seoyeon` |
| 리눅스 | `/home/seoyeon` |
| Windows | `C:\Users\seoyeon` |

**집 폴더**(홈 폴더)는 내 계정의 시작 폴더입니다. 터미널을 열면 보통 여기서 시작합니다. 이 주소를 줄여 쓰는 기호가 `~`(물결표)입니다. 그래서 `~/hello-ai-연습`은 "내 집 폴더 안의 hello-ai-연습 폴더"라는 뜻입니다. 뒤의 장에 나오는 `~/.claude`는 Windows에서 `C:\Users\이름\.claude`입니다.[^win-home]

경로를 쓰는 방법은 두 가지입니다.

- **전체 주소**: `~/hello-ai-연습/터미널`처럼 어디서 쳐도 같은 곳을 가리킵니다.
- **지금 위치 기준**: `inbox`처럼 쓰면 "지금 폴더 안의 inbox"입니다.

`..`은 한 단계 위 폴더를 뜻합니다. `.`은 지금 폴더입니다.

이름에 띄어쓰기가 있으면 `"내 메모"`처럼 따옴표로 감쌉니다. 터미널은 띄어쓰기를 "여기서 다음 말이 시작된다"로 읽기 때문입니다. 이 강좌의 폴더 이름에 띄어쓰기를 넣지 않은 것도 그래서입니다.

## 명령 읽는 법

명령은 낱말 몇 개로 이루어집니다. 낱말은 띄어쓰기로 나뉩니다. 처음 보는 명령도 순서대로 끊어 읽으면 뜻이 보입니다.

```bash
ls -la ~
```

| 조각 | 이름 | 뜻 |
|---|---|---|
| `ls` | 명령 이름 | 무엇을 할까: 목록 보기 |
| `-la` | 옵션 | 어떻게 할까: 숨긴 파일까지 자세히 |
| `~` | 대상 | 어디에 할까: 집 폴더 |

이 예는 맥·리눅스 명령입니다. Windows PowerShell에서는 `ls -Force ~`로 씁니다.

옵션은 명령의 동작을 바꾸는 스위치입니다. 맥·리눅스에는 두 가지 모양이 있습니다.

- **짧은 옵션**: `-` 하나와 글자 하나입니다. `-l`과 `-a`를 붙여 `-la`로 쓸 수 있습니다.
- **긴 옵션**: `--` 두 개와 낱말입니다. `--version`처럼 뜻이 잘 보입니다.

PowerShell은 `-Force`처럼 `-` 하나에 낱말을 붙입니다. 같은 뜻의 옵션이어도 이름이 다를 수 있습니다. `claude`와 `git`의 옵션은 어느 운영체제에서나 같습니다.

옵션 뒤에 값이 붙기도 합니다. `--max-turns 10`은 "횟수 상한은 10"이라는 뜻입니다. 따옴표로 묶은 부분은 한 덩어리입니다. `claude -p "메모를 요약해 줘"`에서 따옴표 안은 띄어쓰기가 있어도 낱말 하나로 칩니다.

모든 명령을 외울 필요는 없습니다. 이 강좌의 명령은 [명령어 사전](command-reference.md)에 모아 두었습니다. 낯선 조각이 보이면 찾아보세요.

## 옮겨 다니고 만들고 복사하기 — cd, mkdir, cp

`cd`는 다른 폴더로 옮겨 갑니다. "change directory(폴더 바꾸기)"의 줄임말입니다. 아래의 연습 폴더는 이 장 끝에서 만듭니다. 지금은 읽기만 하세요.

```bash
cd ~/hello-ai-연습
cd ..
cd ~
```

위에서부터 연습 폴더로 가기, 한 단계 위로 가기, 집 폴더로 가기입니다. PowerShell에서도 그대로 됩니다.

`mkdir`은 새 폴더를 만듭니다. "make directory(폴더 만들기)"의 줄임말입니다. 맥과 리눅스에서는 `mkdir -p`로 쓰면 중간 폴더까지 한 번에 만듭니다. PowerShell의 `mkdir`은 `-p` 없이도 그렇게 합니다. 실제 명령은 이 장 끝의 실습에서 쳐 봅니다.

`cp`는 파일을 복사합니다. "copy(복사)"의 줄임말입니다. **무엇을, 어디로** 순서로 씁니다.

아쉬운 예입니다. 어디로 복사할지 빠졌습니다.

```bash
cp 메모.txt
```

나은 예입니다. 무엇을, 어디로가 다 있습니다.

```bash
cp 메모.txt inbox/
```

복사라서 원래 파일은 그대로 남습니다. 다만 같은 이름의 파일이 이미 있으면 말없이 덮어쓸 수 있습니다. 복사하기 전에 `ls`로 한 번 보세요.

## 손이 편해지는 키

명령을 다 외우고 다 칠 필요는 없습니다. 아래 다섯 가지만 알면 훨씬 편합니다.

**붙여넣기.** 맥은 `Cmd + V`, 리눅스는 `Ctrl + Shift + V`입니다.[^paste] PowerShell은 `Ctrl + V`나 오른쪽 클릭입니다.[^paste-win] 이 페이지의 명령은 복사해서 붙여 넣어도 됩니다. 오타가 줄어듭니다. 붙여 넣은 뒤 아직 실행되지 않았으면 Enter를 한 번 더 누르세요.

**복사하기.** 터미널의 글자를 마우스로 끌어 고른 뒤 맥은 `Cmd + C`, 리눅스는 `Ctrl + Shift + C`를 누릅니다. Windows는 고른 상태에서 `Ctrl + C`나 오른쪽 클릭입니다. 프로그램에 따라 조금 다를 수 있습니다.

**위쪽 화살표.** 방금 친 명령이 다시 나옵니다. 여러 번 누르면 더 예전 명령으로 갑니다. 조금만 고쳐 다시 실행할 때 좋습니다.

**Tab.** 이름을 앞부분만 치고 Tab을 누르면 나머지를 채워 줍니다. `cd ~/Doc`까지 치고 Tab을 눌러 보세요. `Documents` 폴더가 없으면 `ls`에 보이는 다른 폴더 이름으로 해 보세요. 긴 한글 파일 이름에서 특히 쓸모가 있습니다. 한글에서 잘 안 채워지면 이름을 복사해 붙여 넣으면 됩니다.

**Ctrl+C.** 돌고 있는 명령을 멈춥니다. 터미널이 멈춘 것 같으면 먼저 눌러 보세요. 아래 명령은 30초를 기다립니다. 맥, 리눅스, PowerShell에서 모두 됩니다.

```bash
sleep 30
```

기다리지 말고 `Ctrl + C`를 눌러 보세요. 프롬프트가 바로 돌아옵니다. 맥에서도 `Cmd`가 아니라 `Ctrl`입니다. 글자를 고르지 않은 상태에서 Ctrl+C는 "멈춰"입니다. Windows는 글자를 고른 상태에서만 복사입니다.

## 직접 해 보기

연습 폴더를 만들고 메모를 넣어 봅니다. 이 폴더는 이 강좌 내내 씁니다.

**1. 연습 폴더를 만들고 들어갑니다.**

맥·리눅스는 이렇게 칩니다.

```bash
mkdir -p ~/hello-ai-연습/터미널/inbox
cd ~/hello-ai-연습/터미널
pwd
ls
```

Windows PowerShell은 이렇게 칩니다.

```powershell
mkdir $HOME\hello-ai-연습\터미널\inbox
cd $HOME\hello-ai-연습\터미널
pwd
ls
```

맥·리눅스 명령의 `-p`는 중간 폴더까지 한 번에 만들라는 옵션입니다. 이 옵션이 없으면 `hello-ai-연습` 폴더가 없을 때 오류가 납니다. `$HOME`은 PowerShell에서 집 폴더를 가리키는 이름입니다. `pwd` 결과가 `터미널`로 끝나고 `ls`에 `inbox`가 보이면 성공입니다.

**2. 연습 메모를 내려받습니다.**

브라우저에서 아래 링크를 오른쪽 클릭해 「다른 이름으로 링크 저장」을 고릅니다. 브라우저마다 이름은 조금 다릅니다. 저장 위치는 다운로드 폴더 그대로 두세요.

- [회의-2026-10-27-주간회의.txt](/practice/notes/inbox/회의-2026-10-27-주간회의.txt)

모두 지어낸 메모입니다. 날짜와 요일도 이야기를 위해 지어낸 것이라 실제 달력과 맞지 않습니다. 뒤의 장에서 Claude가 이 점을 지적할 수 있습니다. 틀린 말이 아니니 놀라지 않아도 됩니다.

**3. 메모를 inbox로 복사합니다.**

맥·리눅스는 이렇게 칩니다.

```bash
cp ~/Downloads/회의-2026-10-27-주간회의.txt inbox/
```

Windows PowerShell은 이렇게 칩니다.

```powershell
cp $HOME\Downloads\회의-2026-10-27-주간회의.txt inbox\
```

맥은 Finder에 「다운로드」로 보여도 실제 폴더 이름은 `Downloads`입니다. 리눅스를 한글로 쓰면 `~/다운로드`일 수 있습니다. 그럴 때는 `~/Downloads`를 `~/다운로드`로 바꿔 치세요.

**4. 잘 들어갔는지 봅니다.**

```bash
ls inbox
cat inbox/회의-2026-10-27-주간회의.txt
```

`cat`은 파일 내용을 화면에 보여 줍니다. PowerShell에서 한글이 깨지면 이렇게 칩니다.

```powershell
Get-Content -Encoding UTF8 inbox\회의-2026-10-27-주간회의.txt
```

스스로 물어보세요. `pwd` 결과가 내가 생각한 폴더인가? `ls inbox`에 메모 파일이 보이나? 둘 다 그렇다면 다음 장으로 갈 준비가 끝났습니다.

**막혔을 때**: `No such file or directory`나 "찾을 수 없다"는 말이 나오면 대부분 위치나 이름이 다른 것입니다. `pwd`로 위치를 보고, `ls ~/Downloads`로 파일이 정말 있는지 보세요.

## 정리

- 프롬프트는 "명령을 기다린다"는 표시다. 끝 기호는 치지 않는다.
- `pwd`는 지금 위치, `ls`는 목록을 보여 준다. 아무것도 바꾸지 않으니 자주 쓴다.
- `~`는 내 집 폴더, `..`은 한 단계 위다.
- `cd`는 옮겨 가기, `mkdir`은 폴더 만들기, `cp`는 "무엇을, 어디로" 복사하기다.
- 위쪽 화살표는 지난 명령, Tab은 이름 채우기, Ctrl+C는 멈추기다.

## 용어 정리

| 용어 | 읽는 법 | 한 줄 뜻 |
|---|---|---|
| Prompt | 프롬프트 | 터미널이 명령을 기다린다는 표시 |
| Path | 패스 | 파일이나 폴더의 주소(경로) |
| Home | 홈 | 내 계정의 시작 폴더(줄여서 `~`) |
| `pwd` | 피더블유디 | 지금 있는 폴더를 보여 주는 명령 |
| `ls` | 엘에스 | 폴더 안의 목록을 보여 주는 명령 |
| `cd` | 씨디 | 다른 폴더로 옮겨 가는 명령 |
| `mkdir` | 엠케이디르 | 새 폴더를 만드는 명령 |
| `cp` | 씨피 | 파일을 복사하는 명령 |
| `cat` | 캣 | 파일 내용을 화면에 보여 주는 명령 |
