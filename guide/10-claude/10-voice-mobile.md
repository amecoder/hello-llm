# 10장. 음성과 휴대폰 — 말로 묻고, 휴대폰에서 더 빨리

> **한 줄 요약**: 입력창의 **마이크**는 내 말을 글자로 받아 적고(받아쓰기), **음파 기호**는 Claude와 말로 주고받게 해 줍니다(음성 모드).
> 휴대폰에서는 위젯·단축어·잠금 화면으로 더 빨리 열 수 있고, 메시지·메일 초안을 앱으로 바로 넘겨받을 수 있습니다.

화면은 2026년 10월 웹 기준입니다. 휴대폰 앱과 컴퓨터 앱은 버튼 위치가 조금 다를 수 있고, 설정 메뉴 이름도 화면에 따라 다를 수 있습니다.

## 받아쓰기와 음성 모드

말로 쓰는 기능은 두 가지입니다. 이름이 비슷하지만 하는 일이 다릅니다.[^dictation][^voice]

| | 받아쓰기 (Dictation) | 음성 모드 (Voice mode) |
|---|---|---|
| 버튼 | 입력창 오른쪽 **마이크** | 마이크 옆 **음파 기호** |
| 하는 일 | 내 말을 글로 바꿔 보낸다 | 말로 묻고 말로 듣는다 |
| Claude의 답 | 글로 온다 | 목소리로 온다 |
| 어울리는 때 | 긴 질문을 치기 귀찮을 때 | 손이 바쁠 때, 말하며 생각을 정리할 때 |

정확한 문장이 중요하면 **받아쓰기**를 쓰세요. 내 질문과 답이 모두 글로 남아 다시 읽어 볼 수 있습니다. 주고받는 대화가 필요하면 **음성 모드**를 쓰세요.

두 기능 모두 무료 요금제에서도 쓸 수 있습니다.[^dictation][^voice]

## 받아쓰기 해 보기

이 절은 휴대폰 앱(아이폰·안드로이드)의 받아쓰기를 설명합니다.[^dictation] 컴퓨터 앱의 Cowork에서도 받아쓰기를 쓸 수 있습니다.[^voice]

1. Claude 앱에서 새 채팅을 엽니다.
2. 입력창 오른쪽의 **마이크**를 누릅니다.
3. 처음 쓸 때는 말할 언어를 고릅니다.
4. 평소처럼 말합니다.
5. 화살표를 눌러 보냅니다. 보내지 않으려면 「X」를 누릅니다.

아래처럼 말해 보세요.

```
이번 주말에 초등학생 아이와 집에서 할 수 있는 과학 실험 세 가지 알려 줘.
준비물은 부엌에 있는 것만 쓰는 걸로.
```

받아쓰기는 한국어를 포함해 12개 언어를 지원합니다. 영어가 아닌 언어는 아직 시험판(베타)입니다. 언어를 바꾸려면 오른쪽 위 이니셜을 누르고 「음성 입력 언어」를 고르세요.[^dictation]

사람 이름이나 지명은 잘못 받아 적힐 수 있습니다. 보낸 뒤 채팅 창에 적힌 내 질문을 한 번 읽어 보세요.[^dictation]

## 음성 모드 해 보기

음성 모드는 아직 **시험판**입니다. 웹·컴퓨터 앱·휴대폰 앱에서 모두 쓸 수 있지만, 휴대폰에서 가장 잘 되도록 만들어졌습니다.[^voice]

**웹·컴퓨터 앱에서**

1. 새 채팅을 엽니다.
2. 채팅창 오른쪽 아래의 **음파 기호**를 누릅니다.
3. 말을 하면 입력창에 내 말이 저절로 적힙니다. 말을 마치면 Claude가 대답합니다.
4. 끝내려면 오른쪽 아래 「중지」(Stop)를 누릅니다.

**휴대폰 앱에서**

1. 입력창의 마이크 옆 **음파 기호**를 누릅니다.
2. 마음에 드는 목소리를 고릅니다.
3. 말을 시작합니다.[^voice]

### 듣는 방식 두 가지

- **핸즈프리 모드**(hands-free): 처음부터 켜져 있는 방식입니다. Claude가 계속 듣다가 내가 말을 멈추면 대답합니다. 조용한 곳에서 가장 잘 됩니다.
- **푸시투톡 모드**(push-to-talk): 말하는 동안 버튼을 누르고 있다가, 다 말하면 손을 뗍니다. 시끄러운 곳이나 옆에서 다른 사람이 말할 때 더 정확합니다.[^voice]

Claude가 엉뚱한 방향으로 가면 그냥 말을 시작하세요. Claude가 멈추고 듣습니다. 질문이 여러 개라면 한꺼번에 말하지 말고 하나씩 물어보세요.[^voice] 한 번에 하나씩 물으면 답도 짧아져서 귀로 듣기 편합니다.

말로 해 보기 좋은 요청입니다.

```
다음 주에 면접이 있어. 네가 면접관이 돼서 질문을 하나씩 해 줘.
내가 대답하면 좋았던 점 하나, 고칠 점 하나만 짧게 말해 주고 다음 질문으로 넘어가 줘.
```

### 알아 둘 점

- 음성 대화도 **요금제 사용 한도에 들어갑니다**([1장](01-getting-started.md)).
- 같은 대화 안에서 글과 말을 오가도 **앞의 내용이 이어집니다.** 인터넷 주소처럼 정확히 쳐야 하는 것은 중간에 글로 입력하면 됩니다.
- 글 채팅에서 마지막으로 쓴 모델로 시작하고, 대화 중에 바꿀 수 있습니다. 다만 Claude Fable은 음성 모드에서 아직 쓸 수 없습니다(2026-10-26 확인).
- 연결해 둔 도구(Gmail·Google 캘린더 등)도 음성 모드에서 쓸 수 있습니다. 음성 모드 도움말은 무료 요금제에서 도구를 하나 연결할 수 있다고 적습니다. 도구 연결은 [7장](07-projects-tools.md)에서 다룹니다.
- Cowork([8장](08-cowork.md))에서는 받아쓰기만 되고 음성 모드는 안 됩니다. 새 Claude 화면에서는 Claude가 작업 중인 대화를 포함해 어떤 대화에서든 음성 모드를 쓸 수 있습니다.[^voice]

## 목소리와 언어 바꾸기

Claude의 목소리는 정해진 몇 가지 가운데서만 고릅니다. 누군가의 목소리를 흉내 내거나 베끼지 못하게 하려는 것입니다.[^voice]

- **웹·컴퓨터 앱**: 「설정」 → 「기능」에서 아래로 내려 음성 설정을 찾습니다. 없으면 「설정」 → 「일반」을 보세요. 목소리를 누르면 미리 들어 볼 수 있습니다.
- **휴대폰 앱**: 음성 모드 중에 왼쪽 아래 설정 버튼을 누르고 목소리와 말 빠르기를 고릅니다.[^voice]

**말할 언어는 따로 정해야 합니다.** 앱 화면을 한국어로 바꿔도 음성 언어는 바뀌지 않습니다. 「설정」 → 「기능」 → 음성 → 「음성 언어」에서 고르세요. 영어가 아닌 언어는 시험판입니다. 대화 중에 "한국어로 말해 줘"라고 부탁해도 됩니다.[^voice]

## 목소리 기록과 개인정보

**음성 대화도 글로 남습니다.** 음성 모드로 나눈 대화는 글 기록으로 바뀌어 일반 대화처럼 채팅 기록에 저장됩니다.[^voice]

**받아쓰기 녹음은 남지 않습니다.** 말을 글로 바꾼 뒤 녹음은 지워지고, 학습에도 쓰이지 않습니다.[^dictation] 다만 **바뀐 글**은 일반 대화와 같습니다. 대화 보관 기간을 따르고, 학습을 허용했다면 학습에 쓰일 수 있습니다.[^dictation-privacy] 학습 설정은 [9장](09-privacy.md)에서 봤습니다.

말로 하는 대화는 **옆 사람에게도 들립니다.** 내 질문도, Claude의 대답도 들립니다.

- 지하철·카페·사무실에서는 이어폰을 쓰거나 받아쓰기로 조용히 입력하세요.
- [1단계 9장](../00-common/09-safety.md#넣지-말아야-할-것)에서 본 **넣지 말아야 할 정보는 소리 내어 말하지도 마세요.** 말로 할 때는 글로 칠 때보다 무심코 말해 버리기 쉽습니다.

## 휴대폰에서 더 빨리 — 위젯·단축어·잠금 화면

앱을 찾아 열지 않고도 Claude를 부를 수 있습니다. 모두 **사용 한도에 들어갑니다.**[^ios][^android]

### 아이폰 (iOS 18 이상)

- **「Claude에 물어보기」**(Ask Claude): 앱을 열지 않고 질문합니다. Spotlight 검색, Siri, 공유 메뉴에서 쓸 수 있습니다. 예를 들어 글을 골라 공유 메뉴로 바로 Claude에 보낼 수 있습니다.
- **위젯**: 홈 화면이나 오늘 보기에 Claude 위젯을 놓으면 새 채팅, 받아쓰기, 사진 찍어 보내기를 버튼 하나로 엽니다.
- **「Claude로 사진 분석」**(Analyze Photo with Claude): 제어 센터나 잠금 화면에 넣으면 잠금을 풀지 않고도 사진을 찍어 보낼 수 있습니다.
- **「Open Claude」**: 잠금 화면, 제어 센터, 동작 버튼(Action button)에 넣어 Claude를 바로 엽니다.[^ios][^lock]

「Claude에 물어보기」와 단축어는 앱을 열었을 때 보이는 기본 모델을 씁니다.[^ios]

### 단축어로 "요약 버튼" 만들기

아이폰의 단축어 앱으로 나만의 버튼을 만들 수 있습니다. 도움말의 예를 따라 해 보세요.[^ios]

1. 단축어 앱에서 「+」를 눌러 새 단축어를 만듭니다.
2. 공유(Share) 동작을 넣고, 받을 내용의 종류를 고릅니다.
3. 「Claude에 물어보기」 동작을 넣습니다.
4. 그 안에 프롬프트를 적습니다. 예: `다음 글을 세 줄로 요약해 줘: [단축어 입력]`
5. 이름을 붙이고(예: 「Claude로 요약」) 공유 시트에 넣습니다.

이제 어떤 앱에서든 글을 골라 공유 버튼을 누르고 「Claude로 요약」을 고르면 됩니다.

<!-- 스크린샷 필요: 아이폰 단축어 앱에서 「Claude에 물어보기」 동작을 넣은 화면 -->

### 안드로이드 (Android 8.0 이상)

홈 화면 빈 곳을 길게 누르고 「위젯」에서 Claude를 찾아 놓습니다. 버튼은 세 개입니다.[^android]

- **채팅 버튼**: 새 대화를 바로 엽니다.
- **카메라 버튼**: 사진을 찍어 Claude에 보냅니다.
- **마이크 버튼**: 새 대화를 열고 받아쓰기를 시작합니다.

## 휴대폰 앱과 연결하기 — 메시지·메일·캘린더·지도

휴대폰 앱의 Claude는 휴대폰에 들어 있는 다른 앱과 연결해 일을 도울 수 있습니다. 모든 요금제에서 됩니다.[^ios-apps][^android-apps]

| | 아이폰 | 안드로이드 |
|---|---|---|
| 메시지·메일·캘린더 | 된다 | 된다 |
| 위치·지도 | 된다 | 된다 |
| 미리 알림 | 된다 | 안 된다 |
| 알람·타이머 | — | 된다 |

**메시지와 메일은 초안까지만 Claude가 만듭니다.** Claude가 내용을 채운 카드를 보여 주고, 누르면 메시지 앱이나 메일 앱이 열립니다. 내용을 읽고 고친 뒤 **보내기는 내가 직접** 누릅니다. Claude는 이미 받은 메시지나 메일을 읽지 않고, 연락처에도 직접 들어가지 않습니다.[^ios-apps]

아래처럼 부탁해 보세요.

```
내일 아침 회의에 병원 진료 때문에 30분 늦는다고 팀장님께 보낼 메일 초안 써 줘.
짧고 정중하게.
```

초안이 메일 앱으로 넘어가면 받는 사람과 내용을 확인하고 보내세요. [9장](09-privacy.md)에서 본 가짜 "보냈어요"와 달리, 여기서는 내가 보내기 버튼을 눌러야 실제로 갑니다.

### 권한은 내가 정합니다

Claude가 위치나 캘린더를 처음 쓰려 하면 허락을 묻습니다. 한 번 허용(Allow once), 항상 허용(Always allow), 허용 안 함(Don't allow) 가운데 고릅니다.[^ios-apps] 나중에 바꾸려면 휴대폰 설정에서 찾으세요.

- **아이폰**: 「설정」 → 「Claude」
- **안드로이드**: 「설정」 → 「앱」 → 「Claude」 → 「권한」[^ios-apps][^android-apps]

건강 데이터를 읽는 기능도 있지만, 시험판이고 Pro·Max 요금제에 미국에서만 됩니다.[^ios-apps]

## 직접 해 보기

**1. 같은 질문, 두 가지 방법**

아래 질문을 한 번은 **마이크(받아쓰기)**로, 한 번은 새 채팅에서 **음파 기호(음성 모드)**로 해 봅니다.

```
냉장고에 계란, 두부, 대파가 있어. 15분 안에 만들 수 있는 반찬 두 가지 알려 줘.
```

그리고 스스로 물어보세요. 받아쓰기로 적힌 글이 내가 말한 것과 같은가? 답을 듣는 것과 읽는 것 중 어느 쪽이 편한가?

**2. 끼어들어 보기**

음성 모드에서 긴 설명을 부탁한 뒤, Claude가 말하는 도중에 "잠깐, 더 짧게"라고 말해 봅니다. Claude가 멈추고 짧게 다시 말하는지 확인해 보세요.

**3. 휴대폰에 바로가기 하나 놓기**

아이폰이면 홈 화면에 Claude 위젯을, 안드로이드면 Claude 위젯을 놓아 봅니다. 마이크 버튼을 눌러 받아쓰기가 바로 열리는지 확인합니다.

## 정리

- 마이크는 **받아쓰기**: 말을 글로 바꿔 보내고, 답은 글로 온다. 이 장은 휴대폰 앱 기준으로 설명했다.
- 음파 기호는 **음성 모드**: 말로 묻고 말로 듣는다. 시험판이고, 휴대폰에서 가장 잘 된다.
- 음성 모드는 핸즈프리가 기본이고, 시끄러우면 푸시투톡으로 바꾼다. 사용 한도에 들어간다.
- 말할 언어는 앱 화면 언어와 따로 「음성 언어」에서 정한다.
- 음성 대화는 글 기록으로 남는다. 받아쓰기 녹음은 지워지지만 바뀐 글은 학습 설정을 따른다.
- 아이폰은 「Claude에 물어보기」·단축어·위젯·잠금 화면, 안드로이드는 위젯으로 빨리 연다.
- 메시지·메일은 Claude가 초안을 만들고, 보내기는 내가 한다. 권한은 휴대폰 설정에서 바꾼다.

## 용어 정리

| 용어 | 읽는 법 | 한 줄 뜻 |
|---|---|---|
| Dictation | 딕테이션 (받아쓰기) | 말을 글로 바꿔 입력하는 기능 |
| Voice mode | 보이스 모드 (음성 모드) | Claude와 말로 주고받는 기능 |
| Hands-free | 핸즈프리 | 버튼 없이 말을 멈추면 대답하는 방식 |
| Push-to-talk | 푸시투톡 | 버튼을 누르고 있는 동안만 듣는 방식 |
| Beta | 베타 (시험판) | 정식 출시 전에 시험 삼아 내놓은 기능 |
