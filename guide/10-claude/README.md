# 2단계 · Claude 사용 가이드

1단계에서 어떤 AI에든 통하는 **잘 묻는 법**을 배웠다면, 2단계에서는 **Claude라는 서비스의 화면과 기능**을 익힙니다.
버튼이 어디 있는지, 대화를 어떻게 정리하는지, 내 정보가 어떻게 쓰이는지 같은 것입니다.

> **이 가이드는 2026년 10월 26일에 확인한 Anthropic 공식 도움말을 바탕으로 썼습니다.** Claude는 메뉴 이름과 기능이 자주 바뀝니다.
> 지금은 채팅과 Cowork를 합친 새 화면이 차례로 배포되고 있어서, 사람마다 화면이 조금 다를 수 있습니다.
> 내 화면과 다르면 화면에 보이는 이름을 따르세요. 최신 내용은 각 장의 각주에 있는 공식 도움말 링크에서 확인하면 됩니다.

| 장 | 제목 | 이런 걸 알게 됩니다 |
|---|---|---|
| 1 | [시작하기](01-getting-started.md) | 쓰는 곳, 가입하는 법, 요금제와 사용 한도 |
| 2 | [화면 둘러보기](02-screen-tour.md) | 옆 메뉴, 입력창, 모델 고르기, 설정 화면 |
| 3 | [대화 관리](03-chats.md) | 대화 찾기·삭제, 공유, 기록이 남지 않는 시크릿 채팅 |
| 4 | [파일과 아티팩트](04-files-artifacts.md) | 파일 올리기, 문서·표 파일 만들기, 아티팩트 |
| 5 | [기억과 맞춤 설정](05-memory.md) | 지침, 메모리가 기억하는 것과 지우는 법 |
| 6 | [검색과 리서치](06-search.md) | 웹 검색과 출처 확인, 긴 보고서를 받는 리서치 |
| 7 | [프로젝트·커넥터·스킬](07-projects-tools.md) | 자료를 묶는 프로젝트, 다른 앱 연결, 스킬 |
| 8 | [Cowork — 일을 통째로 맡기기](08-cowork.md) | 여러 단계 일을 맡기는 법, 예약 작업, 안전하게 쓰는 법 |
| 9 | [개인정보와 안전](09-privacy.md) | 학습에 쓰이지 않게 하기, 내보내기, 계정 삭제 |
| 10 | [음성과 휴대폰](10-voice-mobile.md) | 받아쓰기와 음성 모드, 휴대폰에서 빨리 여는 법 |
| 11 | [실습 과제](11-practice.md) | 1~10장 기능을 직접 해 보는 과제와 점검표 |
| 12 | [전문가처럼 쓰기](12-expert.md) | 일에 맞는 기능 고르기, 지침·스킬로 쌓기, 표 파일 분석과 차트, Claude Academy |

1단계를 아직 읽지 않았다면 [1단계 · 공통 가이드](../00-common/)부터 보세요. 2단계에서는 1단계에서 설명한 원리를 다시 설명하지 않고 링크로 이어 줍니다.
