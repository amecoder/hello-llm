# 4단계 · AI-SDLC 가이드

SDLC(소프트웨어 개발 생애 주기)는 아이디어가 실제로 돌아가는 소프트웨어가 되기까지 거치는 단계입니다. 4단계에서는 3단계에서 익힌 AI 도구와 함께 **작은 웹 페이지 하나를 기획부터 배포·개선까지** 만들어 봅니다.
코드를 몰라도 괜찮습니다. 이 단계에서 배우는 것은 코드 짜는 법이 아니라 **AI에게 무엇을 건네고, 무엇을 돌려받아 확인하는가**입니다.

> **이 가이드는 2026년 11월 1일에 확인한 GitHub·Claude Code 공식 문서와 spec-kit·OpenSpec 저장소의 설명을 바탕으로 썼습니다.** 기능과 화면 이름은 자주 바뀝니다.
> GitHub 무료 계정이면 됩니다. AI 도구는 3단계에서 쓴 것(Claude Code·Codex·Antigravity)을 그대로 씁니다.
