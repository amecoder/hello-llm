# 2단계 · ChatGPT 사용 가이드

1단계에서 어떤 AI에든 통하는 **잘 묻는 법**을 배웠다면, 2단계에서는 **ChatGPT라는 서비스의 화면과 기능**을 익힙니다.
버튼이 어디 있는지, 대화를 어떻게 정리하는지, 내 정보가 어떻게 쓰이는지 같은 것입니다.

> **이 가이드의 화면은 2026년 10월 웹 화면(한국어, Plus 요금제) 기준입니다.** ChatGPT는 메뉴 이름과 기능이 자주 바뀝니다.
> 내 화면과 다르면 화면에 보이는 이름을 따르고, 각 장의 각주에 있는 OpenAI 공식 도움말 링크에서 최신 내용을 확인하세요.

| 장 | 제목 | 이런 걸 알게 됩니다 |
|---|---|---|
| 1 | [시작하기](01-getting-started.md) | 로그인 없이 써 보기, 가입하는 법, 요금제마다 다른 점 |
| 2 | [화면 둘러보기](02-screen-tour.md) | 옆 메뉴, 입력창의 + 메뉴, 추론 수준, 설정 화면 |
| 3 | [대화 관리](03-chats.md) | 대화 찾기·보관·삭제, 공유 링크, 기록이 남지 않는 임시 채팅 |
| 4 | [파일·사진과 이미지 만들기](04-files-images.md) | 파일 올리기와 한도, 라이브러리, 이미지 만들기 |
| 5 | [기억과 맞춤 설정](05-memory.md) | 메모리가 무엇을 기억하는지, 지우는 법, 사용자 지정 지침 |
| 6 | [검색과 심층 리서치](06-search.md) | 웹 검색과 출처 확인, 긴 보고서를 받는 심층 리서치 |
| 7 | [프로젝트·플러그인·Work](07-projects-plugins.md) | 자료를 묶는 프로젝트, 플러그인, Chat과 Work의 차이 |
| 8 | [개인정보와 데이터 관리](08-privacy.md) | 학습에 쓰이지 않게 하기, 내보내기, 계정 삭제 |
| 9 | [음성으로 대화하기](09-voice.md) | 받아쓰기와 음성 대화, 음성 스타일 |
| 10 | [실습 과제](10-practice.md) | 1~9장 기능을 직접 해 보는 과제와 점검표 |

1단계를 아직 읽지 않았다면 [1단계 · 공통 가이드](../00-common/)부터 보는 것을 권합니다. 2단계에서는 1단계에서 설명한 원리를 다시 설명하지 않고 링크로 이어 줍니다.
