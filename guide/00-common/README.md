# 1단계 · 모든 LLM에 통하는 공통 가이드

ChatGPT든 Claude든 Gemini든, 이 단계에서 배우는 내용은 어디서나 똑같이 통합니다.
순서대로 읽는 것을 권합니다. 각 절 끝의 **확인 퀴즈**로 읽은 내용을 바로 점검할 수 있습니다.

| 장 | 제목 | 이런 걸 알게 됩니다 |
|---|---|---|
| 1 | [LLM이란 무엇인가](01-what-is-llm.md) | AI가 어떻게 답을 만드는지, 왜 가끔 틀리는지 |
| 2 | [왜 이렇게 화제인가](02-why-it-matters.md) | 무엇이 달라졌길래 모두가 이야기하는지 |
| 3 | [왜 배워야 하나](03-why-learn.md) | 잘 쓰는 사람과 그렇지 않은 사람의 차이 |
| 4 | [프롬프트 기초](04-prompt-basics.md) | 좋은 답을 받는 요청 글 쓰는 법 |
| 5 | [프롬프트 패턴](05-prompt-patterns.md) | Few-shot·CoT 등 여덟 가지 요청 요령과 전문 용어 |
| 6 | [대화를 이어 가며 다듬기](06-conversation.md) | 고쳐 달라고 잘 말하는 법, 새 대화를 시작할 때 |
| 7 | [구조화 프롬프트](07-structured-prompts.md) | 마크다운·XML로 긴 요청 정리하기, 프롬프트 편집기로 직접 만들어 보기 |
| 8 | [메타 프롬프팅](08-meta-prompting.md) | 프롬프트를 AI에게 만들게 하고 고치게 하는 법 |
| 9 | [안전하게 쓰기](09-safety.md) | 환각 확인, 개인정보 가리기, 저작권, 숨은 지시(프롬프트 인젝션) 막기 |
| 10 | [실습 과제 모음](10-practice.md) | 배운 것을 내 일에 직접 써 보는 과제 9개와 점검표 |
| 11 | [전문가처럼 쓰기](11-expert.md) | 무엇을 맡길지 판단하고, 맡기기 전에 시험하고, 되풀이하는 일을 쌓아 두는 법 |

각 장에 나온 프롬프트는 [바로 쓰는 프롬프트 모음](prompt-library.md)에 쓰임새별로 모아 두었습니다. 복사해서 빈칸만 바꿔 쓰세요.
