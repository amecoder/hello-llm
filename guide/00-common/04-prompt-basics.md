# 4장. 프롬프트 기초

> **한 줄 요약**: 좋은 프롬프트는 처음 만난 유능한 동료에게 일을 부탁하는 글과 같습니다.
> 그 사람은 똑똑하지만 내 사정은 하나도 모릅니다.

## 프롬프트란

**프롬프트(prompt)** 는 AI에게 보내는 요청 글입니다. 채팅창에 입력하는 모든 글이 프롬프트입니다.

[1장](01-what-is-llm.md)에서 AI는 "내 상황을 모른다"고 했습니다. 그래서 프롬프트의 핵심은
**AI가 모르는 것을 알려 주는 것**입니다.

새로 온 유능한 동료에게 일을 맡긴다고 상상해 보세요. "보고서 좀 써 줘"라고만 하면
그 동료는 무슨 보고서인지, 누가 읽는지, 얼마나 길게 쓸지 몰라 되물을 것입니다.
AI는 대부분 되묻지 않고 그냥 짐작해서 씁니다. 그래서 처음부터 알려 주는 것이 중요합니다.

## 좋은 프롬프트의 5요소

모든 요소를 매번 넣을 필요는 없습니다. 답이 마음에 들지 않을 때, 빠진 요소가 무엇인지 점검하는 목록으로 쓰세요.

| 요소 | 질문 | 예 |
|---|---|---|
| **1. 목표** | 무엇을 원하나? | "거절 메일을 써 줘" |
| **2. 맥락** | 어떤 상황인가? | "협력사가 납품 기한을 2주 늦춰 달라고 요청했어" |
| **3. 대상** | 누가 읽나? | "상대는 10년 거래한 협력사 부장님이야" |
| **4. 형식** | 어떤 모양으로? | "다섯 문장 이내, 정중한 존댓말" |
| **5. 조건** | 꼭 지킬 것·피할 것은? | "다음 거래에 대한 기대는 남겨 줘. 사과는 과하게 하지 마" |

![목표(무엇을 원하나), 맥락(어떤 상황인가), 대상(누가 읽나), 형식(어떤 모양으로), 조건(지킬 것·피할 것) 다섯 가지가 모여 좋은 프롬프트가 된다. 매번 다 넣을 필요는 없고, 답이 아쉬울 때 점검 목록으로 쓴다](assets/ch4-five-elements.svg)

다섯 요소를 모두 넣으면 이렇게 됩니다.

```
협력사가 납품 기한을 2주 늦춰 달라고 요청했는데, 우리 쪽 출시 일정 때문에 어렵다는
답장을 써 줘. 상대는 10년 동안 거래한 협력사 부장님이야.
다섯 문장 이내의 정중한 존댓말로 쓰고, 다음 거래에 대한 기대는 남겨 줘.
사과는 과하게 하지 마.
```

## 전후 비교로 익히기

### 예 1. 요약

**아쉬운 프롬프트**

```
이 기사 요약해 줘.
```

**좋은 프롬프트**

```
아래 기사를 회사 단톡방에 공유하려고 해. 바쁜 팀원들이 30초 안에 읽을 수 있게
핵심 세 줄로 요약하고, 우리 팀(온라인 마케팅)이 참고할 점을 한 줄 덧붙여 줘.

[기사 붙여 넣기]
```

바뀐 점: **맥락**(단톡방 공유), **대상**(바쁜 팀원), **형식**(세 줄 + 한 줄), **목표**(우리 팀이 참고할 점)가 생겼습니다.

### 예 2. 설명 듣기

**아쉬운 프롬프트**

```
환율이 뭐야?
```

**좋은 프롬프트**

```
경제 뉴스를 처음 보는 고등학생이야. 환율이 뭔지 쉬운 비유를 들어 설명해 줘.
환율이 오르면 해외여행 갈 때 왜 손해인지 숫자 예를 하나 들어 주고,
마지막에 뉴스에서 환율 기사를 볼 때 알아 두면 좋은 점 세 가지도 알려 줘.
```

바뀐 점: **대상**(경제 뉴스를 처음 보는 고등학생), **형식**(비유 + 숫자 예 + 세 가지)이 생겼습니다.

받는 답은 대략 이렇게 달라집니다(실제 답은 서비스와 그때그때 다릅니다).

| | 아쉬운 프롬프트의 답 | 좋은 프롬프트의 답 |
|---|---|---|
| 첫 문장 | "환율은 한 나라 화폐와 다른 나라 화폐의 교환 비율로, 외환 시장의 수요와 공급에 따라…" | "환율은 우리 돈을 다른 나라 돈으로 바꿀 때의 '가격표'예요." |
| 예 | 거의 없음 | "1달러가 1,300원에서 1,400원이 되면, 100달러짜리 호텔에 13만 원이 아니라 14만 원을 내야 해요." |
| 읽고 난 뒤 | 용어는 많은데 와닿지 않음 | 내 생활과 연결돼 바로 이해됨 |

### 예 3. 아이디어

**아쉬운 프롬프트**

```
가게 이름 추천해 줘.
```

**좋은 프롬프트**

```
동네 주택가에 여는 작은 수제 베이글 가게 이름을 지으려고 해.
손님은 주로 아침 출근길 직장인과 주말 가족 손님이야.
부르기 쉬운 한글 또는 영어 이름 10개를 추천하고, 각각 어떤 느낌인지 한 줄씩 붙여 줘.
"베이글"이라는 단어가 들어간 이름은 3개 이하로 해 줘.
```

바뀐 점: **맥락**(동네·업종), **대상**(손님층), **형식**(10개 + 한 줄 설명), **조건**(단어 제한)이 생겼습니다.

## 바로 써먹는 습관 세 가지

1. **"나는 ○○인데, ○○하려고 해"로 시작하기** — 이 한 문장만으로 맥락과 목표가 들어갑니다.
2. **원하는 모양을 숫자로 말하기** — "짧게" 대신 "세 줄로", "많이" 대신 "10개".
3. **마음에 안 들면 처음부터 다시 쓰지 말고 이어서 고쳐 달라고 하기** —
   "두 번째 문장이 너무 딱딱해. 조금 더 부드럽게 바꿔 줘."

## 직접 해 보기

요즘 실제로 고민 중인 일 하나를 골라, 아래 빈칸을 채워 프롬프트를 만들어 보세요.

```
나는 [내가 누구인지]인데, [무엇을 하려고] 해.
[상황 설명].
[누가 읽는지/누구를 위한 것인지]를 위해
[원하는 형식과 분량]으로 [원하는 결과]를 해 줘.
[꼭 지킬 것 또는 피할 것].
```

그다음 빈칸 없이 한 줄로만 물어본 결과와 비교해 보세요.

## 정리

- 프롬프트의 핵심은 AI가 모르는 내 사정을 알려 주는 것이다.
- 목표·맥락·대상·형식·조건 다섯 가지를 점검표로 쓴다.
- 한 번에 완벽할 필요 없다. 대화를 이어 가며 고친다.
